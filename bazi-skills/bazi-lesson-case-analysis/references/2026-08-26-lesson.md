## 二、本課最重要的觀念

### 1. 通關：在相剋雙方之間建立相生路徑

老師用「兩神對峙」描述兩種五行相剋、彼此有作用力的情況，以第三種元素承接，形成連續相生。課堂稱為「貪生忘剋」，工程上不能因此假設原來的剋力完全歸零。

| 對峙關係 | 通關元素 | 相生路徑 |
| --- | --- | --- |
| 木剋土 | 火 | 木 → 火 → 土 |
| 火剋金 | 土 | 火 → 土 → 金 |
| 土剋水 | 金 | 土 → 金 → 水 |
| 金剋木 | 水 | 金 → 水 → 木 |
| 水剋火 | 木 | 水 → 木 → 火 |

兩種常見十神表示法：

- 官殺旺、日主弱：官殺 → 印 → 日主，印化殺扶身，兼具扶抑與通關意義。
- 日主強、財星輕：日主／比劫 → 食傷 → 財，以食傷洩身生財。

**通關元素出現，不等於通關成立。** 老師另外要求看位置、力量、透藏、受制與歲運引動。

### 2. 通關能否發揮，要看「路徑」

課堂轉述的檢查順序可整理為：

1. 相剋雙方是否確實構成問題，而非只有字面五行相剋？
2. 通關元素在哪一柱，透干或藏支，能否承接前後兩端？
3. 是否隔柱、干支分隔，或有另一元素阻斷？
4. 通關元素是否被剋、被合住或受沖？
5. 原局不足時，歲運是否提供通關元素或解除阻礙？
6. 這條路徑是否符合日主扶抑需要？

原文提及暗沖、暗會等說法；本文件保留其為來源觀點，App 不能憑空補入四柱與歲運中不存在的字。

### 3. 取用以作用與喜忌為主，不由十神名稱決定

老師將正偏財、官殺、正偏印、食傷分別按共同生剋關係講解，反對直接把傷官、七殺或偏印標成壞。這是本課在取用層面的合併，不表示可以刪除 App 的陰陽或十神細分。

| 與日主的關係 | 十神組 | 課堂用文王卦六親作對照 |
| --- | --- | --- |
| 生我 | 印 | 父母 |
| 同我 | 比劫 | 兄弟 |
| 我生 | 食傷 | 子孫 |
| 我剋 | 財 | 妻財 |
| 剋我 | 官殺 | 官鬼 |

本課以此說明共同的五種關係；「十神歷史上源自文王卦」仍是課堂主張，不能只憑這段講解證實歷史源流。

### 4. 共通法則不是固定公式

老師明說五行不能以單一固定分數完整表示，並反對直接用分數切出強弱後套全部命例。可整理出的工程意義是：**建立可解釋的條件與例外，同時標示 App 的量化代理和老師判斷之間的差異。**

此主張不等於電腦完全不能協助：五行映射、藏干、根氣位置、相生路徑和條件比對都可程式化；「多、重、能制、有效通關」仍須有明確定義，不能冒稱已忠實還原老師判斷。

## 三、四個教材例

### 例一：丁酉／丙午／丁酉／丁酉

來源搜尋：「丁 酉 丙 午 丁 酉 丁 酉」。四柱字面完整，記為 `transcript_exact`，本次未建立測試。

- **定格**：丁火生午月，老師取建祿。
- **強弱**：丙丁多見且午火得令，課堂判身旺；三酉是金財來源。
- **問題**：火比劫在上、金財在下，課堂以比劫爭財、火金相剋解釋。
- **取用**：土食傷通關，使火生土、土生金。
- **喜忌／運勢方向**：老師談土、土金相連，火須有土承接；木火再增火勢不是同一方向。課堂另提金水，但不能據此刪除全局檢查。
- **限制**：「沒有土」宜理解為欠缺可發揮的通關土；午中仍藏己土。程式不能把「無明顯通關」寫成「藏干中完全無土」。

### 例二：癸亥／庚申／甲寅／癸酉

來源搜尋：「癸 亥、庚 申、甲 寅、癸 酉」。記為 `transcript_exact`。

- **定格**：甲木生申月，庚殺透月干，課堂取七殺格。
- **強弱與問題**：申酉金勢強；甲坐寅有根，寅申沖使木根作用需重新檢查。
- **取用**：水印通關，形成金 → 水 → 木，兼化殺生身。
- **相對運勢**：水木為課堂優先方向；金水相連與干支俱金須分開。不能把「金為壓力」簡化成所有含金大運都不可用。
- **限制**：原局已見癸亥及時干癸，這是現有通關是否有效的判斷，不是「缺水補水」。庚子、辛亥等只是課堂組合示意，未逐運驗算。

### 例三：癸亥／己未／癸亥／己未

來源搜尋：「癸 亥 己 未 癸 亥 己 未」。記為 `transcript_exact`。

- **事實**：兩組水柱、兩組土柱，癸水生未月，己殺透且坐未。
- **課堂格名**：老師稱兩神成像，以土水對峙為重點。
- **取用**：金印作土 → 金 → 水的通關元素，原局沒有金藏干，課堂待歲運金來承接。
- **限制**：亥藏甲、未藏丁乙，不能把「兩神」寫成命盤只含土水兩種元素。前課曾主張兩神名稱應保留普通格參照；此例也應把課堂名稱與 App 特殊格判定分開。

## 四、普通格局取用共通表

下表是將財、官殺、印、食傷各節反覆出現的規則整理成共通分支，不是所有格局可無條件共用的決策表。每次仍須保留原本格名、主導問題、可用之神及排除條件。

| 日主狀態與主要問題 | 本課取用方向 | 喜神／支持方向 | 需要防止的作用 |
| --- | --- | --- | --- |
| 強旺、印多 | 財破印 | 食傷生財 | 比劫制財、印再增或制食傷 |
| 強旺、比劫多，官殺可用 | 官殺制比劫 | 財生官殺 | 印比再助；食傷制所用官殺須另看財能否承接 |
| 強旺、比劫多，食傷可用 | 食傷洩比劫生財 | 財承接、必要時破印 | 印制食傷、比劫再增 |
| 強旺、財多；印格／食神格段落 | 官殺洩財並制身 | 財生官殺 | 印比再扶身；不能推成所有財多都用官殺 |
| 身弱、官殺多 | 印化官殺扶身 | 比劫幫身 | 財破印、生官殺，官殺加重 |
| 身弱、食傷多 | 印制食傷扶身 | 比劫；部分格局另列官殺生印 | 財破印、食傷再增；官殺能否化印須確認 |
| 身弱、財多 | 比劫幫身分財 | 印扶身 | 食傷生財、財再增、官殺制比劫或財破印 |

**兩條看似矛盾的取用可以同時是候選。** 比劫多時，官殺制比與食傷洩比是不同解法。老師沒有提供兩者都有時的完整優先順序，因此程式應列候選理由或待判，不能隨取第一條當唯一答案。

### 建祿、陽刃的特別提醒

老師將建祿、陽刃納入普通格局討論：得月令是可能旺的先決條件，遇到大量剋洩耗仍可轉弱，不能一見格名就鎖定身旺。

| 條件 | 課堂方向 | 額外檢查 |
| --- | --- | --- |
| 旺、印多 | 財制印 | 財必須有可用根氣、能制得動 |
| 旺、比劫多 | 官殺制身 | 官殺有根，可由財生；無財時尤其留意食傷制殺 |
| 旺、食傷多 | 財承接食傷 | 比劫爭財、印制食傷的影響 |
| 弱、財多 | 比劫幫身分財 | 印扶身與官殺制身 |
| 弱而不弱、食傷多 | 課堂仍可能取財洩食傷 | 「弱而不弱」未定義，不能套用到所有身弱例 |
| 弱、剋洩交加 | 印化官殺、制食傷、扶身 | 印能否承壓，財是否破印 |

「弱而不弱仍取財」是必須保存的例外，也是單一強弱二分法不足的證據。逐字稿部分表列條件脫漏，例如傷官格一列只有「日干強、多」，不補造缺字或建立規則。

### 推論步驟

1. **定格**：戊土生酉月，酉藏辛，取傷官格。
2. **強弱**：金得令洩土，金再生水；雖有戊己及午印，老師認為支持不及金水，判身弱。
3. **主導問題**：食傷生財造成進一步耗身；課堂以此為「病」，並非醫療疾病。
4. **取用**：土比劫幫身分財。
5. **喜忌**：火印制食傷、扶身為喜；水木及金水再加重洩耗為忌向。金若帶土屬條件性候選，不能將金單列為固定喜神。
6. **大運比較**：白板列甲戌、乙亥、丙子、丁丑、戊寅、己卯、庚辰。老師以戊寅、己卯的木支剋土干說明「截腳」：喜用運干也可能受制；己卯另看卯酉沖、木生火等作用，故兩運評價不同。

### 需要保留的限定

- 申藏戊、午藏己丁，不能把身弱寫成無根無印。
- 「截腳」是本課對運干支剋制的說明，尚無強度、距離及解除條件，不宜直接固定扣分。
- 老師對庚辰先有順的總評，後又說土生金、需保留疑慮；須保留條件並存，不能擷取一句保證該運好。
- 當場的人生回饋不是盲測，也未形成獨立資料集，不可用來宣稱推論命中率。

### 與現有演算法的具體差異

1. `analyze_yong_shen` 目前以 `total_score >= 0` 判強，再看印在天干／地支／不見。這是 App 的量化代理；老師本課並未認可這個閾值。
2. 現有主導問題處理有 `35.0` 及 `1.2` 等工程門檻。本課說「多、重」不能直接視為這些常數的來源。
3. `analyze_sha_yin` 目前天干檢查偏向年干殺、月干印，地支只接受特定純氣鏈。本課包含隔柱、透藏、阻斷及歲運解阻，範圍更廣；現有結果不成立不能直接斷言全局沒有通關。
4. 一條通關路徑可以改善某一關係，同時加重其他元素。需同時保留扶抑衝突與其他合沖，不能把原剋力清零。
