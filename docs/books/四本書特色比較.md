## 二、建議的閱讀順序（給初學者）

1. **《妙算人生八字》**：結構最完整、順序和課堂最接近（強弱 → 格局 → 用神 → 喜忌 → 歲運），規則條列，適合當課堂的**補充講義**。
2. **《輕鬆學算命》第一、二章和第七章**：十干口訣白話（每干一例）＋取用神四法；其他章（神煞、太歲、命宮）可以快速翻過。
3. **《八字心訣》上篇第三章、第六章和下篇**：學「流通」和「作功」兩個看命盤的新角度，下篇當《滴天髓》入門。
4. **《子平正源》**：等十神和六親熟了再讀，轉盤法需要先會看一般八字。

## 三、重要主題橫向比較

### 1. 日主強弱

| 書 | 方法 |
|---|---|
| 課堂（參考） | 得令、得勢（數同黨 vs 異黨，平手看月令）、得地 |
| 子平正源 | **不打分數**；看十干性情、根、調候；「取用不單論強弱」 |
| 輕鬆學算命 | 得時、得勢、得地 |
| 妙算人生八字 | 得時、得勢（數朋黨）、得地＋會合刑沖；十二長生可用可不用 |
| 八字心訣 | 得令、得地、得勢**三選二** |

**結論**：四本書和課堂都用「令、地、勢」三要素，差別只在怎麼算「勢」。子平正源最反對機械化。

### 2. 取用神

| 書 | 方法 |
|---|---|
| 課堂 | **扶抑為基礎**，病藥、調候、通關不能和扶抑衝突 |
| 子平正源 | 不單論強弱：強也可用印化殺，弱也可用洩；調候急先調候；**分陰陽**（庚喜火煉、辛怕火熔） |
| 輕鬆學算命 | 扶抑、調候、通關、病藥；**依日干決定先看哪一法**（木水先調候、火先扶抑、土先通關病藥……） |
| 妙算人生八字 | **調候優先**；另有用神「有力、有情、真假、清濁」四品質 |
| 八字心訣 | 先看**整體氣勢（形象）**和**流通**；用「作功效率」判高低；清濁三法（寒暖、順逆、神枯） |

### 3. 「相生」要多近才算

| 書 | 規則 |
|---|---|
| 課堂 | 生剋遠近：緊貼最強，隔位減弱 |
| 妙算人生八字 | 緊鄰最大、隔一位次之、隔兩位幾乎不算 |
| 八字心訣 | **最嚴格**：同柱干支、相鄰天干、相鄰地支才相生；**異柱干支完全不相生** |
| 子平正源、輕鬆學算命 | 沒有特別規定 |

### 4. 天干五合、地支合

| 書 | 天干合 | 地支合 |
|---|---|---|
| 課堂 | 五種變化（合而不合、合而不化、合來合去、爭合妒合、合而能化） | **有合無化**，用生剋判斷 |
| 子平正源 | 依十干性情看 | 會合可解刑沖（借會合解刑沖） |
| 輕鬆學算命 | 合而不化較多；「合有宜不宜」 | 沖不一定壞、合不一定好 |
| 妙算人生八字 | **日干的合一律不化（除化氣格）**；年月合看通根；陰陽異性相見「為合不為剋」 | **透干才化** |
| 八字心訣 | 合化五條件；**正化／夫從妻化／妻從夫化**；暗五合 | 以沖為重；生方怕沖、庫宜開、敗地看喜忌 |

### 5. 三刑、六害

| 書 | 立場 |
|---|---|
| 課堂 | 三刑有判斷；**害不判斷**（屬神煞） |
| 子平正源 | 會用，配合神煞 |
| 輕鬆學算命 | 「不刑不發」，刑是成功前的考驗 |
| 妙算人生八字 | 第一篇說刑害「不用理會」，第四篇又照傳統講（前後不一） |
| 八字心訣 | **只認寅巳申、丑未戌**，子卯和自刑不應驗；但日課篇又算子卯，滴天髓篇說刑害影響心理不可否定（前後不一） |

### 6. 宮位和年齡

| 書 | 年柱 | 月柱 | 每柱管幾年 |
|---|---|---|---|
| 課堂、多數書 | 祖上 | 父母、兄弟 | — |
| 妙算人生八字 | 祖上、父母 | 父母、兄弟（月柱看父母較準） | 限運 17–18 年 |
| 八字心訣 | **父母宮** | **兄弟宮** | **16 年** |
| 子平正源 | 用轉盤看，不太依賴宮位 | — | 大運「轉角運」 |

### 7. 六親怎麼看

| 書 | 方法 |
|---|---|
| 子平正源 | **轉盤**：以親人那個字為新日主重排十神，看他的格局、喜忌、大運；還有角色轉換、借妻安子 |
| 八字心訣 | 四步法（距離關係、喜忌、宮位、十神旺衰）＋**借盤**（＝轉盤，規定新日主優先位置：父母取年干、夫妻取月干、子女取時干） |
| 妙算人生八字 | 宮位＋十神＋喜忌＋對應大運；**緊貼日主**關係密切 |
| 輕鬆學算命 | 認為子平論六親**不準**，只能看大略 |

**結論**：子平正源和八字心訣的轉盤／借盤是**同一個方法**，子平正源講得最細；妙算的「緊貼日主」和八字心訣的「距離」是同一個概念。

### 8. 神煞

| 書 | 立場 |
|---|---|
| 課堂 | 神煞不可靠 |
| 子平正源 | 作輔助（羊刃、桃花、驛馬、喪門弔客……），也用胎元命宮 |
| 輕鬆學算命 | **大量使用**，還有十二太歲、命宮、小限、雜格（但作者說雜格沒什麼用） |
| 妙算人生八字 | 輔助但有用，列 25 個，大多抄自鍾義明 |
| 八字心訣 | **反神煞**：十神才是真神煞；只認四正、四庫、四長生的數量；用反例否定亡神、天月德、將星 |

### 9. 大運和流年

| 書 | 立場 |
|---|---|
| 子平正源 | 「大運看支，歲君看干」；轉角運；大運剋太歲是犯上 |
| 輕鬆學算命 | 傳統上下五年 |
| 妙算人生八字 | 干支合看、以地支為重、**蓋頭截腳**；**流年重於大運**；大運×流年喜忌組合表 |
| 八字心訣 | 流年影響更直接，太歲決定生死；先合大運流年再加原局；天干看合、地支看沖；汽車比喻 |

### 10. 補救和應用

| 書 | 有什麼 |
|---|---|
| 子平正源 | 改變生活角色、晚婚、選對職業、借妻安子 |
| 輕鬆學算命 | 名字、顏色、方位、朋友、圖片、拜拜、日行一善 |
| 妙算人生八字 | 戀愛時機、擇偶、婚期、考運、行業、田宅、官非 |
| 八字心訣 | **正五行擇日**（扶山相主）、合婚、小兒讀書、健康保養、相隨心轉 |

## 六、四本書共同提醒（要小心的地方）

1. **前後不一致**：妙算（三刑、羊刃、男命子女星）、心訣（三刑、專旺食傷、陳方安生的三種說法）都有，讀時以作者較後、較完整的說法為準，各 README 都有列表。
2. **名人命例的時辰常不可靠**：心訣大量用名人，子平正源用真實故事但匿名；四柱有幾個對不上五虎遁、五鼠遁，筆記都加了「⚠ 四柱待核對」。
3. **舊社會斷語**（妾命、剋夫、生男生女、娼命）四本都有，學方法即可，不要直接拿來說人。
4. **事後解釋為主**：大多是知道結果再找理由。若要驗證方法，挑有明確年份事件的命例（子平正源第三章、心訣的李嘉誠、袁世凱、劉翔、伏明霞）用 App 跑大運流年最有幫助。

## 七、給 App 的綜合建議（四本合看）

依價值排序，詳細說明在各書 README 的「App 想法」：

1. **轉盤／借盤檢視**（子平正源＋心訣）：點任一個字，以它為新日主重算十神，標出它代表哪位親人。兩本書的想法合成一個功能。
2. **流通路線圖**（心訣）：在五行生剋流程圖上加「流通模式」，只畫同柱、鄰干、鄰支的相生箭頭，標起點和終點。
3. **清濁評分**（心訣）＋**用神四品質**（妙算）：都是「用神好不好」的總評，可以合成一張卡。
4. **調候例外提示**（心訣：暖無氣反以無暖為美）＋**濕土燥土提示**（輕鬆學算命：丑辰吸亢陽）：放在寒暖燥濕卡片旁。
5. **大運×流年喜忌組合**（妙算）＋**蓋頭截腳**（妙算）＋**天羅地網、四正四庫四長生齊全**（心訣）：補進大運流年標籤。
6. **戀愛方式卡**（妙算：日支藏干透在哪一柱）。
7. **十干口訣提示卡**（輕鬆學算命）。

不建議：擇日、生男生女、面相、雜格當成吉凶判斷（雜格可以灰色標成「古書名詞」）。
