# 第七、八篇　四柱與六親、姻緣與婚嫁（書第 249–286 頁）

> **這一章在講什麼**：第七篇講怎麼從八字看祖上、父母、兄弟、配偶、子女；第八篇專講感情：什麼時候會戀愛、愛情從哪裡來、怎麼擇偶、什麼時候結婚、早婚晚婚、女命看丈夫、桃花。
>
> **這一章的讀法**：這兩篇沒有命例，是一條一條的「看法規則」。作者看六親有一個很清楚的架構：**宮位（哪一柱）＋ 星（哪個十神）＋ 喜忌 ＋ 對應年齡的大運**，四樣一起看。讀每一條規則時，可以問自己它用的是哪一樣。婚姻篇則加入很多現代社會的觀察（晚婚、不婚、同居），也有不少作者自己的經驗法則。
>
> **要特別提醒**：這兩篇的斷語裡有不少舊社會的說法（妾命、妻不容妾、剋夫剋妻、生男生女、女命「失貞」之類）。作者大部分照抄，沒有全部批註。筆記會把這些標成「古書說法」，**現代不宜拿來斷人**；比較能用的是背後的結構（哪一柱、哪個十神、喜還是忌）。
>
> 下文為了說明規則，有時會用「甲日主、月干己土」這種片段舉例，不是書上的命盤。

## 第七篇　論四柱與六親

### 一、四柱和六親的架構（第 249–250 頁）

#### 1. 根、苗、花、果

作者引珞琭子《消息賦》「觀乎萌兆，察以其原，根在苗先，實從花後」，說古人把四柱比喻成一棵植物：**年柱是根、月柱是苗、日柱是花、時柱是果**。根在苗之前，果實在花之後——這個比喻同時說明了**時間順序**（年柱管早年，時柱管晚年）和**因果關係**（根好苗才好）。

「六親」是父、母、兄（姊）、弟（妹）、夫（妻）、子（女）的總稱，古人用十神來搭配六親。

#### 2. 宮位：看「環境和生活品質」

| 柱 | 比喻 | 宮位 | 管的年齡 | 要配合哪段大運 |
|---|---|---|---|---|
| 年 | 根 | 祖輩、父母宮 | 1–18 歲 | 幼運 |
| 月 | 苗 | 父母、兄弟（姊妹）宮 | 19–36 歲 | 幼運（看父母）、中運（看兄弟） |
| 日 | 花 | 夫妻（配偶）宮 | 37–55 歲 | 中運 |
| 時 | 果 | 子女宮 | 56 歲以後 | 晚運 |

每一柱是喜用神還是忌神，決定那一宮的好壞：

- **喜用神在年柱**：祖上興隆、多得祖蔭；反之祖上破敗、不得祖福。
- **喜用神在月柱**：雙親富貴、多得遺產、兄弟和睦；反之父母困苦、兄弟鬩牆。
- **喜用神在日柱**：配偶賢淑得力、白頭偕老；反之夫妻反目，甚至分離。
- **喜用神在時柱**：子女孝順、能光宗耀祖；反之子女難養或不成材。

作者說：**四柱宮位代表環境條件和生活品質**。

#### 3. 十神：看「有沒有幫助、緣分深淺」

| 六親 | 用哪個十神 |
|---|---|
| 父母 | 正印、偏印（細分見下：偏財為父、正印為母） |
| 兄弟姊妹 | 比肩、劫財 |
| 男命的妻 | 正財（偏財為妾、女友） |
| 女命的夫 | 正官（七殺為情人） |
| 子女 | 食神、傷官（男命另看官殺，見時柱一節） |

作者說：**十神代表有沒有幫助，以及緣分的深淺、關係的好壞**。

#### 4. 四樣一起看

所以看一個六親，要同時看：

1. **宮位**（哪一柱）；
2. **星**（哪個十神）；
3. 宮和星是**喜用還是忌神**；
4. **對應年齡的大運**：看父母要配合「幼運」，看兄弟、夫妻要配合「中運」，看子女要配合「晚運」。

作者說「如此方能驗證無誤」。例如看父母，不能只看印星，還要看年月柱、再看小時候走的大運；三者都好，才能說父母得力。

**用一個比喻**：宮位像房子，十神像住在裡面的人。房子好（宮位喜用），表示環境舒服；人好（星是喜用），表示這個人對你有幫助。房子好人不好、或人好房子不好，都只能算一半。

### 二、一個貫穿全篇的規則：「緊貼日主」

作者在父母、兄弟、子女、夫妻每一段都重複同一句話，可以說是本篇最實用的一條：

- 六親星**緊貼日主**（在月干、時干或日支）→ 和這個人關係密切、影響力大。
  - 是喜用神 → 互相幫忙、感情好；
  - 是忌神 → 常常爭吵、受拖累。
- 六親星**遠離日主**（在年柱、或時支）→ 關係淡、影響小。

為什麼？日主是「我」，月干、時干、日支是離我最近的三個位置。第四篇說過「緊貼最有力、隔一位次之、隔兩位幾乎不算」，用在六親上就是：**離你越近的人，對你的影響越大**——不論是好的還是壞的。

**和其他書比較**：四本書比較檔指出，本書的「緊貼日主」和《八字心訣》的「距離」是同一個概念。App 可以考慮在六親說明裡加入「距離」這一欄（README App 想法第 7 條）。

### 三、年柱：祖上、出身（第 251、255–256 頁）

#### 1. 年柱代表什麼

年柱代表祖德、祖墳、田宅；年是「君」、是太歲，是出生時貴賤的主宰，管 1 到 18 歲。

- **年柱是喜用神**：祖上多是辛苦建立家業、富貴、置產，或命主容易得到祖上福澤庇蔭。
  - **年干**喜用 → 承接祖先的福德和名譽（看得見的、名聲上的）；
  - **年支**喜用 → 有祖產可繼承，或得祖墳庇佑（實質的、私下的）。
  這又是第三篇「天干公開、地支私下」的應用。
- **年柱是忌神**：祖上多顛沛流離、輾轉異鄉；年柱又見死墓絕或逢沖剋 → 不但家道中落，祖上、雙親也壽短（古書說法）。

#### 2. 出身家世（第 255–256 頁）

看出身以**年柱、月柱為主**，並參考**第一步大運（幼運）**：

| 年月柱 | 幼運 | 出身 |
|---|---|---|
| 喜用 | 喜用 | 名門，「炊金饌玉」 |
| 忌神 | 忌神 | 寒微，「簞食瓢飲」 |
| 喜用 | 忌神（或反過來） | 喜忌夾雜，吉凶參半 |

書上再列了六條細則：

1. **身強**，年月柱見財官透干 → 祖業雄厚；財官又通根 → 出身豪門。但若**年柱透印、其他干不透財** → 小時候家境清寒、不得祖蔭。（身強再見印是忌。）
2. **身弱**，年月柱見財官透干 → 書上說也是家業好（身弱擔不起，但出身環境是好的）。
3. **年干乘令、剋月干到死絕** → 少年時期的家境比出生時更艱苦。
4. **喜用神透在年干** → 被照顧得無微不至；**在年支** → 父母出身家庭良好。忌神在年干 → 要靠自己打拼；在年支 → 父母出身背景不佳。
5. 年月柱見**偏官、正印** → 生於庸碌之家；見**傷官、劫財** → 生於貧窮之家；見**偏官、偏印** → 生於繼室或偏房（古書說法）。
6. 年柱的偏官**沒有制、又是忌神** → 祖業飄零，或父母早逝（古書說法）。

> 第 5、6 條是古書的十神象意，很武斷。比較合理的用法是：年月柱的十神組合，大概描述了小時候家庭的「氣氛」（例如偏官偏印 → 家裡壓力大、規矩奇特），不要直接斷成「庶出」「父母早逝」。

### 四、月柱：父母、兄弟（第 251–252、256–258 頁）

#### 1. 月柱的地位

《繼善篇》說「取用憑於生月，當推究於淺深」。月柱是「臣」、是「提綱」，是整個命局的樞紐，從出生起就決定一生吉凶和命局高低，管 19 到 36 歲。月柱的干支看父母兄弟，月支也看事業。

- 月柱見**正官、正印、正財**，又是日主的喜用 → 父母多是富貴人家；
- 是忌神 → 父母不貴也不富；
- 月柱見**比劫** → 用來論兄弟，作者說「精準無誤」。

**林註**：(1) 任何一柱的十神和日主的關係，都可以照這樣推論；(2) **原則上月柱用來看父母，比看兄弟準確**。

#### 2. 父母（第 256–257 頁）

作者引《滴天髓》「父母或興或替，歲月所關果非細」「月看親蔭之有無」：年月兩柱判斷父母興衰，**以月柱為重**，還要參看**幼運**。喜用神群集在月柱 → 得父母細心呵護、大力幫助；是忌神 → 難討父母歡心，多白手起家。

**父母星**：原則上**偏財為父**（偏財剋正印，就像父親「管」母親，所以偏財是「印的官星」）、**正印為母**（生身之母）。命局沒有偏財、正印時，用正財、偏印權宜代替。

為什麼偏財是父親？這是一個很好的十神推理練習：母親是生我的（正印）；父親是和母親配對的人；在五行裡，剋印的是財，對印來說，剋它的異性就是它的「丈夫」——所以財是父親。（男命的妻也是財，所以書上有時兩者一起出現。）

**判斷規則**（白話）：

- **比劫重疊會損父親**（比劫剋財，財是父星）；**正印旺處必傷母**（古書說法，作者沒有解釋；可以理解為印星一面倒地多，代表母親付出過多、太勞累）。年月柱比劫和財同柱，多主和父親無緣，除非財旺過比劫。
- **正印是喜用** → 和母親感情深厚；**財星是喜用** → 和父親感情好。
- 年柱、或年月柱**同時見財星和印綬** → 童年時父母常吵架（財剋印，父母星在打架）。
- **偏財、正印緊貼日主**（在月干、時干或日支）→ 父母子女緣分密切；遠離日主 → 緣分淺、互動差。
- 細則九條：
  1. 以印為用、月令正好是印、幼運又不背 → 必得父母寵愛，福厚。
  2. 命局偏財被劫或完全不現、幼運又不好 → 和父親緣薄，或父親先過世；正印同理看母親。
  3. 月柱的正印或偏財被沖剋 → 多不得庇蔭、早年喪親，喜用神在月柱的更明顯。
  4. 財星不被沖剋、坐長生臨官帝旺或吉神貴人 → 父親富裕長壽；財星太弱、坐死絕空亡 → 父親體弱，或早年剋父（印星同理看母親）。
  5. **印星透干 → 母親當家掌權；財星透干 → 父親掌權**。
  6. 月柱的正官被別柱剋傷 → 父母多災或有官司。
  7. 月柱的財星或印綬坐建祿、驛馬 → 雙親早年離鄉打拼。
  8. 偏財或印星坐沐浴、桃花 → 父母浪漫、注重打扮、擅長交際。
  9. 四柱財多又破印 → 母親健康亮紅燈，或再嫁（古書說法）。

第 5 條很好用：天干是公開的，**誰的星透在天干，誰就是家裡「說話算數」的人**。

#### 3. 兄弟（第 257–259 頁）

作者引《滴天髓》「兄弟誰廢與誰興，提用財神看重輕」，以及「比劫與我同類同輩，專看兄弟姊妹朋友事」。**比肩為兄、劫財為弟**（祿、刃也一樣），但第三篇林註說實際論命不必細分。月柱是兄弟宮，要比較月令（提綱）中的十神和財神、喜用神的輕重，來判斷兄弟興衰。

**基本規則**：

| 情況 | 書上說 |
|---|---|
| 財官弱、比劫旺 | 兄弟多，但沒什麼幫助 |
| 財官旺、比劫弱 | 兄弟少或沒有，但幫助大 |
| 比劫是喜用、沒被沖剋 | 手足情深；四柱沒有比劫 → 換成得到朋友義助 |
| 比劫是忌神 | 受手足拖累；四柱沒有比劫 → 換成被朋友陷害 |
| 比劫緊貼日主（月干、時干、日支） | 和兄弟關係密切；是喜用 → 常聯絡、力挺到底 |
| 比劫遠離日主 | 關係冷淡；是忌神 → 很少聯絡，甚至受拖累 |
| 月柱干支是喜用 | 得父親蔭澤，兄弟有情有義 |
| 月柱干支是忌神 | 得不到父親關愛，兄弟鬩牆 |
| 比劫喜用卻被沖剋、或坐空亡 | 書上說兄弟夭折或死別之兆（古書說法） |

為什麼「財官弱、比劫旺 → 兄弟多但沒幫助」？因為比劫多就是兄弟多；但財官弱，代表資源少，兄弟只會來分你的資源（比劫奪財）。反過來，財官旺時，比劫正好來幫你扛財官，所以人少卻幫得上忙。

**細則**（第 258–259 頁）：

1. 日主旺、忌比劫，歲運再遇比劫 → 要防兄弟朋友拖累、破財傷妻。
2. 日主弱、不見比劫、官殺得令，歲運再走官殺 → 兄弟可能有官司，也影響自己健康；身弱官殺重又無食傷制、無印化 → 損兄弟。
3. 日主通月令、比劫太旺 → 兄弟成群（「鴻雁成行」）；日主不通月令，但印比多 → 也是兄弟多。
4. 財官旺又有比劫幫身 → 必得兄弟助力。比劫是忌神又坐羊刃 → 兄弟有剛戾之氣、難和睦，在那一柱管的年限中兄弟易有災。財輕比劫重時，若有食傷化比劫、或官星制比劫 → 兄弟相安無事。
5. **月柱是偏官、或命局多見偏官 → 大多是長子**，或做事有老大作風，在親友中想當領導人的慾望很強。（這是作者很具體的經驗說法。）
6. 月柱得時秉令、或比劫為用，又坐長生臨官帝旺吉神貴人 → 兄弟成群、富貴；坐死絕空亡 → 兄弟緣淺、不得力。
7. 喜用神在月柱 → 兄弟情義相挺（「打虎捉賊，親兄弟」）。若是**被別柱合會成喜用神** → 受兄弟朋友幫助；合會成「仇神」→ 兄弟感情像外人；合會成忌神 → 受兄弟和他們的朋友拖累。

### 五、日柱：夫妻（第 252–253、266–270 頁）

#### 1. 宮和星的分工

作者引《滴天髓》「夫妻因緣宿世來，喜神有意傍天財」。日柱看配偶的相貌、財帛、遷移。分工是：

- **日支（夫妻宮）** → 夫妻的**生活品質、互動條件**，也看**配偶的素質**。日支是喜用 → 配偶素質好。
- **財星（男）/ 官殺（女）** → 夫妻的**感情和助力**。是喜用 → 配偶體諒、幫助大；是忌神 → 各執己見、沒有幫助，甚至被配偶拖累。

**哪一個是配偶星**：
- 男命正偏財都有 → 正財論妻、偏財論妾或第三者（古書說法，現代可理解為「其他異性緣」）；
- 女命官殺都有 → 正官論夫、七殺論情人；
- 只有一個正官或一個七殺、一個正財或一個偏財 → 就用那一個當配偶星。
- **四柱完全不見財官** → 改看**日支坐下的十神**是喜是忌，再兼看十二長生、貴人神煞，配合歲運判斷夫妻互動。

#### 2. 夫妻星的一般規則（第 266–268 頁）

- **男命以財為妻**：喜神是財星 → 大概能娶到賢妻；但要兼看日支，兩者都是喜用最靈驗。
- **女命以官殺為夫**：也要兼看日支。女命**最宜官星旺**，書云「官星得祿食神旺，夫榮子貴理最明」。但官殺不宜多，多了官殺混雜就亂成一團。官星乘令 → 安和樂利；**傷官重重必傷夫**，需要財星來洩傷官（傷官生財、財生官，把傷官的力量轉成生官）——這就像男命比劫太多必損妻，要用同樣的方法看。
- 女命身弱官殺重 → 書上說婚前失貞或同居、婚後受丈夫欺負（古書說法，現代不宜這樣斷，可以理解為「感情裡壓力大、容易處於弱勢」）。
- **男命財星坐桃花被妒合、女命官星坐桃花被妒合** → 要防配偶外遇。
- **夫妻星緊貼日干** → 配偶和自己關係密切、影響大；是喜用 → 舉案齊眉；是忌神 → 吵鬧不休，「不是冤家不聚頭」。
- 命局**財官都不現** → 雙方不擅甜言蜜語表達感情，夫妻間常有隔閡，宜多溝通。這時看日支十神的喜忌，配合大運推吉凶。
- 財星臨墓絕之地 → 書上說妻子健康差、或「金屋藏嬌」；**男命妻星入墓妻早亡、女命夫星入墓夫早亡**（古書說法，很重，不要拿來斷人）。
- 財星被合化成比劫 → 書上說太太有婚外情（古書說法）。
- 財星是喜用 → 得妻家助力、萬事和諧；是忌神 → 因財色傾家蕩產。
- 男命四柱正偏財都有、日主又強旺 → 書上說享齊人之福；**正財強偏財弱 → 妻不容妾；偏財強正財弱 → 妾奪妻權**（舊社會說法）。
- **日支（夫妻宮）的財星或官殺逢空亡、沖剋 → 再婚或喪偶之兆**。這條和第三篇作者說的「夫星空亡是更值得注意的婚變指標」一致。

#### 3. 男命身強，日支坐什麼（第 268–269 頁）

日支是配偶宮，坐的十神描述配偶的樣子。書上分身強、身弱兩種情況：

| 日支坐（身強時） | 書上說的妻子 | 白話理解 |
|---|---|---|
| 正官 | 端莊、溫柔、賢內助，能相夫教子 | 官剋身，身強喜官 → 配偶能約束、幫助自己 |
| 七殺 | 個性剛毅、盛氣凌人，夫妻常吵 | 七殺是無情之剋 |
| 羊刃 | 不賢、我行我素、破財傾家 | 刃剋財（妻星） |

| 財星（喜用） | 得賢內助、或豐厚嫁妝；**坐將星 → 娶將門閨秀；坐驛馬 → 娶異鄉之妻；坐沐浴桃花 → 妻愛打扮、美麗大方**；身強無財或財弱 → 剋妻（古書說法） | 身強喜財 |

「印多財弱 → 婆媳不和」是很好的十神推理：印是母親、財是妻子，財剋印，兩者在命局裡本來就對立；如果印很多（母親強勢）、財很弱（妻子弱勢），婆媳就容易有摩擦。

#### 4. 男命身弱，日支坐什麼（第 269 頁）

| 日支坐（身弱時） | 書上說 |
|---|---|
| 七殺（坐羊刃） | 先生個性暴躁（書上這一條寫在男命底下，但說的是「先生」，應是女命的條目誤植） |
| 財星 | 身弱財旺 → 太太不得力、不會照顧先生，也主怕妻 |
| 正偏印 | 妻賢慧持家，會照顧先生 |
| 食傷 | 太太愛惹是非、對丈夫嘮叨 |
| 比劫 | 太太剛毅不屈，但會幫助先生的事業 |

身弱時，印、比劫變成喜神，所以日支坐印比反而是好配偶；財、食傷變成忌神，日支坐它們就辛苦。這就是「**同一個十神，對身強身弱的人意義相反**」的又一個例子。

#### 5. 女命（第 269–270 頁）

作者說女命日支夫妻宮的喜忌用神，論法同男命。另外列了幾條：

1. 夫星（官殺）**藏在支內不透干**，卻有比肩比劫**干透支藏** → 書上說「多為妾命或小三」。
   > 這是古書說法，現代不宜這樣看。結構上的意思是：夫星藏而不顯、又有比劫（同性的競爭者）明顯 → 感情裡容易有競爭者、關係不容易公開。
2. **官殺都出現**的女命 → 異性緣佳、容易被感情迷惑；**官殺混雜**更容易受誘惑，引起家庭風波。
3. **日主強旺、比劫又多，或是「月刃格」** → 夫妻同床異夢、貌合神離。（比劫多會「爭官」，也代表自我很強。）
4. **官殺過旺、或若有若無** → 夫緣差，婚姻難美滿，**最好晚婚**。
5. **官殺星被別柱合走**（感情婚姻多挫折），尤其**合到比肩比劫** → 書上說丈夫外遇而分開。（官星被比劫合走 = 丈夫被「同性的人」帶走。）

### 六、時柱：子女（第 253–266 頁）

#### 1. 子女星：書上前後不一

作者引《滴天髓》「子女根枝一世傳，喜神看與殺相連」「時柱子息分高低」。時柱看子息、僕役和福德。

| 子女 | 第三篇（第 81、89 頁） | 第七篇（第 255、261 頁） | 一般書（例如《子平真詮》） |
|---|---|---|---|
| 男命的兒子 | 正官 | **七殺** | 七殺 |
| 男命的女兒 | 七殺 | **正官** | 正官 |
| 女命的兒子 | 傷官 | 傷官 | 傷官 |
| 女命的女兒 | 食神 | 食神 | 食神 |

男命的子女星第三篇和第七篇說法相反（README 錯誤表有記錄）。第七篇的說法和一般書一致，初學者以第七篇為準。

為什麼男命以官殺為子女？官殺剋我，就像子女「管」著父親；更傳統的解釋是：男命的妻是財，財生官殺，所以官殺是妻子生的。女命則是食傷——女命自己生出來的。

#### 2. 一般規則

- **食傷（或官殺）、時柱是喜用** → 子女品性端正、賢孝得力；兩者都喜更明顯；但逢刑沖，子女雖能貴顯，卻有折損之憂（古書說法）。
- **是忌神又被沖剋** → 子女少、不得力，易受子女之累；兩者都忌 → 書上說子女早夭或不孝、晚年孤獨（古書說法）。
- **七殺傷官（兒子星）或正官食神（女兒星）緊貼日主** → 和兒子（女兒）關係熱絡；又是喜用 → 子女出類拔萃。遠離日主 → 關係不夠親密；是忌神 → 子女平凡、大器晚成。

#### 3. 細則（第 263–265 頁）

1. **時支是喜用神多生男，又逢喜用年生產更準；是忌神多生女**（作者的經驗說法，參考）。**女命時支逢三合、六合、對沖的流年，很容易懷孕**。
2. 女命時柱干支是忌神，年輕衝動容易懷孕而墮胎；懷孕後預產期那年**沖合時支又是忌神** → 要特別保養、防流產。
3. **時干喜用 → 女兒貼心聽話；忌神 → 女兒叛逆。時支喜用 → 兒子順從；忌神 → 兒子頑強難管**。（作者把時干配女兒、時支配兒子。）
4. 時支或子女星坐**桃花** → 子女早交異性朋友；兼坐紅鸞天喜 → 俊男美女；坐**孤辰寡宿** → 子女婚姻易波折、有獨身傾向；坐**華蓋** → 子女聰明、愛藝術但特立獨行。
5. 時支或子女星坐**長生、冠帶、臨官** → 子女秀發、運勢強；坐**墓絕** → 子女難有成就、健康不佳；坐**驛馬** → 子女離鄉謀生；坐**天月德貴人** → 子女謙恭有禮、多貴人。
6. **身強**時柱坐財星為用 → 子女成家立業、孝順；坐正官為用 → 子女敦厚正直；坐食傷為用 → 子女體格壯、有才藝。反之時柱坐偏印為忌 → 子女品性不端（古書說法）；坐比劫為忌 → 子女浪蕩敗家，財星又薄更準。
7. **身弱**時柱坐印為用 → 子女孝順、創業有成；坐比劫為用 → 子女多、助力大；坐官殺無制化為忌 → 子女個性暴戾，有制化則子女多且貴但脾氣大。
8. **晚運和時柱都好** → 子女賢孝富貴，自己也安享晚年。

#### 4. 生男生女的兩種民俗算法

書上還抄了兩種算法：

- **《淵海子平》**：以日干對照時支。「陽日陽時男重見，陰日陰時女重見」，例如甲日寅時主生男，乙日卯時、丁日丑時主生女，甲日子時先男後女。
- **南投鍾義明《現代命理學先進》**：用**懷孕流年的地支**（上爻）、**大運地支**（中爻）、**時支**（下爻）三個的陰陽排成八卦：陽陽陽 = 乾（生男）、陰陰陰 = 坤（生女）、陽陰陰 = 震（生男）……。地支的陰陽以藏干論：子丑卯午未酉為陰，寅辰巳申戌亥為陽。

> 這兩種都是民俗說法，沒有統計根據。**App 不宜採用**，筆記只是記錄書上有這段。

## 第八篇　姻緣與婚嫁

### 一、作者的現代觀察（第 271–272 頁）

作者開頭先講感情的道理：一對男女從素昧平生、互通消息到墜入情海；俗話說「十年修得同船渡，百年修得共枕眠」，人生大約三分之二的時間在婚姻中度過。

他從十神點出一個有趣的觀察：**我剋者為財（妻）、剋我者為官（夫）**——夫妻在八字裡本來就是「剋」的關係，站在對立的位置，難怪俗話說「**不是冤家不聚首**」。

他也很務實地談現代社會：長期加班、低薪、高房價，年輕人寧可同居也不敢結婚；他引 2015 年政府統計說「不婚當道」，七年之癢提前成五年之癢。所以**命理推出來的婚期，有時會比實際早**——不是命理不準，而是環境和壓力讓結婚年齡往後延。

這段話很重要：讀下面的婚期規則時，要記得它們推出來的是「感情容易發動的時間點」，不一定真的走進婚姻（作者自己也把同居算進去）。

### 二、愛情何時來：戀愛的時機點（第 272–273 頁）

**以日支（夫妻宮）為主**：

1. **流年和日支形成三合、六合、六沖或三會**的那一年，很容易遇到心儀的對象、擦出火花。**逢對沖的那一年最熱情如火、最積極主動**。
2. 日支逢合，合出喜用神又透干 → 那一年肯定能找到好對象，戀愛容易成功；透出的是忌神 → 那年談戀愛會嘗到失戀之苦。
3. 日支和流年沖合時，看「透出來的字」在哪裡：
   - 透在**自己命局**裡 → 自己主動去追求；
   - 透在**流年天干** → 是周遭環境的氣氛帶來的機會。
4. 日支逢沖，但**沒有天干透出**（以來沖的那個字的透干為主）→ 只是欣賞對方，沒有實際行動。
5. **日支是寅申巳亥**（四生、四馬之地）→ 談戀愛的高手，常在情場得意。
6. 命局帶**桃花** → 戀愛次數多；桃花逢沖 → 更激烈。歲運又遇桃花且是喜用 → 交際應酬多、人緣好，無形中引來的桃花也多；是忌神又是七殺 → 容易三角戀、桃色糾紛。

**舉個片段的例子**：日支是子，遇到午年（子午沖）→ 夫妻宮被沖動，那一年感情容易發動；如果午年的天干或命局裡透出午所藏的丁、己，代表有實際行動；如果只是地支沖、天干沒有相應的字透出，就只是「心動沒有行動」。

**為什麼看日支**：日支是夫妻宮，流年和它「互動」（合、沖、會），就等於有人敲了夫妻宮的門。合是溫和地靠近，沖是猛烈地撞進來，所以沖的那一年最熱烈。

### 三、愛情從哪裡來：看日支藏干透在哪一柱（第 273–275 頁）

這是本書很有特色的看法（四本書比較檔列為本書獨門）：**看日支所藏的人元，透到哪一柱的天干**。

日支藏干代表「配偶宮裡的東西」，它透到哪一柱，就表示感情的線索從哪個方向來。作者給了兩套解讀：

**(1) 用什麼方式吸引異性**

| 日支藏干透在 | 怎麼表現自己最能吸引異性 |
|---|---|
| 年干 | 多參加公益團體活動（廟會、演講、郊遊、演唱會、文化之旅），和不認識的人一見如故 |
| 月干 | 在言行舉止上表現出胸懷磊落、寬宏大量 |
| 時干 | 在事業、工作、技藝上充分展現能力 |

**(2) 透過什麼關係認識對象**

| 日支藏干透在 | 透過誰介紹 |
|---|---|
| 年干 | 長輩、長官、父執輩 |
| 月干 | 兄弟姊妹、朋友、同事、結拜 |
| 時干 | 子女、姪子、下屬、員工等晚輩 |

這兩張表的邏輯是第七篇的宮位：年柱是長輩、月柱是同輩、時柱是晚輩。

**(3) 日支自透**：作者說日支自透的人（日支所藏的天干就透在日干上，例如甲寅日，寅藏甲，日干就是甲），男命多玉樹臨風、女命多秀外慧中，人際關係好、重視浪漫、渴望被愛，對愛情相當主動積極。

**舉個片段的例子**：日柱丙午，午藏丁、己。如果月干是丁 → 丁透在月干 → 愛情多半透過兄弟朋友同事而來，表現大方最能吸引人；如果年干是己 → 己透在年干 → 透過長輩介紹，或在公益活動中認識。

**林註（第 275 頁）**：

1. **日支藏干透得多** → 戀愛機會多、異性朋友多；**日支藏干完全不透** → 戀愛機率自然低，最好請人介紹（包括相親）比較容易成功。
2. **男命的財星、女命的官星**，如果和夫妻宮的日干支被**月柱或時柱「爭合」** → 最容易發生三角戀愛（兩女戀一男、一男戀兩女等）。

另外兩條：

- 女命日干自旺（身旺得地），夫星**明暗交集**（透干為明、在支為暗，都有）→ 書上說性觀念較開放（古書口吻）。
- **日支七殺落空亡** → 戀愛失敗、被異性玩弄感情，或有不堪回首的遭遇。

> 第一條「明暗交集」的結構意思是：異性星在天干和地支都有，感情機會多、來源多；筆記不採用書上對女性私生活的評斷。

**和其他書比較**：「日支藏干透在哪一柱」在其他已整理的書都沒看到，是本書獨有的。README App 想法第 6 條建議做成「戀愛方式小卡」。

### 四、擇偶（第 275–276 頁）

作者先講現代背景：工作忙碌、晨昏顛倒、低薪資、高房價、高學費、物價高漲、老人社會，讓很多年輕人不敢結婚，不婚族增加，晚婚已是時勢所趨。接著給男女擇偶的要訣，核心都是「**日支和配偶星是喜還是忌**」：

**女命**：
1. **日支是喜用神** → 另一半的人品、相貌、學歷、才智、涵養、家世都比自己好，是值得交往的「真命天子」；**是忌神** → 交往對象各方面條件不如自己。
2. **正官（夫星）是喜用神** → 另一半可信賴、有幫助，是擇偶最佳對象；**是忌神** → 另一半不可靠、不負責，不值得交往。
3. **正官透干又和日主五合** → 先生和藹可親、溫柔體貼、能配合遷就自己，是婚嫁的不二人選。

**男命**：
1. **日支是喜用神** → 另一半志節高尚、端莊、博學、家世好，是「白雪公主」；是忌神 → 不是好對象。
2. **正財（妻星）是喜用神** → 另一半堅守正道、是好賢內助；是忌神 → 沒有助力。
3. **正財透干又和日主五合** → 太太中規中矩、相敬如賓、患難與共；流年再逢紅鸞星動，趕快娶回家。

**不論男女**：**日支坐天乙貴人** → 對方身分家世背景良好。

**為什麼「配偶星和日主五合」是好對象**：第四篇說過，日主直接合到的財官是「**合來**」，是「我的」，而且五合是陰陽有情的結合。所以配偶星透干、又直接和日主相合，就是對方主動靠近、彼此有情。

### 五、何時是婚期（第 276–278 頁）

1. **命、運、歲三者的地支**形成「方局」（三會）、「三合局」或「叶合局」時：未婚者那一年有結婚喜訊（**同居也算**）；**已婚者那年容易有婚外情的徵兆**。
2. **流年天干和命局天干五合**，或**流年地支和命局地支三合、六合** → 那一年紅鸞星動，可以論婚嫁。**大運**的天干和命局天干五合、或大運地支和命局地支三合六合 → 這十年姻緣運極佳，結婚機率大。
3. **日支是忌神**，逢流年（或大運）**沖**、又和命局天干**合** → 那一年（或那步大運）容易結婚；但作者加了一句很有意思的林註：**「以經驗來說，這叫壞的開始，情況不太樂觀」**。

第 3 條很值得想：日支是忌神，代表夫妻宮本來就不理想；被沖動了雖然會促成婚姻，但動的是一個不好的宮位，所以婚後不一定順。這提醒我們：**「容易結婚」和「結婚後好不好」是兩件事**，要分開看。

**舉個片段的例子**：命局月干是丁，遇到壬年（丁壬合）→ 流年天干五合命局天干 → 第 2 條「紅鸞星動」。如果命局日支是卯，遇到戌年（卯戌合）→ 流年地支六合日支，同時符合第八篇第二節的「戀愛時機」→ 感情發動的訊號更強。

**和其他書比較**：《八字真理》4.3.2 看婚期是「配偶星／配偶宮被沖合引動」，和本書的方向相同；陸致極則以「夫妻星的庫被沖開」為婚期，App 已有「婚」標籤。本書的特色是把**天干五合**也當成婚期訊號。README App 想法第 5 條建議：流年地支和日支三合、六合、六沖、三會 → 「戀」提示；流年天干五合命局天干 → 「婚」提示。

### 六、早婚晚婚、年齡差、人緣（第 279–282 頁）

- **命局本來就有三會或三合局** → 早婚。（合局代表「容易和人結合」。）
- **日支被兩個以上的字合**（妒合）→ 感情複雜。
- **男命**財星過旺、比劫重、財星入墓、日支逢沖 → **晚婚**。（財太旺擔不起、比劫奪財、財藏起來、夫妻宮不安定，都讓婚姻延後。）
- **配偶年齡差**：看日支透干，以天干配數字推算：甲 1、乙 2、丙 3、丁 4、戊 5、己 6、庚 7、辛 8、壬 9、癸 10。作者自己註明**僅供參考**。
- **人緣**：財、官、印清純的人，人緣好。

### 七、女命看夫君（第 283–284 頁）

| 情況 | 條件 |
|---|---|
| **能得夫助** | 官殺是喜用、又有財來生；日支是喜用 |
| **不得夫助** | 傷官重又沒有財來化解；官殺是忌神；日支逢沖 |
| **離婚的條件** | 官殺混雜又傷官見官；日支被沖刑 |

為什麼「傷官重要有財來化解」？傷官剋官（夫星），如果中間有財，傷官就會先去生財、財再生官，傷官的力量就從「剋夫」變成「間接生夫」。這和第七篇「傷官重重必傷夫，需要財星來洩」是同一個道理，也是第四篇「兩干相剋，中間有化剋者，剋力愈輕」的應用。

### 八、桃花（第 284–286 頁）

- **男命**：比劫重、財弱又見桃花，或財星合日主 → 多主風流。
- **女命**：官殺多、傷官旺、日支桃花被合 → 多主多情。

**林註**：女命**陽日干的食神暗合正官**、**陰日干的食神暗合正印**，是一種「**食神暗合**」的桃花現象，要看喜忌。

這條需要推一下才看得懂：
- 陽日干，例如甲木：食神是丙火，正官是辛金，**丙辛合** → 食神和正官（女命的夫星）合在一起。
- 陰日干，例如乙木：食神是丁火，正印是壬水，**丁壬合** → 食神和正印合在一起。

作者的意思是：食神代表女命自己的才華、魅力、情感表達，它和官星（異性）暗中相合，就是一種吸引異性的力量；是喜神就是好的異性緣，是忌神就可能成為感情困擾。

## 這兩篇學到什麼（給初學者）

1. 看六親四樣一起看：**宮位（哪一柱）、十神（哪顆星）、喜忌、對應年齡的大運**。宮位看環境品質，十神看緣分和助力。
2. 六親星**緊貼日主**（月干、時干、日支）關係密切，遠離則淡；是喜則互助，是忌則互相拖累。
3. 十神推六親的邏輯：印是母、財剋印所以財是父；財是妻、印是母，財剋印所以婆媳易不和；比劫剋財所以比劫多損妻、損父。
4. **同一個十神，身強身弱意義相反**：身強時日支坐財、官是好配偶；身弱時坐印、比劫才是好配偶。
5. **戀愛時機**看流年和日支的合、沖、會；沖的那年最熱烈；有沒有透干決定有沒有行動。
6. **愛情從哪裡來**看日支藏干透在哪一柱（年 → 長輩、月 → 朋友、時 → 晚輩）；完全不透的人適合相親。
7. **婚期**最常用：流年和日支合沖、流年天干五合命局天干、命運歲三合三會。容易結婚和婚後好不好是兩件事。
8. 女命看夫：官殺為喜、有財生、日支為喜 → 得夫助；傷官重要有財化解。
9. 書上很多斷語（妾命、妻不容妾、妻早亡、失貞、生男生女）是傳統或民俗說法，現代不宜這樣看；作者自己也註了「僅供參考」的地方要特別留意。
