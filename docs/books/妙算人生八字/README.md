## 一、這本書是什麼樣的書

一句話：**一本「傳統說法 + 作者理性批註」的完整教科書，從排盤一路講到大運流年怎麼斷**。

和已經整理過的書比起來，它的特色是：

1. **結構非常完整、順序清楚**：基本概論 → 排盤 → 十神神煞 → 干支作用 → 十干喜忌 → 論命順序（強弱、格局、用神、喜忌）→ 六親 → 婚姻 → 健康 → 事業 → 財富 → 學業 → 大運流年。初學者可以從頭讀到尾。
2. **「林註」很有價值**：作者常在傳統說法後面加一句「但以經驗來看……」，把太武斷、迷信的部分拿掉（見下面「作者的立場」）。
3. **規則都整理成條列**：例如「天干合」8 條、「地支三合」3 條、「大運流年喜忌組合」4 條，很適合寫成程式規則。
4. **用神講得特別細**：除了扶抑調候通關病藥，還有「**用神的有力無力、有情無情、真假虛實、清濁**」四個品質指標，每個都有例子。
5. **生活應用面很廣**：戀愛時機、擇偶、婚期、考運、行業、財運、田宅、官非都有一節。
6. **命例少、而且都是教學用的短例**（32 個，大多是一兩句說明），不像蘇民峰或八字真理那樣有完整的人生驗證。

## 四、這本書的特色和要小心的地方

**優點**
- 規則**條理分明**，很多條可以直接變成檢查清單。
- 林註常把迷信的部分拿掉，對初學者是很好的「過濾器」。
- 論命五步驟和課堂的教法高度一致，適合當課堂的**補充教材**。

**要小心**
- **前後不一致**的地方不少（三刑、羊刃陰干、男命子女星、從兒格喜比劫），見下面錯誤表。
- 很多六親斷語仍是**舊社會說法**（妾命、妻不容妾、生男生女），作者沒全部批註。
- 命例都是「一兩句說明」的教學例，**沒有歲運驗證**，不能拿來檢驗方法準不準。
- 神煞、胎元、魁星、命宮的內容大多抄自鍾義明等人的書，作者自己不常用。

## 七、App 想法

> 下面只是想法，還沒有改程式。標「★」的是我覺得最值得做的。

1. ★ **用神品質提示**：在「日主強弱對照」或用神卡片下加一行「用神有力 / 有情 / 清濁」檢查：用神在月支？透干通根？緊貼日主？和日主之間有沒有夾著洩用神或生忌神的字（例二十六的情況）？
2. ★ **大運「蓋頭 / 截腳」標籤**：大運天干和地支喜忌相反時，標出蓋頭（支喜干剋）或截腳（干喜支絕），提示「吉凶減半」或「吉而虛」。
3. ★ **大運 × 流年喜忌組合提示**：依第十三篇的表，流年干支全忌 + 大運一喜一忌 →「凶禍立至」級提醒；大運全忌 + 流年一喜一忌 →「凶中有吉」。用課堂三步法的喜忌當輸入。
4. **限運欄**：大運表加一欄顯示「這段年齡屬於哪一柱」，並標出那一柱的喜忌（本書 37–55 歲看日柱的規則）。
5. **婚期 / 戀愛標籤補充**：流年地支和日支三合、六合、六沖、三會 →「戀」提示；流年天干五合命局天干 →「婚」提示（App 目前已有夫妻星庫沖開的「婚」標籤，可以並列）。
6. **戀愛方式小卡**：顯示日支藏干透在哪一柱（年 / 月 / 時 / 都不透），配書上的白話說明。
7. **六親「距離」欄**：十神組合或六親卡片顯示六親星是否緊貼日主。
8. **規則對照**：本書「地支合化要透干」和課堂「地支有合無化」不同；「調候優先」和課堂「扶抑優先」不同。若要做成可切換的流派選項，這兩點是差異最大的地方。
9. **測試資料**：`命例.tsv` 的 29 個格局/用神例可以當「取格」和「特殊格局判斷」的測試案例（化土格等 3 例時柱有誤，測試前先修正或排除）。
