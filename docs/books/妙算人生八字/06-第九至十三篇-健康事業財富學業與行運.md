# 第九～十三篇　健康、事業、財富、學業考運、大運流年判斷要訣（書第 287–328 頁）

> **這一章在講什麼**：這五篇是「應用篇」。前面六篇教你把命盤看懂（強弱、格局、用神、喜忌），這五篇教你把結論用到生活的各個方面：身體哪裡要小心（第九篇）、適合什麼工作、會不會搬家、房子好不好、會不會有官司（第十篇）、能不能發財（第十一篇）、學歷和考運（第十二篇），最後是**大運流年怎麼判斷**（第十三篇）。
>
> **這一章的讀法**：每一篇都是一條條的判斷規則，沒有命例。規則看起來很多，但幾乎每一條都可以還原成同一個問題：**這件事對應的五行或十神，對這個命是喜還是忌？歲運有沒有去碰它（合、沖、剋）？** 讀的時候建議一邊對照自己的命盤，問「我的用神是什麼？它在哪一柱？」
>
> 最後一篇**大運流年判斷要訣**最重要：作者在這裡講了「蓋頭截腳」「大運不分上下五年」「限運」「喜忌組合」「刑沖會合判斷」「六神與行運」，是全書收尾的總整理。原書正文到第 328 頁結束，沒有後記。
>
> 下文為了說明規則，會用「喜木走庚寅運」這種片段舉例，不是書上的命盤。

## 第九篇　論健康疾病（第 287–292 頁）

### 一、基本觀念：五行配五臟

作者先講中醫的五行配臟腑：

| 五行 | 臟 | 腑 | 天干日主對應的部位（第 288 頁） |
|---|---|---|---|
| 木 | 肝 | 膽 | 甲乙日主：肝膽、筋骨、四肢 |
| 火 | 心 | 小腸 | 丙丁日主：心、血、眼 |
| 土 | 脾 | 胃 | 戊己日主：脾胃、皮肉 |
| 金 | 肺 | 大腸 | 庚辛日主：肺、大腸、氣管 |
| 水 | 腎 | 膀胱 | 壬癸日主：腎、膀胱、耳 |

他引《滴天髓》：「**五行和者，一世無災**。」五行平衡、互相流通的人，一生少病。這句話是整篇的總綱：**疾病來自五行的失衡**。

書上也抄了天干配臟腑的歌訣（「甲膽乙肝丙小腸，丁心戊胃己脾鄉……」）和地支配臟腑的歌訣。林註說**三焦、包絡**的五行歸屬，各家說法不一。

### 二、什麼時候容易生病（第 288–289 頁）

作者列了三種情況：

1. **日主太弱**：本身體質就虛。
2. **某一行剋另一行太過**：例如金太旺把木剋傷 → 肝膽、筋骨的問題。
3. **用神被剋**：用神是命局的「精神」，被剋傷了，身體也跟著出問題。

作者還分「**實症**」和「**虛症**」：**病在日主是實症，病在用神是虛症**。可以這樣理解：日主代表「我」的身體本身，日主受傷是實實在在的病；用神代表我需要的那股力量，用神受傷是「元氣不足」型的問題，比較像調養、虛弱的狀態。

**看哪個器官**有兩條路：
- **以日干看**：日主是哪個五行，那個五行對應的臟腑是「本身」，容易出問題的地方（見上表）。
- **以五行看**：命局裡哪一行**太旺**或**太弱**，那一行的臟腑就有病象。太旺是「實」（例如火太旺 → 心火、發炎），太弱是「虛」（例如水太弱 → 腎虧）。

書上還列了**干支配身體部位**（甲頭、乙項、丙肩、丁心……；子疝氣、丑肚腹、寅臂肢、卯目手……午頭、巳未兩肩……），林註：**有些古籍如此，僅供參考**。

### 三、開刀、血光、車禍（第 291–292 頁）

**開刀或血光**的條件：

1. 命局的**喜用神被沖破** → 主血光之災（含車禍）。用神是保護自己的力量，被沖破等於保護傘破了。
2. **大運、流年同時沖破**命局的喜用 → 必有大病或橫禍。（歲運「聯手」，力量最大。）
3. 流年和命局**合出強旺的忌神** → 也主開刀。（原本不起眼的忌神，被合化成一股大力量。）
4. 命局**兩強五行相剋**（例如金木交戰）**卻沒有水通關** → 容易犯血光。（第六篇例二十二的命局有壬水通關；如果沒有，就是這種情況。）
5. 犯**反吟、伏吟**，或行運時**忌神併臨** → 主開刀住院。

**車禍**的條件：

1. 命局地支本來就有**六沖**，又被流年地支**對沖**；
2. 流年和日支**反吟或伏吟**、又透出年干；
3. 命局被**流年、流月、大運雙沖**；
4. 流年和命局合出強旺的忌神；
5. 命局五行偏旺偏枯，再遇歲運沖剋。

**舉個片段的例子**：命局用神是時支的卯木（例如身強的戊土以卯木正官為用）。走到酉運（卯酉沖），又遇到酉年 → 大運、流年同時沖破用神 → 書上說「必有大病或橫禍」，那段時間要特別注意健康與交通安全。

### 四、意外災厄看「忌什麼五行」（第 292 頁）

作者說八字五行的喜忌和災難有關，給了一個很直觀的對照：

| 忌 | 要防 |
|---|---|
| 忌木 | 木器所傷 |
| 忌火 | 火災、爆炸 |
| 忌土 | 土石、落石 |
| 忌金 | 刀槍、鐵器 |
| 忌水 | 不要去郊外水邊玩耍 |

這是用五行象意推災厄的方法：你忌的五行，它的「實物」就是你要小心的東西。當作生活提醒即可，不必過度緊張。

**和其他書比較**：陸致極《基礎教程》有完整的弱臟、強臟表（App 已做「健康」標籤）；本書的規則比較粗，但「**用神被沖破 → 血光**」「**歲運合出強旺忌神 → 開刀**」兩條，可以和 App 現有的健康標籤互相印證。

## 第十篇　如何選擇事業（第 293–303 頁）

作者開頭說「**男怕入錯行**」：選對適合的行業，才有升遷的機會。他給了三種方法：以用神選行業、以五行選行業，以及看遷移變動（驛馬）。後面再加上田宅、官非兩節。

### 一、以用神選行業（第 293–296 頁）

**原理**：用神是命局最需要的力量，**從事和用神相關的工作，就是每天在補充自己需要的東西**。所以先找出用神是哪個十神，再看那個十神適合什麼工作。

#### 1. 正官、七殺為用

有管理能力，宜政治、司法、公務。
- **正官格**多從事政治、行政、公教。**正官配印**（官印相生）→ 多成高級主管。
- **財生正官** → 多為文官；**財生七殺** → 多為武將。
- **七殺格**宜軍事、警察，以及競爭性、破壞性的行業。
- **身旺坐下七殺羊刃**，叫「**刃殺相資**」→ 威權萬里。（羊刃幫身、七殺給權，兩者互相制衡又互相成就。）
- **身弱殺多又無印化** → 書上說容易成為市井無賴、加入黑幫。（意思是壓力大又沒有轉化的管道，人容易走偏；不要當定論。）

#### 2. 正印、偏印為用

宜文學、文藝、學術、行政、宗教、慈善。
- **正印格**宜教育、文學、行政管理。
- **偏印格**宜醫師、科技、發明、研究、武術、宗教、五術等冷僻專門行業。
- **偏印是副業之星**，常身兼兩種以上工作（第三篇也說過）。

#### 3. 正財、偏財為用

有理財能力，宜金融、財政、股票、證券、營商。
- **正財格**趨向穩定的事業、開店。
- **偏財格**宜國際貿易、交通運輸、觀光旅遊；偏向冒險投機性、動態開發的事業，例如貿易、推銷、代理商。
- **正財為用又見傷官** → 反而以專業技術白手起家。（傷官生財：靠技術、創意賺錢。）

#### 4. 食神、傷官為用

宜文學藝術，「筆底生花」而成名。
- **食神格**偏向知性、感性的活動：慈善、服務、幼教、演藝、美容、餐飲。**食神和正印同柱**，特別利於文章創作。
- **食神制殺** → 最適合軍警界。（食神能制住七殺，等於能管住暴力、危機。）
- **傷官格**傾向口才：律師、名嘴、教授、辯論，以及技術行業。
- **傷官佩印** → 宜公營事業，可任一級主管。
- **傷官生財** → 可以靠文章出版，或舉辦技術性商展賺錢。

#### 5. 比肩、劫財為用

宜自由業、服務業、合夥事業，主得朋友大力相助；宜外銷、貿易、律師、會計、仲介、外交。
- **劫財**選擇行業和比肩相同；除了從旺格之外，多能白手起家，宜合夥開公司。
- 若**不逢刑沖、空亡**，從事投機性、賭博性的行業也不錯（偏財亦同，身強更準）。

### 二、以五行選行業：取「透旺」（第 297–298 頁）

除了用神，作者還給了另一種方法：取「**透旺**」來推論工作的**性質**。

**什麼是透旺**：日主以外，命局中**最旺的那個天干**（透干的），就拿來當作「格」推工作性質；如果沒有透干的，就取氣勢最專旺的五行。

**但要看身強身弱**：
- **身強**：不可以取印星、比劫（它們讓日主更強，是忌神），要取食傷、官殺、財。
- **身弱**：各類都可以取。

這個方法的道理是：最旺的五行是命局裡「最有存在感」的力量，往往就是這個人每天接觸最多的東西；但身強的人如果最旺的是印比，那是讓他失衡的東西，不適合拿來當工作方向。

各五行對應的行業：

| 五行 | 行業 |
|---|---|
| 木 | 花草苗圃、園藝、竹器木器、文具、書局、出版印刷、傢俱、建材、糧食、農林牧 |
| 火 | 熱能、光學、核能、爐冶、照明、電器電子、製造、化妝美容、餐飲食品、百貨、手工藝 |
| 土 | 土地礦產、營造、農產畜牧、仲介、房地產、殯葬、土木建築 |
| 金 | 金融銀行、保險信託、當舖、銀樓珠寶、刀劍機械、模具五金、鑄造電鍍、礦冶、儀器 |
| 水 | 和流動、液態有關：飲料冰品、冷凍、航海、海產、釣具、清潔、化學品、滅火器、消防、旅遊、傳播、交通運輸、水利、水產養殖 |

**舉個片段的例子**：一個身強的甲木日主，天干透出兩個丙火、地支有午 → 日主以外最旺的是火（食傷）→ 依透旺法，工作性質偏向火：電子、照明、美容、餐飲；再配合用神法（食傷為用 → 文學藝術、服務），可以推出「餐飲創意」「設計」這類方向。

### 三、遷移與異動：驛馬（第 298–300 頁）

#### 1. 驛馬的性格

**寅申巳亥**是「四馬之地」（四長生）。命帶驛馬的人**一生閒不住**，變化性大，常出差、外調、出國旅遊；但意志不堅的人，凡事受外界影響，或思慮不周、衝動行事。

作者說驛馬是**成大功、立大業的推手**，也主奔波。**格局好**的人帶驛馬，是動作敏捷、衝鋒陷陣、努力打拼的人；**格局不好**的人坐驛馬，只是徒勞無功。

（驛馬怎麼查見第三篇神煞：以年支或日支的三合局查，申子辰馬在寅、寅午戌馬在申、巳酉丑馬在亥、亥卯未馬在巳。）

#### 2. 驛馬在哪一柱，就在哪段年齡變動

| 驛馬在 | 遷變的年齡 | 因為誰 |
|---|---|---|
| 年柱 | 1–16 歲 | 祖上、父母 |
| 月柱 | 17–32 歲 | 父母、兄姊 |
| 日柱 | 33–48 歲 | 自己或配偶 |
| 時柱 | 49–64 歲 | 自己或子女 |

注意：這裡用的是**每柱 16 年**，和第二篇、第十三篇的限運（每柱 17–18 年）不同（README 錯誤表有記錄）。

#### 3. 驛馬逢合、逢沖

- 命帶驛馬、又**行運合會** → 這匹馬**被絆住**，想動動不了。
- **逢歲運沖剋** → 這匹馬必定**狂奔不已**。
  - **吉馬逢沖**（驛馬是喜用）→ 凶中有吉，動了反而好；
  - **凶馬逢沖**（驛馬是忌神）→ 雪上加霜。

#### 4. 判斷遷動的具體規則（第 300 頁）

變動之後是吉是凶，看流年和時支的沖合及透干。以**年柱為主、次參時柱**，再看行運沖合：

1. **年支和時支三合、六合或六沖，又都是喜用** → 異鄉打拼、卓然有成。
2. **年月支對沖** → 很早離開出生地。
3. 時柱代表事業；**流年沖合年支** → 主遷變；**大運同時沖合年支和時支** → 必有遷動，透出年支的天干更準。
4. **年支被雙沖，或合時支兩支又透出年干** → 大多因工作或求學而遷動。
5. **流年逢驛馬**、或年支被沖、或**流年和命局三合三會又透年干** → 遷動遠行。
6. **歲運或流月和命局三者會齊**亥卯未、寅午戌、巳酉丑、申子辰任一組 → 遷動。

**為什麼以年柱為主**：年柱是祖上、出生地（第七篇），年柱被動，就是「離開根」。時柱是事業、晚年，時柱被動是因為工作而遷。

### 四、田宅（第 301–302 頁）

看住宅以**年柱為主、次參時柱**，再看行運沖合變化。從年干支看住宅格局好壞和內部裝潢：

| 年干 | 年支 | 住宅 |
|---|---|---|
| 喜用 | 喜用 | 外觀、周圍環境好，室內設計妥當，有增值可能 |
| 忌神 | 忌神 | 情況剛好相反 |
| 喜用 | 忌神 | **外牆不錯，室內凌亂** |
| 忌神 | 喜用 | **外觀老舊，室內美侖美奐** |

這張表是「天干公開、地支私下」最可愛的應用：**天干是房子的外面，地支是房子的裡面**。

坊間另有兩種說法：一是以屋宅的納音剋日主的納音、或宅運在衰敗休囚空亡沖破，代表宅運不好；二是以年柱納音和田宅關係密切。作者對這兩種**保留**。

### 五、官非與刑訟（第 302–304 頁）

1. **身弱而官殺旺** → 口舌是非多；走官殺歲運更嚴重；有印轉化則較輕微。（官殺代表法律、上司、外力壓迫；身弱扛不住。）
2. **身強以官殺為用，卻被傷官剋破**；或不論身強弱，**傷官和官星同柱或緊貼**；或以官星為用又見傷官 → 要慎防官非纏身（作者說這條最重要）。這就是「**傷官見官，為禍百端**」。
3. 命局用神或調候用神被剋破成偏枯，身弱官殺混雜又走財運（財生官殺）→ 容易犯官非。
4. **命局和歲運刑沖併見**，全局動盪；或行運和命局成**反吟伏吟**；或**四正（子午卯酉）、四生（寅申巳亥）會齊** → 都主官非刑傷。
5. 以上各項再逢**年支被沖合且透年干**，或年干被合又剋透干支 → 有田宅、職業異動的徵兆，**牢獄之災似乎難免**（古書口吻）。
6. **命局中貴人多**，縱然身弱官殺旺，也比較不會犯官非；歲運逢官非也多能化解。

## 第十一篇　財富的看法（第 304–308 頁）

作者開頭說，人人都希望「恭禧發財」，有人買彩券、有人經營企業；但能大撈一筆的，比起百年家族企業還差一截。意思是：真正的財富要看命局的「底子」。

### 一、能不能發財（第 305 頁）

**基本條件**：要賺大錢，必須**命局身強、財星多**，又要日以繼夜打拼；人生 **30 到 60 歲之間走 20 到 30 年的好運**，必然能成為富翁。如果大運不好，但連續幾年流年很好，也能發一筆小財。

| 命局 | 書上說 | 白話 |
|---|---|---|
| 身強財旺、或身財兩停 | 先天大富之命，歲運幫助則財源滾滾 | 有能力、有機會 |
| 財多身弱，但有印比幫身 | 也有發財之命 | 機會多，有人幫忙扛 |
| 身強財星透干、或身弱印星透干 | 能賺到錢但較節儉 | — |
| **財星不透干、歸藏於庫** | 生性勤儉樸實、不亂花錢 | 錢藏起來（第三篇「正財宜藏」） |
| 身強比劫透干、或身弱財星透干 | 能賺能花，不易累積財富 | 比劫公開奪財；身弱的財擺在外面守不住 |

為什麼「身強比劫透干」存不住錢？比劫剋財，比劫透在天干代表「公開地」分財——朋友多、應酬多、出手大方。

### 二、何時發財、何時破財（第 305–306 頁）

| 命局 | 發財的歲運 | 破財的歲運 |
|---|---|---|
| 身強 | 食傷、財星（透干更好） | 比劫、印星 |
| 身弱 | 比劫、印星 | 食傷、財、官殺 |
| 從旺格 | 順從旺神的運 | **財星年大破財** |
| 從財格 | — | 比劫運 |

這張表就是扶抑喜忌的直接應用：走喜用運發財、走忌神運破財。

**從旺格的破財，原因看財星沖合哪一柱**（這是很有特色的一條）：
- 財星沖合**月支** → 因替人擔保、借錢給人、被倒會而破財；
- 沖合**時支** → 因子女或經商而破財；
- 沖合**日支** → 因配偶而破財。

這又是「宮位代表六親」的應用：被動到哪個宮位，破財就和那個宮位的人有關。

另外：**身強歲運地支合化財、天干合化比劫** → 雖然能發財，但也有破失，屬於「敢賺敢花」型。

### 三、財富從哪裡來（第 306–308 頁）

1. **年干支是喜用** → 有祖產可以繼承；**年月都忌** → 多不得祖蔭，白手起家。
2. **日支藏干透到年干、又是喜用** → 「嫁妝一牛車」，因結婚而意外發一筆財。（日支是配偶，透到年干是「配偶的家族」。）
3. **年柱為喜用、年月支又三合** → 喜歡出生地的環境，最適合在故鄉發展。
4. **年柱為忌、年月支又對沖** → 不但不能得祖產，更宜年少離鄉打拼。
5. **身弱歲運走比劫** → 因合夥而發財（比劫幫身扛財，第三篇「接大訂單要找人合作」）。**時柱為忌而大運正在走好運** → 最好和朋友合夥，但作者給了一個很實際的建議：**掛頭銜可以，不要當負責人**。

## 第十二篇　學歷與考運（第 308–315 頁）

作者開頭說：古代有科舉、十年寒窗，學歷自古就是評估錄取的標準；但有人滿腹經綸卻名落孫山，命運迥然不同——除了先天命局結構，最明顯的差異在於**行運、考運的好壞**。

### 一、學歷高低（第 309–312 頁）

**看哪段大運**：學歷高低要看**第一、二步大運**（甚至第三步），並考慮驛馬、桃花，配合命局判斷；考試以**行運喜忌**為主要考量。作者提到：青少年 16 歲左右推甄、指考、會考，19 歲考大學；中老年人想學新知，看 13 歲前的運氣（書上說法）。

**命局看什麼**（逐條白話）：

1. **印星是文書知識的來源**。不論身強弱，有印的人求知慾強、喜歡博覽群書；**印透干的人手不釋卷**。日主強、官印透干相生、又以印為喜用 → 學歷必然不低。**命中不帶印星** → 多不喜讀書，知識常識較少。
2. **食傷洩秀**主聰明過人；身強的人能充分顯示才華。尤其「**金水洩秀**」（庚辛日主見壬癸水）海闊天空，書云「金水洩秀，出身科甲」，學歷大多很高。
3. **調候、通關得用**：金寒水冷見木火調候、木火炎燥見金水調候、通關用神得官，歲運又不背逆 → 文采不弱。五行如木火通明、火土相生、水木相涵等「五象相成」的祥和之氣，又不見刑沖剋破 → 博學多聞。
4. **正官、正印代表地位權勢，也代表自制力和自尊心**。官印、殺印相生為用神，命局不見傷官剋官、食神制殺不過重、財星不緊貼日主壞印，月令又合為印星官殺星，是喜用又不逢剋破 → 在學功課優秀，必可獲高學位。
5. **正官為用卻落空亡、或被妒合剋破、或月柱印星被合** → 求學因意外變化受挫、半途而廢。**官殺過旺為忌** → 本來對唸書沒興趣，甚至看到書就頭痛；但**有印星轉化**，反而孜孜不倦、勤勉用功。（官殺生印、印生身：壓力轉成學習動力。）
6. **天干秀氣流通 → 名列黃榜、學歷高；地支秀氣流通 → 學歷更高**（書云「金殿傳臚」）。
7. **身強印重、食傷輕**（或印剋食傷）→ 才華難發揮，幼少年功課差。**身強印重、財星弱**，印透干、月柱藏印、其他柱又不見財透 → 青少年時期常為家庭經濟操心而影響課業。
8. **傷官佩印**且為喜用、不見財星壞印 → 天生聰穎，行運相助必獲高學歷。身強官殺也旺，得**食神制殺、傷官駕殺**為用；或身強比劫旺，得食傷洩秀為用、又不見印星破壞 → 都主高學歷。
9. **喜用神（官殺、印、食傷）集中在年月柱** → 少年就才華洋溢、嶄露頭角，作者說甚至國中就越級唸大學；**集中在日時柱**，大運到第三、四步才走喜用 → 中年後興起再讀書的慾望，大都能如願取得學歷。

第 9 條是**限運觀念**的應用：喜用神在哪一柱，那段年齡就發揮。

**魁星**：書上抄了鍾義明引南投竹山「鍾大師」的說法：魁星不是指特定干支，而是指甲辰到癸丑這一旬中，地支坐辰戌丑未四庫（以墓庫為印）的組合；凡人命四柱、大運流年得到**甲辰、丙午、丁未、庚戌、癸丑**這幾位魁星中的三個，考試必中；只有一兩柱但能和驛馬對沖的更吉，「十有九中」；和驛馬相合則合去魁星，反而不利。林註：**摘錄以供參考**。

### 二、考運（第 312–314 頁）

作者引《滴天髓》「巍巍科第邁等倫，一個元機暗裡存；清得淨時黃榜客，雖雜濁氣亦中式」，以及註解「秀才不是塵凡子，清氣還嫌官不起；異路功名莫說輕，日元得氣遇財星」。結論是：**考運好壞以命局清淨、官星生起為根基**——第六篇的「清濁」在這裡用上了。

他也很務實：現代社會要進名校、公營事業、知名企業都要考試；功課好、實力強的人通常能發揮，但「命運之神常捉弄人」，實力強的有時考不上，實力平庸的卻意外金榜題名。考運看法仍然離不開命局的喜忌用神、通關、調候、病藥。

**兩個重點**：
- **流年最重要**：**日主和太歲要相合，忌相刑沖**；就算有魁星，刑沖太歲的那年也不利。
- **看有沒有財星**：財星代表一個人的反應能力和思維敏感度；尤其**身旺用官、官星弱時，以財生官**（財滋殺）最好。

**大運流年的組合**：

| 情況 | 結果 |
|---|---|
| 八字格局清奇、喜忌各歸其所、又行吉運 | 一生考運奇佳，幾乎每試必中 |
| 大運、流年都好 | 考上理想學校和科系（或職場升遷、考上理想公司） |
| 大運好、流年不好 | 考得上學校，但科系不如所願 |
| **大運不好、流年好** | **考取機會也大（流年重於大運）** |
| 大運、流年都不好 | 任何考試都名落孫山 |

**哪些流年容易考上**：

1. 命局用神透干，又走喜神運 → 成績優異、易中；或用神被剋破，但流年剛好把剋破的字制化掉 → 易中。
2. 命局是**殺印相生**的貴格、或**官印雙清**的美格，考試那年走官殺印的用神運 → 輕鬆過關。
3. 命局**官殺混雜而且並旺**，流年「**去官留殺**」或「**去殺留官**」→ 金榜題名。（官殺混雜要合去一個，第三篇正官林註。）
4. 歲運走**調候運**，或兩神成象走**通關運**，氣勢流通 → 可以上榜；特殊格局走旺神喜用運 → 必春風得意。
5. 以下組合，流年走對的地方、大運也好 → 榜上有名；大運不好 → 也能考上但吊車尾：

| 命局 | 流年宜走 |
|---|---|
| 身印兩旺 | 財星之地（財剋印） |
| 身比兩強 | 官殺、食傷之地 |
| 身官（殺）兩強 | 食神制殺、傷官駕官之地 |
| 身衰財旺 | 比劫祿刃之地 |
| 身弱印旺 | 官殺之地（官殺生印） |

**時支和流年**：看考運還要參考時支和流年的合沖、通透：合出喜用神 → 吉上加吉；合出忌神 → 大打折扣；合了又通透年柱 → 因考試而變動住處（住校、受訓、外派）。

**和其他資料比較**：「流年重於大運」在第十三篇又說了一次，是本書的一貫立場（README 作者立場第 16 條）。

## 第十三篇　大運流年判斷要訣（第 315–328 頁）

### 一、命與運的關係

書云：「**富貴定乎於格局，窮通實乎於歲運**。」格局決定一個人的層次（富貴），歲運決定什麼時候順、什麼時候不順（窮通）。

作者又用了一次車和路的比喻：

| 命 | 運 | 比喻 |
|---|---|---|
| 好 | 好 | 好車走好路 |
| 好 | 不好 | 好車走顛簸泥路 |
| 不好 | 好 | 普通車走寬闊大道 |

俗話說「**命好不如運好，運好不如流年好**」——這句話本書是真的照用的：流年的影響最直接。

### 二、大運干支怎麼看：作者反對「上下五年分」（第 315 頁）

一步大運一組干支管十年，坊間有三種看法：

1. 天干管前五年、地支管後五年（《淵海子平》「上下五年分」）；
2. 以地支為重，干支一起合看十年；
3. 前五年以天干為主、地支為輔，後五年單看地支。

**林註**：以經驗來說**應以地支為重**，干支不相違背、以相生相扶為美，**切不可分上下來看**。理由是大運干支有「**蓋頭**」「**截腳**」的情形，如果硬要分開看，吉凶多不驗。

為什麼以地支為重？地支是一個季節的「氣」，影響整整十年的環境；天干是表面的現象。而且天干坐在地支上，天干有沒有力量，要看下面的地支撐不撐得住它（第六篇「虛浮」的觀念）。

### 三、蓋頭、截腳（第 315–316 頁）

這是本書解釋得很清楚的一個觀念：**大運的天干和地支互相剋，吉凶都打折**。

#### 1. 蓋頭：喜用的地支被天干剋

**例子**：命局喜木運，卻走到**庚寅、辛卯**運——寅卯是木（喜），但頭上蓋著庚辛金（金剋木），叫「金蓋木頭」。

**結果**：作者說蓋頭運**以地支（喜）為主，吉凶減半**。以「喜木走庚寅、辛卯」為例：本來金剋木是凶，但**金的長生在巳、絕在寅**，金坐在寅卯上是「**支不載干**」（地支撐不住天干），金也剋不太動，所以凶減半。如果原命局或流年有**水**（金生水、水生木，通關）或**火**（制金），就沒有妨礙。

其他蓋頭的例子：

| 喜 | 蓋頭運 |
|---|---|
| 喜木 | 庚寅、辛卯 |
| 喜火 | 壬午、癸巳 |
| 喜土 | 甲戌、甲辰、乙未、乙丑 |
| 喜金 | 丙申、丁酉 |
| 喜水 | 戊子、己亥 |

#### 2. 截腳：喜用的天干坐在剋它的地支上

**例子**：命局喜甲乙木，卻走到**甲申、乙酉**運——甲乙木是喜，但腳下是申酉金（金剋木），木的根被截斷。

**結果**：甲乙木的長生在亥、**絕在申**，木坐在申酉上同樣是「支不載干」，所以這個木運「**吉而無吉，謂之虛也**」——看起來是喜運，實際上沒什麼力量。如果原命局或流年又有庚辛金剋甲乙木，反而變凶。

其他截腳的例子：

| 喜 | 截腳運 |
|---|---|
| 喜木 | 甲申、乙酉 |
| 喜火 | 丙子、丁亥 |
| 喜土 | 戊寅、己卯 |
| 喜金 | 庚午、辛巳 |
| 喜水 | 壬戌、癸未 |

#### 3. 結論

作者說：「運逢蓋頭截腳，主吉非吉、凶非凶。」除此之外，還要考慮原命局、大運、流年三者之間的生剋刑沖會合，以及十神關係，綜合判斷。

**用比喻說**：蓋頭是「好的房子，上面壓著壞的屋頂」——住起來還可以，但不舒服；截腳是「好看的招牌，下面沒有地基」——看起來好，其實撐不住。

**一個練習**：一個喜火的人，走丙子運。丙火是喜，但坐在子水上（截腳）→ 吉而虛。走壬午運：午火是喜，但頭上蓋著壬水（蓋頭）→ 以地支為主，吉減半；如果命局有甲乙木，水生木、木生火，通關，就沒什麼妨礙。

**和其他書比較**：
- 《滴天髓命例研究》也說大運以地支為重。
- 課堂（10/14）的「大運天干五合化不化看坐支」和這個思路一致（天干要看坐下的地支）。
- App 目前的大運標籤是干支分開判斷再合看，可以考慮加一個「蓋頭 / 截腳」提示（README App 想法第 2 條）。

### 四、先天命局：四柱各代表什麼（第 317–319 頁）

作者說基本上八字要先定格局，看日主強弱、喜忌用神，再據此推論歲運對命局的禍福。四柱又叫根苗花果，每一柱管的年限、代表的六親不同。他把古代的看法和自己的「現代觀念」並列：

| 柱 | 古代看法 | 作者的現代觀念 |
|---|---|---|
| 年干 | 祖父、祖上的身分地位財富權勢、家族企業；和年支管 15 歲以前 | 人體的**頭部**；雙親和祖父母的關係、幼年成長環境和教育；先天體質 |
| 年支 | 祖母的關係；其餘和年干相似 | **大腦神經、語言系統**；祖墳風水；和兄弟姊妹的關係（書上又說年支管 61 歲以後，和上面「年干年支管 15 歲前」不一致，可能是古法把一生分成五段的說法，照錄） |
| 月干 | 和父母兄姊的關係；和月支管 16–30 歲 | 人體**腹部**；工作適應性、人際關係 |
| 月支 | 和母親、弟妹的關係；判斷人體強弱寒暖的主要條件 | **胸部、後腦、右足、血液循環**；基本性格、責任心、自制力 |
| 日干 | 自我，是生命之主 | 心性、相貌、身材、氣質、智慧、體質、疾病、人生觀、遺傳基因 |
| 日支 | 妻妾的容貌、個性、緣分、健康、助力；和日干管 31–45 歲 | 人體**左手左足**；和配偶的關係、自己顯露出來的性情行為 |
| 時干 | 和兒子、長子、孫兒的關係；和時支管 46–60 歲 | 晚年境遇、成就、身後（包括遺產）；後代品質 |
| 時支 | 和次子以下、女兒、孫女的關係；和時干合參一生結局 | 人體**足部**；對下屬晚輩的照顧、嗜好、性能力、身後歸宿（墓園） |

（年柱還代表田宅、遷移；月柱代表門風、情緒、事業；日柱代表命宮本人、婚姻、財帛；時柱代表子息教育、疾厄、奴僕、福德。）

### 五、限運：大運要配合「這段年齡是哪一柱」（第 319–320 頁）

#### 1. 什麼是限運

作者說行運分三大部分：**限運、大運、流年**。把四柱分成四個時期，就是限運。上面古代的分法是以農業社會平均壽命 60 歲為基準（每柱 15 年）；現代人壽命延長，所以把四柱往後延推兩年左右，**每柱大約管 17 到 18 歲**。

| 限 | 柱 | 年齡 | 作者說 |
|---|---|---|---|
| 第一限 | 年（根） | 出生–18 歲 | 一切人事物的發源地，事情的變化較不明顯 |
| 第二限 | 月（苗） | 19–36 歲 | **命局的關鍵**；嗜好、學業啟蒙，未來事業和人際的拓展期；這段發生的事特別明顯應驗 |
| 第三限 | 日（花） | 37–55 歲 | 決定成敗的發榮期，「一生富貴貧困從此分」 |
| 第四限 | 時（果） | 56 歲以後 | 承先啟後（延續月柱），影響最長；老來吉凶的「期末考」，人生的歸結之地 |

#### 2. 限運怎麼用

作者說這樣區分有利於更準確掌握大運流年的休咎：**大運流年必須配合限運才能準確判斷吉凶**。

- 37 到 55 歲期間的**任何一個流年**，都要參酌**第三限（日柱）**來推論。
- **大運流年好，但日柱虛弱** → 發也有限。
- **大運流年都差，但日柱喜用得力** → 凶中藏吉，不至於有性命之憂。
- **喜用神不論在哪一柱**，只要不逢刑沖剋破、行運又來扶助，走到那一柱管的時期（大運）時，會「**發得金光閃閃**」；行運不來幫忙，只要不遇刑沖剋破，這段時間也比其他時期好一點。
- 作者總結：以大運好壞做基本判斷，就有些準確率；再配合四限的十神，就更應驗。

**舉個片段的例子**：某人的喜用神集中在日柱（例如日支是用神、又沒被沖）。他 37 到 55 歲這段，即使大運普通，日柱的喜用也會撐住，事業多半在這段發展；如果這段又剛好走喜用大運，就是一生最好的時候。反過來，若日柱是忌神，這段時間即使大運好，也要打折扣。

這是本書的特色規則，其他已整理的書沒看到這麼明確的「大運 × 限運」配合法（README App 想法第 4 條建議做成「限運欄」）。

### 六、大運流年的喜忌組合（第 321–322 頁）

這是全書最像「查表」的一段，非常實用。

#### 1. 大運本身的吉凶

| 大運天干 | 大運地支 | 結果 |
|---|---|---|
| 喜 | 喜 | **吉運** |
| 忌 | 忌 | **劣運** |
| 不喜不忌 | 不喜不忌 | 平常運，「海不揚波」 |
| 喜 | 忌（或反過來） | 坊間說五年吉五年凶（但作者主張干支合看、以地支為重、注意蓋頭截腳） |
| 喜 | 不喜不忌（或支喜干平） | 小吉運 |
| 忌 | 不喜不忌（或支忌干平） | 小凶運 |

#### 2. 大運 × 流年

| # | 大運 | 流年 | 結果 |
|---|---|---|---|
| 1 | 干支全喜 | 干支全喜 | 鴻運當頭 |
| 1 | 全忌 | 全忌 | 禍不單行 |
| 1 | 不喜不忌 | 不喜不忌 | 平常運 |
| 2 | 一方全喜 | 另一方不喜不忌 | 吉運 |
| 2 | 一方全忌 | 另一方不喜不忌 | 凶運 |
| 2 | 一喜一忌 | 一喜一忌 | **吉凶參半，以流年為重** |
| 3 | 一方全喜 | 另一方一喜一忌 | 大有可為 |
| 4 | **一喜一忌** | **全忌** | **凶禍立至** |
| 4 | **全忌** | **一喜一忌** | **凶中有吉** |

第 4 條最值得記：同樣是「一個全忌、一個一喜一忌」，**流年全忌比大運全忌更危險**。這又一次說明作者的立場：**流年是君、大運是臣**（第二篇），流年的影響更直接、更立即。

**舉個片段的例子**：某人喜火、忌水。大運走丙子（丙火喜、子水忌 → 一喜一忌），流年遇到壬子（壬水、子水都忌 → 全忌）→ 第 4 條「凶禍立至」，那一年要特別小心。如果反過來，大運走壬子（全忌）、流年遇到丙子（一喜一忌）→「凶中有吉」，十年辛苦中，這一年還有轉機。

這張表很適合做成 App 的流年小提示（README App 想法第 3 條）。

### 七、命運歲刑沖剋合的吉凶（第 322–324 頁）

命局、大運、流年三者之間由於刑沖剋合，變化錯綜複雜，有時吉變凶、有時凶變吉。作者分兩部分講：先講**什麼時候成立**，再講**怎麼判斷吉凶**。

#### 1. 刑沖剋合什麼時候成立

1. **命局沒有合，大運流年帶來合** → 產生合局；但**要有化神透干引化，才合化**，否則合而不化。（第四篇「地支合化要看天干」。）
2. **命局沒有沖剋，歲運來沖剋** → 產生沖剋之局；**命局本來有沖剋，歲運來合** → 可以化解沖剋。（「六合可以解沖」。）
3. 命局本來沒有刑，歲運帶來刑 → 產生相刑之局。
4. **歲運同時帶來合和沖** → 一沖一合並見，吉凶參半。
5. 命局本有沖剋或合局，歲運帶來刑 → 可以化解原來的沖或合，但會和大運或流年形成相刑。
6. **命局本有干合支合，歲運來沖剋** → 原來的合被破壞。

#### 2. 怎麼判斷吉凶

1. 歲運**合住、沖去、剋制命局的喜用神** → 凶；合住、沖去、剋制**忌神** → 反而吉。
2. 歲運本身是喜用，卻**被命局合住、沖去、剋制** → 吉中藏凶；歲運本身是忌神，被命局合住沖去剋制 → 凶中有吉。
3. **合化**：命運歲合化成喜用 → 更吉；合化成忌神 → 更凶。歲運是喜但和命局**合化成忌** → **先吉後凶**；歲運是忌但合化成喜 → **先凶後吉**。
4. 命運歲形成**三會或三合局** → 那一年影響力極大；合神透出天干，吉凶更準。
5. 大運流年和命局產生**相刑、反吟、伏吟** → 主凶禍。大運和命局反吟、流年又和大運或命局反吟 → 健康、投資、事業、財富、感情多不順，嚴重時生死交關。
6. 命運歲干支形成**一沖三、三沖一、一沖二、二沖一** → 容易發生意外之災，**一三對沖最嚴重**。
7. 命運歲形成**三刑**、又在本限運 → 那年有大災難；再逢沖更加險象環生；除非這個限運有貴人、或三刑逢合，才轉輕。
8. 命局本有**兩柱天剋地沖**，在那一柱的限運中又見大運和命局反吟 → 危機重重；流年再反吟 → 生死交關。

**林註**：**反吟 = 干支天剋地沖；伏吟 = 干支相同**。（第一篇說反吟就是地支六沖，這裡更精確地說是天干也相剋。）

**用一個片段例子串起來**：命局日柱甲子（日支子是喜用）。流年午（子午沖）→ 第 1 條：流年沖去喜用 → 凶。如果大運是丑（子丑合）→ 第 2 小節「命局本來有沖剋、歲運來合可以化解」的精神：丑合住子，午就沖不動，凶減輕。如果大運流年又湊成三刑（例如寅巳申），而且正在日柱的限運（37–55 歲）→ 第 7 條，要特別小心。

**和 App 比較**：App 已經有反吟、伏吟、三刑、「三沖一」、歲運並臨等標籤（陸致極那一批）。本書的第 1–3 條（**歲運合去 / 沖去喜用 → 凶，合去忌神 → 吉**）和 App 現在大運×原局標籤判斷沖、合有利不利，方向一致。

### 八、六神與行運：事情會發生在哪方面（第 325–328 頁）

作者說：**命運歲的刑沖剋合只能推論吉凶的「程度」**；但事情會發生在人事物的**哪一部分**，必須藉由六神（十神）來判斷。

這是全書最後一節，也是把第三篇十神的意思帶回大運流年：**走到哪個十神的運，就是那個十神代表的事情在動**；是喜用就是好事，是忌神就是壞事。

#### 1. 官殺

**有關的事**：職位、名譽、主管、冒險刺激、丈夫、情人、子女、侵佔詐欺、權力鬥爭、事業競爭、外力壓迫、意外事故。

- **正官是喜用**：學生考試、職場升等、求職容易中；上班族易得長官提拔、調職升遷；打官司易得平反勝訴；未婚女性有好姻緣，有對象的可論婚嫁；男性容易得子女。
- **正官是忌神**：口舌是非多、身敗名裂，甚至丟官丟職；女性多有感情煩惱或失戀。
- **七殺是喜用**：和正官雷同，但**過程較突然、激烈、剛強**，所有功名利祿都要經過一番競爭才能如願。
- **七殺是忌神**：外力競爭激烈、行事衝動，或與人作奸犯科惹上官司；無謂開銷大，易遭意外刑傷；也主兄弟刑傷或失和；女性多感情困擾或失戀，書上還有一句「衝動之下易墮入風塵」（古書口吻）。

#### 2. 正印、偏印（同論）

**有關的事**：外在的助力（貴人）、心靈寄託（宗教）、母親、長輩、老師、飲食、渴望安定、學習新知、女性的子女。

- **喜用**：得父母長輩、貴人幫助；學業職場平安順遂；名聲大噪，尤其利於文學宗教。
- **忌神**：不得長輩幫助或發生誤會；考試謀職多波折；金錢上因判斷錯誤或受騙而損財；母親身體和運氣都不好；女命的子女易有損傷。

#### 3. 比肩、劫財（同論）

**有關的事**：父親、妻子、兄弟姊妹、朋友，以及自己的思想、言行、決策、健康。（比劫剋財，財是父親和妻子，所以比劫運也牽動他們。）

- **喜用**：兄弟姊妹、朋友、合夥人拔刀相助、財源滾滾；多能繼承祖產或家族企業；有征服、佔有慾，有開創事業的雄心。
- **忌神**：被兄弟朋友連累、被小人陷害；合夥事業經營不善而破財拆夥；和妻子衝突或妻子多病痛；或妻子被朋友誘拐而夫妻生波（古書口吻）。

#### 4. 食神、傷官（同論）

**有關的事**：創作、思想、籌劃、文藝表演、展示、公共關係、子女、學生、員工部屬、性慾、排泄、女命的丈夫和情人（食傷剋官殺）。

- **喜用**：有傑出創作或發明；比賽中榜得獎；才華發揮淋漓盡致；企劃案順利通過；文藝表演成功；一技在身的人聲譽高升、升官發財；多有男歡女愛之事；女命容易懷孕生子。
- **忌神**：理想多、實現少；用不當手段求財會惹官司，重者入獄；感情畸形發展；女命不利於丈夫；男命易損傷子女。

#### 5. 正財、偏財（同論）

**有關的事**：商業、金融、交易買賣、金錢、田宅財產（動產、不動產）、婚姻、父母親、物質享受、居家生活（傢俱、衣服、家電）。

- **喜用**：財運特別好，賺錢機會多，也容易享受財富；但交際應酬多，額外花費也多；男命女人緣佳，是未婚男性結婚的好機會。
- **忌神**：意外無端破財、事業垮台、財務糾紛；因桃花、婚外情惹禍；影響父親健康和運氣，或父親突發疾病；或傷及太太的運勢。

### 九、把第十三篇串起來：看一年運勢的流程

作者沒有寫成流程，但把第十三篇的內容排起來，就是一個很完整的「看流年」步驟：

1. **先看原局**：格局、強弱、喜用忌神（第六篇）。
2. **看限運**：這個年齡是哪一柱？那一柱是喜是忌、有沒有被沖破？
3. **看大運**：干支各是喜、忌、還是平？有沒有蓋頭截腳？以地支為重。
4. **看流年**：干支各是喜、忌、還是平？用「大運 × 流年」表判斷吉凶程度；流年為重。
5. **看刑沖剋合**：歲運有沒有合住、沖去命局的喜用或忌神？有沒有三合三會、反吟伏吟、三刑、一沖三？
6. **看六神**：走到的是哪個十神？事情會發生在那個十神代表的領域。

## 這五篇學到什麼（給初學者）

1. **健康**：五行和者一世無災；日主太弱、某行剋太過、用神被剋時易病。**用神被沖破、歲運合出強旺忌神** → 要小心開刀血光；忌哪個五行就防哪類意外。
2. **事業**：先看用神是哪個十神（官殺 → 管理公職、印 → 文教、財 → 商業、食傷 → 才藝口才、比劫 → 合夥自由業），再看「透旺」的五行；身強不取印比。
3. **遷移**：驛馬逢沖則動、逢合則絆；吉馬逢沖凶中有吉，凶馬逢沖雪上加霜。年柱被動是離鄉，時柱被動是因事業而遷。
4. **田宅**：年干是房子的外觀，年支是房子的內部。
5. **官非**：傷官見官最要小心；身弱官殺旺要有印化；貴人多比較不犯官非。
6. **財富**：身強財旺最好；財藏庫的人節儉；身強比劫透干存不住錢；身弱的人走比劫運靠合夥發財，但「掛名不當負責人」。
7. **學歷考運**：印是知識、食傷是才華、官印相生功課好；喜用在年月柱少年得志，在日時柱中年再進修。考運**流年比大運重要**，日主和太歲要合、不要沖；命局清淨最好考。
8. **大運**：**干支一起看、以地支為重**，不分上下五年；注意**蓋頭**（喜支被干剋 → 吉減半）和**截腳**（喜干坐絕地 → 吉而虛）。
9. **限運**：每柱管 17–18 年（年 0–18、月 19–36、日 37–55、時 56+），大運流年要配合那一柱的喜忌。
10. **流年**：用「大運 × 流年」的喜忌組合表判斷吉凶程度（**流年全忌 + 大運一喜一忌 → 凶禍立至**），用刑沖剋合判斷變化，用六神判斷事情發生在哪裡。
