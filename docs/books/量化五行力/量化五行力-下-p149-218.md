**位置分值（位調）**：本分 × 位置百分比

| 位置 | 年 | 月 | 日 | 時 |

- 得根係數：祿根 0.5、墓（庫）根 0.25、中根 0.185（N 女士例）、微根 0.125，再乘上干支之間的距離係數（同柱 1，其餘依遠近有 0.8、0.6、0.4、0.3 等不同數值）。

# 第六篇　從與不從（書頁 152–164）

## 6.1 導論：從與不從的爭議（書頁 153–155）

**重點**
- 坊間判斷從格的說法很多，標準也不統一。常見的有：見一比或一印出干就不能從；得月令就不能從；天干見官殺就不能成專旺；局中見剋制所從五行的干支就不可從；有兩個逆黨就不能從，逆黨無力則可從。這些說法各有道理，但都有反例，作者認為不能當作定律。例如地支三會化比或化印時，就算有二三個逆黨，也可以成專旺。
- 作者反對「看命主經歷才判斷從不從」的做法。他認為從與不從應有定律，並引愛因斯坦「上帝不玩骰子」。
- **從格的本質**：局中某一五行太旺，只能順勢。專旺也是一種從格，就是從日元的五行。從量化角度看，從格只有兩種：
  - **從強**：包括專旺、從娘（從印）。
  - **從弱**：包括從兒、從財、從殺。
- 日元的五行性質永遠不變。所謂「從」是從局勢的強弱，並不是把日元當成所從的五行。所以從兒格可以喜財官，因為從兒其實就是從弱，弱勢之下財官自然可用。
- **界線概念**：命局總能量得分的正值超過某條界線就從強，負值超過某條界線就從弱。

**書中例一、例二（摘自李修《滴天髓摘要》，書頁 153）**

| 例 | 年 | 月 | 日 | 時 | 原書評語 | 作者質疑 |
|---|---|---|---|---|---|---|
| 例一 | 丁卯 | 丙午 | 庚午 | 戊寅 | 天干印星（戊土）出干，不能從 | 寅午半合化殺，滿盤官殺，互相呼應、得根透干，力量甚大。這樣都不算從，就沒有命局可從了 |
| 例二 | 辛巳 | 辛丑 | 壬寅 | 癸卯 | 地支丑寅等不透干，天干勢力強大，可從（成專旺） | 天干強，但三干都沒有強根，寅卯巳三支又泄耗壬水。這樣也算從，從局就太多了 |

## 6.2 尋找從與不從的界線（書頁 155–161）

方法：找一個總分很大卻不從的命局，再找一個總分較低卻是從格的命局，兩者之間就是界線。

### 命例：P 先生（書頁 156–158）
- **四柱**：甲子　丙子　辛巳　乙未（1924 年生）
- **大運**：27 丁丑、37 戊寅、47 己卯、57 庚辰、67 辛巳、77 壬午、87 癸未、97 甲申、07 乙酉
- **初判**：辛日元失月令，天干二財一殺盡失勢，地支只有巳、未，看似日主無氣，像是從弱。
- **經歷**：48 年由內地來港，58 年運程開始好轉，60 年獲聘為常駐泰國的技術指導，月薪千五港幣，58–67 年是人生最風光的時期。67 年入辛巳運，辛與丙合化水，金運變水運，泄耗加重，又是日柱伏吟，於是辭職回港，過了最潦倒的十年，到 77 年才找到正式工作。
- **得分表**

| 項目 | 得分 |
|---|---|
| 年干 甲（財）微根在未 | −28.4 |
| 月干 丙（官）強根在巳、微根在未 | −60.9 |
| 時干 乙（財）微根在未 | −33.8 |
| **天干總得分** | **−123.1** |
| 月令 子（癸食） | −45 |
| 年支 子 | −20.3 |
| 日支 巳（丙 −28.8、戊 +11、庚 +13.8） | −4 |
| 時支 未（己 +20、乙 −12.8、丁 −12.2） | −5 |
| **地支總得分**（不含月令） | **−29.3** |
| **命局總得分** | **−197.4** |

- **結論**：不從，只是身弱。庚辰運得利、辛化水運失利，可以印證。庚運入局與年干甲相沖，又與時干乙合而不化，一沖一合之下，庚運力量沒有受損。
- **推論**：巳、未兩支本來都有生旺日元的作用。雖然內藏氣透出使兩支變成負能量，但它們還是消減了不少負能，所以命主不從。如果把年干甲財換成丙殺，丙的得分 = −75/100 × 45 × (1 + 0.3 + 0.125 × 0.4) = −45.6，原本甲是 −28.4，時支未透出到甲的增值 −1.5 也要扣除，負能增加 45.6 − 28.4 − 1.5 = 15.7，總分變成 −(197.4 + 15.7) = **−213.1**，這樣就可能變成從弱。
- **示範規則**：用「改一字」的方法試探界線，看界線是不是在 −210 附近。

### 命例：白韻琴（書頁 159–161）
- **四柱**：甲申　壬申　戊辰　辛酉（1944 年生）
- **大運**：52 辛未、62 庚午、72 己巳、82 戊辰、92 丁卯、02 丙寅、12 乙丑
- **出處**：羅量《點算八字格局》，評為從兒格。
- **經歷**：79 年完成美國大學學士、碩士課程後回港，在電台主持節目「盡訴心中情」走紅，九十年代中期停播。77 年入巳運，巳與局中酉合化金，火運變金運，又透辛干，是有力的泄身運。82 年入戊辰運，戊是旺身運，而辰與酉合化金，也是有力的泄身運。據說七十年代初期正行己運時離婚，己與甲合化土，是旺身土運；女命離婚應在惡運，可以印證從弱。
- **沖合處理**：辰酉合化金。按精算法，酉化成 1 個金，辰化成 0.8 個金，還剩 0.2 個辰的餘氣。干根在原辰（餘氣）的，增值再乘 0.2；根在辰化金的，增值再乘 0.8。
- **得分表**

| 項目 | 得分 |
|---|---|
| 年干 甲（官） | −34.3 |
| 月干 壬（財） | −41.1 |
| 時干 辛（食） | −52.3 |
| **天干總得分** | **−127.7** |
| 月令 申（庚食 −29.3、戊比 +25、壬財 −22.5） | −26.8 |
| 年支 申 | −10.3 |
| 日支 辰（化金 0.8、餘氣 0.2） | −27.3 |
| 時支 酉（化金） | −33.8 |
| **地支總得分** | **−71.4** |
| **命局總得分** | **−225.9** |

- **結論**：從弱（從兒）。
- **示範規則**：合化局的「化成量」與「餘氣」怎樣分配得根係數。

### 界線結論（書頁 161）
- P 先生 −197.4 不從，白韻琴 −225.9 從弱，界線大概在正負 200 至 220 之間。
- 白韻琴局的得透多，負能增加不少，所以作者估計**真正的界線是 ±210**：

| 命局總得分 | 判定 |
|---|---|
| > +210 | 從強（專旺／從印） |
| −210 至 +210 | 正格（身強或身弱） |
| < −210 | 從弱（從兒／從財／從殺） |

- 八字七個位置的分值總和是 400，界線大約在一半多一點，作者認為合理。
- **以十神力量分析各種從格**：
  - 從兒最難成格。食傷分值低，除非碰上三合、三會或得透得令，否則天干見一比或一印有根就很難從。
  - 從殺較易成格。官殺分值高，如果天干二殺見地支二殺及月令，彼此強烈呼應、得透增值很大，就算有二三個非專氣的逆黨也可能從殺。
  - 從強（印比）分值都大，比較容易成格。有三合或三會成化，就不怕二三個逆黨。

### 命例：W 先生（書頁 162–164）
- **四柱**：戊戌　庚申　辛巳　辛卯（1958 年生）
- **大運**：60 辛酉、70 壬戌、80 癸亥、90 甲子、00 乙丑、10 丙寅、20 丁卯
- **背景**：母親早年請算命先生推算，批為正格身強、用木火，於是替他改了帶木、火字旁的名字。
- **沖合處理**：地支巳申合而不化，二支得分要 ×0.52；天干得根在申、巳二支的，增值也再乘 0.52。
- **得分表**

| 項目 | 得分 |
|---|---|
| 年干 戊（印）墓根在戌 | +48.3 |
| 月干 庚（比）祿根在申 | +77.7 |
| 時干 辛（比） | +62.9 |
| **天干總得分** | **+188.9** |
| 月令 申（祿 +52、庚 +20.8、戊 +4.2、壬 0） | +77 |
| 日支 巳 | +9.7 |
| 年支 戌 | +36.7 |
| 時支 卯（乙財） | −30 |
| **地支總得分** | **+16.4** |
| **命局總得分** | **+282** |

- **結論**：超過界線，屬從強（專旺），用土金，忌木火。
- **經歷驗證**：75 年入戌運，戌與卯合而不化，仍能生旺日元；76 年會考獲 4A，78 年考進港大。95 年入子運，轉到名校任科主任，並在補習學校兼職。00 年入乙運，乙與庚合化金，又在月令得祿根，木運變成很有力的金運，是大吉運，同年全職轉到補習學校，收入倍增。05 年入丑運，丑中辛金在月干、時干雙透，是生旺運，逐漸成為補習天王。
- 時干辛是辛日的學堂星，在月令得祿根，力量大而且是用神，所以一生在學校任教。
- **示範規則**：合而不化 ×0.52 的應用；說明「二印三比、地支巳火剋金、卯木耗金」不一定妨礙成專旺，要看總分。

# 第七篇　精算算命顯神通（書頁 165–195）

## 案例一：男命（書頁 166–167）
- **四柱**：壬申　壬寅　壬午　甲辰（古人命例，出自《滴天髓》）
- **大運**：癸卯、甲辰、乙巳、丙午、丁未、戊申、己酉
- **沖合處理**：寅申相沖、寅午半合不化。按沖合論，長生沖勝過半合不化，所以寅申相沖成立。寅中主氣甲與申中主氣庚相沖，二氣都化為零；寅中旁氣丙與申中旁氣壬相沖，二氣也化為零。寅、申都只剩戊旁氣。天干二壬不能得微根在申，時干甲也不能得祿根在寅。
- **得分表**

| 項目 | 得分 |
|---|---|
| 壬（比，位調 45）微根在辰 | +47.3 |
| 壬（比，位調 55）微根在辰 | +59.1 |
| 甲（食）微根在辰 | −25.3 |
| **天干總得分** | **+81.1** |
| 月令 寅（只剩戊殺） | −18.8 |
| 年支 申（戊殺 −8.4，庚、壬為 0） | −8.4 |
| 日支 午（丁財 −20.8、己官 −15.3） | −36.1 |
| 時支 辰（戊 −18.8、乙 −8.4、癸 +18.8） | −8.4 |
| **地支總得分** | **−52.9** |
| **命局總得分** | **+9** |

- **結論**：小身強，用木火土，忌金水。據說命主是古代高官，運行木火，在乙運發跡，官運亨通，位至宰相；到申運不祿（不再做官）。
- **示範規則**：長生相沖時主氣與旁氣分別相沖、同時歸零；沖後干不得根。只有 +9，很難靠經驗判斷。

## 案例二：假從女命（書頁 168–170）
- **四柱**：丁未　丙午　辛未　庚寅（1967 年生）
- **大運**：68 丁未、78 戊申、88 己酉、98 庚戌、08 辛亥、18 壬子
- **出處**：易天生《子平辯證》。原書認為滿盤官殺，是從殺格，用木火、忌土金。命主自述的經歷是：父親是生意人，出生後環境轉差，仍屬小康；戊申運留學外國；酉運大賺千萬；庚運仍然賺錢；戌運被丈夫倒財千萬，自己被降職；戌運離婚，新丈夫性格暴躁。
- 作者指出命主在酉、庚二金運發跡，到戌運（與局中寅午三合化火）大破，顯然是正格身弱，不是從殺。
- **沖合分析**
  - 地支有三個合局：寅午半合，午未有兩個六合。
  - 兩個性質相同的合力量可以累加，形成「未午未」夾合局。每個六合讓每個支各產生 0.48 個五行合力，一個六合的總能量是 0.96，兩個六合是 **1.92**。
  - 寅午隔一位半合化局，五行能量總和只有 **1.88**，比不上未午未的 1.92，所以寅午半合化不能成立。
  - 午被二未夾住，按精算五行力對夾合的量化分析，午只剩原本分數的 **0.04**，局中負能也就不足以成為從殺格。
  - 月令午無氣，辛日元天干被二殺剋，地支見二未，看似得地。但未支生旺日元的能力有限（+6），未中丁火又雙透年、月二干，二未剋耗日元的力量其實多於生旺。總分約 **−63**，正格身弱，用土金，忌水木火。
- **大運解讀**：酉、庚二運是比劫幫身（身弱比劫為財），大賺千萬。戌運入局，與寅午三合化火。三合化局能量總和是 **3.44** 個專氣五行力，遠超過未午未的 1.92，三合化火可以成立；午被沖出夾合牢籠化成大火，熔化弱金，破財難免。08 年入辛運，雖然與丙合而不化、力量有損，仍算吉運，比戌運好很多。
- **作者列出的誤判原因**
  1. 午未不能合化成火。午未合化是成土，只是略帶火氣，所以叫火土；其引化之神是土。
  2. 一支不能同時支持兩個以上的合化。寅午半合只是有條件成化，但被兩個六合疊加局逼退。
  3. 月令午被二未夾合，很容易被忽略；合力能否擊退寅午半合，要靠沖合論和精算才能判斷。
  4. 如果寅午合化成立，天干丙丁二殺與地支化局互相呼應，就可以從殺；但午被夾死，從殺不成。
- 女命丙丁官殺二透、官殺混雜，婚運本來就不佳，加上官殺是忌神，所以前夫倒財、新夫暴躁。
- **示範規則**：同性質合力可累加（夾合）；半合 1.88、雙六合 1.92、三合 3.44 的能量比較；被夾合的支只剩 0.04。

## 案例三：N 女士（書頁 171–173）
- **四柱**：甲子　乙亥　壬戌　乙巳（1984 年生）
- **大運**：90 甲戌、00 癸酉、10 壬申、20 辛未、30 庚午
- **初判**：壬日元在亥月得祿得令，天干見三食盡失，地支比、官、財各一，一得一失，應是身弱。不過子是祿神，得分很高，或許能扭轉形勢。
- **沖合處理**
  - 巳亥隔一位相沖，是 75% 的相沖，受沖的支氣得分 ×0.75。
  - 亥中甲氣佔 0.37，其中受沖的只有 0.25（份量相當的部份）。受沖後剩 0.25 × 0.75 = 0.188，加上未受沖的 0.12，共 0.308。0.308 / 0.37 = **0.83**，所以天干乙得中根在亥的，增值也要再乘 0.83。

## 案例七：阿儀女士（書頁 183–186）
- **四柱**：戊子　丙辰　戊子　庚申（以大運 1957 起運推算，1948 年生）

- **推算步驟**
  1. 先假設天干有化神。日、月、時的子辰申可先合化成水：日支子化成 1.4 個水，申、辰各化成 1.02 個水。此化局可繼續與年支子合化，彼此提升水氣。

  5. 假設全部合化，二子各 1.8、其他二支各 1.2，全局水專氣共 6 個。
  6. 三合不化時，水氣只提升到化局的五、六成；本局有兩個三合不化，提升程度應較高，取六成：6 × 0.6 = **3.6** 個水。

- **其他論斷**：年柱為正官坐正財，應是出身名門；事實上祖上原是當地大戶，因政治變革而家道衰落。夫星為丙，既坐長生，又在日支得祿根，祿根受沖有損但仍有力；夫星得令是用神，可望嫁得貴夫。夫宮雖受沖，但有寅亥六合牽制沖力，問題不大。13 癸巳年夫星透出，嫁給一名小商人，夫婿以兩人名義在上海購置婚房。
- **10 年入酉運的四連環**：酉入局與時支卯相沖，又與日支巳半合化金，同時巳亥相沖、亥寅合而不化，形成「四連環」。酉巳化局的兩頭被卯酉沖局及巳亥沖局扯破；巳亥沖局的兩頭又被酉巳化局及寅亥合局牽制。互相扣住，四個沖合局都不能成立。酉運入局後仍然是酉，並在局中透干，是身弱命的大吉運；入酉運後不久便升為分店經理，並結識富貴的丈夫。
- **示範規則**：六合緩沖的量化（合力 0.48 抵消斥力 0.75）；連環沖合局互相牽制都不成立。

## 7.10 量化分析就是嚴謹求證（書頁 194）
- 以上九例，不必知道命主經歷也能準確判斷，靠的是嚴謹分析與求證，作者不相信算命神仙。

# 第八篇　大運（書頁 196–218）

## 8.1 大運與歲運的分值（書頁 197–198）

**重點**
- 大運一字掌五年，歲運掌一年。大運影響較大，力量應比歲運大。
- 大運的份量不應小於八字局中除月令外的干支。月令分值是其他干支平均的兩倍，所以大運分值也約是歲運的兩倍。歲運由一干一支組成，干支相加的分值應略高於大運的一半。
- 某年的運程 = 當值大運入局的剋應 + 歲運入局的剋應。

| 項目 | 基本分值 | 佔比 |
|---|---|---|
| 大運（當值的干或支，一字） | 60 | 60% |
| 歲運干 | 20 | 20% |
| 歲運支 | 20 | 20% |
| **某年運程合計** | **100** | 100% |

- **位調計算**：大運位調 = 本分 × 60/100，例如食神 −45 → −27。歲運干支位調 = 本分 × 20/100，例如官 −75 → −15。
- 一般情況下，大運起主導作用。大運吉、歲運惡，年運仍然吉，只是減吉而已；反之亦然。
- 大運值大（得根、透干或合化得成），可以完全主導五年，歲運難與之匹敵。
- 大運值小（例如支運受局中專氣相沖，力量化零），就算是好運也枉然，這五年只能看歲運。
- 十年干支大運間的生剋會對干運或支運有一定影響。例如庚戌運：庚為好運，戌生庚、庚得令，此運更佳。又如丁亥運：丁為惡運，受亥所剋、丁失令，惡得有限。不過干支之間的生剋之情不可量化。
- 運程有累進效果：差的命連行 10–20 年好運也不會太差；好的命連行 10–20 年厄運，際遇也難佳。

## 8.2 大運之剋應及衡量（書頁 197）
- **身弱命**：大運給正能量就是好運，分值越大越佳；給負能量就是惡運，分值越大越差，分值較低時程度減少。
- **身強命**：大運給負能量是好運，給正能量是惡運。
- 大運得根或透干都會大顯威力，吉運大吉，惡運大惡。
- 要特別留意大運的合化：合化會影響原局得分，令命身強弱產生一定程度的變化。大運入局三合或三會成化，影響更大，往往不是大好運就是大厄運。

## 8.3 大運不可改變命身強弱的本質（書頁 199）
- 大運量化主要考慮威力大小，即生旺或抑制日元命局的能力；大運不能改變原局命身的本質。
- 大運得分對命局的影響是相對的，不是累加的。命局 −50，大運正能再大也不會把命局變成正數。命身的強弱性質一旦生成就不可改變；如果改變了，此命也就不是此命，等於命局已不存在。

## 8.4 大運入局沖擊命身之相對關係：R 值（書頁 199–201）

**公式**

> 設命局總得分為 M，大運（運程）得分為 L，L 對 M 的影響為 R：
>
> **R = L / √(M² + L²)**
>
> 運後的命局狀態：**M′ = M × (1 − R)**（M 為正）／ **M′ = M × (1 + R)**（M 為負，見下例）

| 情況 | M | L | R | M′ | 解讀 |
|---|---|---|---|---|---|
| 身強遇負運 | +100 | −50 | −50 / 112 = −0.45 | 0.55M = +55 | 身強之氣減低 45%，是吉運 |
| 身弱遇負運 | −100 | −50 | −0.45 | M(1 − (−0.45)) = 1.45M = −145 | 身弱之氣再弱 45%，是惡運 |

**R 值的性質與判讀**
- R 的正負與 L 一致；L 再高，|R| 也不超過 1。所以就算 M 很小、大運很大，也不能把 M 由負變正或由正變負，改變不了命身強弱的本質。
- R 越接近 1，對命主的剋應越厲害，不是大吉運就是大惡運；R 越接近 0，此運對命主幾乎沒有影響。
- 原局總得分越接近零，大運分值相對原局就越大，R 值也非常接近 1。如果局中五行流通不佳，命運容易大起大落；五行流通無阻的話，反而不怕逆運。五行流通的命局總分應較低或接近零，但總分接近零的命局不一定五行流通。
- 原局得分越大（命主身極強或極弱），就要靠大運補救；大運的反分值越大，R 值越大，運也越佳。

| R 值（吉運方向） | 意義 |
|---|---|
| > 0.5 | 很不錯的運程 |
| > 0.6 | 命主機遇可有明顯突破 |

- 命局總得分超過 120，就不是很好的命局。一是局中五行太過偏側一邊、流通有礙，日元難以舒展得順；二是較難遇上 R 值 > 0.5 或 0.6 的吉運，事業較難有好發展。例外是女命：只要夫星透出得根並為用神，就是好命，可嫁得貴夫，自己無甚發展也可得美滿生活。

## 8.5 大運之剋應（書頁 201）
- 吉凶剋應並非絕對。例如用金水、忌火土的命行申運，是吉運，但不代表期間不會遇上不愉快的事。申含庚壬戊，庚壬之氣令命主舒暢，但戊土是惡，也會搞局；整體雖好，可能仍有波折。遇上庚運較佳，因為庚中沒有雜氣，金氣得分也較申高；但庚運期間仍可能碰上火土歲運，也不一定一帆風順。
- 紫微斗數可以補充八字：大運輪轉時，十二宮的剋應不一樣，事業佳不等於財運佳，財運佳也可能健康出問題。
- 不要以為行吉運就甚麼事情都可成功。陳振聰是風水師，可能評估自己在行吉運，便妄想併吞龔家千億財產；但他可能沒有推算清楚所行吉運的 R 值是否足以推動千億之財，以及命身能否承受得起。

## 8.6 大運入局：量化推算注意事項（書頁 202–207）

1. **大運入局的性質**：大運游走於局中四柱之間。大運與局中干支的得透互動，都按「同柱」處理；大運與局中任何干支的沖、合、合化，都按「相互緊貼」處理。
2. **大運入局之得根或透干**：干運入局，在局中任何地支得根，都按「直坐」處理。在局中得祿根，增值是其原本分數的 **0.5**，其他得根情況類推。支運入局透出在局中任何天干，也按同柱處理，增值為原本分數的 **0.5**。
3. **大運干支依次入局**：例如十年辛巳運，辛掌前五年，巳掌後五年。辛運當值時巳運還在局外，巳運入局時辛運已出局。雖然有時要把十年干支一起看（例如四柱伏吟、天沖地沖之運），但干支並非同時入局，一般可以獨立考慮；干運與支運之間只有化學影響，沒有量化影響。
4. **歲運干支同時入局**：一柱歲運的干支同時入局，不能以為歲干掌上半年、歲支掌下半年。甲子年就是甲年，也是子年。某年的運程 = 當值大運（干或支）+ 歲運干支一柱。
5. **大運與歲運之間的得根透干**：
   - 十年大運的運干不可得根在運支，運支也不可透出在運干（因為兩者依次入局）。例如辛巳運，辛不可得根在巳運；巳中庚氣也不可透出在辛運。
   - 運干可以得根在歲運地支，運支也可以透出在歲運天干。
   - 歲運干支同時入局，所以歲干可得根在歲支，也可得根在當值入局的大運支；歲支可透出在歲干，也可透出在當值入局的大運干。例如行辛巳運時遇丁酉年：酉可透在辛運；但丁不可得根在巳運，因為巳運還沒入局。
6. **大運入局與局中干支合化及其合化條件**：例如甲運入局見局中己，甲己可合化成土，木運變土運。不過合化條件與原局正常合化沒有分別：運干與局中天干合化，要看月令是否有化神，以及月令主氣是否剋制合化之五行；運支與局中地支合化，要看天干是否有化神，以及月令主氣是否剋制合化之五行。條件符合的話，大運的運干或運支也可以與歲運干支合化。
   - 大運入局的運干或歲干，可以作為歲支與原局地支合化的化神；但大運入局的運支或歲支，不可作為歲干與原局天干合化的化神，因為天干合化都看月令支氣為化神。未入局或已出局的大運干支，也不可作為合化之神。
   - 有些書說十年大運的運支可作運干與局中天干合化的化神，作者認為沒有道理：一是干支不是同時入局，二是所有天干合化看的是月令支氣，大運也不例外。
7. **大運被合**：大運入局與局中干支形成天干五合或地支六合，**合而不化**，大運得分 **×0.52**，力量仍有約五成。吉運減吉、惡運減惡，但仍然是吉運或惡運；流年歲運的影響力相對較大。坊間以「大運被合為平運」，是忽略了大運本身的價值，也不懂相合的力量本質。
   - 大運入局遇上**半合不化**：得分不用扣減。
   - 遇上**三合或三會不化**：相關五行專氣的力量可有所提升。
8. **大運受沖**：
   - 干運與原局某干相沖：得分 **×0.5**。
   - 支運與局中某支相沖，按相沖性質處理：專氣相沖，支運力量化零；長生相沖，只剩其土旁氣；墓庫相沖，只剩其主氣。
   - 大運受沖，力量損耗嚴重，歲運可當道。惡運受沖，惡難為；但要看此運是否也沖及局中用神或提綱（月令）。惡運與月令喜神相沖，惡雖然難為，局中用神嚴重受損也是大問題。
9. **大運入局之沖合變化**（按沖合論定律處理）：
   - 申運入局，見原局子及巳，天干不見水：申子半合不化、申巳六合亦不化；申子半合力量勝過申巳六合，按申子半合論。申子半合是專氣之合，申運得分不用扣減。
   - 丑運入局，原局地支申子緊貼合而不化：丑運亦與子合而不化，但申子合力勝丑，子被申合住，故子合不了丑運，丑運得分不用扣減。
   - 巳運入局，原局地支巳酉半合化金：原局巳化金後，酉仍是酉，可與巳運繼續合化，最後巳運也化為金，火運變金運。
   - 戌運入局，地支卯酉緊貼相沖：卯酉沖力勝過戌卯相合，按沖論，卯戌合力已被消弱，戌運得分不用扣減。
   - 子運入局，見地支午及丑：子午相沖本應化零，但子丑六合的合力可緩和相沖之力，按沖合並見精算處理。子運力量雖有損耗，但不會化零，仍有一定力量。
10. **干運之二次合化**：干運入局如遇上局中年月天干合化，可能產生第二次合化。根據沖合論，專氣可作第二次合化；天干都是純粹的五行專氣，所以天干也可如地支般進行第二次合化。原局不會發生這種情況，因為日元不受合化。只有兩種情況：
    - 乙運遇上原局年月干乙庚合化金：乙運也與局中庚干合化金，木運變金運。
    - 甲運遇上原局年月干甲己合化土：甲運可與局中己干合化土，木運變土運。
    - 除此之外，其他干運入局遇上局中年月天干合化，均不可再合化。例如丙運入局遇上局中年月干丙辛合化為水，由於局中之辛已化為水，不能再與丙運合化，丙運仍然是丙運，沒有變化。
11. **大運與日元**：干運入局與日元相沖或相合，干運得分不用扣減，因為日元能量為零，不會與干運發生能量互動。不過化學變化仍然存在：干運入局與日元相沖，干運力量雖無損，但日元受沖，命主在該運期間會變得較衝動，易有不智行為；就算此運可用也要注意，如果是惡運就更要小心。

**其他留意事項（書頁 207）**
1. 天沖地沖之年對大運的影響：天沖地沖六十歲前總會遇上，同時沖擊日主及其根基，就算在好運期間也要注意。
2. 大運交接時，有時會出現後運接不上前運，就像接力賽交棒時出現紕漏。前運已衰弱而後運尚未發揮時，歲運有機會當道。這種情況不常出現，但值得留意。
3. 也要留意歲運沖大運、歲運合大運的影響。尤其大運本身分值不高時，再受歲運沖合，大運的力量就所餘無幾了。

## 8.7 大運的推算（書頁 207）
某年運程 = 當值大運 + 歲運：大運基本分值 60，歲運基本分值 40（干、支各 20）。

### 案例：張靚穎成名之運（書頁 208–209）
- **四柱**：甲子　甲戌　戊寅　丁巳（1984 年生）
- **大運**：85 癸酉、95 壬申、05 辛未、15 庚午
- **事件**：05 年參加「超級女聲」獲季軍，聲名鵲起，成名於辛運乙酉年。命局身強，可用金水木，忌火土。命局總得分 M = **+57**。
- **推算**：歲運乙干入局與當值辛運相沖，二干運得分都 ×0.5。

| 項目 | 計算 | 得分 |
|---|---|---|
| 大運 辛（食）：本分 −45，位調 −45/100 × 60 = −27；乙辛沖 −27 × 0.5 = −13.5 | 微根月戌 −13.5 × 0.125 = −1.7；微根時巳 −1.7；祿根歲酉 −13.5 × 0.5 = −6.8 | **−23.7** |
| 歲干 乙（官）：本分 −75，位調 −75/100 × 20 = −15；乙辛沖 −15 × 0.5 = −7.5 | 祿根日寅 −7.5 × 0.5 = −3.8 | −11.3 |
| 歲支 酉（傷）：本分 −45，位調 −9 | 透干辛 −9 × 0.5 = −4.5 | −13.5 |
| 歲運得分 | | **−24.8** |
| **運程總得分 L** | −23.7 − 24.8 | **−48.5** |

- **R 值**：0.65，大大的好運年。乙酉年歲干乙與辛運相沖，辛運力量受損，幸好整體歲運得分不錯，助命主踏上成名之旅。離開乙酉年後辛運力量逐漸恢復，此後幾年的成就竟然超越當年超女的冠亞軍。
- **示範規則**：運干受歲干沖 ×0.5；運干可得根於局中地支及歲支；歲支透出在運干按同柱 0.5。

### 案例：許瑋倫出事之運（書頁 210–212）
- **四柱**：戊午　癸亥　己卯　戊辰（1978 年生，台灣明星）
- **大運**：80 壬戌、90 辛酉、00 庚申
- **事件**：03 年因拍廣告進入娛樂圈，之後逐漸走紅，06 丙戌年尾遇車禍喪生。出處是羅量《點算八字用神》，羅師父推算命主身強，用金水，忌火土；00 年入庚申吉運，06 年仍在申吉運中，所以問題應出在丙戌歲運。作者的疑問是：大運佔六成、歲運佔四成，大運若真是吉運，歲運再差也不至於出這麼大的問題。
- **命局總得分** M ≈ **+21**，身強，用金水木，忌火土。
- **申運得分**

  1. 庚是申的主氣，佔 0.5，比位調 = −45 × 0.5 / 100 × 60 = −13.5，其他類推。
  2. 原局年月干戊癸合而不化，二干得分 ×0.52；支氣透出在這兩干的，增值也乘此比例。
  3. 申中庚氣透出在運干（庚）不能增值，因為申運入局時庚運已出局。
- 這個申運表面上是泄耗強身的金吉運，實際上旁氣戊土雙透，力量竟比主氣金及旁氣水相加還強，是生旺強身的土惡運，只是很微小。這種情況下，歲運可以當道。

- **結論**：出事的主因確實在歲運，但不應在未完全剖析大運前就以歲運論運程。此案的申運實際上並非吉運，才會讓惡年當道；若申確為吉運，稍有泄耗之力就可把歲運的生旺之能稍為抵消，命主亦未必會出這麼大的事故。

- **示範規則**：支運主氣被旁氣透干逆轉（呼應第七篇誤區 6）；大運微弱時歲運當道；原局合而不化 ×0.52 也適用於大運透干的增值。

### 案例：意外凶死男命出事之運（書頁 213–214）
- **四柱**：癸巳　丙辰　甲午　乙丑
- **大運**：56 乙卯、66 甲寅、76 癸丑、86 壬子
- **事件**：在《量化算命顯神通》篇（上冊）提過，命局總得分 M = **+5.4**，命主出事於子運甲戌年。
- **沖合情況**
  - 子運入局與月令辰半合化水，但被月令主氣所剋，不可合化。子運也與日支午相沖，與時支丑合而不化。
  - 歲支戌入局雖與月令相沖，但也與日支午半合化火。
  - 綜合來看，歲支戌牽制住午支，加上子運被辰、丑二支合留，子午相沖肯定不能成立。歲支戌入局按戌午半合化火論；子運入局按子辰半合論，因子辰半合強於子丑六合。這樣，歲支戌變成火，子運仍為子水。

| 項目 | 計算 | 得分 |
|---|---|---|
| 大運 子（癸印）本分 +80，比位調 +48 | 透干年癸 +48 × 0.5 = +24 | **+72** |
| 歲干 甲（比）本分書上印 +80，但比調 +20 = 100 × 20%，應為 +100 的誤植 | 微根月辰 +20 × 0.125 = +2.5 | +22.5 |
| 歲支 戌（化火，食）本分 −45，比調 −9 | 透干月丙 −9 × 0.5 = −4.5 | −13.5 |
| 歲運得分 | | +9 |
| **運程總得分 L** | +72 + 9 | **+81** |

- **結論**：這個運程得分對普通身強之人已是大大的惡運，何況命主只有 +5.4。R 值達 **0.99**，出事有因。局中丙干及午巳二支佔了剋耗日元負能的全部，負能量完全偏側於火；總分雖然只有 +5.4，卻並非五行流通之局。非五行流通的低分值命局，的確較易受到大運沖擊。
- 大運入局有時會與局中干支出現多沖合並見的情況，需要小心判斷，應根據沖合論原理處理。

## 8.8 大運之分析歸納（書頁 216）
1. 先看大運的十神性質：印比、殺印力量較大，食財力量較小；沖合會減低其力，得根透干則增其力。
2. 大運力量宏大時，歲運可以較為忽略。例如遇上大吉運，五年內必有應時；五年十字干支不太可能全是逆運，大吉運遇上吉年就如虎添翼，運程可有突破。
3. 大運力量微弱時，歲運影響力可以主導，要更加留意歲運。
4. 必須留意支運旁氣透出的情況，不要完全被支運的主氣蒙蔽。

## 8.9 大運可否引化原局質變（書頁 216–218）
- 問題：大運入局得分對原局的影響是相對的，力量再強也不能改變命身強弱的本質。但大運入局是否可能因與原局沖合，令原局總得分產生巨變，導致命身強弱轉向？

**示例：X 乙 丙 X（書頁 217）**
- **四柱**：X戌　丙申　乙X　X午（書上只給部份干支，X 為省略）
- 地支午戌半合化火，丙干等於得二祿根，簡化推算得分 −42。乙日元身弱，設命局總得分 −60。遇上大運辛，辛運入局可與丙干合化成水，丙財化水印，丙在原局的得分從 −42 變成 +49.5，原局得分增加 91 分。命身會否因此由弱變強？堅強的堡壘真的可從內部攻破嗎？若命身由弱變強，辛化水之運本是吉運，卻會變成惡運。

**再看假從女命（第七篇案例二，書頁 217–218）**
- **四柱**：丁未　丙午　辛未　庚寅
- **大運**：1968 丁未、78 戊申、88 己酉、98 庚戌、08 辛亥、18 壬子
- 命局總得分 −63，實為身弱。分析她從月賺十多萬元的庚吉運到倒財千萬的戌惡運：

| 大運 | 合化 | 十神 | 本分 | 比位調 | 總分 | R 值 |
|---|---|---|---|---|---|---|
| 庚 | — | 比 | +100 | +60 | **+60** | **+0.69**（大大的吉運） |
| 戌 | 寅午戌三合化火 | 殺 | −75 | −45；透干在丙 −45 × 0.5 = −22.5；透干在丁 −22.5 | **−90** | **−0.82**（真惡運） |

- 戌運入局與寅午三合化火，點燃原局大火燒身，令身弱命主更弱，對命主負面影響很大。
- **關鍵論證**：戌運與寅午三合成化，三合化局力量宏大，遠勝二未夾午之合，讓午可以沖出二未夾合牢籠而成化。按精算法，局中午化為 1.4 個火，原局出現極大變化，總分在 −250 以上，從殺無疑。如果大運可以點化原局變化，此局就會變成從殺格，應用水木火、忌土金；照此說法，化火的戌運應是吉運而非惡運。但命主在戌運中倒財千萬，戌運肯定是大惡運，所以「大運可點化原局質變」的理論難以成立。
- **結論**：大運雖可點化原局個別干支的質變，但對原局得分的影響仍然是相對的，不會導致命身強弱轉向。命身的強弱，或從強、從弱，是其本質與基因，一旦生成就終身不可改變；如果真的出現改變，命局就應不再存在，或稱破局。

## 本段小結

1. **從格界線是 ±210**。命局總得分超過 +210 為從強（專旺、從印），低於 −210 為從弱（從兒、從財、從殺），兩者之間為正格。七個位置分值總和是 400，界線大約在一半多一點。
2. **從格只分從強與從弱**，日元五行性質永不改變。從兒最難成（食傷只有 −45），從殺較易（官殺 −75，得透呼應增值大），三合或三會成化的從強不怕二三個逆黨。
3. **沖合量化的關鍵係數**：
   - 合而不化 ×0.52；六合每支 0.48 合力；夾合中的支只剩 0.04。
   - 能量比較：寅午半合 1.88 < 雙六合 1.92 < 三合 3.44。
   - 隔位支沖 75%（×0.75）；六合緩沖 0.75 − 0.48 → 受沖支氣 ×0.64。
   - 隔位干沖 ×0.875；日元能量為零，不參與合化，與日元沖合的干不扣分。
4. **三會與三合**：三會不化時，專氣及長生主氣提升到 1.45、墓庫相關氣提升到 0.5。三會化比（例：寅卯各化 2.1、辰化 1.05 個木），只要天干不與月令強烈呼應，必定身強。兩個三合不化局的專氣，以化局水平的六成估算。
5. **大運與歲運分值**：大運 60、歲干 20、歲支 20，合計 100。大運干支依次入局，歲運干支同時入局。大運被合 ×0.52，干運被沖 ×0.5；專氣支運受沖化零，長生受沖剩土旁氣，墓庫受沖剩主氣。大運入局的得根按直坐、透干按同柱，增值都是 0.5。
6. **R 值公式**：R = L / √(M² + L²)；M′ = M(1 − R)（M 為正）或 M(1 + R)（M 為負）。|R| < 1，大運不能改變命身強弱。R > 0.5 的吉運很不錯，> 0.6 可有明顯突破；R 達 0.8–0.9 的惡運要小心，但不一定出事。
7. **總分接近零但五行偏側的命局最怕大運沖擊**（凶死男命：M +5.4，R 0.99）；總分超過 120 的命局較難遇上高 R 值的吉運。
8. **不要只看支的主氣**：旁氣透干可以逆轉主氣之勢。許瑋倫的申運表面是金吉運，實際上戊土雙透，成了微小的土惡運，讓丙戌歲運當道。
9. **大運不能引化原局質變**：大運可點化個別干支，但對原局得分的影響是相對的。命身強弱與從強從弱是終身不變的基因，假從女命的戌運就是反證。
10. **常見誤區**：巳可生金、寅可生土、丑可生水；官殺剋身比食傷泄身重六成多；一支不能同時支持多個合化；沖與合的勝負要量化較量，不能一概而論。
