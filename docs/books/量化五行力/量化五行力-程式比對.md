## 不一致之處

依影響大小排序。「實測」表示已用程式實跑確認。

### A. 影響大的

**1. 大運入局的位置算錯（實測）**
- 書 p202：大運游走於四柱之間，與局中任何干支的得根透干一律按「同柱」（×0.5），與局中干支的沖、合一律按「緊貼」。
- 程式 `quant_model.rs:1996`、`:2011`：運干的 position_index 用 `stems.len()`，結果是 3，和時干同一格；運支是 4，只緊貼時支。
- 後果（實測 甲子 丁卯 己巳 丙寅 行庚申運）：運干庚與年干甲不算相沖（書應緊貼沖，二干各 ×0.5）；運干庚在巳得微根只給 ×0.1（書 0.125）；運支申透出運干只給 ×0.4（書 0.5）；運支申與日支巳被當成「隔柱合 ×0.9」（書應緊貼合）。運干和時干距離 0 時還會被當成可合。流年干支同樣問題。

**2. 大運對命局的影響用加法，不是書上的 R 值（實測讀碼）**
- 書 p199-200：R = L / √(M² + L²)；身強 M′ = M(1+R)，身弱 M′ = M(1−R)；大運不能讓命局由正變負。
- 程式 `quant_model.rs:1802-1803`、`ratio()` 在 `:5943`：`impact_ratio = L / |M|`，`effective_natal_score = M + L`，所以大運可以把命局翻號。`docs/quant-cases/014` 寫說 R 值已接上，實際沒有。

**3. 大運分值與「依次入局」（讀碼）**
- 書 p197-198、p202：大運一字掌五年，當值的那一字分值 60；歲運干支各 20、同時入局；運干不可得根於運支，運支也不可透出運干。
- 程式 `position_weight`（`:5249` 起）：運干 35、運支 25，而且干支同時放進同一盤一起裁決，運干運支之間會互相得根、透干（實測申透出運干庚）。

**4. 專氣支隔一位沖被扣兩次（實測）**
- 書 p45：子午卯酉隔一位相沖，二支各 ×0.75。
- 程式：沖合耗損 ×0.75（`branch_clash_score_multiplier`，`:5647`）之後，支氣折減 modifier 又 ×0.75（`build_branch_clash_qi_modifier`），兩者在 `:1665` 相乘，變成 ×0.5625。祿支路徑 `:1592` 也一樣。
- 實測 壬子 乙卯 庚午 丁丑：年支子 = −45×0.75×0.75，應為 −45×0.75。

**5. 長生沖、墓庫沖化零只按「同一個天干字」比對，陰陽不同就漏掉（實測）**
- 書 p20、p28：量化五行力不分陰陽，寅也是乙的祿根、申也是辛的祿根；p45-46：寅申緊貼沖時寅中甲丙化零、只剩戊。
- 程式 `build_branch_clash_qi_modifier`（`:4701` 起）只對「甲、丙」這種字設倍率，`branch_qi_multiplier`（`:5773`）查不到「乙」就回傳 1.0。
- 後果（實測）：
  - 乙丑 戊寅 壬申 辛丑：年干乙在被沖的寅仍得祿根 ×0.4；時干辛在被沖的申仍得祿根 ×0.4（書推論應為 0）。

**6. 中根倍率用成墓庫根的數字（實測）**
- 書 p29-30、p44：中根（午中己、亥中甲）0.185 / 0.148 / 0.111 / 0.074；墓庫根才是 0.25 系列。
- 程式 `root_multiplier`（`:5757`）把 Middle 和 Tomb 合併成 0.25/0.2/0.15/0.1。
- 書 p32 例（時干戊、年支午）：書 +53，程式 +54（中根 +4.0，書為 +3）。

### B. 合化條件與特殊沖合

**7. 天干五合化的條件太窄（實測）**
- 書 p99、p101：天干合化需月令有化神，主氣或旁氣都可以，且月令主氣不剋化神；月令若半合／六合化，化前支氣仍可當化神。
- 程式 `:3910`：只在「月令主氣五行 == 化神五行」時才化。
- 實測 丁亥 壬亥 丙戌 己丑：丁壬合木、月令亥（旁氣甲、主氣壬生木），書應可化，程式判合而不化。

**8. 三會化被月令擋掉（讀碼）**
- 書 p133：三會力量 5.25，月令剋不住，只要天干見化神就可化。
- 程式三會候選（`:3447`）用和半合、六合一樣的 `should_transform_branch_combination`，月令主氣剋化神就不化。

**9. 半合隔二位完全不考慮（讀碼）**
- 書 p130：半合隔二位仍可化（專氣支 1.0、另一支 0.5、餘氣 0.5）。
- 程式 `:3514` 距離大於 2 就跳過，`resolve_half_combination_factor` 裡隔二位的數值因此永遠用不到。

**10. 六合隔一位仍扣分（實測）**
- 書 p46、p128：六合屬偶合，隔一位之合不需理會。
- 程式 `:4293`：隔一位六合給 ×0.9（`:4291` 另有 ×0.85 的近合後備值），書上找不到來源。實測 甲子 丙寅 己丑 丙寅：子、丑各 ×0.9。

**11. 專氣支隔二位沖 ×0.89（讀碼）**
- 書 p45、p147：隔二位相沖可忽略；p148 總表也只有緊貼和隔一位兩欄。
- 程式 `:5652`、`:5663`：給 ×0.89，書上找不到來源。

**12. 天干隔一位沖只處理甲庚（讀碼）**
- 書 p147 簡化法：隔一位可忽略；p148 精算總表：干沖隔一位 0.25（即各 ×0.875），而且不限甲庚。
- 程式 `:5597-5601`：只有「月干與時干是甲庚」才 ×0.875，乙辛、丙壬、丁癸隔一位都不算。兩種做法擇一即可，但現在是混用。
- 同類：p146 天干合而不化又被隔位沖，書算 ×0.645；程式會變成 0.52×0.875。

**13. 六合不化逢沖（實測）**
- 書 p139：卯酉沖、辰酉合並見，以沖論，但合力緩沖，卯酉各 ×0.48，辰不變。
- 實測 癸辰 丁酉 癸卯 己未：程式卯 = 0、酉 = 0（0.52×0），辰 ×0.52。

**14. 三合化、三會化留了書上沒有的餘氣（讀碼＋實測）**
- 書 p132：三合、三會成化後，非專氣支沒有餘氣（三合非專氣支 1.02，三會墓庫支 1.05）。
- 程式 `:5551` 三合非專氣支留 0.08 餘氣、`:5563` 三會墓庫支留 0.2 餘氣，餘氣按原藏干比例計分，所以辰、申等會多出戊、庚、乙等非化神的分數，也能被天干拿去得根。數值小，但性質和書不同。

**15. 書上的不化提升與夾沖規則沒有實作（讀碼）**
- 書 p133-134：三合不化，專氣支 1.1、他支相關支氣 0.25→0.4；三會不化，專氣支與長生支 1.45、墓庫支相關支氣 0.5。
- 書 p145：左右夾沖專氣支，中支化零、兩側各 ×0.5。
- 程式裡搜不到這些數值（1.45、0.48、0.04、夾沖 ×0.5 都沒有），git 歷史也沒有出現過。`docs/quant-model-system-guide.md` §5.3 和 `docs/quant-cases/011`、`018` 寫成已實作，和程式不符。
