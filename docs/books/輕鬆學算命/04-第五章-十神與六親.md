# 第五章　八字的十神與六親（書第 157–187 頁）

> **這一章在講什麼**：十神（比肩、劫財、食神、傷官、偏財、正財、七殺、正官、偏印、正印）是八字最核心的語言。這一章作者先講十神怎麼來、代表哪些六親，再用很多生活例子講每個十神的「個性」和相關口訣（傷官見官、財多身弱、官多變鬼、殺無刃不顯……），中間穿插「算命的說話技巧」，還有作者自己年輕時連三年流年不順的親身例子。
>
> **這一章的讀法**：
> - 十神的**定義**很重要，一定要熟；十神的**個性描述**是作者的經驗談，可以幫你記，但不要當公式。
> - 每個十神都有好壞兩面，作者常常一句話講好的一面、下一句講壞的一面。讀的時候把它整理成「這個十神有用時怎樣、太多或被破壞時怎樣」。
> - **先提醒**：作者自己說子平八字論六親「不準」，只能看大略方向；夫妻宮看配偶胖瘦、美醜是民俗說法。
> - 這一章書上只有一個帶流年應事的命例（作者自己的八字，命盤見 01 檔），筆記整理在第二節「正官與七殺」後面。

## 一、十神怎麼來（第 157–160、185 頁）

### 1. 以日干為「我」，看生剋和陰陽

十神的推法只有兩步：先看那個字和日干是什麼五行關係（同我、我生、我剋、剋我、生我），再看陰陽是不是相同。

| 關係 | 同陰陽（陽見陽、陰見陰） | 不同陰陽 |
|---|---|---|
| 同我（同五行） | 比肩 | 劫財 |
| 我生 | 食神 | 傷官 |
| 我剋 | 偏財 | 正財 |
| 剋我 | 七殺（偏官） | 正官 |
| 生我 | 偏印（梟神、倒食） | 正印 |

舉例：日干甲木（陽木）。丙火是陽火，木生火、同陰陽 → 食神；丁火是陰火 → 傷官。戊土是陽土，木剋土、同陰陽 → 偏財；己土 → 正財。庚金剋甲、同陽 → 七殺；辛金 → 正官。壬水生甲、同陽 → 偏印；癸水 → 正印。

### 2. 作者用卜卦的叫法幫你記

作者先用六爻卜卦的五個名稱：**生我者父母、我生者子孫、剋我者官鬼、我剋者妻財、同我者兄弟**。這五個名稱本身就帶著六親的意思：生我的是父母（印）、我生的是子孫（食傷）、我剋的是妻子和錢（財）、剋我的是官和鬼（官殺）、和我一樣的是兄弟（比劫）。先記這五個大類，再分陰陽，就是十神。

### 3. 為什麼同性相剋比較凶

這本書沒有特別講這個道理，但《妙算人生八字》的林註講得很清楚，可以補在這裡：**陽剋陽、陰剋陰**（例如庚剋甲）沒有陰陽配合，是猛烈的剋，所以叫「七殺」；**陽剋陰、陰剋陽**（例如辛剋甲）像異性相吸，是有規矩的約束，所以叫「正官」。同樣地，日主去剋的字，異性是「正財」（穩定、有情），同性是「偏財」（要花大力氣去搶）。這個道理一懂，十神的個性就好記了。

作者自己的比喻也很好懂：**正官像警察，七殺像地痞流氓；正財是上班賺的錢，偏財是投機賺的錢**（六合彩、股票）。他還用台語說「軟阿錢」是偏財中的偏財——用不正當手段賺的錢。

## 二、每個十神的個性（作者的白話）

### 1. 食神與傷官（我生的）

食神、傷官都是日主「生出去」的東西，代表表達、才華、創造。差別在於食神溫和、傷官銳利。

| | 食神 | 傷官 |
|---|---|---|
| 個性 | 溫和、有口福、懂得吃、懂生活 | 有才氣、高傲、叛逆、有創作力 |
| 作者舉例 | 李小龍、作者自己（食神吐秀格），對五術有興趣 | 李白、杜甫；康有為（作者說是「水木傷官格」） |
| 口訣 | 「食神旺相，老壽彌高」：食神旺的人長壽（他舉彌勒佛） | 「傷官見官，為禍百端」；「傷官原是產業神，傷盡真是大貴人」 |
| 婚姻 | — | 傷官旺的人容易用「主人對僕人」的態度對待伴侶 |

**食神**：作者說命中有食神的人有口福，可以開飯店；食神吐秀格的人對中國五術（算命、卜卦、看相、中醫、針灸、武術）都很有興趣，也會有成就。他又說從算命這一行賺錢，要懂得吃，然後附了一份「七天高湯食譜」（星期一竹筍雞湯、星期二排骨海帶湯……）。這是本書的風格：命理之外，也教你過生活。

**傷官**：作者說命帶傷官的人恃才傲物，但有點才氣，詩詞歌賦都能來一點；叛逆性強，所以有創作精神。兩句口訣要記：
- 「**傷官見官，為禍百端**」：傷官剋正官，流年、大運、小限走到傷官（尤其原局有正官時），容易碰到麻煩、和上司或規矩起衝突。
- 「**傷官原是產業神，傷盡真是大貴人**」：作者解釋成命帶傷官的人懂得變化、很會賺錢（傷官生財）；「傷盡」他解釋成「取之不盡、用之不竭」。（多數古書的「傷盡」是指傷官被制盡或傷官洩盡官星的意思，作者的解釋比較口語化。）

**和其他書比較**：課堂把傷官格、食神格列為普通格局；《八字心訣》第一章有十神類象。本書的個性描述最生活化，但「傷盡」的解釋和古書不同，要知道。

### 2. 正財與偏財（我剋的）

作者說「財為養命之源」，是人的第二生命。這一段他講了很多理財觀念：不可隨便借錢、不可隨便投資；男人要會賺錢、女人要會理家；懂得賺錢也要懂得花錢的藝術，當守財奴是可悲的。

**財要先看庫**：這是作者很強調的一點。有財沒有庫（辰戌丑未），錢存不住；古書有「三財兩庫」「兩財一庫」的說法，**庫就是保險箱**。例如甲木以土為財，土本身就有庫的性質；水的庫是辰、火的庫是戌、木的庫是未、金的庫是丑。

**正財**：正當工作的錢。正財格的人誠實、行為檢點、比較節儉（作者說比較吝嗇）；以正財為用神的男命多得女性貴人幫助，結婚時太太會帶很多嫁妝來。作者還有一句「**財為馬、官為祿，二者缺一不可**」：只有錢沒有地位，或只有地位沒有錢，都不完整。

**偏財**：投機、意外之財。偏財旺的男命輕財好義、愛被奉承、喜歡說是非、喝酒、上花街柳巷；偏財旺的女命喜歡打扮、穿漂亮衣服、吃好東西。

**財多身弱喜比劫**：這是很重要的口訣。財很旺而日主很弱，要靠比劫（兄弟朋友）幫忙。作者的比喻很傳神：一個很有錢的富翁生病躺在床上，鈔票再多也享受不到，要找人幫他去買東西——那個人就是比劫。他說「健康就是財富」。

**食神生財**：作者說食神生財格的人懂得賺錢、懂得用錢，並說自己就是食神生財格。

**和其他書比較**：課堂講「財多身弱」時，用神取比劫或印，原則相同。「財要有庫」在《妙算人生八字》談財富篇也有，本書講得比較口語。

### 3. 正印與偏印（生我的）

**印沒有受傷 → 多得父母庇蔭**。作者把庇蔭分成有形的（遺產、不動產、黃金股票）和無形的（父母做善事積德、暗中保佑）。

**用神和個性**：作者說以正印為用神的人心地善良；以七殺為用神的人個性剛暴、不好駕馭；以食神為用神的人溫和；以傷官為用神的人恃才傲物。（這段書上的語氣有點不確定，當作經驗談。）

**正印和天德貴人一起出現 → 與佛有緣**，會吃素拜佛。

**以印為用神，走財運最不順**：財剋印，用神被破壞，「百事不能亨通」。這是很實用的規則：**用神被剋的運就是壞運**。

**偏印又叫梟神、倒食**：「倒食」是因為偏印剋食神（例如甲日，壬水偏印剋丙火食神），把你的「飯碗」打翻了。作者說偏印旺的人叛逆性很強；顏回貧困早逝、韓信被呂后殺害，都是遇到梟神的大運流年。他還講了曹操見匈奴使者的故事來說「梟雄」。

### 4. 正官與七殺（剋我的）

**正官**：天地的正氣，治國齊家的要道。以正官為用神的人大多在官場上有一番作為；作者還說了一句：所有六神之中，只有正官和七殺並存（官殺並見）可以大發富貴，也有算命先生「有殺只論殺」，專以官殺為用神論命。

**官多變鬼**：官星太多太旺，就變成「鬼」，做事太拘泥、沒有作為。要走正印的大運流年，官生印、印生身，平衡了才會有思想、有作為——作者說這叫「福至心靈」。反過來，福不至，心就不靈，下面作者自己的例子就是。

**七殺**：攻身之物。作者說命中七殺過旺無制，或走七殺運，身體容易受傷。

- 「**殺無刃不顯**」：七殺格要有羊刃撐住（逢殺看刃）。
- 七殺格的人叛逆、性急：古書說「七煞之勢壓三公，喜酒色而好爭鬥……性暴如虎、性急如風」。作者說七殺格的命要好好指點，指點得好能做大事，指點不好就成了社會上的米蟲。
- 七殺格最宜走**食神運**＝「**食神制殺**」。

**官殺混雜**：遇到官殺混雜，要用「調和、通關、制衡、生扶」的方法去安排，安排得宜這個人就有作為。作者也說男命官殺混雜個性不穩定（有時正派有時反派）；女命官殺混雜，作者說身邊一定有另一個男人——**這是古書式的斷語，帶有偏見，現代不宜這樣看人**；比較合理的理解是：女命以官殺為丈夫星，官殺並見表示感情上的選擇或壓力比較複雜。

**時上一位貴**：作者坦白說他原本以為「時上一位貴」是指時支遇到天乙貴人或天月德貴人，後來才知道是**時干只有一個七殺**，而且日主旺、七殺有制，就貴。古詩「時逢七殺是偏官，定作邊臣立大功，制伏得宜無缺陷，兵權赫赫真威風」。

**年上七殺不用制**：年是祖宗的位置，七殺在年像「祖父的老僕」，只要日主旺健，它會盡力服侍幼主；作者說這表示家裡還有一點錢或官位。第八章有一個年上七殺的命例（見 07 檔）。

#### 命例：錢老師連三年水流年、又逢梟神運（第 179–180 頁；命盤見 01 檔）

**書怎麼說**：作者講「福至心靈」時，拿自己當反例。他說自己的八字**用神是火**；民國 60、61、62 年是辛亥、壬子、癸丑，三個流年都是水，水剋火；這時大運正好在**庚**（偏印、梟神），再加上水的流年，「差一點活不下去」。那幾年學業沒完成、談戀愛不順、預備軍官沒考上、大學沒畢業，兩年的兵又當二等兵，身心壓力很大——這就是「福不至，心不靈」。作者接著說，市面上的算命書很多，但他還沒看過一本從算命角度談思想啟發的書。

四柱：庚寅年、丁亥月、壬申日、甲辰時（命盤見 01 檔）。
（大運：二歲上運，陽男順排：戊子、己丑、庚寅、辛卯……）

**一步一步看**

1. **先回顧原局**（01 檔有詳細分析）：壬水生亥月，日坐申，水很旺；時支辰是水庫；甲木、寅木是食神，丁火是正財。旺水靠木洩、靠火耗，所以作者說**用神是火**（月干丁火）。
2. **算出當時的大運**：作者生於庚寅年（民國 39 年），二歲上運，陽男順排：戊子（約 2–11 歲）、己丑（約 12–21 歲）、**庚寅（約 22–31 歲）**。民國 60–62 年作者虛歲 22–24 歲，正好剛交入庚寅運。
3. **大運的天干庚是什麼**：庚金是壬水的偏印，也就是**梟神**。原局的時干甲木是食神，庚剋甲——這正是本章說的「偏印又叫倒食」：**梟神把食神（作者引以為傲的「食神吐秀」）剋住了**。而且庚金生水，讓本來就旺的水更旺。
4. **流年辛亥（民國 60 年）**：辛是正印，又生水；亥是壬的祿，水更旺。亥和原局月支亥重疊，水勢加重。
5. **流年壬子（民國 61 年）**：壬是比肩，而且**流年壬會和月干丁火相合**——用神丁火被合走（「用神被合就慘了」）。地支子水和原局的申、辰湊成**申子辰三合水局**，水勢沖天。這一年應該是三年裡最重的。
6. **流年癸丑（民國 62 年）**：癸是劫財，**丁癸相沖**，直接剋用神丁火；丑和原局的亥，加上前一年的子，是亥子丑北方水的氣。
7. **合起來看**：大運的天干剋食神（洩秀的管道被堵住），三個流年連續加水、合火、剋火（用神被打擊），所以作者說那三年什麼都不順。這是「**用神被流年連續剋、大運又不幫忙**」的典型。
8. **之後會怎樣（筆記的推論，書上沒寫）**：庚寅運的地支寅是食神，寅還能和亥合木、生丁火；下一步辛卯運地支卯也是木。所以只要流年轉成木火，用神就有生機。書上沒有交代作者後來那幾年的情形，但從他三十歲以後到處教學算命來看，可以拿來和 App 的大運流年對照練習。

**學到什麼**：
- **用神被剋、被合的流年就是壞年**；連續幾年都這樣，影響會累積。
- 「偏印奪食」（梟神剋食神）不是抽象名詞：大運來一個偏印，原局的食神就受傷。
- 看流年時，要把流年和原局的合（丁壬）、沖（丁癸）、三合（申子辰）都找出來。

### 5. 比肩與劫財（同我的）

比劫在命局中的地位是**平衡日主**：日主太弱，或被官殺剋、被食傷洩、自己不斷賺錢花錢（財耗）而體力沒了的時候，就要請兄弟朋友來幫忙擋剋、擋洩、幫忙賺錢。所以比劫不一定壞。

作者用交朋友來比喻：「益者三友、損者三友」，有的朋友像米酒、有的像 XO；他還說「朋」字是兩個月亮比來比去。比劫多的人朋友多，但要分辨好壞。

**和其他書比較**：課堂說比劫和祿刃是一家（天干叫比肩劫財、地支叫祿刃），第八章作者也這樣說。比劫不取格（普通格局八格裡沒有比劫，祿刃另立建祿、陽刃格），見 07 檔。

## 三、十神與六親（第 163–166、185–187 頁）

### 1. 基本對照

| 十神 | 男命 | 女命 |
|---|---|---|
| 正印 | 母親 | 母親 |
| 偏印 | 祖父、庶母 | 庶母（繼母） |
| 偏財 | 父親、偏妻 | 父親 |
| 正財 | 妻子 | — |
| 正官 | 女兒 | 丈夫 |
| 七殺 | 兒子 | 偏夫（情人） |
| 食神 | （孫） | 女兒 |
| 傷官 | （祖母、孫女） | 兒子 |
| 比肩/劫財 | 兄弟姊妹 | 兄弟姊妹 |

道理和第一節的卜卦名稱一樣：生我的是父母（印）；男命我剋的是妻（財），剋我的是子女（官殺，因為子女是妻所生，財生官殺）；女命剋我的是丈夫（官殺），我生的是子女（食傷）。父親是偏財，因為父親是「正印（母親）的丈夫」——剋正印的就是偏財。

### 2. 作者的具體用法

作者舉甲日生的人為例：
- 甲以**癸水為正印（母親）**，從癸水在八字裡的狀況，可以看出母親慈祥不慈祥、長不長壽。作者還說從這個字也能看出母親有沒有別的男朋友，並說他統計一百位母親約百分之五有婚外情——**這種說法沒有根據，不要拿來斷人**。
- 甲以**戊土為偏財（父親）**，看戊土和整個八字的關係，可以看出父親的為人、壽命、對你的幫助。
- 甲以**己土為正財（太太）**：甲日生的人遇到己年（正財年），會有女朋友追；男命遇到流年、大運、小限是正財，都有女性暗中喜歡；**女命遇到正官運，一定有追求者**。

最後這一條很實用：**男看財、女看官**，財星、官星出現的年份，常常是感情事件發生的年份。《妙算人生八字》談戀愛時機也是用這個原則。

### 3. 本書附錄表的特別規則：用那個字的陰陽定男女

書末附錄的十神六親表，子女、兄弟的性別是**用那個字本身的陰陽決定**：陽干是男、陰干是女。例如男命的官殺是子女：剋我的字是陽干就是兒子、陰干就是女兒。所以附錄表要分「日主陰／陽」兩欄（同一個「七殺」，日主是陽干時七殺也是陽干＝兒子；日主是陰干時七殺也是陰干＝女兒）。

這和很多書「七殺＝兒子、正官＝女兒」的固定說法不一樣。更麻煩的是，本書第 166 頁的正文又寫「**七殺為男孩、食神為女孩**」（女命食神吐秀的人女兒勝於男孩；女命殺印相生，男兒出類拔萃），和附錄表**前後不完全一致**（README 已列入書上疑點）。初學者先記上面的簡表即可。

**和其他書比較**：《妙算人生八字》也有「男命子女星」前後不一的問題；子平正源用**轉盤法**看六親——以那位親人代表的字為新日主重排十神，看他自己的格局和喜忌，比單看十神細得多；《八字心訣》用「借盤」，是同一個方法。本書作者則直接說子平論六親不準，推崇鐵板神數。

### 4. 從日支（夫妻宮）看配偶（第 165–166 頁）

這是作者很具體、也很民俗的說法：

| 夫妻宮 | 作者說配偶 |
|---|---|
| 子、午、卯、酉（桃花） | 長得好看（美男子、俏女娘） |
| 辰、戌、丑、未（土） | 比較胖、皮膚比較黑（土厚） |
| 寅、申、巳、亥（驛馬） | 比較愛往外跑 |

配偶的個性：照日支的生肖去推（日支是子，就用老鼠的個性推；日支是寅，就說「虎死留皮」）。配偶的健康：用五行對五臟，或用生肖的生活習性推。

這一套**沒有命理推論的根據**，是作者把生肖、桃花、驛馬套到夫妻宮上。比較有道理的部分是「日支是夫妻宮」本身——課堂和多數書都同意日支代表配偶的位置，可以看日支是喜神還是忌神、有沒有被沖。

## 四、算命的說話技巧（第 166–167 頁）

作者花了一些篇幅教「怎麼跟客人說」：

- 先了解來算命的人的年齡。年輕小姐多談感情（夫宮）；年輕男生多談太太；夫妻一起來就談子女。
- **多往好的方面說**：例如說結婚第七年有「七年之癢」，彼此要互相忍耐。
- 年輕父母要好好教育孩子，可以帶小孩去參加兒童祈福法會。
- 說話要切題，看對方沒反應就改變方向。台語說「得主人意，是好功夫」。

第六章他又說算命要「三句好話兩句壞話」。這對學命理的人是很實際的提醒：**命理的結論怎麼說出口，和結論本身一樣重要**。

## 這一章學到什麼（給初學者）

1. 十神＝日干和其他字的「生、剋、同」關係，再分陰陽；同性相剋（七殺、偏財）比較猛烈，異性相剋（正官、正財）比較有情。
2. 每個十神都有好壞兩面：食神溫和長壽、傷官有才但傲、正財踏實、偏財慷慨、正官守法、七殺有魄力但要有制、正印庇蔭、偏印叛逆（又會「奪食」）。
3. 幾句常用口訣：**傷官見官、財多身弱喜比劫、官多變鬼、殺無刃不顯、食神制殺、時上一位貴、年上七殺不用制**。
4. **用神被剋、被合的大運流年就是壞運**：印為用神怕財運；作者自己用神是火，連三年水年、又逢梟神運，就是活生生的例子。
5. **男看財、女看官**：財星、官星出現的年份常有感情事件。
6. 作者自己認為子平看六親只能看大方向；夫妻宮看外貌、母親有無外遇這類說法沒有根據，參考即可。附錄表和正文對子女男女的說法前後不一，先記簡表。
