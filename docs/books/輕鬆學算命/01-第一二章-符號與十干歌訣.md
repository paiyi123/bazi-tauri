# 第一、二章　算命的符號、《滴天髓》十天干歌訣（書第 1–81 頁）

> **這一章在講什麼**：第一章把八字的「零件」——十天干、十二地支——一個一個介紹，但作者不是只給你一張表，而是把每個字能聯想到的東西（植物生長、生肖、方位、味道、星宿、八卦、大六壬的神名）全部攤開來講。第二章是全書最紮實的部分：作者把《滴天髓》十個天干的口訣，一句一句翻成白話，每個天干配一個命例。
>
> **這一章的讀法**：
> - 第一章的資料很多，**真正和論八字有關的只有幾樣**：天干的形象、地支的五行與季節、**濕土（丑辰）和燥土（未戌）的分別**、合會沖刑的基本表。其他像味道、星宿、門戶，知道作者在講什麼就好。
> - 第二章請慢慢讀。《滴天髓》的十干口訣是課堂、蘇民峰、子平正源、八字心訣都會引用的經典，這本書的白話版最好懂。讀法是：先懂每一句在說這個天干「喜歡什麼、怕什麼」，再看命例怎麼「逐句打勾」。
> - 四柱照 App 的排法：由左到右是**時、日、月、年**；「藏干」列的**粗體是本氣**，放在中間；下一列是藏干的十神。書上是直排「年、月、日、時」，筆記已轉成 App 排法。
> - 這本書是「錢老師」和學生「明慧」的對話，很多台語諧音和生活故事。筆記把命理重點挑出來用白話重寫，故事只留一兩句讓你知道作者想說什麼；古書口訣只引短句。

## 一、天干：用「種樹」的故事記十個字（第 1–3 頁）

### 1. 十天干是一棵樹從發芽到收成的過程

作者開場說「天干」就是「老天爺的干涉」，然後用植物從種下去到收割的過程，把十個字串成一個故事。這個方法的好處是：**你不只記住順序，也同時記住每個字的「形象」**，而後面《滴天髓》的口訣，全部都是用形象在講道理。

故事是這樣的：先有一顆種子破土而出（甲），長出彎彎曲曲的嫩芽（乙）；植物要曬太陽才長得大，所以第三個是太陽（丙）；光有太陽不夠，還要柔和的月光、星光（丁），作者比喻成小孩要父愛也要母愛。有了樹苗和陽光，還要有土來栽種：種大樹的厚土是戊（作者說戊加草頭就是「茂」），種稻米蔬菜的田土是己。樹長大了要修剪、砍伐才能為人所用，所以來了大剪刀、大斧頭（庚）；修剪很辛苦，所以是辛。最後要灌溉：江河的大水是壬，雨露的小水是癸。

| 天干 | 作者的比喻 | 白話形象 |
|---|---|---|
| 甲 | 種子破土而出 | 大樹、陽木 |
| 乙 | 彎彎曲曲的嫩芽 | 花草藤蔓、陰木 |
| 丙 | 太陽 | 樹要曬太陽才長得大，所以排第三 |
| 丁 | 月光、星光、燭光 | 柔和的光；像小孩需要父愛（丙）也需要母愛（丁） |
| 戊 | 種大樹的厚土 | 高山、堤防、城牆 |
| 己 | 種稻米蔬菜的田土 | 田園之土；作者說己日生的人度量大 |
| 庚 | 大剪刀、大斧頭 | 修剪砍伐，讓樹成材 |
| 辛 | 「辛苦」 | 珠寶首飾、小刀；作者說辛日生的人比較辛勞 |
| 壬 | 江河 | 大水，可灌溉田地樹木 |
| 癸 | 雨露 | 小水，滋潤花草 |

### 2. 作者的立場

作者特別強調：天干的**次序就代表先後**——先有木，再有火，再有土、金、水，這正好是五行相生的順序，也對應春夏秋冬。他還順便講了一句人生道理：「失敗是成功之母」，植物要經過修剪（庚辛）才會成材，人也要經過磨練。

### 3. 和其他書比較

《妙算人生八字》也用樹來比喻（天干是主幹、地支是枝葉和根），但重點放在天干五合、相剋的規則；本書則把重點放在**每個字的形象**，因為作者後面論命大量依賴《滴天髓》的形象口訣。課堂上許老師講天干時也會提到甲是大樹、乙是花草，但不會延伸到「辛日生的人辛苦」這類個性斷語——**這類從字形、字音推個性的說法，是作者個人的聯想，參考就好**。

## 二、地支：每個字都有一串「身份」（第 4–22 頁）

### 1. 作者把每個地支能聯想的東西全部列出

作者用黃帝造指南車、把地區分成十二個角度的故事，帶出十二地支。然後每個地支他都列了一長串：時辰、生肖、大六壬的神名（例如子叫「神后」、寅叫「功曹」）、大衍之數、味道、二十八宿、八卦。這些資料大部分是大六壬和奇門遁甲的東西，**和子平八字的推論關係不大**。

對初學者來說，真正有用的是下面這張表：

| 地支 | 時辰 | 季節／五行 | 作者特別提的性質 |
|---|---|---|---|
| 子 | 23–1 點 | 冬、水 | 六壬叫「神后」（貴婦）；作者說八字有子容易娶好太太，子被沖壞則婚姻不穩 |
| 丑 | 1–3 點 | 冬末、**濕土** | 能生金、能讓乙木扎根；**最重要：能吸收燥熱** |
| 寅 | 3–5 點 | 春、木 | 火的長生地；甲木的根 |
| 卯 | 5–7 點 | 春、木 | 代表東方、長男、陽宅大門 |
| 辰 | 7–9 點 | 春末、**濕土、水庫** | 「天罡」；能收水、能生金、能吸燥氣 |
| 巳 | 9–11 點 | 夏、火 | 金的長生地 |
| 午 | 11–13 點 | 夏、火 | 陽氣到頂點（夏至一陰生） |
| 未 | 13–15 點 | 夏末、**燥土、木庫** | 乙木冬天生有未在旁就安心（未是燥土能取暖） |
| 申 | 15–17 點 | 秋、金 | 水的長生地；作者說申多的人喜歡跑來跑去 |
| 酉 | 17–19 點 | 秋、金 | 代表西方、少女 |
| 戌 | 19–21 點 | 秋末、**燥土、火庫** | 能吸收寒濕；像冬天吃胡椒 |
| 亥 | 21–23 點 | 冬、水 | 「天門」；作者說丙丁日見亥叫「貴登天門」 |

表裡「作者特別提的性質」那一欄，有些是命理道理（例如寅是火的長生、申是水的長生），有些是民俗聯想（例如子代表太太、申多的人愛跑）。分辨的方法很簡單：**能用五行生剋解釋的，是命理；只能用字音、生肖、卦象解釋的，是聯想。**

### 2. 全書最重要的觀念：四個土不一樣

如果這一章只記一件事，就記這個。地支有四個土：辰、戌、丑、未。它們雖然都是土，但「溫度」完全不同：

- **丑、辰＝濕土**。丑在冬末，裡面藏癸水、辛金；辰在春末，裡面藏癸水、乙木，而且是「水庫」。作者把丑比成「做磚塊的濕泥」，把辰比成「石門水庫」。濕土的功能有三個：**能吸收太熱的火氣、能生金、能收藏水**。所以八字太熱太燥（夏天生、火很多）的時候，有丑或辰就是救星。作者甚至說：八字有五個火，只要見到丑或辰其中一個，就是好命。
- **未、戌＝燥土**。未在夏末，藏丁火；戌在秋末，是火庫，也藏丁火。燥土**不能生金**（作者原話的意思是「未戌乃燥土不能生金」），因為它太乾，像曬乾的土磚；但是它能讓寒冷的八字變暖。作者用一句養生俗語來記：「晴三酸、雨三椒」——冬天寒濕，年支、日支、時支有一個戌土，就像冬天吃胡椒，身體就暖了。

為什麼這個觀念這麼重要？因為「調候」（調節冷熱）是取用神的四種方法之一，而濕土、燥土就是調候最常用的工具。後面第二章的丁火、癸水命例，第七章的調候命例，第八章的拱貴、炎上命例，都會用到「丑辰吸收亢陽」這句話。

> 書上第 19 頁說「戌中藏丁、乙、己」，這是**印錯**了（已放大原頁確認書上確實這樣印）。一般書（包括 App）都是戌藏**戊、辛、丁**；乙和己是「未」的藏干。

**和其他書比較**：課堂講調候時也說「生於三夏太燥用水」，但較少單獨強調濕土；《八字心訣》講清濁時說「寒雖甚而暖無氣，反以無暖為美」，討論的是調候的例外。本書是把「丑辰吸燥、未戌暖寒」講得最直接、用得最多的一本，四本書比較檔也把它列為本書的「獨門」。App 若要做寒暖燥濕提示，這是很好的規則來源。

### 3. 門戶的說法（第 26–28 頁）

作者引大六壬，把地支兩兩配成「門戶」：子午是天地出入、卯酉是日月出入、寅申是鬼神出入、丑未是貴人出入、辰戌是天羅地網（貴人不臨）、巳亥是人類出入。然後他給每一組配了一個個性：八字有卯酉的人第六感強、能通神；有寅申的人一生常旅行；有辰戌的人適合當警察。

這些在其他子平書很少見，課堂也不教。**聽聽就好，不要拿來斷人**。比較值得記的只有「辰戌是天羅地網」這個名詞，因為《八字心訣》談劫難時也提到天羅地網。

### 4. 地支的陰陽、方位與五行旺衰（第 29–31 頁）

作者把方位、八卦和五行連在一起：東方木是震卦（長男、仁）、南方火是離卦（中女、禮）、西方金是兌卦（少女、義）、北方水是坎卦（中男、智）、中央土是坤艮。這裡他第一次提出本書的招牌建議：**五行太旺要「削減」，太弱要「補」，可以用名字、圖畫、住的地名、交的朋友來平衡**。例如「木旺無制，長髮師姑」——木太旺又沒有金來修剪的人，作者說容易出家，改善方法是名字加金字旁。

這種「用生活補五行」的做法，是本書最大的特色，也是和課堂差別最大的地方：課堂和量化五行力只談推論，不談補救；子平正源談的是「改變生活角色」；本書則具體到名字、顏色、方位、圖片。**看成民間命理的應用層，不是推論規則**。

## 三、合、會、長生（第 32–40 頁）

### 1. 天干五合：「合有宜不宜，合多不為奇」

天干五合：甲己合土、乙庚合金、丙辛合水、丁壬合木、戊癸合火。作者的重點不在背表，而在一句古訣：「**合有宜不宜，合多不為奇**」。意思是：合不一定好。合有兩種結果——「合而化」（兩個字一起變成另一種五行）和「合而不化」（兩個字只是綁在一起）。

作者用計程車比喻用神：司機先要加油（油是他的用神），載到客人以後，客人變成重點，再來是客人付的鈔票——**用神會隨情況變來變去**。最怕的是「**用神被合走**」：你需要的那個字被別人綁住了，等於失去作用。

**和其他書比較**：課堂把天干合分成五種變化（合而不合、合而不化、合來合去、爭合妒合、合而能化），比本書細很多；《妙算人生八字》說日干的合一律不化（除化氣格）。本書在這裡只給大原則，細節不如課堂。

### 2. 地支六合

子丑合土、寅亥合木、卯戌合火、辰酉合金、巳申合水、午未合火。作者用「月將（太陽）往左走、月建往右走」解釋六合的由來：當月將走到子，月建就走到丑，兩者相會，所以子丑合（第四章會再講）。民間說法：屬牛配屬鼠、屬虎配屬豬大吉；**日支（夫妻宮）有六合代表婚姻幸福**。

**和其他書比較**：課堂說地支六合「有合無化」，用生剋判斷，還把六合分成生合（寅亥、辰酉、午未）與剋合（子丑、卯戌、巳申）。本書只列合化結果，沒有討論化不化。

### 3. 三合、三會、十二長生

三合來自十二長生的「長生、帝旺、墓」三個位置：申子辰水（水生在申、旺在子、墓在辰）、亥卯未木、寅午戌火、巳酉丑金。三會是同一季節的三個字：寅卯辰木、巳午未火、申酉戌金、亥子丑水。作者說**三會的力量比三合大**，這和多數書一致。

十二長生（長生、沐浴、冠帶、臨官、帝旺、衰、病、死、墓、絕、胎、養）作者比喻成人的一生。他有一個和多數書不同的主張：**土的長生在申**（跟水一樣，叫「水土同宮」），而不是在寅（跟火一樣）。他說是從六爻卦體會出來的。這是有爭議的說法；App 目前不用土的長生，不受影響。

### 4. 刑沖破害的基本表（第 40 頁）

| 關係 | 組合 |
|---|---|
| 天干沖 | 甲庚、乙辛、丙壬、丁癸（戊己不沖） |
| 六沖 | 子午、丑未、寅申、卯酉、辰戌、巳亥 |
| 三刑 | 寅巳申、丑未戌、子卯、自刑辰午酉亥 |

## 四、《滴天髓》十天干歌訣（第二章，第 43–81 頁）

### 這一章怎麼讀

《滴天髓》是明清命理最重要的古書之一，它用每個天干八句（有的六句）的口訣，講這個天干的「性情」：它是什麼樣子、喜歡什麼、怕什麼。作者的做法是：**每一句翻成白話，再附一個命例，看命例符合哪幾句、缺哪幾句**。缺的那一句，就是這個人一生要補的東西——從大運去補，或從名字、生活去補。

這個「逐句打勾」的方法對初學者非常有用。你拿到一個八字，先看日干是什麼，背出那個天干的口訣，然後一句一句問：這個八字有沒有做到？很快就能抓到重點。課堂、子平正源（「取用不單論強弱，看十干性情」）、八字心訣下篇都引用《滴天髓》，可以對照著讀。

一個要先知道的背景：作者解釋口訣時，常常用**奇門遁甲的家族比喻**——甲是皇帝、乙是皇后、丙是兒子、丁是女兒、庚是敵人（蚩尤）、辛是丙的好同學。這不是子平的十神，看到時知道它的來源就好，不要混淆。

### 甲木：「甲木參天，脫胎要火」（第 43–46 頁）

甲是純陽之木，作者說「參天」就是雄壯高大，甲日生的人體型應該比較魁梧。整段口訣在講：大樹要成材需要什麼、怕什麼。

| 口訣 | 作者的白話 |
|---|---|
| 甲木參天 | 甲是純陽的大樹，高大雄壯 |
| 脫胎要火 | 甲木要「有作為」，一定要見一點丙丁火（洩秀）。奇門裡丙丁是甲的兒女 |
| 春不容金 | 春天木最旺，金砍不動它 |
| 秋不容土 | 秋天金旺會剋甲，這時不要再有土去生金 |
| 火熾乘龍 | 夏天火太旺，要有**辰**（濕土）來吸收熱氣 |
| 水蕩騎虎 | 水太多會把樹沖走，要有**寅**（甲的根）讓它站穩 |
| 地潤天和，植立千古 | 五行都有又不過分（土不燥、金不銳、火不狂、水不蕩），就能像阿里山神木一樣長久 |

注意「秋不容土」的邏輯：秋天金已經很旺，土又生金，金就更旺，甲木更站不住。這就是「生剋要看整體」的道理——土本來是甲木的財，平常是好東西，但在秋天它會變成幫敵人的角色。「火熾乘龍」「水蕩騎虎」則是調候和扶抑的形象說法：太熱用濕土吸熱，太濕用根來站穩。

**和其他書比較**：課堂把這些都歸入扶抑與調候；子平正源講十干性情時也用同一套口訣。本書的白話最貼近口訣原意，也最好記。

#### 命例：封疆大臣（第 45–46 頁）

**書怎麼說**：作者說這是一個「封疆大臣」（地方大員）的八字。他引古訣「甲木秋生貴元武，富貴坎離宮」：甲木生在秋天，就像大樹被修剪成棟樑，本身就有貴氣；「坎離」是水和火（子是坎卦、午是離卦），八字同時見到水和火，才能富貴。作者最後說：偉大的八字能產生偉大的思想。

| 十神 | 比肩 | 日主 | 正財 | 偏印 |
| 天干 | **甲**<sub>木</sub> | **甲**<sub>木</sub> | **己**<sub>土</sub> | **壬**<sub>水</sub> |
| 地支 | **子**<sub>水</sub> | **申**<sub>金</sub> | **酉**<sub>金</sub> | **午**<sub>火</sub> |
| 藏干 | **癸** | 壬 **庚** 戊 | **辛** | 己 **丁** |
| 藏干十神 | **正印** | 偏印 **七殺** 偏財 | **正官** | 正財 **傷官** |

**一步一步看**

1. **日主和月令**：日主甲木，生在酉月。酉是金旺的月份，金剋木，所以甲木**不得令**。這就是口訣說的「秋天金旺要剋甲」。
2. **得地**：看地支有沒有甲木的根（寅、卯，或藏甲的亥）。年支午藏丁己、月支酉藏辛、日支申藏庚壬戊、時支子藏癸——**沒有木根**。不得地。
3. **得勢**：天干有時干甲木（比肩）一個幫手，年干壬水是偏印、也在生甲。所以勢上還有一點幫助。
4. **強弱判斷**：不得令、不得地，只靠一個比肩和印，日主偏弱。剋它的金（酉、申＝正官、七殺）很旺，官殺並見。
5. **用神**：甲木弱、官殺旺，最好的辦法是「**殺印相生**」：用水（印）把金的力量轉過來生木。年干壬水、時支子水正好就是印。這也是口訣「秋不容土」的反面——秋天要水不要土；月干己土是正財，又生金又剋水，正是要小心的字。
6. **火的作用**：年支午火是傷官，一方面「脫胎要火」讓甲木有表現，另一方面火能剋金，壓住太旺的官殺。所以這個八字**水火並見**：水化殺生身，火制殺洩秀。這就是作者說的「富貴坎離宮」。
7. **小提醒**：子午相沖，但子在時支、午在年支，隔得很遠，作用很小；課堂也說遙隔的沖力量弱。

**學到什麼**：
- 同一個甲木，秋天生不一定差。只要有水來「化殺」、有火來「雕刻」，反而是貴格。
- 讀口訣要看整體：「秋不容土」的道理是秋天金已旺，再生金就太過。

### 乙木：「乙木雖柔，刲羊解牛」（第 46–49 頁）

乙是花草、藤蔓、蘭花、葡萄藤。作者說乙日生的男女多半長得好看（他舉楊貴妃、西施）。乙木的口訣在講：這株柔弱的植物要怎樣才能扎根、開花、不被沖走。

| 口訣 | 作者的白話 |
|---|---|
| 乙木雖柔 | 乙是花草藤蔓，柔軟 |
| 刲羊解牛 | 生在**丑月、未月**或乙丑、乙未日：丑是濕泥可養木，未是木庫，乙木可以扎根 |
| 懷丁抱丙 | 天干有丙丁火（花要曬太陽、要開花） |
| 跨鳳乘猴 | 地支有**酉（雞/鳳）、申（猴）**金：花要園丁修剪，才不會長得太高太亂 |
| 虛濕之地，騎馬亦憂 | 水太多時，就算地支有午火也沒用；乙木像浮萍漂泊。作者說這種人**離鄉發展**較好 |
| 藤蘿繫甲，可春可秋 | 有甲木（或寅）可以攀附，春天秋天都好 |

「刲羊解牛」字面是殺羊宰牛，作者解釋成乙木在丑（牛）、未（羊）可以盤根。「跨鳳乘猴」是說乙木坐在申酉金上面，金剋木，但對花草來說，適度的修剪是好事——這和甲木「秋天要修剪成棟樑」一樣，都是在說**剋不一定壞**。「藤蘿繫甲」是整段最有名的一句：柔弱的乙木只要有甲木可以攀附，就不怕環境變化。

**和其他書比較**：課堂和子平正源都常用「藤蘿繫甲」；《八字心訣》下篇也逐句解《滴天髓》。本書特別加了「水多的人宜離鄉」這種應用建議，是作者自己的延伸。

#### 命例：口訣幾乎全中，只缺園丁（第 48–49 頁）

**書怎麼說**：作者用這個八字示範「逐句打勾」：生寅月，寅中有甲＝藤蘿繫甲；日坐丑＝刲羊解牛；年干丁火（還有時支午火）＝懷丁抱丙。唯一的缺點是地支沒有申酉金，「少了一個園丁」。他建議名字加金字旁，或認一位姓金、錢、鍾、劉的乾爸爸來補。

| | 時 | 日 | 月 | 年 |
|---|:-:|:-:|:-:|:-:|
| 十神 | 正印 | 日主 | 正印 | 食神 |
| 天干 | **壬**<sub>水</sub> | **乙**<sub>木</sub> | **壬**<sub>水</sub> | **丁**<sub>火</sub> |
| 地支 | **午**<sub>火</sub> | **丑**<sub>土</sub> | **寅**<sub>木</sub> | **亥**<sub>水</sub> |
| 藏干 | 己 **丁** | 癸 **己** 辛 | 丙 **甲** 戊 | 甲 **壬** |
| 藏干十神 | 偏財 **食神** | 偏印 **偏財** 七殺 | 傷官 **劫財** 正財 | 劫財 **正印** |

**一步一步看**

1. **日主和月令**：乙木生寅月，春天木旺，**得令**。寅中本氣甲木是劫財——就是「藤蘿繫甲」的甲。
2. **得地**：年支亥藏甲木（亥是木的長生），而且寅亥六合；日支丑雖然藏的是己癸辛，但它是濕泥，能讓乙木盤根（刲羊解牛）。根很足。
3. **得勢**：月干、時干兩個壬水是正印，生乙木；年支亥也是水。印很多。
4. **強弱判斷**：得令、得地、印又多，日主偏強。
5. **用神**：日主強，要洩或剋。年干丁火（食神）、時支午火（本氣丁火，食神）＝「懷丁抱丙」，火洩木之秀氣，是很好的用神，又能暖一暖春初還帶寒氣、水又多的八字。
6. **缺的那一句**：金（官殺）可以修剪乙木，但地支沒有申酉，天干也沒有庚辛，只有丑中藏一點辛金。作者說「少了園丁」，就是官殺不顯。
7. **一個書上沒提的細節**：年干丁和月干壬緊貼，**丁壬相合**，而且生在寅月（木旺），有合化成木的條件。如果真的化了，丁火這個用神就被合走了，木更旺。所以這個八字的火其實要靠時支午火比較可靠。這是用課堂「合要看月令」的方法補充的觀察，書上沒有討論。

**學到什麼**：
- 用口訣逐句打勾，很快能看出一個八字「有什麼、缺什麼」。
- 缺的東西可以從大運補；用名字、乾爸爸補是作者（和很多民間命理師）的做法，課堂不談。
- 看到用神時，順便檢查它有沒有被合住（「合有宜不宜」）。

### 丙火：「丙火猛烈，欺霜侮雪」（第 49–52 頁）

丙是純陽之火，像赫赫的太陽，光明正大、沒有私心。作者說丙日生的人光明、有口才、有說服力。在奇門裡，丙是甲的兒子，能幫甲木抵抗庚金。

| 口訣 | 作者的白話 |
|---|---|
| 丙火猛烈 | 丙是太陽，最猛烈 |
| 欺霜侮雪 | 冬天的太陽能融化霜雪——這就是「調候」 |
| 能煅庚金 | 能把硬的庚金煉成器 |
| 逢辛反怯 | 遇辛反而怕：丙辛合，丙被「綁住」了（作者笑說像怕太太的訓導主任） |
| 土眾生慈 | 土多時丙火的猛烈被洩掉，變得慈祥 |
| 水猖顯節 | 水多時丙火反而顯出氣節 |
| 虎馬犬鄉，甲來成滅 | 地支寅午戌火局，火已太旺，再來甲木就把自己燒光了 |

這段口訣最值得注意的是「逢辛反怯」和「甲來成滅」。前者說明**合會讓強者變弱**：丙火能剋庚金，卻對辛金沒辦法，因為丙辛一合就綁在一起了。後者說明**生太多也是壞事**：火已經滿了，木再來生，不是幫忙，是「火上加油」到燒光。

**和其他書比較**：作者在這裡第一次提出「調候」這個詞（命學中調節氣候的功能）。課堂說調候不能違背扶抑；子平正源說調候急時先調候。本書沒有討論優先順序，但第七章會給一張「不同日干先看什麼」的表。

#### 命例：火太旺，月干辛金是唯一生機（第 51–52 頁）

**書怎麼說**：地支巳午未三會南方火，又是甲午時，作者說整個八字「全被燒毀了」，正好應了「虎馬犬鄉，甲來成滅」。唯一的一線生機在月干辛金——「能煅庚金，逢辛反怯」，辛金讓丙火有所收斂。作者建議取名用金字旁、水字旁，住在淡水、南港這類有水的地方，多穿金戴銀。

| | 時 | 日 | 月 | 年 |
|---|:-:|:-:|:-:|:-:|
| 十神 | 偏印 | 日主 | 正財 | 正印 |
| 天干 | **甲**<sub>木</sub> | **丙**<sub>火</sub> | **辛**<sub>金</sub> | **乙**<sub>木</sub> |
| 地支 | **午**<sub>火</sub> | **午**<sub>火</sub> | **巳**<sub>火</sub> | **未**<sub>土</sub> |
| 藏干 | 己 **丁** | 己 **丁** | 戊 **丙** 庚 | 丁 **己** 乙 |
| 藏干十神 | 傷官 **劫財** | 傷官 **劫財** | 食神 **比肩** 偏財 | 劫財 **傷官** 正印 |

**一步一步看**

1. **日主和月令**：丙火生巳月，夏天火旺，**得令**。
2. **得地**：地支巳、午、未三會南方火局，再加時支午——四個地支全是火或火的同黨，**得地到極點**。
3. **得勢**：年干乙木、時干甲木都是印，生丙火。天干只有月干辛金不是幫手。
4. **強弱判斷**：極強。這已經接近「炎上格」（火的專旺格）的條件了。
5. **辛金的角色**：辛是丙的正財，而且和日干緊貼，**丙辛相合**——口訣說「逢辛反怯」，丙火被辛金綁住，猛烈之氣收斂一點。但辛金本身在一片火裡，只有巳中藏一點庚金，非常弱。
6. **作者的取向**：作者把辛金看成「一線生機」，用金水來平衡火——等於是把這個八字看成**極旺的普通格局**，用財（金）和官殺（水）來耗、來剋。
7. **另一種看法**：《妙算人生八字》把同一個八字（第六篇例九）論成**炎上格**：火既然已經旺到極點，就順著火勢走，喜木火、忌水。兩種看法的關鍵在於：辛金這個財能不能算是「破格」的東西。如果看成炎上，金水運反而是逆勢。
8. **怎麼判斷**：課堂的專旺格條件是「不可見剋它的五行」——這裡沒有水（壬癸亥子），所以從課堂的標準，論炎上是說得通的；辛金只是被火熔的弱財。初學者遇到這種盤，**兩種可能都要想到**，再用大運的實際經歷驗證。

**學到什麼**：
- 火極旺的八字，有兩條路：當普通格局用金水去平衡，或當炎上格順著走。不同書會有不同結論（四本書比較檔也列了這個命盤）。
- 「逢辛反怯」：合會讓強者收斂，這是看天干合的基本感覺。
- 「甲來成滅」：生太多也是病。

### 丁火：「丁火柔中，內性昭融」（第 52–55 頁）

丁是燭光、燈光、焊接的火花，陰火、溫和。在奇門裡丁是甲的女兒，最大的功勞是抵抗庚金（丁火煉金）。

| 口訣 | 作者的白話 |
|---|---|
| 丁火柔中 | 丁是燭光、燈光，溫和 |
| 內性昭融 | 內在光明 |
| 抱乙而孝 | 奇門裡乙是甲的太太、丁是甲的女兒，所以乙是丁的母親；丁和乙在一起＝孝順 |
| 合壬而忠 | 壬是丁的正官（丈夫），丁壬合＝對丈夫忠心 |
| 旺而不烈，衰而不窮 | 旺時不暴烈，弱時也不熄滅 |
| 如有嫡母，可秋可冬 | 天干有乙木（母親、印）照顧，秋冬生也不怕 |

用十神的語言翻譯：乙木是丁火的偏印，壬水是正官。「抱乙而孝」說丁火喜歡印來生；「如有嫡母，可秋可冬」說只要有印，丁火就算生在金水旺的秋冬也能撐住。這句在本書後面用了好幾次（第六章命宮例、第七章病藥例），請記住。

> 注意：作者用的是「奇門遁甲家族比喻」（甲是皇帝、乙是皇后、丙丁是兒女、庚是敵人），不是子平的十神。在子平十神裡，乙對丁是偏印、壬對丁是正官，意思接近，但名稱來源不同。

#### 命例：中第一特獎的學生（第 54–55 頁）

**書怎麼說**：這是作者一位丁卯日生的學生。作者說丁火生在夏天非常燥熱，本來是一個平淡無奇的八字；但有兩個生機：時支**辰**是濕土，能把燥氣全部吸收；年支**申**金（財）是全八字的喜神，代表祖先積善。這位學生二十六、七歲走**庚申、辛酉**大運（金是丁火的財），結婚生子之後中了第一特獎。作者說秘訣在「結婚生子之後」：時支是子女宮，生了孩子就把辰這個宮位「填實」了——這是借六爻卦的術語，像用石頭把破的馬路填平——八字就不平凡了。

| | 時 | 日 | 月 | 年 |
|---|:-:|:-:|:-:|:-:|
| 十神 | 正印 | 日主 | 比肩 | 傷官 |
| 天干 | **甲**<sub>木</sub> | **丁**<sub>火</sub> | **丁**<sub>火</sub> | **戊**<sub>土</sub> |
| 地支 | **辰**<sub>土</sub> | **卯**<sub>木</sub> | **巳**<sub>火</sub> | **申**<sub>金</sub> |
| 藏干 | 乙 **戊** 癸 | **乙** | 戊 **丙** 庚 | 壬 **庚** 戊 |
| 藏干十神 | 偏印 **傷官** 七殺 | **偏印** | 傷官 **劫財** 正財 | 正官 **正財** 傷官 |

**一步一步看**

1. **日主和月令**：丁火生巳月，夏天火旺，**得令**。
2. **得地**：日支卯木是偏印（生火），月支巳火是劫財，根很好。
3. **得勢**：月干丁火是比肩，時干甲木是正印。幫手很多。
4. **強弱判斷**：偏強，而且夏天燥熱——這是「平淡無奇」的原因：一片火木，缺乏平衡。
5. **喜用**：日主強，要洩、要耗。年干戊土（傷官）、時支辰土（傷官）都在洩火；其中**辰是濕土**，能吸收燥熱，又藏癸水，一物兩用，作者說是生機。年支申金是正財，火剋金為財，是耗身的好東西。
6. **巳申的關係**：月支巳和年支申是六合，也是三刑的一部分（作者說「刑合」）。巳申合讓年支的財和月令連在一起，財有了通路。
7. **大運**：戊是陽年，書上的庚申、辛酉在月柱之後，表示順排，也就是男命（陽男順排）：從月柱丁巳往後是戊午、己未、**庚申、辛酉**。庚申、辛酉都是金（財），正好補強這個八字最需要的財星，所以在這步運中獎。
8. **「填實」的說法**：作者認為八字的宮位要等人生事件發生才被「啟動」。這是作者借用六爻的術語，課堂和其他子平書沒有這種說法。

**學到什麼**：
- 身強的八字，**財運**就是發財的時候；夏天的丁火，濕土（辰）是寶。
- 作者「宮位被人生事件填實」的論法很有特色，但屬於他個人的說法，參考即可。

### 戊土：「戊土固重，既中且正」（第 56–58 頁）

戊是堤防、城牆、高山的土，作者說它只能當水壩看，不能像己土那樣種養萬物。戊日生的人個性穩重、按部就班，當董事長、總經理夠格。

| 口訣 | 作者的白話 |
|---|---|
| 戊土固重，既中且正 | 戊是陽土，氣厚重，居中央，所以中正 |
| 靜翕動闢 | 靜時收斂（翕＝合聚）、動時開展。作者說卯巳未酉亥丑是靜月，寅辰午申戌子是動月 |
| 萬物司令 | 萬物靠它 |
| 水潤物生，火燥物病 | 有水滋潤就生機旺；火太多就燥熱生病 |
| 若在艮坤，怕沖宜靜 | 艮是東北（丑寅）、坤是西南（未申）；生在這幾個月最怕被沖 |

「水潤物生，火燥物病」是戊土最重要的一句：戊土是火的「兒子」（火生土），火太多它就燥，所以戊土要水。「若在艮坤，怕沖宜靜」說的是：戊土生在寅月或申月時，月令是戊土寄生的地方（寅中藏戊、申中藏戊），最怕寅申相沖把它的根沖動。

#### 命例：犯「若在艮坤，怕沖宜靜」，死於非命（第 58 頁）

**書怎麼說**：戊土生在正月（寅月），最怕申時，寅申一沖，正好犯了「若在艮坤，怕沖宜靜」。作者說這個人作惡多端，死於非命。他接著說人的死法很多（車禍、毒藥、上吊、癌症……都算非命），最好的是躺在床上安詳過世，所以要「日行一善」。

| | 時 | 日 | 月 | 年 |
|---|:-:|:-:|:-:|:-:|
| 十神 | 食神 | 日主 | 七殺 | 正財 |
| 天干 | **庚**<sub>金</sub> | **戊**<sub>土</sub> | **甲**<sub>木</sub> | **癸**<sub>水</sub> |
| 地支 | **申**<sub>金</sub> | **戌**<sub>土</sub> | **寅**<sub>木</sub> | **丑**<sub>土</sub> |
| 藏干 | 壬 **庚** 戊 | 辛 **戊** 丁 | 丙 **甲** 戊 | 癸 **己** 辛 |
| 藏干十神 | 偏財 **食神** 比肩 | 傷官 **比肩** 正印 | 偏印 **七殺** 比肩 | 正財 **劫財** 傷官 |

**一步一步看**

1. **日主和月令**：戊土生寅月。寅是木旺的月份，木剋土，戊土**不得令**；但寅中藏戊，所以月令裡有一點點戊土的氣。
2. **得地**：日支戌是戊土的根（本氣戊），年支丑也是土。有根。
3. **得勢**：天干年干癸水（正財）、月干甲木（七殺）、時干庚金（食神），**沒有一個比劫或印來幫**。
4. **強弱判斷**：中等偏弱。月干甲木七殺透出，又坐寅木，七殺很有力，壓在日主旁邊。
5. **關鍵的沖**：時支申和月支寅相沖。申金是食神，能制寅木七殺，看起來是「食神制殺」；但寅也是戊土寄生之地，被沖了，月令的根基就動搖了。天干也有一組：月干甲和時干庚**甲庚沖**（隔一位）。整個八字的上下都在打架，沒有一個平靜的地方——這就是口訣「怕沖宜靜」的意思。
6. **書上的結論**：作者沒有分析用神，直接說死於非命，並把原因歸到「作惡多端」。這是作者用來勸人行善的例子。

**學到什麼**：
- **月令被沖是大事**。課堂也說月令最重要，月令被沖代表根本動搖；但課堂會用「沖的雙方誰強、誰貼近」來看結果，不會直接斷吉凶。
- 七殺旺、日主無幫手，又四處相沖，是很辛苦的組合。至於「死於非命」，是作者的事後說法，不能光看這幾點就這樣斷人。

### 己土：「己土卑濕，中正蓄藏」（第 59–61 頁）

己是田園之土，低濕，能養萬物，但要人力耕耘。作者說己土屬陰，比較有包容力，像母親能懷孕。甲乙木最喜歡見己土（甲乙以己為財），作者順口說了一句台語「錢是膽量、衣是威風」。

| 口訣 | 作者的白話 |
|---|---|
| 己土卑濕 | 己是田園之土，低濕，能種萬物 |
| 中正蓄藏 | 有包容力，像母親 |
| 不愁木盛 | 不怕木多（田可以長很多作物） |
| 不畏水狂 | 能蓄水 |
| 火少火晦 | 火少時會被己土吸掉而變暗，所以己土要多一點火 |
| 金多金光 | 能生金，一點金就能發光 |
| 若要物旺，宜助宜幫 | 要己土發揮，要丙火曬乾、要戊土擋水 |

和戊土比較：戊土怕火太多（火燥物病），己土卻是「火少火晦」——要多一點火。這是因為己土本身濕，戊土本身燥。同樣是土，喜忌不一樣，這就是《滴天髓》分陰陽看天干的精神（子平正源也特別強調十干要分陰陽看）。

#### 命例：蔣中正，傷官吐秀（第 61 頁）

**書怎麼說**：作者說這是「蔣公」的八字。己土生在戌月，正好是最後一句「若要物旺，宜助宜幫」：戌中有戊土幫身、巳午有丙丁火生身、年支亥中有壬水。月、時兩個庚金是傷官，作者說這是「**傷官吐秀格**」，兩個庚金讓整個八字活躍起來。

| | 時 | 日 | 月 | 年 |
|---|:-:|:-:|:-:|:-:|
| 十神 | 傷官 | 日主 | 傷官 | 偏印 |
| 天干 | **庚**<sub>金</sub> | **己**<sub>土</sub> | **庚**<sub>金</sub> | **丁**<sub>火</sub> |
| 地支 | **午**<sub>火</sub> | **巳**<sub>火</sub> | **戌**<sub>土</sub> | **亥**<sub>水</sub> |
| 藏干 | 己 **丁** | 戊 **丙** 庚 | 辛 **戊** 丁 | 甲 **壬** |
| 藏干十神 | 比肩 **偏印** | 劫財 **正印** 傷官 | 食神 **劫財** 偏印 | 正官 **正財** |

**一步一步看**

1. **日主和月令**：己土生戌月。戌是土，**得令**（而且是秋末的燥土）。
2. **得地**：日支巳（本氣丙火，正印）、時支午（本氣丁火，偏印，又藏己土）、月支戌（本氣戊土，劫財）——根和印都很足。
3. **得勢**：年干丁火是偏印，生己土。
4. **強弱判斷**：日主強，而且火土偏燥（巳午戌都帶火）。
5. **用神**：身強要洩。月干、時干兩個庚金是傷官，**土生金**，把太旺的土氣洩出去，這就是「傷官吐秀」，也是口訣「金多金光」的意思——己土能生金，金一出來就發光。
6. **財的角色**：年支亥水是正財，傷官再生財（金生水），形成「傷官生財」的流通。亥水又能稍微潤一潤這個燥熱的八字（巳亥相沖，但年支和日支隔一位，力量不大）。
7. **小觀察**：庚金坐戌（燥土）、坐午（火），口訣說「土乾則脆」，燥土不太能生金；所以庚金其實不算很有力。不過作者這裡重點放在「傷官透出讓八字活起來」。

**學到什麼**：
- 己土要有火來暖、有土來幫，才有力量「生金」（洩秀）。
- 身強時，傷官、食神透出把力量洩出來，叫「吐秀」，主才華和表現。
- 名人命例的時辰常有不同版本，學方法就好。

### 庚金：「庚金帶殺，剛健為最」（第 62–67 頁）

庚是斧頭，最剛硬。在奇門裡庚是蚩尤，甲是皇帝，甲最怕庚——所以口訣說庚「帶殺」（庚是甲的七殺）。作者說庚日生的人有志氣、有鬥志，用得好可以當將軍，用不好成土匪頭子；古人在秋天處決犯人，也是因為秋天是庚金肅殺之氣。

| 口訣 | 作者的白話 |
|---|---|
| 庚金帶殺，剛健為最 | 庚是斧頭，最剛硬 |
| 得水而清 | 有壬水洩秀，金清水白 |
| 得火而銳 | 有丁火鍛鍊，成為利刃 |
| 土潤而生，土乾則脆 | 遇丑辰濕土能生金；遇未戌燥土反而讓金變脆（未戌都藏丁火） |
| 能贏甲兄，輸於乙妹 | 庚剋甲（贏）；但乙庚合，庚被乙「合住」（輸）。作者用皇帝把妹妹嫁給匈奴「和親」來比喻 |

作者特別說：**庚日生最好天干有壬水和丁火**——一個洩秀，一個鍛鍊。「土潤而生，土乾則脆」正好呼應第一章的濕土燥土：同樣是印（土），濕土才生得了金。

作者在這段順便談了七殺：命中七殺旺的人自我約束強、壓力大，但七殺多不一定當將軍，賭徒、殺豬殺雞的人也可能七殺旺。他用孫悟空比喻：天下沒有絕對好壞，要懂得變化。

> 這一段書上**沒有命例**。第七章的「扶抑」命例（辛卯 庚寅 庚午 己卯）會用到「能贏甲兄，輸於乙妹」，見 06 檔。

### 辛金：「辛金軟弱，溫潤而清」（第 65–70 頁）

辛是珠寶首飾、手錶項鍊、餐具，屬陰金，不像寶劍斧頭那麼硬，所以「軟弱」；「溫潤而清」，作者說可以改成「輕」——漂亮而輕的金屬。辛也有辛苦的意思，作者說辛日生的人比較辛勞，喜歡把責任攬在自己身上。

| 口訣 | 作者的白話 |
|---|---|
| 辛金軟弱，溫潤而清 | 辛是珠寶首飾，軟而美 |
| 畏土之疊 | 怕戊己、丑辰這些土太多把它埋掉（有才華被埋沒） |
| 樂水之盈 | 喜歡壬癸水來洗，越洗越亮；所以辛日生的人名字用水字邊有道理 |
| 能扶社稷，能救生靈 | 社稷是皇帝（甲），辛是甲的正官；丙辛合，丙（甲的兒子）會邀請辛（好同學）一起來幫甲 |
| 熱則喜母，寒則喜丁 | 夏天生要己土（母親）照顧；冬天生要丁火取暖——這也是調候 |

作者另外說辛是「天醫星」，辛日生的人適合當醫生（作者個人說法）。

「畏土之疊」是整段最實用的一句：土是辛金的印，印本來是生我的好東西，但**印太多會把日主埋掉**，叫「土重金埋」。這和甲木「秋不容土」、丙火「甲來成滅」是同一類道理：生太多也是病。

#### 命例：土多金埋（第 70 頁）

**書怎麼說**：作者說這個八字犯了「畏土之疊」：辰、丑、丑三個土，土重金埋，辰丑把辛金埋起來。好在生於午時，「寒則喜丁」——冬天有一點火取暖；時干甲木又可以疏土。所以這個八字如果大運走木，或者用木字旁、金字旁取名，就可以扭轉。

| | 時 | 日 | 月 | 年 |
|---|:-:|:-:|:-:|:-:|
| 十神 | 正財 | 日主 | 食神 | 傷官 |
| 天干 | **甲**<sub>木</sub> | **辛**<sub>金</sub> | **癸**<sub>水</sub> | **壬**<sub>水</sub> |
| 地支 | **午**<sub>火</sub> | **丑**<sub>土</sub> | **丑**<sub>土</sub> | **辰**<sub>土</sub> |
| 藏干 | 己 **丁** | 癸 **己** 辛 | 癸 **己** 辛 | 乙 **戊** 癸 |
| 藏干十神 | 偏印 **七殺** | 食神 **偏印** 比肩 | 食神 **偏印** 比肩 | 偏財 **正印** 食神 |

**一步一步看**

1. **日主和月令**：辛金生丑月。丑是土（印），**得令**，而且丑中藏辛金，是辛的根。
2. **得地**：日支丑、年支辰也都是濕土，藏辛或生金。根和印都很多。
3. **得勢**：天干年干壬、月干癸是食傷（金生水），時干甲是正財，沒有比劫、印透出。
4. **強弱判斷**：地支三個濕土都在生辛金，日主不弱；問題不是弱，是**印太多、太濕、太冷**——冬天的濕泥把首飾埋住了。
5. **病**：土（印）太多，這是「病」。
6. **藥**：能剋土的是木。時干甲木是財，「財星破印」，把土疏開，讓辛金露出來。甲木坐午，午火又能暖局。
7. **調候**：冬天生、天干壬癸水又透，整個八字寒濕。時支午火是七殺，「寒則喜丁」——午中本氣就是丁火，正好調候。
8. **大運的建議**：作者說走木運最好，因為木疏土、木又生火，一次解決「土埋」和「寒冷」兩個問題。

**學到什麼**：
- 印太多反而不好，要有財（木）來制印——這是「財星破印」用得好的例子，和第七章「病藥」的道理一樣。
- 冬天生的金要火來暖，是調候的典型。

### 壬水：「壬水通河，能洩金氣」（第 71–76 頁）

壬是長江、黃河、黑龍江這樣的大河，源遠流長。作者說壬日生的人很有作為，智慧和思想都不簡單，適合當科學家、發明家、思想家。他引孔子「智者樂水」：水放在瓶子裡變瓶形、杯子裡變杯形，有適應環境的智慧。

| 口訣 | 作者的白話 |
|---|---|
| 壬水通河 | 壬是長江黃河，源遠流長 |
| 能洩金氣 | 大河從西方（金）發源，所以能把金的氣轉成水 |
| 剛中之德，周流不滯 | 剛強，能突破障礙（像長江三峽） |
| 通根透癸，沖天奔地 | 壬生在**申、亥、子月**又透癸水，水勢沖天。作者強調**只有這三個月**才符合 |
| 化則有情 | 春天生，最好有丁火來丁壬合化木 |
| 從則相濟 | 夏天生，八字沒有金水，壬水就順從火勢 |

作者在「通根透癸」這一句講了一段很好的話：天下事要成氣候都要有條件，不要以為壬水見癸水就一定沖天奔地——**一定要生在申、亥、子這三個水有根的月份**。他借此提醒學生不要一知半解就當「猜命專家」。這個態度很值得學：口訣都有前提條件，不能只看字面。

作者也在這裡介紹了「姓的五行」：木姓（李林陳杜楊宋）、水姓（江湯潘游汪池）、金姓（金錢鍾劉）、土姓（黃王丘邱）。這是他用來「補五行」的工具之一。

#### 命例：錢老師自己的八字（第 72、75–76 頁）

**書怎麼說**：這是作者自己的八字，二歲上運。作者說：壬水生於十月亥月，日坐申，水很旺；生於辰時，辰是水庫，像「石門水庫」把大水收住，水配合得宜，才有今天的智慧。他還給了幾個美稱：寅年辰時叫「龍虎排衙」；亥是乾宮、申是坤宮，叫「天地交配」。整個八字正好是「壬水通河、剛中之德、周流不滯、沖天奔地」。在第五章（第 169、173 頁）作者又說自己是「**食神吐秀格**」「食神生財格」，所以對五術（算命、卜卦、相學、中醫）有興趣。

| | 時 | 日 | 月 | 年 |
|---|:-:|:-:|:-:|:-:|
| 十神 | 食神 | 日主 | 正財 | 偏印 |
| 天干 | **甲**<sub>木</sub> | **壬**<sub>水</sub> | **丁**<sub>火</sub> | **庚**<sub>金</sub> |
| 地支 | **辰**<sub>土</sub> | **申**<sub>金</sub> | **亥**<sub>水</sub> | **寅**<sub>木</sub> |
| 藏干 | 乙 **戊** 癸 | 壬 **庚** 戊 | 甲 **壬** | 丙 **甲** 戊 |
| 藏干十神 | 傷官 **七殺** 劫財 | 比肩 **偏印** 七殺 | 食神 **比肩** | 偏財 **食神** 七殺 |

（大運：二歲上運，陽男順排：戊子、己丑、庚寅、辛卯、壬辰……）

**一步一步看**

1. **日主和月令**：壬水生亥月，亥是壬的祿（臨官），**得令**。
2. **得地**：日支申是壬水的長生，申中藏壬；時支辰是水庫，藏癸。根很深。
3. **得勢**：年干庚金是偏印，生壬水。
4. **強弱判斷**：日主強，水勢大。
5. **怎麼收住大水**：時支辰土是七殺，又是水庫，像水庫把河水收住，不讓它氾濫——作者最得意的就是這一點。
6. **怎麼洩**：時干甲木是食神，年支寅木也是食神，水生木，把太旺的水氣洩出來，這就是「食神吐秀」。月干丁火是正財，木再生火，形成**水 → 木 → 火**的流通，所以作者又說是「食神生財」。
7. **一個小細節**：月干丁火和日干壬水緊貼，**丁壬相合**。生在亥月，不是木當令的寅卯月，所以合而不化，只是丁火（財）被日主「綁住」——對日主來說是「財來合我」，通常看成好事。
8. **作者的用神**：作者在第五章說自己的用神是**火**。這和上面的分析一致：水旺用木洩、用火（財）耗。所以第五章他說民國 60–62 年連三年辛亥、壬子、癸丑水年剋火，大運又在庚寅（庚是偏印、梟神），日子非常難過（見 04 檔的命例）。
9. **大運怎麼排**：庚是陽年，男命，陽男順排，從月柱丁亥往後：戊子、己丑、庚寅、辛卯、壬辰。二歲上運，所以庚寅運大約是二十二到三十一歲。

**學到什麼**：
- 水旺的人，有土（庫）收、有木洩、有火流通，就是好的水——「旺者宜洩」。
- 美稱（龍虎排衙、天地交配）聽聽就好，真正的道理是五行流通。
- 作者在不同章節提到同一個八字，合起來看才完整：第二章看格局，第五章看流年應事。

### 癸水：「癸水至弱，達於天津」（第 76–81 頁）

癸是雨露之水，屬陰水，從天上降下來。作者說癸日生的人與鬼神有緣（「癸」和「鬼」音近），地支又有卯酉的，能通神。

| 口訣 | 作者的白話 |
|---|---|
| 癸水至弱 | 雨露之水，最柔弱，能潤土養金、孕育萬物 |
| 達於天津 | 從天上來（天津＝天河） |
| 得龍而運，功化斯神 | 遇**辰**（龍）就有變化；辰中有乙木、癸水，作者另說辰時有太陽（丙）配合 |
| 不愁火土，不論庚辛 | 夏天生只要有辰在旁，不怕火土，也不必靠金生 |
| 合戊見火，化象斯真 | 戊癸合，要生在夏天、八字幾乎沒有水，才會真的化火 |

「得龍而運」是這段的重點，和第一章的「辰是濕土、水庫」連在一起：癸水這麼弱，夏天生一定會被火烤乾；但只要有一個辰，辰中藏癸水給它根，辰又是濕土能吸收熱氣，癸水就活了。作者說「只要一條龍在旁邊」，就不怕火土，也不必靠庚辛金來生。

「合戊見火，化象斯真」則是化氣格的條件：戊癸合化火，要生在火旺的月份（作者說農曆四、五、六、九月），八字幾乎沒有水，才是真化。作者說化格以後專章講（但書後面其實只在附錄表列了條件，見 07 檔）。

#### 命例：富貴八字，得龍而運（第 80–81 頁）

**書怎麼說**：作者說這是一個富貴八字，大運走辛丑、庚子時貴極一時。癸水至弱，但生在辰時，「得龍而運」；用神在辰時，也在丑日——丑辰能吸收夏天的亢陽之氣。走辛丑、庚子運，如魚得水，大富大貴。作者接著開了一張「補五行」清單：取名用金旁水旁、穿藍色、開藍色的車、房子坐北朝南、星期三是幸運日、拜清水祖師、房間掛瀑布畫、交姓江湯潘游的朋友、店開在內湖淡水。

| | 時 | 日 | 月 | 年 |
|---|:-:|:-:|:-:|:-:|
| 十神 | 正財 | 日主 | 食神 | 偏財 |
| 天干 | **丙**<sub>火</sub> | **癸**<sub>水</sub> | **乙**<sub>木</sub> | **丁**<sub>火</sub> |
| 地支 | **辰**<sub>土</sub> | **丑**<sub>土</sub> | **巳**<sub>火</sub> | **巳**<sub>火</sub> |
| 藏干 | 乙 **戊** 癸 | 癸 **己** 辛 | 戊 **丙** 庚 | 戊 **丙** 庚 |
| 藏干十神 | 食神 **正官** 比肩 | 比肩 **七殺** 偏印 | 正官 **正財** 正印 | 正官 **正財** 正印 |

（大運：逆排（推定為陰年男命）：甲辰、癸卯、壬寅、辛丑、庚子……）

**一步一步看**

1. **日主和月令**：癸水生巳月，夏天火旺，水**不得令**（巳中藏庚金，是印的長生，但力量弱）。
2. **得勢**：天干年干丁、時干丙是財（火），月干乙是食神，**沒有一個比劫或印**。很孤單。
3. **得地**：日支丑（濕土，藏癸水、辛金）、時支辰（濕土、水庫，藏癸水）——這兩個是癸水僅有的根。
4. **強弱判斷**：日主弱，財（火）旺。這是「財多身弱」。
5. **用神**：要幫身。最直接的是比劫（水）和印（金）。丑中藏辛金（印）、癸水（比肩），辰中藏癸水——**丑辰就是用神所在**，又兼調候（吸收火氣）。這就是「得龍而運」「不愁火土」。
6. **大運**：書上沒寫性別，但能走到辛丑、庚子，表示大運是從月柱往前逆排，也就是陰年（丁）男命：乙巳往前是甲辰、癸卯、壬寅、**辛丑、庚子**。辛丑是金（印）坐濕土，庚子是金坐水——正是金水幫身的運，所以作者說貴極一時。
7. **和課堂講義對照**：中級二課本第 26 章的實例演練也有這個八字，講義判斷為**財格、身弱，喜土金水、忌木火**，評語是「溼土帶金，水星緊實亦可」——和本書結論一致，只是講義把濕土也列為喜神（因為丑辰藏金水）。

**學到什麼**：
- 命理部分很標準：弱水夏生，喜濕土、金水運。
- 「得龍而運」的真正道理：辰是濕土，既給癸水根，又吸收火氣。
- 後面一大串生活補救是作者的特色，課堂和其他書都不這樣做，看成「民間的做法」即可。

## 這一章學到什麼（給初學者）

1. **十天干要用「形象」理解**：甲是大樹、乙是花草、丙是太陽、丁是燭光、戊是城牆、己是田園、庚是斧頭、辛是首飾、壬是大河、癸是雨露。《滴天髓》的口訣就是用形象講每個天干喜歡什麼、怕什麼。
2. **濕土（丑辰）和燥土（未戌）不一樣**：丑辰能吸收亢陽、能生金、能藏水；未戌能暖寒、但不生金。本書幾乎每個夏天、冬天的命例都會用到。
3. **生太多、剋太多都是病**：秋不容土、甲來成滅、畏土之疊，都在說「好東西太多也會壞事」。這是取用神「病藥」法的基礎。
4. **剋不一定壞**：跨鳳乘猴（乙木要金修剪）、甲木秋生是貴，說明適度的剋是磨練。
5. **口訣有前提條件**：「通根透癸」要生在申亥子月才算，「合戊見火」要夏天又無水才化。不要只看字面。
6. 作者的論命方式是**逐句對口訣**：看八字符合哪一句、缺哪一句，缺的就從大運、名字、生活去補。前者是命理方法，後者是民間做法，要分開看。
7. 作者常用**奇門遁甲的家族比喻**（甲皇帝、乙皇后、丙兒子、丁女兒、庚敵人），這不是子平的十神，不要混淆。
8. **同一個八字可能有不同看法**：乙未 辛巳 丙午 甲午 本書當成極旺的普通格局，妙算當成炎上格。遇到這種情況，把兩種可能都列出來，再用大運驗證。
