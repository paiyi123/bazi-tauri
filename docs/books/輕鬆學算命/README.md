## 一、這本書是什麼樣的書

一句話：**一位台灣街頭實戰派命理老師，用聊天的方式把整個傳統命理「工具箱」打開給你看**。

和其他已經整理過的書比起來，它最不一樣的地方是：

1. **對話體、很好讀**：每一頁都是師生問答，常常講一個故事、一句台語俗諺再帶出一個命理觀念。初學者讀起來沒有壓力。
2. **什麼都講**：除了子平八字，還有神煞、十二太歲、命宮、小限、胎元、大六壬、奇門遁甲的比喻、六爻卦的術語、面相、陽宅風水、姓名學。
3. **重視「補救」**：每講到用神，就教你用**名字、顏色、方位、居住地、交的朋友、掛的圖片、拜的神**去補。
4. **重視「做人」**：作者一直強調「心存善念、日行一善」能改命，「算命三不準」裡有兩條是善惡念頭和做人處事。
5. **論命方法其實很傳統**：拆掉那些故事和民俗後，核心是《滴天髓》十干口訣 + 扶抑/調候/通關/病藥 + 格局。

## 三、和其他書比較

| 主題 | 輕鬆學算命 | 許老師課堂 | 蘇民峰《八字論命》 | 子平正源（轉盤） | 量化五行力 |
|---|---|---|---|---|---|
| 用神取法 | 扶抑、調候、通關、病藥，依日干分先後 | 扶抑為本，病藥/調候/通關不能和扶抑衝突 | 寒熱為先，再看強弱 | 取用不單論強弱，看十干性情 | 算分數，用神由分數決定 |
| 日主強弱 | 得時、得勢、得地 | 得令、得勢（同黨 vs 異黨）、得地 | 看月令和根 | 看月令與透根 | 量化分數 |
| 神煞 | **大量使用**，還加大六壬、擇日 | 說神煞不可靠 | 只用 9 個 | 會用 | 不用 |
| 雜格 | 介紹二十多種，但作者自己說沒用 | 不教 | **明確反對**飛天祿馬、井欄叉 | 少用 | 不用 |
| 命宮、胎元 | 命宮很重要（找用神、看太歲）；胎元參考 | 不用 | 不用 | 有列胎元命宮 | 不用 |
| 十二太歲、小限 | 有 | 無 | 無 | 無 | 無 |
| 六親 | 認為子平不準 | 有教 | 不分正偏 | **轉盤法細看** | — |
| 陰干羊刃 | 往前推（乙辰、丁未…） | — | — | — | — |
| 補救 | 名字、顏色、方位、拜拜、法會 | 不談 | 少談 | 改變生活角色 | 不談 |
| 寫法 | 師生對話、故事多 | 講義 | 條列 + 大量命例 | 理論 + 真實故事 | 計算 |

**簡單說**：課堂和量化書是「理論派」，蘇民峰和子平正源是「實戰派但講道理」，這本書是「民間實戰派」，把命理放進日常生活。

## 四、這本書的特色和要小心的地方

### 值得學的

- **《滴天髓》十干口訣的白話講解**（第二章）：每個天干一段、一個命例，是全書最紮實的部分，可和課堂、子平正源對照。
- **「丑辰濕土吸收燥氣、未戌燥土溫暖寒濕」**：全書最常用的觀念，對看夏天、冬天生的八字很有幫助。
- **四種用神的命例**（第七章）：病藥、扶抑、調候、通關各一例，很清楚。
- **命宮速算法**（14 / 26 減法）：簡單好用。
- **文昌＝食神的祿位**：讓神煞回到十神道理。
- **作者自己對雜格的保留態度**：知道古書名詞，也知道它們的限度。
- **用神被大運沖走＝大凶**（建祿格的例子）、**從格遇到日主的根＝危險**。

### 要小心的

- **民俗和統計說法很多**：屬蛇的女人、夫妻宮看配偶胖瘦、桃花種樹、廚房貼長頸鹿……當作文化看，不要當作推論規則。
- **奇門遁甲的家族比喻**（甲皇帝、乙皇后、丙丁兒女、庚敵人）和子平十神不同，看到時不要混用。
- **很多斷語沒有交代推理過程**（例：「這是封疆大臣的命」），只有結論。
- **名詞有前後不一致**的地方（三刑的名稱、六親表的子女男女），見下面「書上的錯誤」。
- **有 3 個命例四柱有誤**，筆記已標 ⚠（用大運推算可看出錯字比較可能在哪一柱，見下面錯誤表）。

## 五、名詞解釋

| 名詞 | 白話 |
|---|---|
| 用神 | 讓八字變平衡、變流通的那個字 |
| 扶抑 | 日主弱就幫（印、比劫），日主強就壓（官殺、食傷、財） |
| 調候 | 調整冷熱燥濕：冬天要火、夏天要水和濕土 |
| 通關 | 兩種五行打架，找中間能「接力」的五行（例：木剋土，用火通關） |
| 病藥 | 八字某個五行太多是「病」，能去病的字是「藥」 |
| 亢陽 | 火太旺、太熱 |
| 濕土 / 燥土 | 丑辰是濕土（能吸熱、生金）；未戌是燥土（能暖寒、不生金） |
| 得時 / 得勢 / 得地 | 生對月份 / 天干有幫手 / 地支有根 |
| 命宮 | 由出生月和時辰算出的一個干支，作者當成八字的「家」 |
| 十二歲君（十二太歲） | 太歲、太陽、喪門……病符，用來看每年運氣的民間系統 |
| 小限 | 每人每年不同的「小運勢」，補大運流年之不足 |
| 胎元 | 受孕的月份（月干進一、月支進三） |
| 填實 | 宮位或「拱」的字真的出現（作者也用來指人生事件啟動宮位） |
| 拱 / 夾 | 兩個地支中間夾住一個字（例：寅辰夾卯） |
| 雜格 | 古書的各種特殊格局名稱（飛天祿馬、井欄叉、六乙鼠貴……） |
| 專旺格（一行得氣） | 日主五行極旺，整個八字幾乎只有一種五行 |
| 從格 | 日主極弱，只好順從最強的五行 |
| 建祿 / 專祿 / 歸祿 | 日干的祿在月支 / 日支 / 時支 |
| 羊刃 / 日刃 / 飛刃 | 祿的下一位 / 日支自坐羊刃 / 日支沖出羊刃 |
| 魁罡 | 庚辰、庚戌、壬辰、戊戌四日 |
| 藤蘿繫甲 | 乙木有甲木（或寅）可攀附 |
| 食神吐秀 | 日主有力又有食神洩秀，主才華 |

| 314 | 從革格例 庚辰 庚辰 庚申 庚辰 | — | 生在辰月（春），不合附錄「庚辛日秋月」的從革條件；比較像作者自己分類裡的「從強」 |

**原筆記抄錯、已更正的地方**（不是書的錯）：時上正官例日柱是**庚戌**不是庚午（第 285–286 頁）；天干順食例日柱是**丙戌**不是丙午（第 279 頁）；萬育吾的話是「命犯羊刃者多**瞽**」（瞽＝盲），不是「多聲」；第七章最弱命例，書上說的是「年之申金及時之庚金來剋」，不是「三個庚」。

另外，作者的日柱速算公式我用程式驗算是正確的；作者說很多萬年曆把 1900 年印成閏年是錯的，這點也對。

## 七、可以加進 App 的想法（未實作）

依「對 PaiYi 學習有幫助、又不會把民俗說法當推論」排序：

1. **「十干口訣」提示卡**：依日干顯示《滴天髓》八句口訣和白話，並自動打勾（例：乙木→有沒有甲/寅「藤蘿繫甲」、有沒有丑未「刲羊解牛」、有沒有丙丁「懷丁抱丙」、有沒有申酉「跨鳳乘猴」、水是否過多「虛濕之地」）。這是本書最有學習價值的部分，課堂也常引用。
2. **濕土 / 燥土調候提示**：夏天生火旺時，標出原局和大運的丑、辰（濕土能吸亢陽）；冬天寒濕時標出未、戌。可以放在現有的寒暖燥濕資訊旁邊。
3. **命宮、胎元資訊欄**：用 14/26 速算法算命宮（含過中氣加一）、五虎遁出天干；胎元月干進一、月支進三。只顯示，不參與強弱和喜忌。
4. **雜格偵測（標成「古書名詞」）**：飛天祿馬、倒沖、井欄叉、六乙鼠貴、六陰朝陽、六甲趨乾、六壬趨艮、壬騎龍背、日貴、日德、拱祿拱貴、天干順食、地支夾拱、兩干不雜、天干一字/地支一字。灰色標籤，說明「作者也說了解即可」。
5. **用神被大運沖、從格遇根**的大運標籤：本書建祿、從格兩段都有例子（現有大運標籤可能已部分涵蓋，要先比對）。
6. **十二太歲**：依生肖（或命宮）顯示每年歲君名稱。這純屬民俗，若要做建議放在流年的附註，不給吉凶。

本書的 69 個命例在 [命例.tsv](命例.tsv)，可以拿來測試第 4 項的雜格偵測。
