## 一、這本書在講什麼

作者鄭偉雄是香港的子平八字老師。這本書要傳的是一個技巧——**轉盤**：

> 在原來的命盤上，以某一位六親（父、母、配偶、子女、兄弟、上司……）那個字為中心，重新排一次十神，然後用看一般八字的方法去看**那個人**的格局、喜忌、大運。

所以一張八字不只看本人，還能看出身邊每個人的際遇。作者把這套方法總結為「**子平相對論**」：看某件事，就拿日主跟代表那件事的字比強弱，而且隨大運一回合一回合變化。

| 章 | 書頁 | 主題 | 一句話 |
|---|---|---|---|
| 一 | 14–115 | 八字理論研究 | 基本功：定格、取用、十干性情。「不懂十天干的脾氣，轉盤就轉不起來」 |
| 二 | 116–198 | 轉盤法研究 | 用《淵海子平》的六親口訣，證明古人早就在用轉盤；再加上作者的補救法 |
| 三 | 200–366 | 真實命例分析 | 21 個有事實驗證的故事，示範轉盤怎麼用在婚姻、子女、父母、事業 |

## 二、轉盤法入門（給初學者）

### 步驟

1. **先照常看本人**：月令定格、分強弱、找用神。
2. **決定要看誰**，找出代表他的字：

| 想看 | 用哪個十神（以日主為我） | 說明 |
|---|---|---|
| 母親 | 正印（偏印＝繼母、乳母） | 生我者 |
| 父親 | **偏財**（母親的丈夫）；感情好、常支持你的父親也可用印 | 第二章 |
| 妻子／女友 | 正財／偏財 | 我剋者 |
| 丈夫／男友 | 正官／七殺 | 剋我者 |
| 男命子女 | 官殺（不見官殺就借食傷） | 妻子（財）所生 |
| 女命子女 | 食傷（傷官為子、食神為女） | 我生者 |
| 兄弟姊妹、朋友、情敵、合伙人 | 比肩、劫財 | 同我者 |
| 上司、大公司、政府工 | 官殺 | 管我者 |
| 下屬、學生、晚輩 | 食傷 | 我教的人 |

3. **以那個字當日主，重算全部十神**（筆記的轉盤表就是這一步）。
4. **用同一套方法看他**：他得不得令、有沒有根、他的格局是什麼、他喜什麼忌什麼。
5. **看大運對他是什麼**：同一步運，對本人是官殺運，對妻子可能是食傷運，對丈夫可能是比劫運。
6. **再比較兩個字的強弱**（相對論）：家裡誰話事、誰需要誰。

### 三個關鍵觀念

- **親人受剋＝那個字遇到它自己的官殺**。所以古書說「比劫剋妻」（比劫是財的官殺）、「食傷剋子」（男命，食傷是官殺的官殺）、「梟印傷孫」（印是食傷的官殺）。
- **親人那個字要強，才「任」得起**財、官、桃花；弱的話，同樣的東西就變成病痛。
- **同一個人可以對應不同的十神**：太太同時是你的上司 → 也可以用官殺看她（角色轉換法）。

## 三、作者的立場（附例子）

### 1. 定格局：以月令為主，但一命可以多格

- 月令本氣透不透都可以取格；**月令餘氣透出也能自成一格**（例：己日申月，申中壬透 → 也是正財格）。
- 作者自己的十干逐月定格表（第一章三）有一條特別規則：**月令本氣是劫財時，改取下一個藏干**（例：乙日寅月 → 傷官格；丁日巳月 → 傷官格）。另外**陰干沒有陽刃**，己日午月作建祿。
- 格局好壞：正財、偏財、正官、食神、正印是好格；建祿、陽刃、七殺、傷官、偏印較差。「八字中每一個字都是獨立個體」→ 物物一太極。

### 2. 取用不單論強弱

- 批評把強弱**換算成分數加減**的方法：「看似精密，密中有疏」。
- 強也可以用印（化殺）、弱也可以用洩（辛金喜壬水洗）、調候急時先調候。
- 「**不用財星也不可劫**」：財是妻、官食是子女，就算不是用神也不能傷；身不太弱就能走財官運，差別只是辛苦或安逸。

### 3. 十干性情非常重要

全書反覆用《滴天髓》十干賦解釋命例：「乙木忌埋根之鐵」「辛金畏土之疊、樂水之盈」「丙火猛烈、欺霜侮雪」。取用神不能只分金木水火土，**要分陰陽**（同是金，庚喜火煉、辛怕火熔）。也分**濕土（己丑辰）**和**燥土（戊戌未）**：濕土潤金洩火，燥土吸水。

### 4. 從格只論日主，其他字個別判斷

從格是日主「從」，其他字（親人）照常看；大運把被沖壞的根合回來，從格就「還原」成正格（第三章故事 18）。

### 5. 六親規則不是死的

- 偏財為父或印為父、男命官殺為子或食傷為子：**看實際關係選用**。
- 命中沒有子女星不一定沒子女；**有而被刑沖**比沒有更差（第三章故事 17）。

### 6. 大運以地支為重，注意轉角運

「大運看支，歲君看干」。辰→巳、未→申、戌→亥、丑→寅這類換方位的「轉角運」，人生環境大變。太歲剋大運尚可，大運剋太歲是犯上。「原有原無，原輕原重」：原局財無根，走財運反被劫。

### 7. 胎元、命宮、神煞都用

- 胎元、命宮常參與判斷（沖夫妻宮、補三合、解沖），作者說五六十年代的香港，數兄弟還要加上胎元命宮的比劫。
- 神煞作輔助：羊刃血光、桃花外緣、伏吟靜守、反吟動變、驛馬外出、貴人助力、喪門弔客孝服。
- 數子女、兄弟用**生成數**（一六水、二七火……）和**太玄數**（甲己子午九、乙庚丑未八……）。

### 8. 時間用真太陽時，接受月律分野

- 一生大事用**真太陽時**；鐘錶時只適合占眼前事。
- 接受「節氣深淺／月律分野」（人元司令），用來判斷月令中哪個藏干當權。

### 9. 補救法：改變生活上的角色和選擇

- **角色轉換法**：把太太當上司、把子女當朋友，換一個十神來看。
- **借妻安子／借夫安子**：找出生年五行能通關的配偶；現代醫學是「借醫安子」。
- **借會合解刑沖**、晚婚、嫁離過婚的人、不和兄弟合伙、選對職業、急流勇退、把錢轉成不動產。

**本書最有特色的地方**
1. **轉盤**：別的書看六親多半只說「財星弱 → 妻緣差」，本書會**把妻子那個字當成一個人來看她的格局和大運**，甚至一個字一位男朋友。
2. **用《淵海子平》口訣做證據**：例如「食神多者其女私通」，作者用轉盤解釋（食神是女兒的官殺），說明宋朝已經在用這套方法。
3. **補救法偏向生活選擇**（角色轉換、擇偶、職業、進退），而不是改名、風水。
4. 命例多是作者親自驗證、有後續事實的真實個案，而且**常寫到具體事件**（何年離婚、何年官司、幾個子女）。

**要小心的地方**
- 轉盤的「哪個字代表誰」常有幾種選擇（父親可用偏財、也可用印；丈夫可用庚也可用酉），作者會**依事實選最吻合的那個**——事後解釋很漂亮，事前推斷就需要經驗。
- 某些斷語（整容紋身、同性戀等）是作者的經驗聯想，不是規則。
- 書中十干逐月定格表的「本氣劫財改取下一藏干」「陰干無陽刃」是作者的派別做法，和課堂未必相同。

## 六、書上的疑點

- 第一章己土例（丙戌 丁酉 己亥 戊辰，第 80 頁）書上寫胎元甲寅、命宮壬辰；照「月干進一、月支進三」，丁酉月的胎元應是**戊子**。筆記照書抄並註明。
- 第二章例 4（甲辰 庚午 庚子 庚辰）說辰是空亡：這是用**日柱**庚子起旬（甲午旬空辰巳）；如果用年柱甲辰起旬，空亡是寅卯。作者在別處說「以年干支起看日支空亡」，兩處用法不一，讀時留意。
- 筆記抄寫錯誤（已對照 PDF 改正）：第一章丁火例應為**戊午 己未 丁丑 辛亥**（舊筆記日、時柱寫錯）；第一章辛金例日柱應為**辛卯**（舊筆記寫辛亥）。
- 第二章例 11 書上胎元乙巳；照公式應是**乙未**。
- 第三章故事 6（齊人之福）書上命宮甲子；年干用五虎遁推到子宮應是**戊子**。
- 第三章故事 10 例 2（丁酉 戊申 乙卯 辛巳）書上命宮甲戌；五虎遁推到戌宮應是**庚戌**。
- 第三章故事 17 例 1（癸卯 乙卯 戊午 乙卯，第 334 頁）書上寫胎元癸亥、命宮丙午；照公式胎元應是**丙午**，癸亥符合命宮，兩者疑似互換。正文也用「胎元癸亥」比較，筆記照書並加註。
- 數字小疑點：故事 14 說「三十歲甲午年」，按年柱己未應是三十多歲；故事 15「43 歲戊運」應指壬戌運的戌（本氣戊）；故事 1 說丑是「年干」天乙貴人，年干丙的貴人是亥、酉，應是指甲或庚；第一章戊土例把丑中癸水稱偏財，實為正財。
- 其他命例的月柱、時柱都通過五虎遁、五鼠遁檢查（58 個命盤已逐一對照 PDF）。
