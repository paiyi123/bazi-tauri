## 一、這本講義在教什麼

前面的講義教的是「**取格 → 判強弱 → 定喜忌**」（三步法）。中級二這本叫「解盤」，教的是下一步：

> **八字裡的天干、地支會互相生、剋、合、沖……這些「作用」發生之後，日主的強弱和喜用神會變成什麼樣子？**

同一個八字，只算「得令、得勢、得地」可能判身強；但把合化、三會、沖剋等作用算進去以後，可能變成身弱。第 26 章的 45 個例子，很多強弱都是「作用變化後」才成立的。

| 第 23 章 | 4–20 | 天干生剋合化的作用變化 | 天干之間誰剋得到誰、合了會不會化（10/07、10/14 已教） |
| 第 24 章 | 21–41 | 地支沖合會刑害的作用變化 | 地支之間沖誰贏、合了加強誰、三合三會成不成局、刑害怎麼讀 |

### 第 23 章複習（第 4–20 頁）

第 26 章常引用第 23 章的觀念，這裡簡單複習（完整逐例解說見 [第23章-天干生剋合化.md](第23章-天干生剋合化.md)）：
- **天干生剋看遠近**：相鄰最有力，隔一位次之，隔兩位（年與時）最弱。
- **坐旺通根有力，坐剋虛浮無力**；同黨相助更有力。
- **貪生忘剋**：一個字去生別人，就忘了剋另一個字（例：金遇水又遇木，金去生水，不剋木）。
- **通關**：兩個五行打架，中間的五行可以把它們連起來。
- **母慈滅子**五種：木旺火熄、火多土焦、土多金埋、金多水濁、水多木漂。印太多反而把日主埋掉（第 24 章刑害例一就是土多金埋）。
- **天干五合的五種變化**：
  1. **合而不合**：被剋或隔位，合不起來。
  2. **合而不化**：合了但不化，只互相牽絆。喜神被合則減吉，忌神被合則減凶。
  3. **合來合去**：日干之合叫合來，年月之合叫合去。
  4. **爭合、妒合**：兩干爭合一干（只限特定排列）。
  5. **合而能化**：
     - 年月之合：坐支是化神且通根乘旺，**時支見辰**（10/21 老師補充）。
     - 日干之合：其餘六字都是化神或生化神，化後以專旺或從格論。

## 二、作者的核心觀念（附例子）

### 1. 解盤就是看「作用變化」

先各個擊破（天干生剋洩合化 → 地支生剋洩合會刑沖 → 同柱干支），再看它們合起來對日主與喜用神的影響。作用變化可以**破格損用**，也可以**成格助用**；可以**化喜為忌**，也可以**化忌為喜**。

- 例：第 26 章天干例三，丁壬合化木，原本的印（丁）變成剋身的木，戊土由「看似強」變成身弱。
- 例：第 26 章地支例三，寅卯辰三會木方，把月令辰土（印）剋掉，辛金失時寡勢，變身弱。
- 例：第 24 章刑害例五，子辰半合水局、雙庚生壬，失令的壬水「有轉強之勢」。

### 2. 力量看位置、黨眾、時令、通根，沒有固定公式

- **位置**：貼近（相鄰）比隔開有力。
- **黨眾與時令**：人多、得令的一方贏。同黨異黨數量差不多時，**得令者為旺**（第 26 章天干例十八）。
- **藏干力量**：四生（寅申巳亥）本氣＞長生＞寄土；四墓（辰戌丑未）本氣＞餘氣＞庫神；同一柱以透出天干的那個最大（第 25 章）。
- 作者明說：「八字結構複雜多端，又無固定公式可以計算，全賴學者多看實例，時常演練，久而久之自能心領神會。」

### 3. 對「化」非常保守

- 天干合化有嚴格條件，大部分的合都是「合而不化」。
- **地支六合只論合，不論化**（天干氣專，地支藏干氣雜）。
- **三合、三會只論合力大小、成不成氣，不論化**：
  - 「非月令戌土化為火，戌仍然是戌土」（第 26 章地支例十九）。
  - 「戌土之氣盡洩於金，但非化為金」（第 26 章地支例二十二）。
  - 「非子丑合而化土」（第 24 章六合例四）。

### 4. 反對死套口訣，一律「不可執一」

| 口訣 | 作者的看法 | 例子 |
|---|---|---|
| 墓庫逢沖則發 | 四庫之沖是餘氣沖餘氣、庫神戰庫神，各有損傷 | 第 24 章第一節論述 |
| 土沖土愈旺 | 土得令或黨眾才愈旺；土是日主唯一的根時，被沖反而鬆動 | 第 26 章地支例二（愈旺）、第 24 章論述（戊日壬戌時遇辰沖） |
| 六合可解六沖 | 要看合進來的是誰：辰合酉反而加重卯酉沖；亥合寅可減寅申沖但不完全解；卯合戌能緩辰戌沖 | 第 24 章六合例五、例六；第 26 章天干例二十二 |
| 辰酉合化金等 | 地支合不論化 | 第 24 章第二節論述 |
| 刑害有吉凶 | 近乎神煞，改用五行生剋讀 | 第 24 章第五節全部 8 例 |

### 5. 吉凶永遠回到日主喜忌

同一個沖、合、刑，對喜神是凶，對忌神是吉：
- **去忌存喜為吉，去喜存忌為凶**（第 24 章沖例一～四：兩個卯酉沖，一吉一凶）。
- **得令者沖衰，衰者拔；失時者沖旺，旺神發**（第 24 章沖例三、例五）。
- 在原局、在大運都是同一個道理。

### 6. 用神是「命中所須之五行」

> 「坊間諸多子平書論普通格局，見日主身旺的八字，即尋剋洩耗之五行為喜用神，行運遇之皆論吉，此誤會殊深。須知用神乃合於命中所須之五行。」（第 26 章地支例二十）

同一種五行的運，也要分好壞：
- 辰、丑同是濕土：丑沖未，美中不足；辰合酉，晦火生金為美（第 26 章地支例五）。
- 亥、子同是水：亥能合卯緩沖、制火潤土；子沖午，動盪不安（第 26 章地支例五、例二十）。
- 土要分濕燥：辰丑能晦火生金；未戌與火會合無用（第 26 章天干例十五）。

### 7. 命局「基因」

講義用「基因」形容原命局本身的好壞：
- **基因優良**：五行順生、上下有情、喜用有力 → 好運能發、壞運也不致傾倒（第 26 章天干例十一、例十九）。
- **基因太壞**：喜用被合、被沖、深藏不出 → 「逢好運不見得好，縱有一二好事亦如過眼雲煙稍縱即逝，行壞運則雪上加霜」（第 26 章天干例二十三、地支例十一、例二十一）。
- **二行、三行閉塞**：五行偏枯，「格中無用神可取」，只能靠大運流通（第 26 章地支例十八、十九）。

### 8. 調候常常是關鍵

- 夏天火炎土燥，要水（第 26 章天干例五：辛金「外強中乾」；地支例五）。
- 冬天金寒水冷、木凍，要火（第 26 章天干例八、九、十一、十九；第 24 章三會例四「寒木向陽」）。
- **調候已足，再見同一五行反而不宜**（第 24 章刑害例四、第 26 章地支例十七）。

### 9. 從格的界線

- **日主無一根氣、必從其勢**才論從（第 26 章天干例六、十四；地支例二）。
- 有一點印比暗藏就**不入從格**，結果常是「身弱難扶」最辛苦的命（第 24 章三合例七、第 26 章天干例二十三、地支例九）。
- **從兒不忌身強弱，只要吾兒又見兒**（第 26 章天干例二十一）。

## 三、名詞解釋

| 名詞 | 意思 |
|---|---|
| 得令、得時 | 日主（或某五行）與月令同五行或得月令生 |
| 失令、失時 | 反之 |
| 得勢、黨眾 | 八字中同一方的字多 |
| 通根 | 天干在地支藏干裡有同五行 |
| 坐祿、坐旺、坐長生 | 天干坐在自己的祿位、帝旺位、長生位（有力） |
| 臨絕、坐絕、坐病 | 天干坐在自己的絕地、病地（無力） |
| 截腳、坐剋 | 天干坐在剋自己的地支上 |
| 合神、會神 | 三合、三會中最旺的那一支（子午卯酉） |
| 填實 | 缺合神的半合（如申辰），大運流年帶來合神（子） |
| 生合、剋合 | 地支六合依本氣分：生合加強受生者，剋合削減受剋者 |
| 牽絆、互絆 | 被合住，不能發揮原本作用 |
| 貪合忘剋（忘沖、忘生） | 被合住就忘了剋（沖、生）別人 |
| 貪生忘剋 | 去生別人就忘了剋 |
| 通關 | 兩五行交戰時用中間的五行連接（金木戰用水、水火戰用木、火金戰用土） |
| 調候 | 冬天用火暖、夏天用水潤 |
| 晦火 | 濕土吸收火氣 |
| 病神 | 破壞平衡的五行；去病的五行就是藥 |
| 天地交戰 | 天干、地支同時出現同一組相剋（如上庚甲、下申寅） |
| 去忌存喜、去喜存忌 | 沖掉忌神留下喜神為吉；反之為凶 |
| 背祿逐馬 | 官（祿）和財（馬）都受破壞 |
| 二行／三行閉塞 | 八字只有兩、三種五行，氣不流通 |
| 從財、從殺、從勢、從兒 | 日主無根，順從財、官殺、食傷財官殺連成的勢、食傷 |
| 炎上、稼穡 | 火、土的專旺格 |
