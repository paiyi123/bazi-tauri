# 第二十五章　同柱干支生剋合的作用變化（講義第 42–46 頁）

> 本章沒有完整的四柱命例，只講「一柱之內」天干和地支的關係。第 26 章的命例會一直用到本章的觀念（例如「坐祿」「截腳」「暗合」）。
> 本章的內容已寫進 App 的「同柱干支」卡片，見文末。

## 本章在講什麼

前面兩章講的是**不同柱**之間的關係（天干跟天干、地支跟地支）。本章講的是**同一柱**裡，上面的天干和下面的地支之間的關係。

為什麼重要？因為一個天干**坐在什麼地支上**，大大影響它的力量：
- 坐在生它或同類的地支上，叫做**通根、坐旺**，有力。
- 坐在剋它的地支上（俗稱**截腳**），或坐在它要去生的地支上（被洩），力量就打折扣。

## 第一節　同柱干支生剋的情形（第 42–45 頁）

### 一、六十甲子分五類

十天干配十二地支，共六十組（六十甲子）。看每一組**天干**和**地支本氣**的五行關係，可以分成五類，每類剛好 12 組：

| 類別 | 意思 | 12 組 |
|---|---|---|
| 1. 天干生地支 | 上面生下面，天干被洩 | 甲午、乙巳、丙辰、丙戌、丁丑、丁未、戊申、己酉、庚子、辛亥、壬寅、癸卯 |
| 2. 地支生天干 | 下面生上面，天干得生 | 甲子、乙亥、丙寅、丁卯、戊午、己巳、庚辰、庚戌、辛丑、辛未、壬申、癸酉 |
| 3. 天干剋地支 | 上面剋下面，天干耗力 | 甲戌、甲辰、乙丑、乙未、丙申、丁酉、戊子、己亥、庚寅、辛卯、壬午、癸巳 |
| 4. 地支剋天干 | 下面剋上面，天干坐剋（截腳） | 甲申、乙酉、丙子、丁亥、戊寅、己卯、庚午、辛巳、壬辰、壬戌、癸丑、癸未 |
| 5. 天干地支同類 | 上下同一五行，比助 | 甲寅、乙卯、丙午、丁巳、戊辰、戊戌、己丑、己未、庚申、辛酉、壬子、癸亥 |

**基本原則**：不考慮時令（生在哪個月）、不考慮地支本氣以外的藏干、不考慮整個八字結構時：
- **上下受生**（第 2 類）和**上下同類**（第 5 類）的那組，五行力量自然比較大。
- **上下受剋**（第 4 類）的那組，五行力量自然比較小。

但是，只要**配合時令**和**地支所藏各干**，綜合四柱八字來看，力量就會有很大的變化（可以參考第六章「五行週行於四時的旺相死囚休」）。

### 二、五類各舉一組說明

講義每一類舉兩組做代表，說明「一般情況」和「例外情況」。

#### (1) 天干生地支：甲午、乙巳

- **一般**：甲坐午、乙坐巳，甲乙木一定生巳午火，使火的力量加強；甲乙木也因為被巳午火洩氣而減力。
- **更弱的情況**：甲乙木生在巳午月（夏天），又沒有根（虛浮無根），木就**從火**，「必遭焚化」。
- **還好的情況**：甲乙木生在寅卯月（春天），又在其他柱有強根，就**不怕火洩**。
- 同類的其他組：丙辰、丙戌、丁丑、丁未、戊申、己酉、庚子、辛亥、壬寅、癸卯，都依此類推。

#### (2) 地支生天干：甲子、乙亥

- **一般**：甲坐子、乙坐亥，甲乙木一定受亥子水生，使木的力量加強；亥子水也因為被甲乙木洩氣而減力。
- **木很強時**：甲乙木生在寅卯月，又在其他柱有強根，水就**從木**，木旺水縮。
- **水很強時**：甲乙木生在亥子月，壬癸水又出干，水就不怕被木洩。
- 同類的其他組：丙寅、丁卯、戊午、己巳、庚辰、庚戌、辛丑、辛未、壬申、癸酉，依此類推。

#### (3) 天干剋地支：丙申、丁酉

- **一般**：丙坐申、丁坐酉，丙丁火一定剋申酉金，使金的力量減弱；丙丁火也因為剋金而損力（打人自己也會累）。
- **火很強時**：丙丁火生在巳午月，又在其他柱有強根，火旺金熔，**金無存身之地**。
- **金很強時**：丙丁火生在申酉月，庚辛又出干，金就**不怕火剋**。
- 同類的其他組：甲戌、甲辰、乙丑、乙未、戊子、己亥、庚寅、辛卯、壬午、癸巳，依此類推。

#### (4) 地支剋天干：戊寅、己卯

- **一般**：戊坐寅、己坐卯，戊己土一定被寅卯木剋，使土的力量減弱；寅卯木也因為剋土而損力。
- **木很強時**：戊己土生在寅卯月，天干又透甲乙，木旺，**難容弱土**。
- **土很強時**：戊己土生在辰戌丑未月，又在其他柱有強根，土就**不怕木剋**。
- 同類的其他組：甲申、乙酉、丙子、丁亥、庚午、辛巳、壬辰、壬戌、癸丑、癸未，依此類推。

#### (5) 天干地支同類：庚申、辛酉

- **一般**：庚坐申、辛坐酉，上下五行相同，互相比助，金的力量加強。**在六十甲子中，以干支同類的氣最專**。
- **金很強時**：生在當令之月（申酉月），四柱又有生扶，就不怕剋洩。例如庚申、辛酉生在申酉月，又有一兩個土生金，這時強金**反而喜歡火來煉**（官殺制身），或**見水流通秀氣**（食傷洩身）。
- **金失時時**：四柱又見木火兩盛，就須得**濕土晦火養金**（濕土吸收火氣又生金），否則雖然自坐祿位，也難敵烈火剋制。
- 同類的其他組：甲寅、乙卯、丙午、丁巳、戊辰、戊戌、己丑、己未、壬子、癸亥，依此類推。

**這五段要學的共同道理**：同一柱的上下關係只是「起點」。真正的力量要再看兩件事：
1. **生在什麼月**（得不得時令）。
2. **其他柱有沒有根、天干有沒有同類出干**。

### 三、地支所藏各干的力量順序（第 45 頁）

地支裡面藏好幾個天干，它們的力量也不一樣，會隨春木、夏火、秋金、冬水、季土值令不同而增減，也會被同柱的生剋合改變。講義給的順序：

| 地支類別 | 藏干力量順序 |
|---|---|
| 四生之地：寅、申、巳、亥 | **本氣最大**，其次**長生**，再次**寄土** |
| 四墓之地：辰、戌、丑、未 | **土星本氣最大**，其次**餘氣**，再次**庫神** |

（名詞說明：寅藏甲丙戊，甲是本氣、丙是長生（丙火長生在寅）、戊是寄土。辰藏戊乙癸，戊是本氣、乙是餘氣（春木的尾巴）、癸是庫神（水庫）。）

**同一柱裡面**，則是**透出天干的那個五行力量最大**，其次看干支上下的生剋合情形。講義舉四個例子：

| 干支 | 力量由大到小 | 理由 |
|---|---|---|
| 甲寅 | 甲木 ＞ 丙火 ＞ 戊土 | 甲木本氣出干，最大；木生火，丙火居次；戊土雖受火生，但也受木剋，最小 |
| 壬申 | 壬水 ＞ 庚金 ＞ 戊土 | 壬水長生（申是壬水長生之地）出干，最大；庚是本氣，但因生水而力量居次；戊土氣洩於金，最小 |
| 戊戌 | 戊土 ＞ 辛金 ＞ 丁火 | 戊土本氣出干，最大；土生金，金的餘氣尚存，辛金居次；丁火藏在戌中，氣洩於土，最小 |
| 癸丑 | 癸水 ＞ 己土 ＞ 辛金 | 癸水餘氣出干，最大；己土生金、剋水，居次；辛金的氣洩於癸水，最小 |

其餘各組都依此類推。

**最後講義強調**：實際論命時，必須配合四柱八字綜合判斷。天干生剋合化、地支會合刑沖、四時五行的衰旺等，都要一一比較。**因為八字結構複雜多端，又沒有固定公式可以計算，全靠學者多看實例、時常演練，久而久之自然能心領神會。**

## 第二節　同柱干支相合的情形（第 46 頁）

### 一、干支暗合 12 組

六十甲子除了上下生剋、同類比助之外，還有**天干和地支藏干相合**的情形（天干五合：甲己、乙庚、丙辛、丁壬、戊癸），共 12 組：

| 干支 | 誰跟誰合 | 純粹 |
|---|---|---|
| 甲午 | 天干甲木 ＋ 午中己土 | ★ |
| 乙巳 | 天干乙木 ＋ 巳中庚金 | |
| 丙戌 | 天干丙火 ＋ 戌中辛金 | |
| 丁亥 | 天干丁火 ＋ 亥中壬水 | ★ |
| 戊子 | 天干戊土 ＋ 子中癸水 | ★ |
| 戊辰 | 天干戊土 ＋ 辰中癸水 | |
| 己亥 | 天干己土 ＋ 亥中甲木 | ★ |
| 庚辰 | 天干庚金 ＋ 辰中乙木 | |
| 辛巳 | 天干辛金 ＋ 巳中丙火 | ★ |
| 壬午 | 天干壬水 ＋ 午中丁火 | ★ |
| 壬戌 | 天干壬水 ＋ 戌中丁火 | |
| 癸巳 | 天干癸水 ＋ 巳中戊土 | |

**其中甲午、丁亥、戊子、己亥、辛巳、壬午六組比較純粹，論命時有絕對性的影響，要特別留意。**

為什麼這六組比較純粹？講義沒有說明。我的推測：這六組裡，被合的那個藏干是該地支的**本氣或主要的氣**（午中丁己、亥中壬甲、子中癸、巳中丙），所以合的力量大；另外六組合的是餘氣或庫神（例如辰中癸水是庫神、戌中辛金是餘氣），力量較小。這只是推測，以老師說法為準。

### 二、怎麼判斷吉凶

> **若為日主所需之五行，喜其通根乘旺，忌被剋敗、合壞；**
> **若為日主所忌之五行，則喜其虛浮無根、遭剋敗或坐絕，忌通根乘旺。**

白話：
| 這一柱的天干是… | 好的情況 | 不好的情況 |
|---|---|---|
| 喜神（日主需要的） | 坐下有根、得生（通根乘旺） | 坐下剋它（剋敗）、被暗合絆住（合壞） |
| 忌神（日主討厭的） | 坐下無根、被剋、坐在絕地 | 坐下有根、得生（通根乘旺） |

### 三、日柱的上下相合

> **日柱干支上下之合，若不入外格（特別格局），就以生合、剋合論之。**

例如日柱是戊子（戊土合子中癸水），如果整個八字沒有構成特別格局，就不要說「戊癸合化火」，而是看成土剋水的剋合（戊土剋子水，子水被絆住減力）。

## App 怎麼用本章

App 的課堂三步法新增了「同柱干支」卡片（講義第 25 章）：
- 每一柱標出屬於五類中的哪一類（例如「甲午 天干生地支」）。
- 有暗合的柱，標出是哪兩個字合，六組純粹的特別註明。
- 非日柱的天干，依照上面的吉凶表標示：
  - 喜神坐同類或坐生 → **喜神通根乘旺**（有利）。
  - 喜神坐剋 → **喜神坐剋受損**（不利）。
  - 忌神坐同類或坐生 → **忌神通根乘旺**（不利）。
  - 忌神坐剋 → **忌神坐剋減力**（有利）。
  - 天干生地支、天干剋地支 → 只算「稍有耗損」，不判吉凶。
  - 純粹暗合絆住喜神 → 不利；絆住忌神 → 有利。
- 日柱只標「日主自坐得生扶」「日主坐剋」「日主坐下耗洩」，暗合就照講義說的以生合、剋合論。
- 寅申巳亥、辰戌丑未的柱，附上藏干力量順序的提醒。

**哪些是講義明說、哪些是推論**：五類分類、12 組暗合、六組純粹、吉凶原則是講義明說；逐柱套用吉凶標示（例如「天干生地支只算稍有耗損」）是我依原則推論的。
