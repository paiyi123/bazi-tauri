# 八字諸書融會貫通指南

2026-10-30 · 整理：Claude（依 PaiYi 要求）

## 導讀：十幾本書其實是同一棵樹的不同枝幹

結論先說：所有書的骨架都一樣，就是**定格局 → 判強弱 → 取用神 → 明喜忌 → 看大運流年**。書與書的差別，大多只在「強弱怎麼算」「合會沖要不要化」「調候和扶抑誰優先」這幾個節點上。所以學習時以許老師課堂為主幹，其他書當成在某個節點上的「第二意見」。

本指南的章節順序跟 App 分析頁的分組一樣（強弱用神喜忌、格局十神、干支作用、六親婚姻、健康、事業財富學業、大運流年），每章都分成三段：**各書共識**、**各書分歧**、**建議做法**。

### 涵蓋的書與它們的「立場」

| 書（簡稱） | 作者 | 立場一句話 | 最值得拿的 |
| --- | --- | --- | --- |

### 怎麼用這份指南

1. 先讀第十章的「統一解盤流程」，知道整體步驟。
2. 解一張命盤時，照步驟走，卡在哪一步就翻到那一章看各書怎麼說。
3. 書與書說法不同時，**以課堂為準**；附錄的分歧速查表告訴你分歧在哪、App 哪張卡片會顯示不同看法。
4. 每本書的詳細筆記和命例都在 repo 的 `docs/books/` 各資料夾，本指南只做橫向整合，不重複命例。

## 一、日主強弱：大家都看「令、地、勢」，差在怎麼算「勢」和「根」

結論：每本書都用同三個要素判強弱——**得令**（生在日主當旺的月）、**得地**（地支有根）、**得勢**（生我、助我的字多）。分歧只在三件事：勢怎麼數、根有多重要、合沖後要不要重算。

### 各書共識

- **旺和強不一樣**：「得時為旺，失時為衰；黨眾為強，助寡為弱」（子平真詮）。課堂、命理新論都引這句。建禄、陽刃只是「有旺的條件」，滿盤剋洩耗一樣會轉弱。
- **根比天干比肩重要**：任鐵樵「天干得一比肩，不如地支得一餘氣」（命理新論、陸致極都引）。根的力量：禄、旺（本氣）＞長生＞餘氣＞墓庫。
- **月令最重**：所有量化、計數法都給月支加權（課堂平手時看月令在哪一邊；量化書直接乘倍數；妙算「月支算兩份」）。
- **合沖會改變強弱**：課堂 07-29「五行會變，不可執一端」；陸致極「合去根、沖拔根」；量化書把合沖寫成增減係數。

### 各書分歧

| 書 | 怎麼判 | 和課堂不同的地方 |
| --- | --- | --- |
| 課堂 | 得時、得勢、得地三選幾；得勢＝八字中同黨（印、比劫）多於異黨（食傷、財、官殺），平手看月令 | —（基準） |
| 八字心訣 | 令、地、勢**三選二** | 幾乎一樣，只是更機械 |
| 妙算、輕鬆學算命 | 得時得勢得地＋會合刑沖 | 妙算說十二長生可用可不用 |
| 量化五行力 | 每個字依位置、月令、通根算分，合沖再乘係數，得一個正負分數 | 精細但不認「刑」、「半合不化」對強弱的影響 |
| 陸致極 | 九級（極強…極弱）；**印不能代替根**；無根一定弱；同方 ≥5 個為「五指傘」 | 課堂把印算進同黨，陸認為無根時印再多也是弱（母慈滅子） |
| 命理新論 | 旺、強、衰、弱四級，不打分；強調「沒有統一標準」 | 「旺、強」定義與課堂 07-22 剛好相反，只是用詞不同 |
| 子平正源 | 不打分，看十干性情、根、調候；「取用不單論強弱」 | 反對機械化 |
| 十神洩天機 | 幾乎不談強弱 | 預設你已經知道喜忌 |
| 蘇民峰 | 傳統講義要算；寒熱命論說「不必算強弱」 | 寒熱法是作者自創，只當參考 |

小提醒：課堂自己也有用詞不一致。「得時＋得勢」07-22 說是「強」，07-29 說是「旺」。兩者都屬於「身強這一邊」，取用方向一樣，不影響結果。

### 建議做法

1. **用課堂三步法定方向**：先數得令、得地、得勢，分出「身強這邊」或「身弱這邊」。
2. **用陸致極的兩條硬界線檢查**：無根就別輕易判強（印多也一樣）；同方 ≥5 個、或禄刃印全，就別再說「還可以更強」。
3. **再看合沖有沒有改變人數**：天干合化成功會換黨，地支成局會加強一方，被沖的根要打折。
4. **量化分數當「第二意見」**：分數靠近 0 的命盤，就是各書最容易判不一樣的命盤，要特別小心。
5. 三個方法一致時可以放心；不一致時，先記下來，用過去的大運事件反驗。

App 對應：「強弱・用神・喜忌」組的**日主強弱對照**卡片，並列了量化、課堂、陸致極三個結果，不一致會標紅；「作用變化後強弱複核」卡片就是第 3 步。

## 二、用神喜忌：四法大家都認，分歧在「調候能不能插隊」

結論：所有書都用**扶抑、調候、通關、病藥**四法（蘇民峰多一個「扶抑用神」共五法）。真正的分歧只有一個：**調候和扶抑衝突時聽誰的**。課堂說扶抑優先，陸致極、妙算、蘇民峰說調候優先。實際上大多數命盤兩者不衝突，所以結論很少不同。

### 四法白話版（各書共識）

| 方法 | 什麼時候用 | 怎麼取 | 例子 |
| --- | --- | --- | --- |
| 扶抑 | 永遠先看 | 身弱：印生、比劫助（兩種）。身強：官殺剋、食傷洩、財耗（三種） | 甲木生寅月、地支寅卯，身旺。本該用金剋，但「木旺金缺」砍不動，改用火洩（課堂 08-05） |
| 調候 | 生在三冬（亥子丑）太寒、三夏（巳午未）太燥 | 冬取火、夏取水 | 「寒木向陽」：甲生亥月身強，用火既洩身又取暖，扶抑和調候方向一致 |
| 通關 | 兩個五行力量相當、互相剋 | 取中間那個五行「貪生忘剋」 | 木土對峙用火、火金用土、土水用金、金木用水、水火用木 |
| 病藥 | 命盤有一個明顯傷害用神的字 | 傷用神的是「病」，去病的是「藥」 | 用財怕比劫（病），用官殺制比劫（藥）。木多火熄以金劈木為藥 |

### 喜、忌、仇、閒（各書共識）

- **用神**：最需要的那個五行。**喜神**：生用神、護用神的。**忌神**：剋用神的。**仇神**：生忌神的（滴天髓命例研究、蘇民峰用這個詞）。**閒神**：剩下不太相干的（命理新論）。
- 課堂 08-26 強調**喜忌要用十神說才通用**，例如「財格、日干強、印多 → 用財破印，喜食傷生財，忌比劫爭財」。這張表（財格、官殺格、印格、食傷格 × 強弱 × 哪個十神多）是整個用神篇最實用的工具。
- 任鐵樵的扶抑細則課堂、蘇民峰都引：身弱官殺旺用印；身弱食傷多用印；身弱財旺用比劫；身強印多用財；身強比劫多無財用食傷；身殺兩停用食傷制殺。

### 各書分歧

| 書 | 四法的優先順序 | 獨特的補充 |
| --- | --- | --- |
| 課堂 | **扶抑是憲法**，其他三法是民法，衝突時聽扶抑 | 「金水傷官喜見官」是論格局不是論用神，不要一見冬生就取火 |
| 蘇民峰 | 扶抑是基本，但需要調候時「只以調候為重」 | 反生剋：燥土不生金、寒金不生水、凍水不生木 |
| 陸致極 | **調候為先**（先活下來才談強弱）；形象（順勢）也可以蓋過扶抑 | 寒暖燥濕打分（−6…+6）、窮通寶鑑調候表 |
| 妙算 | **調候優先** | 用神四品質：有力、有情、真假、清濁 |
| 輕鬆學算命 | 依日干決定先看哪法：木先調候；火先扶抑；土先通關病藥；金先通關調候；水先調候通關 | 丑辰濕土能吸亢陽 |
| 子平正源 | 調候急時先調候；「取用不單論強弱」 | 分陰陽：庚喜火煉、辛怕火熔 |
| 八字心訣 | 先看整體氣勢和流通 | 清濁三法（寒暖、順逆、神枯）；「寒雖甚而暖無氣，反以無暖為美」 |
| 十神洩天機 | 不討論取用 | 四正神（官印財食）順用、四偏神（殺梟傷劫）逆用 |
| 蘇民峰寒熱命論 | 只看季節：寒命喜火、熱命喜水 | 作者自創，和傳統法有時不同 |

為什麼分歧沒有想像中大：課堂 08-19 的觀察是，好的調候例子幾乎都是「調候字剛好也是扶抑字」。輕鬆學算命的命例也一樣。真正衝突的是少數命盤，例如冬生身弱的金：調候要火，但火剋身。課堂說這時要用土（一字制水、洩火、生金），火只是「配合」。

特別格局是調候的例外：潤下（全金水）不喜火、炎上（全木火）不喜水。課堂引任鐵樵，心訣也說「寒雖甚而暖無氣，反以無暖為美」，這點各書一致。

### 建議做法

1. **先用扶抑定大方向**：身強從食傷、財、官殺挑；身弱從印、比劫挑。
2. **用 08-26 十神表挑出是哪一個**：看「是什麼太多」。例如身強印多用財、身強比劫多用官殺。
3. **身強但很旺時先洩後剋**：太旺用剋會「激旺」（課堂 07-29、陸致極「犯旺」）。
4. **再看調候**：冬、夏生的人，從第 2 步的候選裡優先挑「同時能調候」的那個。如果候選裡沒有可調候的，仍用扶抑，調候字只當「配合」，且要注意健康（冬生無火留意心血管）。
5. **再看通關、病藥**：是否有兩強相戰、或有一個字專門傷用神。通關、病藥的答案通常就是「喜神」。
6. **最後評用神品質**（妙算四品質＋心訣清濁）：用神在月支或透干通根、緊貼日主、沒被剋合沖 = 有力有情，命格較高。這一步不改喜忌，只改「好到什麼程度」。

App 對應：**用神喜忌判斷**卡片（用、喜、忌、仇、閒）、**四本書檢核**的「用神四品質」「清濁」「調候例外」區塊、陸致極的寒暖燥濕分數。

## 三、格局與十神：格局是「主題」，用神才是「答案」

結論：各書都從**月令**取格，而且都提醒格局名稱不等於用神（蘇民峰：格局是體、用神是用）。格局告訴你「這張命盤的重心在哪個十神」，強弱和喜忌才決定要怎麼處理它。

### 各書共識：怎麼取格

1. **看月支本氣有沒有透干**：透了就是那個十神格（寅月透甲 → 取甲）。
2. **本氣不透，取透出的中氣、餘氣**（寅月透丙或戲）。兩個都透時，比力量（課堂 07-29：甲坐禄、戲不在月令又被牵制 → 取甲）。
3. **都不透，就用月支本氣**。
4. **比劫在月令**：叫建禄（比肩）、陽刃（劫財）。課堂列入普通十格；命理新論引陳素庵「禄刃比劫不以取格」。兩者只是叫法不同。

### 各書分歧

| 書 | 對格局的看法 |
| --- | --- |
| 課堂 | 普通十格（八格＋建禄、陽刃）和特別格局兩類；古書雜格一律不用 |
| 子平正源 | 自己的十干逐月定格表：**月令本氣是劫財時改取下一個藏干**（乙日寅月 → 傷官格）；**陰干無陽刃**；可以「一命多格」 |
| 陸致極基礎教程 | 格局＝「主導勢力」，大多在月令但**不一定**；「干重不如支重」，根多的十神才是主導 |
| 蘇民峰 | 《子平真詮》路線：八格逐一講成敗救應；格局高低六項（真假、虛實、清濁、有力、有情、團結） |
| 十神洩天機 | 月令本氣或透干的十神是「十神領袖」＝取格；重點在十神「一主一副」的配對 |
| 八字心訣 | 看整體「形象」和賓主體用；格局高低看「作功」效率 |
| 滴天髓命例研究 | **格局、十神只是名目**，要看五行氣勢 |
| 輕鬆學算命 | 列二十多種古書雜格，但作者自己說「沒什麼用」 |

### 成格、敗格（蘇民峰整理《子平真詮》，陸致極、妙算同意）

格局的好壞不在名稱，在「配合」。初學者記住這張表就夠：

| 格 | 怎樣成格 | 怎樣破格 | 怎樣救 |
| --- | --- | --- | --- |
| 正官 | 身強有財生官；身弱有印化官 | 見傷官、被刑沖 | 印制傷、合去傷官 |
| 財 | 身強有官護財；有食傷生財 | 比劫重（財被奪）、財透殺 | 官殺制比劫、食制殺 |
| 印 | 身弱：殺印相生；身強：食傷洩秀 | 印輕逢財 | 比劫去財 |
| 食神 | 生財、制殺 | 逢梟印奪食 | 財制梟 |
| 傷官 | 身強生財、身弱佩印 | 見官（金水傷官例外）、生財又透殺 | 印制傷 |
| 七殺 | 食制、印化 | 無制無化、財黨殺 | 印化殺（「制殺不如化殺高」） |
| 陽刃、建禄 | 官殺制刃、或食傷洩 | 沒有官殺也沒有食傷 | 運補 |

### 十神組合（十神洩天機為主，各書一致）

- **四正神順用、四偏神逆用**：正官、正印、食神、財要生、要護；七殺、偏印、傷官、比劫要制、要化。這和上面成敗表是同一個意思。
- **好組合**：殺印相生、食神制殺、傷官配印、財官並舉、食傷生財。**壞組合**：梟神奪食、傷官見官、比劫爭財、官殺混雜、財破印。
- **但一定要配喜忌看**：課堂一直強調「十神不可望文生義」。例如印是忌神時，「財破印」反而是好事。
- **四大動神**（七殺、傷官、偏財、比劫）：大運流年帶來這些十神且有根，代表「變動」，不一定是壞。

### 建議做法

1. 用「本氣透 → 中餘氣透 → 都不透取本氣」定格；兩個都透時比通根。
2. 如果月令的十神很弱、另一個十神根很多，參考陸致極「主導勢力」在筆記寫下「實際重心」。
3. 格局只用來挑「成敗表」那一列，實際喜忌還是回到第二章。
4. 古書雜格（飛天祿馬、井欄叉…）不用：課堂、蘇民峰、心訣都否定。

App 對應：「格局・十神組合」組的**十神組合**、**結構分析圖解**（陸致極主導勢力、格局成敗）卡片。

## 四、干支作用：合沖本身沒有好壞，看它動到喜神還是忌神

結論：各書最大的共識是「**去忌存喜為吉、去喜存忌為凶**」。沖、合、刑不會自己帶吉凶，要看被動到的字是喜是忌。最大的分歧是「**合了會不會化**」：課堂和中級二課本最保守（地支一律不化），陸致極、妙算有條件地讓它化，量化書則用係數。

### 各書共識

- **距離很重要**：緊貼（相鄰）最有力，隔一位減弱，遙隔幾乎不算（課堂 10-07、妙算、陸致極「緊沖為剋，遙沖為動」、量化書的位置係數）。
- **天干動、地支靜**：地支要被沖、被會才「動」、才作禍福（蘇民峰、陸致極）。
- **合而不化是互相牵絆**：喜神被合減吉，忌神被合減凶（課堂 10-14、陸致極「兩失其用」）。
- **旺衝之沖**：「旺者沖衰衰者拔，衰神沖旺旺神發」（滴天髓；課堂、中級二、陸致極都引）。弱的去沖強的，反而把強的激怒。
- **合要看合進來的是誰**：六合不一定解沖。辰酉合是土生金，反而加重卯酉沖；亥合寅只是減弱寅申沖（課堂 07-22、中級二）。陸致極的「貪合忘沖」也是同一個想法，只是說得比較樂觀。
- **墓庫要沖開才能用**：透干為庫、不透為墓（陸致極）；心訣「庫宜開」。但中級二提醒「墓庫逢沖則發」不可套公式，四庫互沖各有損傷。

### 各書分歧

| 題目 | 課堂、中級二 | 其他書 |
| --- | --- | --- |
| 天干五合什麼時候化 | 分五種：合而不合（隔位或被剋）、合而不化（牵絆）、合來合去、爭合妒合、合而能化；年月合化要**時支見辰**且坐支化神通根 | 陸致極：月令是化神＋下坐支持。妙算：**日干的合一律不化**（除非化氣格）。心訣：五條件，分正化／夫從妻化／妻從夫化。蘇民峰：化氣格六條件 |
| 地支六合、三合、三會 | **有合無化**；六合分生合（寅亥、辰酉、午未）與剋合（子丑、卯戌、巳申）；三合三會只論力量「成不成氣」 | 陸致極：天干透化神就化、合去根。妙算：**透干才化**。量化書：用增減係數（三會化×2.1）。命理新論：優先序三會＞三合＞六沖＞六合 |
| 三刑 | 讀成五行生剋，不另論吉凶 | 心訣：只認寅巳申、丑未戌。輕鬆：「不刑不發」。陸致極：六親上刑重於沖 |
| 六害 | **不判斷**（屬神煞） | 妙算前後不一；子平正源配合神煞用 |
| 「相生」要多近 | 緊貼最強、隔位減弱 | 心訣**最嚴**：只有同柱干支、相鄰天干、相鄰地支才相生，異柱干支不生 |
| 暗合、遙合、拱夾 | 不採（奇格異局） | 蘇民峰只認地支拱夾；陸致極要天干引化才成立；心訣有暗五合 |

提醒一個已知的爭議：10-21 的 69 年次女命（庚申 丙戌 己未 丁卯），老師用「卯未半合解未戌刑」判身弱，量化、陸致極、課堂三步法都判強。這是「刑和半合要不要改強弱」的分歧，建議上課問老師。

### 建議做法（解盤五步）

1. **天干先看**：有沒有五合？是緊貼還是隔位？有沒有被旁邊的字剋？用課堂五種情形歸類。化不化用最嚴的標準（沒把握就當合而不化）。
2. **地支再看**：三會 → 三合／半合 → 沖 → 六合 → 刑。合一律不化，只看哪一方力量變大。沖看誰贏（貼近、得令、黨多）。
3. **同柱干支**：蓋頭（干剋支）、截腳（支剋干）、坐支通根。
4. **回頭複核強弱**：上面的變化有沒有改變同黨、異黨的人數或根？
5. **每個作用都問「動到的是喜還是忌」**，去忌為吉、去喜為凶。六害、暗合留作參考，不下吉凶。

## 五、特別格局：大家都認從格和專旺，分歧在「有一點根還算不算從」

結論：特別格局就是「太偏到無法扶抑，只好順著它」。各書都認**從格**（日主極弱，順從旺方）和**專旺**（日主極強、沒有人能剋它）。化氣格、兩神成象各書認定不同；古書雜格幾乎都被否定。

### 各書共識

| 格 | 成立條件（白話） | 用、喜 | 忌 |
| --- | --- | --- | --- |
| 從財 | 日主無根無印，財星成勢 | 財，喜食傷生財 | 比劫、印 |
| 從殺（官殺） | 日主無根，官殺成勢 | 官殺，喜財 | 比劫、食傷 |
| 從兒（食傷） | 食傷成勢，「兒又生兒」最好（見財） | 食傷、財 | **印**；唯一不忌比劫的從格 |
| 從勢 | 無根無印比，食傷財官殺混雜 | 財（流通食傷與官殺） | 印比 |
| 專旺（曲直炎上稼穡從革潤下） | 全局幾乎都是日主五行，**不見剋它的五行** | 比劫、印，取食傷洩秀 | 官殺（犯旺）、財 |

- 特別格局不代表富貴（課堂 09-02、蘇民峰）。
- 「從格遇不從之運」（走印比運）是壞運；專旺走官殺運是「犯旺」。
- 專旺和陽刃的分界：只要有剋、洩的字透出有力，就回到普通格局的建禄陽刃（課堂 07-01、陸致極「透干剋神破專旺」）。

### 各書分歧

| 題目 | 說法 A | 說法 B |
| --- | --- | --- |
| 真從、假從 | 課堂 07-01：不分真假，有條件就論從 | 中級二課本、蘇民峰、陸致極：**有一點印比暗藏就不入從**，常是「身弱難扶」最辛苦的命；蘇民峰分真從假從 |
| 陰陽干 | 多數書不分 | 蘇民峰、心訣：**陰干比陽干容易從**；月令是印就不能從 |
| 從印格 | 部分古書有 | 陸致極**反對**：印太多是「母慈滅子」，仍要扶日主、制印 |
| 介於中間的命 | 大多書：不從就是普通格局 | 陸致極：「順勢而不從」，氣勢很強的命就順著它（形象、重心法）；心訣「成形成象」同理 |
| 化氣格 | 課堂：化神為用、忌剋破化神，可併入專旺、從格一起看 | 蘇民峰：六條件（日主極弱、緊貼五合、月令是化神、化神旺、原神透、不爭妒）；妙算：日干之合只有化氣格會化 |
| 兩神成象 | 課堂：不是獨立格局，走一般流程 | 蘇民峰認可；陸致極放寬到「兩行成勢」也算，用重心法取用 |
| 魁罡、金神 | 課堂不談 | 蘇民峰認可（魁罡：戊戌、壬辰、庚戌、庚辰日） |
| 古書雜格 | 課堂、蘇民峰、心訣都否定（飛天祿馬、井欄叉、六陰朝陽…） | 輕鬆學算命列了很多，但自己也說沒用 |

同一個命不同書判不同格的例子：伍廷芳 壬寅 丁未 己卯 乙亥，妙算說從官殺格，心訣說陰干從勢。丁卯 壬寅 癸卯 丙辰，妙算說從兒格，心訣說忌神合化成用神。結論的喜忌方向大致相同，只是名稱不同。

### 建議做法

1. **先當普通格局看**，只有「三要素全無、滿盤剋洩耗」（衰極）或「三要素全有、完全沒有剋洩」（旺極）才考慮特別格局。
2. **從格用嚴標準**：地支藏一點根或印，就先當「身弱」看，再用過去的大運驗證：如果走印比運反而差、走財官運反而好，才改論從。
3. **專旺也用嚴標準**：天干透出一個有根的剋神，就不是專旺。
4. **名稱不重要，喜忌重要**：不同書取的名字不同，但只要都「順旺方、忌逆旺方」，就是同一個判斷。

App 對應：「強弱・用神・喜忌」組的「**特別格局（蘇民峰）**」卡片，及大運的「化神還原」「沖魁罡」標籤。

## 六、六親與婚姻：「星」看人、「宮」看關係，再配喜忌

結論：各書都用兩樣東西看六親——**六親星**（哪個十神代表那個人）和**宮位**（哪一柱代表那個人），再問「對我是喜還是忌」。配偶宮在日支，各書一致。最大的分歧是年柱算祖上還是父母，以及要不要用「轉盤／借盤」。

### 各書共識：六親星與宮位

| 親人 | 六親星 | 宮位 |
| --- | --- | --- |
| 父親 | 偏財（沒有才用正財） | 年柱或月柱（見分歧） |
| 母親 | 正印（沒有才用偏印） | 同上 |
| 兄弟姊妹 | 比肩、劫財 | 月柱 |
| 妻（男命） | 財星（正財為主） | **日支** |
| 夫（女命） | 官殺（正官為主） | **日支** |
| 子女 | 男命官殺、女命食傷 | 時柱 |

- **宮要安靜、星要有力**：配偶宮被沖刑代表關係不穩；配偶星有根、不被剋代表配偶有力（陸致極、八字真理、妙算）。
- **「星在宮」最好**：妻星坐妻宮、夫星坐夫宮，不論身強身弱都代表有歸屬感（陸致極、八字真理）。
- **緊貼日主的關係密切**：月干、時干、日支是「近」，年柱「遠」（妙算「緊貼」、心訣「距離」、陸致極親疏表是同一個概念）。
- **婚期**：大運流年來合、來沖日支，或沖開配偶星的庫（陸致極）；天干合日干、地支合日支是「天地合」（心訣）。課堂提醒：命理說的婚期是「第一次男女接觸」，登記年份人可以選。
- **男命婚變常在比劫年或財星年**（陸致極）：男命的婚姻主線是「財星與比劫」的關係；女命則是「官殺與食傷」。

### 各書分歧

| 題目 | 各書說法 |
| --- | --- |
| 年柱、月柱 | 多數書：年柱祖上、月柱父母兄弟。妙算：年柱祖上父母，但月柱看父母較準。心訣：**年柱父母宮、月柱兄弟宮** |
| 正偏要不要分 | 蘇民峰：**不分正偏**，男命正偏財都是妻；八字真理：正＝年齡差距小的正式婚姻、偏＝年齡差大或不尋常的關係 |
| 子女 | 一般時柱整柱看；妙算作者：時干看女兒、時支看兒子 |
| 轉盤／借盤 | 子平正源、心訣：把親人那個字當新日主，重排十神看他的格局喜忌（心訣規定：父母取年干、夫妻取月干、子女取時干）。其他書沒有這個方法 |
| 六親準不準 | 輕鬆學算命：子平論六親**不準**，只看大略；子平正源則認為轉盤可以看得很細 |
| 合婚 | 命理新論（引張楠、袁樹珊）、心訣：**不看生肖神煞**，看夫子二星、雙方五行互補；蘇民峰：寒熱互補 |
| 桃花、紅鸞等神煞 | 課堂、心訣：不用；蘇民峰只用紅鸞、天喜、沐浴、咸池、紅艷；八字真理：可以拿來「錦上添花」但不當依據 |
| 舊社會斷語 | 各書都有「剋夫」「妾命」等說法，只學結構（例如官殺混雜＝感情對象較多），不拿來說人 |

### 建議做法

1. **先找星**：那個親人的十神在哪？透干、藏支、還是沒有？沒有的話關係較薄或較晚出現。
2. **再看宮**：日支（配偶）、時柱（子女）、年月柱（父母兄弟）有沒有被沖刑、被合走。
3. **問喜忌**：星是喜＝那個人對我有幫助；宮是喜＝我對那個關係感覺好（妙算：宮＝我對他的感覺、星＝他對我的幫助）。
4. **看距離**：緊貼日主＝關係密切、影響大。
5. **想看細節時才轉盤**：例如想知道配偶自己的運，把配偶星當新日主重排。先會看一般命盤再學這個。
6. **婚期用「合沖日支」「沖開配偶星庫」「天地合」先圈出候選年份**，再用喜忌判斷好壞，最後拿實際人生事件驗證。

App 對應：「六親・婚姻」組的「**四本書：六親、婚姻**」、「**婚姻・財運・健康**」（陸致極）卡片、「四本書檢核」的轉盤／借盤和戀愛方式，以及大運的粉紅「婚」標籤。

## 七、健康：看「太過」「不及」「相戰」三種失衡

結論：各書都把健康當成「五行失衡」來看，對應的臟腑也大致相同。差別在「哪一種失衡最要緊」：陸致極看最弱的五行又被剋（弱臟）；妙算看太多、太少；心訣看兩強相戰；課堂和蘇民峰強調寒熱。這些都只是「預防提醒」，不是診斷。

### 各書共識：五行與身體

| 五行 | 臟腑（各書一致的部分） |
| --- | --- |
| 木 | 肝膽、筋、四肢、神經 |
| 火 | 心、小腸、血液循環、眼 |
| 土 | 脾胃、腸胃、肌肉 |
| 金 | 肺、大腸、呼吸、皮膚、骨 |
| 水 | 腎、膀胱、生殖、耳 |

- **冬生無火、夏生無水**比較容易有毛病（課堂 08-19：冬生無火留意心血管；蘇民峰反生剋、陸致極寒暖燥濕同理）。
- **忌神旺的運**、**用神被沖的年**，是健康要留意的時間（妙算「運歲雙沖用神」、陸致極「禄被沖」）。
- **日主無根是壽元的警訊**：最忌再走衰、敗、死、絕運（陸致極）。

### 各書分歧：哪種失衡最要緊

| 書 | 判法 | 例子 |
| --- | --- | --- |
| 陸致極（進階、基礎） | **弱臟**：某五行孤露、虛透無根，又被旁邊強剋；另看強臟、陰陽失衡 | 表 13.3 部位表 |
| 妙算 | 某五行**太旺＝實症**、**全缺＝虛症**；忌神五行對應意外 | 月支算兩份來數 |
| 八字心訣 | **兩強相剋**最傷（火金相戰傷肺、土水相戰傷腎…）；精神面：土多無木、食傷洩重 | 先天性心臟病例：火只藏不現 |
| 蘇民峰 | 寒熱 + 干支部位表 + 八字秘法口訣（如「丁坐亥 → 眼疾」） | 作者說秘法不是百分百準 |
| 量化書 | 用分數找最弱、最強的五行 | — |

心訣的對照結果：App 用「兩強相戰」「只藏不現」「土多無木」抓到了大部分書上的病例，但精神分裂、肺病等幾個命例書上是看刑沖和流年，不是看原局多寡。所以「原局指向哪個器官」和「哪一年發作」要分開看。

### 建議做法

1. **先看寒熱**：冬生有沒有火、夏生有沒有水。這是最常見、各書一致的提醒。
2. **再找「最弱又被剋」的五行**（陸致極弱臟）：它對應的部位最需要保養。
3. **看有沒有兩強相戰**（心訣）：有的話看局中有沒有通關的五行。通關五行又是喜神時，走到通關運就是改善時機。
4. **太旺、全缺的五行當補充參考**（妙算）。
5. **要問「哪一年」時才看運**：用神被運歲雙沖、忌神成局、日主無根又走衰運。
6. 只當保養提醒，不拿來說「會得什麼病」。

App 對應：「健康」組的陸致極弱臟／強臟、寒暖燥濕，和四本書的健康區塊（妙算實症虛症、心訣兩強相戰）；兩邊指向不同器官是正常的，因為看的是不同的失衡。大運的綠色「健」標籤和「雙沖用神」對應第 5 步。

## 八、事業、財富、學業：先問「身能不能任」，再問「靠什麼十神」

結論：各書的共同邏輯是**身強才能任財官**。身弱的人不是沒有財，而是要等幫身的運才接得住。事業方向看用神是哪一類十神，學業看印和食傷。這一章各書分歧最少，只是細節多寡不同。

### 財富（各書共識）

| 命盤類型 | 意思 | 出處 |

| 身強財旺 | 最好：財來得了、也接得住 | 課堂「身旺身強任財官」、陸致極、妙算 |
| 財多身弱 | 看得到、拿不住；走比劫、印運才發 | 同上 |
| 食傷生財 | 靠技術、才華賺錢 | 課堂「食傷雖巧，無財亦貧」 |
| 比劫爭財 | 錢容易被兄弟、朋友、同業分走 | 課堂 08-05、陸致極、十神洩天機 |
| 財藏於庫 | 勤儉、會存錢；庫被沖開的年份財動 | 妙算、陸致極 |

提醒：「比劫奪財」也要配喜忌。財是忌神時，比劫去財反而是救。

### 事業（各書共識＋各自的工具）

- **用神是哪類十神 → 工作性質**（妙算、十神洩天機）：用官殺適合管理、公職；用財適合商業；用食傷適合技術、創作、表達；用印適合教育、學術、專業證照；用比劫適合合作、業務、競爭性工作。
- **用神五行 → 行業類別**（陸致極五行行業表、輕鬆學算命）：木＝文教、出版、家具裝潢、中醫、公務；火＝照明、燃料、熱食、加工製造、美容飾品；土＝房地產、建築、農牧、仲介代理、顧問；金＝電子電腦、機械、金融保險、汽車、司法；水＝水運、旅遊酒店、冷凍、清潔環保、記者、奔波流動性工作（進階教程 p235–237 節錄，有些行業重複出現在兩個五行）。
- **妙算的「透旺」**：日主以外最旺且透干的五行，代表實際做的事（身強時不取印比）。
- **官非、口舌**：傷官見官（緊貼才算）、身弱官殺旺（妙算）。
- **子平正源的補充**：命不好可以「選對角色」——選一個用得到喜神的職業或生活方式。
- **八字心訣的「作功」**：用「賓主體用」看這個人「做事的效率」。方法另成一套，建議熟了一般方法再學。

### 學業、考運（主要是妙算，其他書沒有反對的說法）

- **印是讀書星**：印透干有力利於考試；藏而不透要等運引出；命中無印要靠運補。
- **食傷是表達、靈活**：金水洩秀、食傷洩秀聰明。「傷官佩印」「官印相生」是好的讀書組合。
- **第一、二步大運的喜忌**決定求學階段順不順。
- **考試年份**：身印兩旺走財年、身比兩強走官殺或食傷年……也就是走喜神年。

### 建議做法

1. 先用第一、二章定強弱喜忌，這一章所有判斷都建在這上面。
2. 財：看「財強不強」和「身能不能任」的組合，再看有沒有比劫爭財、有沒有食傷生財。
3. 事業：用「用神十神」定性質、「用神五行」定行業，兩個交集最有參考價值。
4. 學業：看印、食傷和少年的大運。
5. 一切時間點都交給第九章的大運流年。

App 對應：「事業・財富・學業」組，含四本書的事業、財富、學業區塊，和陸致極的財庫、財多身弱判斷。注意：兩張卡片的「財多身弱」一張用課堂強弱、一張用陸致極強弱，結論可能不同。

## 九、大運流年：運也是「來了一個字」，用看原局的同一套方法

結論：各書都同意**看運和看命是同一套方法**（蘇民峰話）：大運、流年的干支拿回原局，看它和原局的字合不合、沖不沖、幫喜還是幫忌。分歧在「干和支哪個重」「大運和流年哪個重」。

### 各書共識

- **吉凶看喜忌**：喜神運好、忌神運壞，但要看運的字進來後跟原局發生什麼作用。蘇民峰的「似喜實忌」（印運却合走官星）、「似忌實喜」（傷官運但原局有印回剋）就是這個意思。
- **地支要動才應**：原局藏著的喜忌，等大運流年「透出」「沖動」「會成局」才應驗（蘇民峰、陸致極）。
- **一沖引兩沖**：原局本不沖，運來一個字就引動（康有為午運）。
- **年齡宜運**：幼年宜扶、中年宜旺、老年宜弱（陸致極）；先天太過宜行休衰運、不及宜行旺相運（命理新論引萬育吾）。
- **一步運不只一件事**：課堂提醒十年大運會有多種人事變化，不能只說「這運賺錢」。
- **四大動神**（十神洩天機）：七殺、傷官、偏財、比劫的運會帶來變動。

### 各書分歧

| 題目 | 各書說法 |
| --- | --- |
| 大運干、支哪個重 | 傳統（輕鬆學算命）：干管前五年、支管後五年。陸致極也提干前支後。妙算：干支合看、以地支為重。子平正源：**大運看支、歲君看干**。滴天髓命例研究：大運以支為重，干先動、支後發。量化書：干、支各算 60 分分開評 |
| 大運、流年哪個重 | 多數書：大運定十年底色、流年定當年事件。妙算：**流年重於大運**。心訣：流年更直接，太歲決定生死 |
| 流年地支 | 滴天髓命例研究：流年地支常可忽略；其他書都照算 |
| 大運天干五合化不化 | 課堂 10-07：看大運自己坐的地支（丁壬合坐卯 → 化木） |
| 轉角運 | 子平正源：大運地支從一個方位跨到另一個（辰→巳）是轉折點 |
| 組合判斷 | 妙算：大運×流年喜忌四種組合（喜喜＝鴻運、忌忌＝禍不單行…）；心訣：先合大運流年、再加原局，天干看合、地支看沖 |
| 特殊事件標誌 | 陸致極：沖提（沖月支）、歲運並臨、歲運交戰、反吟伏吟、日犯歲君、三沖一、禄刃印全、填實。妙算：蓋頭截腳。子平正源：運剋歲（犯上）。心訣：四正四庫四長生齊全 |
| 流年從何時開始 | 一般立春。蘇民峰第 13 章說流年天干、地支各有起始月；命理新論以冬至換年 |

### 建議做法（看一年的步驟）

1. **先看大運**：大運干、支各是喜是忌？以地支為主（多數書的做法），天干當十年的「表面」。天干五合化不化看大運坐支。
2. **看大運和原局的作用**：沖不沖月支、日支？有沒有填實半合、會成局？有沒有把藏著的喜忌「透出」？
3. **再加流年**：流年和大運有沒有交戰、並臨、合沖？再看流年動到原局哪個字。
4. **用妙算組合表下結論**：運喜歲喜最好、運忌歲忌最差，一喜一忌看哪個較強。
5. **看動到哪一宮、哪一個十神**，對應到六親、健康、事業財富的章節。
6. **用已經發生的年份反驗**：如果過去幾年的判斷都不對，回頭檢查強弱和喜忌，而不是硬套標籤。

App 對應：「大運流年」組的大運表。每個格子上的標籤就是上表各書的事件標誌：橙色＝各書認為較嚴重、灰色＝提示、粉紅＝婚、金＝財、綠＝健、藍紫＝動。標籤只是「這年有事情動」，好壞仍看▲▼喜忌。

## 十、建議的統一解盤流程（初學者步驟版）

這是把前面九章的「建議做法」串成一條線。骨架是課堂的「定格 → 取用 → 明喜忌 → 下判斷」，其他書只在指定的步驟補強。每一步後面標出 App 對應的卡片。

1. **核對命盤**：用五虎遁、五鼠遁檢查月柱、時柱；接近子時、節氣交接的要考慮真太陽時。（書上命例也常有錯，筆記標「⚠ 四柱待核對」。）
2. **定格**：月支本氣透 → 中餘氣透 → 都不透取本氣。月令十神很弱時參考陸致極「主導勢力」。→ 十神組合、結構分析圖解
3. **解盤：干支作用**：天干五合（五種情形）→ 地支會合沖刑 → 同柱干支。化不化一律用最嚴標準。→ 干支作用組五張卡
4. **判強弱**：得令、得地、得勢（同黨異黨，平手看月令）；用「無根」「五指傘」檢查兩端；用第 3 步的變化複核。→ 日主強弱對照、作用變化後強弱複核
5. **排除特別格局**：只有衰極或旺極才考慮，而且用嚴標準。→ 特別格局（蘇民峰）
6. **取用神**：扶抑定方向 → 08-26 十神表挑哪一個 → 身太旺先洩後剋 → 冬夏生優先挑「同時能調候」的 → 通關、病藥補上喜神。→ 用神喜忌判斷
7. **明喜忌並評品質**：寫出用、喜、忌、仇、閒；用神有力、有情、清不清。→ 四本書檢核（用神四品質、清濁）
8. **看人生各項**：六親婚姻（星＋宮＋喜忌＋距離）、健康（寒熱、弱臟、相戰）、事業財富學業（身能任不能任、用神十神）。→ 六親婚姻、健康、事業財富學業三組
9. **看大運流年**：大運（支為主）→ 運×原局 → 加流年 → 喜忌組合 → 動到哪一宮哪一神。→ 大運流年組
10. **用已發生的事反驗**：結論和過去不符時，回到第 4、第 6 步（最容易判錯的兩步），不要硬套。

### 三個「不要」（各書的共同警告）

- 不要望文生義：七殺、傷官、偏印不是壞字，正官、正財也不是好字，全看喜忌。
- 不要用神煞下吉凶：課堂、心訣、命理新論都反對；蘇民峰、八字真理只當錦上添花。
- 不要拿舊社會斷語說人：剋夫、妾命、生男生女等只學結構。
