# 《命理新論》上冊 第16章：論命的方法及其程序（書頁 p196–210，PDF 104–111）

## §1 先賢論命的方法（引文摘要）
- 萬育吾：子平取「平」意，像秤：年為鉤、時為權（秤錘）、月為提綱、日為銖兩（秤星）。八字以日為主，財官印食旺相、日干亦坐旺相之地，像以鉤稱重物而權相應（平、中和），命則富貴；權不相應（不平、不中和）則貧賤。財官印食休囚而日干旺，或日干休囚而財官印食旺相，都不平。先天太過宜行休衰運，不及宜行旺相運，這就是醫家補瀉之法；日干太旺又行旺運、太衰又行衰運則太過不及、生禍生災。大運十年一轉，窮通皆由大運之興衰，以驗歲君（流年）之禍福。
- 星平會海：唐李虛中取年月日時干支，以年為本；後徐子平專以日為主，年為根、月為提綱、時為輔佐。以日為主，大要以加臨於甚度（身旺或身弱）；先看年月格局及金木水火土何者得令，後看歲運有何旺神；並與日干消詳（如甲子日生人四柱有申子辰三合水，日干弱取申子辰水為用，忌土神破局）。
- 陳素庵：看命大法不過生剋扶抑。先看日干五行，隨看月支：本氣透干即取為格（寅中甲、午中丁…）；本氣不透，用所藏透出者（寅透丙或戊）；用神為正官、偏財、印為佳（宜生之助之），傷官、七殺為忌（宜制之化之）。若所藏之神不透遭剋，則不用月支而用別干支之勢盛力旺者為格。祿刃比劫無論在干在支均不以取格，但作日干之助耳。總之以日干與財官等較其強弱，強者抑之、弱者扶之（常）；不可扶者順之、不可抑者從之（變）；惟合化格一以運扶抑之（常），其必不可扶者則棄之。
- 又（陳素庵）：推命先看日干得時（值旺相月支）或失時、得勢（日干黨多）或失勢，下坐（日支）何支、緊貼（月時）何干支，生剋扶抑如何；再看餘干餘支。年月日時各一一推究。以月令為提綱，得時者榮、失時者悴；取日干為主，益我者喜、損我者憎。陽見陰、陰見陽為正（正官、正財、正印），陽見陽、陰見陰為偏。……七殺、梟神、劫財、傷官皆「偏」，但六格古分（官、殺、財、印、食、傷），有病方為貴，無傷不是奇；格中如去病，財祿兩相隨。
- 三命通會看命口訣：以日干為主，取提綱所用之物為命；取其節氣先後、輕重淺深，成局破衡，細加考究：官、印、財、殺、食神、傷官六法（六格為正常格局）。逢官看財、逢殺看印、逢印看官、逢財看殺。生剋制化為上，破害休囚為下；有生有去為福，有助有剝為禍。另有用年日時支合成格者、合局成一行或從旺（屬變格）；十八格內取六格為重。月令通官（官星）、柱中遇財、財旺生官，乃為富貴；柱中見財，要入財旺運發福。但見一殺，則以殺為重，不可用財；若行財旺運，乃財生殺黨，作貧賤言。凡格以殺為重。
- 淵源看命入式：凡看命排下八字，以日干為主，取年為根（祖上財產、世派盛衰）；取月為苗（父母兄弟）；日支為妻妾；時為花實（子息）。法分月氣淺深，得令不得令；年時露出財官，須要身旺；身衰財旺，多反破財傷妻；身旺財多，財亦旺，則財多稱意；若無財官，次看印綬，得何局式，吉凶斷之。學者不可拘執。

2. **取用神**：格局只代表八字的一部份；不可一見「正官格」「正印格」「食神格」就說是好命，也不可一見「傷官格」「七殺格」「偏印格」就說是壞命。須知格局有成有敗、有太過有不及。取用神第一要瞭解命主日干的衰旺強弱及天干生剋合化、地支沖合刑穿；第二要瞭解推命的普通法則與特別法則：普通是弱者宜扶、強者宜抑（扶、抑即用神）；特別是一行得氣、兩神成象等，其用神選取另有特別法則。命以用神得力者為上（富貴），用神不得力者為下（衣食無憂），無用神者為更下（貧賤凶夭）。用神像人的精神。例：
   - 丙午　丁酉　辛巳　癸巳（辛生酉月「建祿格」，巳酉半合日干不弱；年月丙丁官殺混雜通根巳午，火盛金衰，取時干癸水食神制丁火七殺，化殺為權）→ 秋金生水其源不絕，行金水運一路亨通，國家上將。

4. **下判斷**：論命目的在判斷人生的六親、個性、體格、地位，以及何時為吉、何時為凶。作者認為各家所以互異，是推論者不明其人生時的空間現象（風雲雨雪晴陰、近火靠水、出生地域等）及後天居止的境遇。從四柱位置判斷：喜用在年柱主祖上有餘蔭；在月柱主父母兄弟得力；在日柱主妻妾賢慧或得力；在時柱主子息可靠。以比劫、食傷、財官殺印分別代表六親（以財為妻…以官殺為權貴…）。以五行陰陽論生剋制化，如甲木得時得勢、戊土全無或失時失勢，必主脾胃之疾；辛癸旺相、乙丁休囚，必主心臟衰弱。例：
   - 乙亥　甲申　癸亥　乙卯（女，癸生申月，根基尚不太弱，天干甲乙齊透，地支亥卯會木，盜洩太甚；五行火絕，秋水浸淫，草木凋零，飄蕩無依；益以滿盤傷食、貴人、紅艷、劫、合、穿，女人得之，必主淪落花酒生涯，雖得將星臨貴人，也不過是一個紅酒吧女郎而已）。
