# 《命理新論》上冊 第15章：四時五行宜忌（書頁 p172–195，PDF 92–103）

主要引《窮通寶鑑》（即《欄江網》）與《三命通會》，作者白話解說。原書另附各月出生者對應地區（徐揚、兗青、荊梁、冀雍、豫）的古地理說法（作業題問其現在何地），筆記略。
作者前言：初學者要先對五行四時宜忌有綜合認識，之後才講「取用神」「明喜忌」；有數力有優勁，「好高騖遠、不求實際」是不行的。

## 木
- 總則：木性騰上而無所止；木多則欲金任使、木有金則有斧斤之用；土重則根蟠深固、土少則枝茂根危；木賴水生，少則滋潤、多則漂流。生木（甲寅乙卯甲辰）得火而秀；死木（甲申乙酉甲午）得金而造。活木喜火忌金，死木喜金忌火。木無水則無生氣，水太多則漂蕩。
- 春木：餘寒猶存，喜火溫暖；藉水資扶，但初春不宜水盛；土多損力，土薄財豐；忌逢金重，傷殘剋伐。木旺得金則良。正月木三陽交泰見火生意融然；二月卯木正盛，宜金剋而能發；三月（辰）宜火，見水則寒。
- 夏木：根乾葉燥，盤而且直；欲得水盛以滋潤；忌火旺而招焚化；土宜在薄；惡金在多。五六月木不宜火多。
- 秋木：氣漸淒涼；初秋火氣未除，猶喜水土以相滋；中秋果已成實，欲得剛金而修削；霜降後不宜水盛（水盛則木漂）；寒露節又喜火炎；木多有多材之美，土厚無自立之能。
- 冬木：盤屈在地，欲土多而培養，惡水盛而忘形；金縱多不能剋伐；火重見溫暖有功；歸根復命之時，木病安能輔助，須忌死絕之地，只宜生旺之方。
- 綜合：木生春天得時，生於秋天失時；四柱多比劫印綬得勢，多財官食傷失勢。

## 火
- 總則：炎炎真火，位鎮南方，故火無不明之理；輝光不久，全要伏藏。火以木為體，無木則火不長焰；火以水為用，無水則火太酷烈。火多則不實，火烈則傷物。
- 春火：母旺子相，勢力並行，喜木生扶，不宜過旺；欲水既濟，不愁水盛；土多則塞、晦光；火盛則傷多烈燥；見金可以施功，縱重見財可望。
- 夏火：陽氣之極，草木焦枯，江河涸竭；晴則流金爍石，雨則水濟其威，方得中和。逢水制則免自焚之咎；見木助必遭夭折之憂；遇金必作良工；得土遂成稼穡。金土雖為美利，無水則金燥土焦，再加火助，太過傾危。
- 秋火：性息體休，得木生則有復明之慶；遇水剋難逃隕滅之災；土重而掩息其光；金多而損傷其勢。
- 冬火：體絕形亡，喜木生而有救；遇水剋以為殃；欲土制為榮，愛火比為利；見金而難任為財。運喜東南。

## 土
- 總則：五行之土散在四維，金木水火依而成象，四時皆有用有忌。火死酉、水旺子，土賴火生；土喜金火方成大器；土高無貴、空惹灰塵；土聚則滯、土散則輕。辰戌丑未為土之正，但分陰分陽：辰有伏水（水庫）、未有匿木（木庫）、戌有藏火（火庫）、丑有隱金（金庫）。辰為木之餘、未為火之餘、戌為金之餘、丑為水之餘，所以辰未水木可滋生萬物，戌丑金火則能肅殺萬物，貴賤喜忌不同。
- 春土：其勢虛浮，喜火生扶，惡木太過；忌水泛濫，喜土比助；得金而制木為祥，金太多仍盜土氣。
- 夏土：其勢燥烈，得盛水滋潤成功；忌旺火煆煉焦坼；木助火炎，水剋無礙；金生水泛，妻財有益；見比肩蹇滯不通，如太過又宜木剋。
- 秋土：子旺母衰，金多而耗盜其氣；木盛須制伏純良；火重而不厭；水泛泛而不祥；得比肩則能助力，至霜降不比無妨。
- 冬土：外寒內溫，水旺財豐；金多子秀；火盛有榮；木多無咎；再加比肩扶助為佳，更喜身主康強足壽。
- 四季土：四立前十八日內土神用事。辰戌丑未四土之神，惟未土為極旺；辰戌丑雖旺而未極，帶金氣洩之，以金洩其旺氣，不失中和。未月土旺不可作稼穡看，臨此月見金結局者，不貴即富。

## 金
- 總則：金以至陰為體，中含至陽之精，乃能堅剛，獨異眾物。若獨陰而不堅，冰雪是也，遇火則消。金無火煉不能成器；金重火輕執事繁難；金輕火重鍛鍊消亡。金火兩停，格名「鑄印」；遇金庫（丑）則犯刑損模。金多火旺叫「殺刃兩停」。金白水清（純金遇水）富而聰明；金重而無火則頑鈍；金能生水、水旺則金沉。金無水則乾枯；金無土則死絕；土重則埋沒不顯。金火相停最妙。「金未成器，欲得見火；金已成器，不欲見火。」
- 春金：餘寒未盡，貴乎火氣為榮；性柔體弱，欲得厚土輔助；水盛增寒，難施鋒銳之勢；木旺損力，有剉鈍之危；金來比助，扶持最妙；比而無火，失類非良。
- 夏金：尤為柔弱，形質未具，尤嫌死絕；火多而卻不厭；水盛而滋體呈祥；見木而助鬼傷身；遇金而扶持精壯；土薄而最為有用，土厚而埋沒無光。
- 秋金：當權得令，火來煆煉遂成鐘鼎之材；土多培養反惹頑濁之氣；見水則精神越秀；逢木則琢削施威；金助愈剛，剛過則決；氣重愈旺，旺極則損。
- 冬金：形寒性冷；木多則難施斧鑿之功；水盛而未免沉潛之患；土能制水，金體不寒；火來助土，子母成功；喜比肩聚氣相扶，欲官印溫養而利。

## 水
- 總則：水不絕源，仗金生而流遠；水流泛濫，賴土剋以堤防。水火均則合既濟之美；水土混則有濁源之凶。四時皆忌火多則水受涸；忌見土重則水不流；忌見金死則水困；忌見木旺則水死。
- 春水：性濫滔淫，再逢水助，必有崩堤之勢；若加土盛，則無泛漲之憂；喜金生扶，不宜金盛；欲火既濟，不要火多；見木而可施功；無土仍愁散漫。
- 夏水：執性歸源，時當涸際，欲得比肩；喜金生而助體，忌火旺而焰乾；木盛則盜其氣；土旺則制其流。
- 秋水：母旺子相，表裡晶瑩；得金助則清澄；逢土旺而混濁；火多而財盛，太過不宜；木重而子榮，中和為利；重重見水增其泛濫之憂；疊疊逢土始得清平之意。
- 冬水：司令當權；遇火則增暖除寒；見土則形藏歸化；金多反曰無義；木盛是謂有情；土太過勢成涸轍；水泛濫喜土堤防。

## §6 五行四時宜忌綜述（作者總結）
- 子平以日干為命主，十天干與日干的生剋、衰旺強弱實在有太多變化，四柱干支及刑合沖會、天透地藏都有關係，本章只是簡單的粗糙概念。
- 淵海子平「五行生剋制化各有所喜所忌」（須背）：金旺得火方成器皿；火旺得水方成相濟；水旺得土方成池沼；土旺得木方能疏通；木旺得金方成棟樑。金賴土生，土多金埋；土賴火生，火多土焦；火賴木生，木多火熾；木賴水生，水多木漂；水賴金生，金多水濁。金能生水，水多金沉；水能生木，木多水縮；木能生火，火多木焚；火能生土，土多火晦；土能生金，金多土變。金能剋木，木多金缺；木能剋土，土多木折；土能剋水，水多土流；水能剋火，火多水熱；火能剋金，金多火熄。金弱遇火必見銷鎔；火弱逢水必為熄滅；水弱逢土必為淤塞；土弱逢木必為傾陷；木弱逢金必為砍折。強金得水方挫其鋒；強水得木方泄其勢；強木得火方化其頑；強火得土方止其燄；強土得金方制其壅。
- 「旺」= 五行得時令或雖不得時令而八字天干地支黨多；「強」= 五行得時令又兼八字天干地支黨多。「旺者宜剋不宜洩，旺極（強）宜洩不宜剋」。「多」= 得時或得勢；「弱」= 失時或失勢。
- 取用簡則（作者整理，日干 = 命主）：
  | 日干 | 情形 → 取用 |
  |---|---|
  | 木 | 木重水多（盛）→ 金剋木，金少逢土亦可；木微金剛（衰）→ 火制金，火少逢木亦可；水多木漂 → 土制水，火次之；土多木折 → 取木，水次之；火多木焚 → 取水，金次之；得時得勢旺極 → 取火洩其旺氣 |
  | 火 | 火炎木多（旺）→ 水剋火，水少逢金亦可；火弱水旺（衰）→ 土制水，土少逢火亦可；木多火熾 → 水制火，金次之；金多火熄 → 取火，木次之；土多火晦 → 取木，水次之；旺極 → 取土洩 |
  | 土 | 土重火多（厚）→ 木疏土，木弱逢水亦可；土少木多（薄）→ 金制木，金弱逢土亦可；水多土流 → 取土幫身，火次之；火多土焦 → 取水制火，金次之；金多土弱 → 取火剋金，木次之；旺極 → 取金洩 |
  | 金 | 金多土厚（老）→ 火煉金，火少逢木亦可；木重金輕（嫩）→ 土生金，土薄逢金亦可；土多金埋 → 取木，水次之；火烈金傷 → 取水，金次之；水多金沉 → 取土，火次之；旺極 → 取水洩 |
  | 水 | 水多土少（大）→ 土剋水，土少逢火亦可；水少土多（小）→ 木剋土，木少逢水亦可；金多水濁 → 取火，木次之；火炎水熱 → 取水，金次之；木多水縮 → 取金，土次之；旺極 → 取木洩 |
