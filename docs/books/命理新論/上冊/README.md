# 吳俊民《命理新論》上冊：按章節詳細筆記

上冊是函授「初級」講義，第一至二十章，書頁 p.1–372。這份筆記每「章」一個檔，2026-11 從初學者的角度重新讀過整本掃描檔整理：先講本章在學什麼，再依書上的節次與小標題詳細解說，艱澀詞句與古文引文都另外白話解釋。

每個檔案的結構：一句話導讀 → 本章在講什麼 → 依書上節次詳解（附書頁）→ 命例 → 作業（附答題提示）→ 名詞小辭典 → 和課堂、App 的對照。

命例一律用 App 排盤格式（時 日 月 年，十神在天干上方，藏干本氣置中加粗並附藏干十神，五行寫成小字 `**壬**<sub>水</sub>`），每例分「書上怎麼說／一步一步看／學到什麼」。上冊命例大多只有八字、沒有出生日期，少數附大運吉凶。作業題書上沒有答案，筆記的「答題提示」是依本章內容整理；需要計算的題目標明「筆記者試答／試排」。這是讀書筆記，不是原文，引文只取短句。

## 章節架構

- **第一至八章　基礎**：天干地支、陰陽五行、天干沖剋合化、地支沖合會刑穿、時辰節氣月建、十二長生、地支藏干與月令分日用事、旺相休囚死。
- **第九至十三章　排盤**：四柱排法（作者用冬至換年、真太陽時、夜子時）、十神定名、命宮、神煞、大運流年。
- **第十四至十六章　五行性情與論命程序**：十天干性質、四時五行宜忌、論命四步驟（定格局 → 取用神 → 明喜忌 → 下判斷）。
- **第十七至二十章　論命核心**：格局的種類（普通格局、特別格局及歷代議論）、日干強弱（得時、得地、得勢）、干支生剋合化與沖合會刑穿、十神的一般作用與喜忌。

## 作者的特殊排盤規則（讀命例前先知道）

- **冬至換年**：作者以冬至（而不是立春）換年柱，但月柱照節氣排。所以冬至後、立春前（子月下半、丑月）出生的命例，年柱已換成下一年，月柱卻還是前一年的干支，與五虎遁不合。筆記照書錄入，表下保留 ⚠ 警示，並加「筆記者註」說明。
- **夜子時**：23:00–24:00 出生，日柱用當日、時干用次日的子時干（第九章例二）。
- **真太陽時**：時辰依出生地經度校正。
- **命宮過中氣加一月**、**小運不用**（起運前看月柱）、**大運天干管前五年、地支管後五年**。

## 本版對舊筆記的更正

舊版主題筆記與逐頁筆記是逐頁快速判讀，直排小字的命例有些抄錯或缺漏。本版重讀原書後，主要更正如下：

- **第十七章**：從財格時柱為己丑；化土格為「戊辰 壬戌 甲辰 己巳」（年柱是最右一欄）；暗沖例三、例四四柱；四庫格例為「乙丑 癸未 壬辰 庚戌」。
- **第十八章**：強例四為「甲寅 丁卯 甲子 甲子」、強例七為「癸卯 乙卯 甲寅 乙亥」；原本「四柱判讀不確定」的 8 例全部補齊。
- **第十九章**：第二節例三「己卯 甲戌 乙亥 己卯」、例六時柱乙巳、例七「丁卯 壬寅 庚午 丙戌」、例八「丁未 甲辰 己酉 戊辰」；第四節例八時柱己酉、例十七至二十補齊；第六節例四「庚寅 戊寅 戊寅 甲寅」。
- **第二十章**：七殺的作用書上是「兩種」（生印耗財、攻身制劫），不是三種；第四節印的喜忌總結舊筆記接錯行，已依原書更正。
- 章節頁碼：第十九章實際到 p.345，第二十章從 p.346 開始（舊筆記寫 p.347／p.348）。
