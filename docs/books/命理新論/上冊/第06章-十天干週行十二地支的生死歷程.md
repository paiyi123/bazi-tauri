# 第六章　十天干週行十二地支的生死歷程（書頁 p.39–47）

> 一句話導讀：這一章就是俗稱的「十二長生」：每個天干走過十二地支時，會經歷長生、沐浴、冠帶、臨官、帝旺、衰、病、死、墓、絕、胎、養十二個階段。學會它，才看得懂後面的「得地」「通根」「坐墓」「臨官（祿）」等說法。作者同時介紹了古今對「陰干是否逆行」的爭論，並提醒初學者先背熟、再評論。

---

## 本章在講什麼

本章三節：

1. **第一節　事物存在發展的共同歷程**（p.39–42）：萬物有週期；把發展分成十二階段，各階段的比喻；陰陽的生死順逆。
2. **第二節　十天干週行十二地支的生旺死絕**（p.42–44）：甲乙丙丁戊己庚辛壬癸各自的十二階段，總表，以及掌上記憶法。
3. **第三節　十天干週行十二地支的議論**（p.44–46）：《滴天髓》劉伯溫註、任鐵樵註、沈孝瞻《子平真詮》對「陽生陰死、陰生陽死」的不同看法。

最後是「第六次作業題」（p.47）。

## 第一節　事物存在發展的共同歷程（p.39–42）

### 一、事物發展的週期性（p.39–40）

太極是事物存在的本體，陰陽是事物發展的現象，五行是調理事物存在發展的樞機（第一、二章已說過）。一切事物在時空不斷的綜合變遷中，它的本身也無時無刻不在變化中。基於「天人合一」的道理，一切事物的變化，也好像日月星辰一樣「**週而復始**」，只是時間有長有短不同而已。

作者舉行星繞日的週期為例：金星繞日一週約 225 天、水星約 88 天、火星約 1.88 年、木星約 11.862 年、土星約 29.5 年、天王星約 84.015 年、海王星約 164.788 年、冥王星約 248.43 年。研究事物發展，應該經過哪幾個階段才算循環一週，這是個重大問題。作者說美國已有許多專門學者（包括科學家、哲學家及宗教家）組織「**週期學會**」，正在積極對各種有形無形事物發展的歷程加以廣泛研究（p.39）。

自從科學昌明以來，宇宙的神秘凡是可以用人類的手、目、智力或儀器探知的，確已發現不少；但現在的科學研究已進入純「數」的境界，單靠手、目、儀器似乎已有技窮的狀態。如果沒有相當的理論（尤其是哲學上的理論）可以根據，一切靠「大膽假設」，歷經「嘗試錯誤」而期得「相當成果」，不但人力、物力、財力浪費，一切希望也甚渺茫。所以現代「先知」的科學家已覺悟到科學必須回復與哲學為友的階段了。換句話說，今後的科學必須以哲學為指針，否則海底撈針，徒勞無功，可以預測。事物發展的「週期性」，雖然到了現代科學家才加以注意，可是命理學者在奠定命理學的基礎之時，就已確立了（p.40）。

### 二、事物發展的共同歷程：十二階段（p.40–41）

命理學者一向認為，不管事物發展週期的久暫，其必須經過的歷程大概可以分為十二個階段，好像一年十二個月、一日十二時辰一樣。這是一個命理的設定，不過這個設定絕對不是「玄之又玄」的東西，而是比照日月循環的道理而來的。就邏輯學看來，凡是一種道理或法則，在一定的時空中，它必須能同時說明有形事物及無形事物的現象，否則有變無常、本身已走進孤陰孤陽的境界。

歷代命理學者依據「**無而有者謂之生，有而盛極謂之旺，盛極漸消謂之衰，有而無者謂之絕**」以及「**貞下起元**」（終而復始）之義，設定事物發展各階段的代名詞，按序說明如下（生旺死絕十二名詞應背念）：

| 階段 | 比喻（作者的白話） |
|---|---|
| ① 長生 | 好像人初生出來，或植物出芽一樣。 |
| ② 沐浴 | 好像人既生以後沐浴去垢，或葉芽脫去苗端青殼一樣。 |
| ③ 冠帶 | 好像人漸長大，必須有交際的禮服一樣。 |
| ④ 臨官 | 好像人到壯年，必須治事一樣。 |
| ⑤ 帝旺 | 好像人的體力、智力及事業已發達到最高階段。 |
| ⑥ 衰 | 物極必反，好像人開始走下坡一樣。 |
| ⑦ 病 | 衰盛則病，已無多大氣力了。 |
| ⑧ 死 | 氣盡而無餘力了。 |
| ⑨ 墓（庫） | 造物收藏，而各歸其庫。 |
| ⑩ 絕 | 前氣已盡，而後氣將續。 |
| ⑪ 胎 | 後氣繼續，而結聚成胎。 |
| ⑫ 養 | 好像人養胎於母親的腹中一樣。 |

作者說：這是命學上生存發展的十二個階段，它是循環無窮的。雖然對於名詞的設定或許比擬失當，且其解釋也不一定可以確切說明萬事萬物發展的現象；可是事實上事物的發展確實有這種歷程，在沒有更適當的名詞可以代替以前，還是暫時保留。同時對於每一個名詞，**千萬不要專靠「望文生義」**，須知道這是一串事物發展歷程中各階段的代名詞，即使改用符號代表，亦無不可。但是用符號代表，更不易了解其含義，則可想而知（p.41）。

> 💡 初學者解說：「死」不是真的死，「墓」不是墳墓，「沐浴」也不是洗澡。它們只是「第八階段」「第九階段」「第二階段」的代號。例如八字說「甲木坐午為死地」，意思是甲木在午這個位置氣已洩盡、沒有根力，不是說這個人會死。

### 三、陰陽的生死順逆（p.41–42）

事物的陰陽原是同時存在、無所謂生與死；然而就天體運行之道加以觀察：太陽正照子位為**陽生**，歷經丑、寅、卯、辰、巳至午位為陽之極，陽極則陰生；太陽正照午位為**陰生**，歷經未、申、酉、戌、亥至子位而陰極，陰極則陽生。這樣交互演變、循環不息，只是陰陽的始終而已，也就是「陽之始為陰之終，陰之始為陽之終」。

但是事物於始生之前常有「**幾兆**」，到始生時才能成象。「幾」是一種不容易看得見摸得到的東西，好像男精女卵；「兆」是一種逐漸成形的東西，好像腹中的胎兒，一旦出生時才能成完整的形象。如前述陽生於子、陰生於午，則陽始生的幾兆應該在子之前，陰始生的幾兆應該在午之前。近代兵家之所以重視研幾或制機，其原因就在這裡。所以說陰陽始終或生死，並不是可以截然分開的，而是陽中有陰、陰中有陽（p.42）。

**但研究還是要分**：我們研究命理學，如果始終抱定「陰陽一體」的見解，則將無法分析人生的一切現象了。因此仍然要用科學的方法，設法把它區別出來，以便觀察、比較、研判，而斷定人的吉凶悔吝；否則僅能說一句「好的就是壞的、壞的就是好的」，那又何貴乎我們來研究呢？（p.42）

**沈孝瞻《子平真詮》**：「陽主聚，以進為進，故主順；陰主散，以退為進，故主逆。此長生沐浴等，所以有陰陽順逆之殊也。四時之運，成功者退，待用者進，故每干流行於十二支，而生旺死絕又有一定。陽之所生，即陰之所死，彼此互換，自然之運也。」

白話：陽氣主凝聚，往前走就是前進，所以順行；陰氣主發散，往後退反而是前進，所以逆行。這就是十二長生有陰順陽逆差別的原因。一年四季，完成任務的退場、等待上場的進場，所以每個天干在十二地支的生旺死絕有一定規律；陽干長生的地方就是陰干死的地方，互相交換，這是自然的運行。

所以命理學就有五行「**陰生陽死、陽生陰死、陽順陰逆**」的說法（p.42）。

## 第三節　十天干週行十二地支的議論（p.44–46）

### 《滴天髓》原文與劉伯溫註（p.44–45）

《滴天髓》說：「**陰陽順逆之說，洛書流行之用，其理信有之也，其法不可執一。**」

作者解釋：這是說陰陽順逆的道理大體上是可以相信的，但不可「執一不變」。好像今天的直流電、交流電，陰陽流行雖有不同，而其發光發熱或產生力量則無二致（p.45）。

**劉伯溫註**：甲木死在午，因為午是（木的）洩氣之地，道理說得通；但乙木死在亥，亥中有壬水，是乙木的生母（嫡母），怎麼會死呢？凡此都要詳察干支輕重之機、母子相依之勢、陰陽消息之理來論吉凶才對；如果專執「生死敗絕」之說，推斷多半會錯。

**任鐵樵註**之一：「若論命理，則不專以順逆為憑，須觀日主（日柱天干）之衰旺，察生時之淺深，究四柱之用神，以論吉凶，則了然矣。」
- 白話：論命不能只靠陰陽順逆的十二長生，要看日主強弱、出生時令的深淺、四柱的用神來論吉凶。

**任鐵樵註**之二（作者照錄，這裡摘要）：

- 古法只有「**四長生**」（亥、寅、巳、申），從來沒有「子午卯酉為陰長生」的說法。
- 例如木：水生木，申為天關、亥為天門，天一生水，生生不息，所以木（不論甲乙）都生在亥；木到午發洩已盡，所以木（不論甲乙）都死在午。其他五行類推。
- 五陽「育於生方、盛於本方、弊於洩方、盡於剋方」，在理為順；五陰卻「生於洩方、死於生方」，在理為背。即使曲為之說，子午之地終究沒有產金產木之道（辛生子、乙生午說不通），寅亥之地也終究沒有滅火滅木之道（丁死寅、乙死亥說不通）。
- 古人取格時：丁遇酉以「財」論，乙遇午、己遇酉、辛遇子、癸遇卯，以「食神洩氣」論，都不以「長生」論；乙遇亥、癸遇申以「印」論，不以「死」論；己遇寅藏的丙火、辛遇巳藏的戊土也以「印」論，不以「死」論。
- 結論：「**陰陽同生同死可知也**，若執定陰陽順逆，而以陽生陰死、陰生陽死論命，則大謬矣！」

### 沈孝瞻的反方意見（p.46）

而山陰沈孝瞻先生（《子平真詮》作者）則力主陰陽順逆：

以甲乙為例，甲是木之陽，是天之生氣流行於萬木者，所以生於亥而死於午；乙是木之陰，是木的枝枝葉葉承受天之生氣者，所以生於午而死於亥。

- 木當亥月，正是枝葉剝落之時，但內在的生氣已收藏飽足，可以作為來春發洩之機，這就是甲木生於亥的原因。
- 木當午月，正是枝葉繁盛之時，為什麼甲木反而死？卻不知外表雖繁盛，而內在的生氣已發洩殆盡，這就是甲木死於午的原因。
- 乙木反過來：午月枝葉繁盛，就是乙木的「生」；亥月枝葉剝落，就是乙木的「死」。

「以質而論，自與氣殊也。」——甲是「氣」，乙是「質」，本來就不一樣。以甲乙為例，其餘可以類推。

> 💡 初學者解說：兩派的差別一句話就是：
> - **陰陽同生同死派**（任鐵樵）：乙木也長生在亥、死在午，和甲木一樣。
> - **陽順陰逆派**（沈孝瞻、多數傳統命書）：乙木長生在午、死在亥，與甲相反。
>
> 實際論命時，大家最常用的是「通根」：看地支藏干裡有沒有同類五行。乙木見亥，亥中有甲（比劫根）、壬（印），不管叫它「死地」還是「長生」，乙木在亥都有幫助。

### 作者的態度（p.46）

初學命理，對於歷史上理論的爭辯，一時尚難判斷誰是誰非。作者之所以一再提供若干參考資料：

1. 使大家知道凡是一種學問，均不免有爭辯之處；
2. 使大家排除迷信的心理，而能以客觀的科學精神來研究命理上的諸問題。

不過在初學時，對於若干基本條件或法則，必先盡力設法熟記；那麼今後為人推算命運也好，推翻舊有的法則或建立新的法則也好，總不至於臨時東翻書籍、西閱表冊之苦。至於歷史上爭議的事項，到了相當的程度，作者自然會給講評（p.46）。

## 第六次作業題（p.47）

1. **試就所知，舉一例說明事物發展的「週期性」。**
   - 答題提示：行星公轉、四季、晝夜皆可。見第一節一。
2. **按序默寫事物發展十二階段的名稱。**
   - 答題提示：長生、沐浴、冠帶、臨官、帝旺、衰、病、死、墓、絕、胎、養。
3. **幾、兆、象是什麼意思？能舉例說明嗎？**
   - 答題提示：幾如男精女卵（看不見摸不到的開端），兆如腹中胎兒（逐漸成形），象如出生後完整的形象。見第一節三。
4. **試就十天干週行十二地支生旺死絕的關係，舉一例說明「陰生陽死、陽生陰死及陽順陰逆」。**
   - 答題提示：甲生亥死午（順行），乙生午死亥（逆行）；甲死之地即乙生之地。見第二節。
5. **五陽干各長生於何地支？五陰干各長生於何地支？**
   - 答題提示：甲亥、丙戊寅、庚巳、壬申；乙午、丁己酉、辛子、癸卯。
6. **為什麼研究命理不可存有迷信的心理？**
   - 答題提示：學問都有爭辯，要以客觀的科學精神研究。見第三節「作者的態度」。

作業題旁作者引《中庸》：「禍福將至，善必先知之，不善必先知之。」

## 名詞小辭典

- **十二長生**：長生、沐浴、冠帶、臨官、帝旺、衰、病、死、墓、絕、胎、養，天干在十二地支的十二個氣勢階段。
- **臨官（祿）**：天干的第四階段，也是「祿」所在。甲祿寅、乙祿卯……
- **帝旺（刃）**：第五階段，力量最旺；陽干的帝旺位也是羊刃位。
- **墓（庫）**：第九階段，收藏之地。辰戌丑未為四庫。
- **火土同宮**：戊隨丙、己隨丁論長生（本書採用）。另一派「水土同宮」讓戊己隨壬癸，本書不用。
- **陽順陰逆**：陽干十二長生順著地支走，陰干逆著走。
- **陰陽同生同死**：任鐵樵主張陰干與陽干同一長生、同一死地，不逆行。
- **四長生**：亥、寅、巳、申，五陽干的長生之地（也是四孟、四驛馬位）。
- **望文生義**：只看字面就推想意思。作者提醒「死、墓、沐浴」只是階段代號。
- **貞下起元**：終而復始，冬（貞）盡又回到春（元）。
