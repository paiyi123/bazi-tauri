# 第十五章　四時五行宜忌概說（書頁 p.172–195）

> 一句話導讀：上一章講十個天干的個性，本章改從「五行 × 四季」來看：同樣是木，生在春天和生在秋天，喜歡和害怕的東西完全不同。作者主要引《窮通寶鑑》（《欄江網》）與《三命通會》（逐月說明），最後一節把全部濃縮成一張「日主屬什麼、遇到什麼情況、取什麼為用」的速查表，並解釋「旺、強、多、弱」四個字的分別。

---

## 本章在講什麼

1. **第一節　四時木的宜忌**（p.172–177）
2. **第二節　四時火的宜忌**（p.177–180）
3. **第三節　四時土的宜忌**（p.180–184）
4. **第四節　四時金的宜忌**（p.184–188）
5. **第五節　四時水的宜忌**（p.188–191）
6. **第六節　五行四時宜忌綜述**（p.191–194）：《淵海子平》「五行生剋制化各有所喜所忌」（須背念）；旺、強、多、弱的定義；五行取用簡則。

最後是「第十五次作業題」（p.194–195）。

每一節的寫法都一樣：先引《窮通寶鑑》對該五行的總論與春、夏、秋、冬各季的說法；再引《三命通會》逐月說明（並附古代「某州人生此月如何」的說法）；最後是作者的白話總結。

> 💡 初學者解說：本章其實就是「**調候**」與「**扶抑**」的入門。課堂說普通格局取用神以扶抑為本，調候、病藥、通關不可和扶抑衝突；本章各季的宜忌，就是在練習這兩種思路。

### 作者前言（p.172）

- 前章雖就十干分別說明性質及喜忌，但初習命理者因尚少揣摩，對陰陽異性、喜忌不同，一時還不易體會。論命者談五行而不談陰陽，只是知其一而不知其二；今後要談的傷食、官殺、比劫的區別，及肝膽、脾胃互為表裡等，都須論陰陽。
- 作者自述：二十餘年前初習命理時，對這些複雜多端的五行陰陽性質及喜忌，也是興趣不濃、勉強研讀，多是囫圇吞棗；後來一再玩索、一再體會，才知道這是論命得失的最大關鍵。如果不徹底研究，只就五行情勢粗枝大葉地應用，雖也能略知命運的梗概，對細微末節就沒有辦法推論。
- 初習命理的人常有浮躁急切之情，想既簡易又速成，對繁雜的理論與法則多不願、不敢下最大的工夫去記憶推論，這是治學最可怕的現象；任何學問都不能坐以倖致，必須經年累月不斷探討，有毅力有恆心才能有成就。
- 本章為使初學者對五行宜忌有一個綜合的認識，暫不分陰陽，介紹四時五行的宜忌；逐月五行陰陽的宜忌，以後再詳談。

## 第一節　四時木的宜忌（p.172–177）

### 木的總論（《窮通寶鑑》）

- 木性騰上而無所止；木多（氣重）則欲得金來任使，木有金則有斧斤之用。
- 土重則根蟠深固，土少則有枝茂根危之患。
- 木賴水生，少則滋潤，多則漂流。
- 生木（如甲寅、乙卯、甲辰）得火而秀，丙丁相同；死木（如甲申、乙酉、甲午）得金而造，庚辛必利。生木見金自傷，死木得火自焚（活木喜火忌金，死木忌火喜金）。
- 金木相等，格成「斲輪」；若向秋生，反為傷斧，是秋生忌金重也。
- **作者解說**：木為陽，性質是騰上而無所止，所以木多愛金氣以收斂，同時愛土來培育。木沒有水則無生氣，水太多則成飄蕩。活木喜火忌金、死木忌火喜金。如果金木力量相等，是為「身殺兩停」，怕生於秋或行西方運；若木旺得金則良，終身獲福。

### 春木

- **《窮通寶鑑》**：木生於春，餘寒猶存，喜火溫暖，則無盤屈之患；藉水資扶，而有舒暢之美。春初不宜水盛，陰濃則根損枝枯；春木陽氣煩燥，無水則葉槁根乾，所以水火二物既濟方佳。土多而損力，土薄則財豐；忌逢金重，傷殘剋伐，一生不閒；設使木旺，得金則良，終身獲福。
- **《三命通會》逐月**：
  - 正月（寅）木：三陽交泰，寒氣未除；見火則生意藹然，富貴無敵；火多洩其元氣，也只是衣食而已；逢金折傷之患，得火制之為福；見水不為子（木）母（水）相生，蓋初春（寅）之木，纔有生意，見水則寒，反為不吉。
  - 二月（卯）木：生意暢茂，遇土培植為佳；火土同行，富貴而壽；火盛亦洩其氣，蓋花木始含英而值陽發散故也。
  - 三月（辰）木：正條達長茂之時，春陽和煦，萬紫千紅；雨水浸淫（水太多），根株搖動；見土則根深蒂固、福壽綿延；見火則木通火明，文章秀發；逢金伐木，凶。
- 先賢有云：「春木雖旺，不宜逢金。」

### 夏木

- **《窮通寶鑑》**：夏月之木，根乾葉燥，盤而且直，屈而能伸；欲得水盛而成滋潤之力，誠不可少；切忌火旺而招焚化之憂，故以為凶。土宜在薄，不可厚重，厚則反為災咎；惡金在多，不可欠缺，缺則不能琢削；重重見木，徒以成林，疊疊逢華，終無結果。
- **《三命通會》**：夏木病巳、死午、墓未，蓋南方火盛洩其真氣故也；陰雨則吉，亢晴則忌。四月木未甚衰、火未甚旺，見微火則枝葉茂盛；五、六月（午未）之木喜雨水、夜生尤奇；值此者富貴而壽；火盛無水者貧夭。夏令炎威火盛、爍石流金，木有枯槁之患；或水制、或夜生、或陰雨天，化凶為吉；得土以培其根、得水以達其枝，若水土同行，非惟富貴，且壽考康寧；見金不能剋木，火旺金衰，有子復仇（火為木之子，旺相可剋衰金）。

### 秋木

- **《窮通寶鑑》**：秋月之木，氣漸淒涼，形漸凋敗。初秋之時，火氣未除，尤喜水土以相滋；中秋之令，果已成實，欲得剛金而修削；霜降後不宜水盛，水盛則木漂；寒露節又喜火炎，火炎則木實。木多有多材之美，土厚無自立之能。
- **《三命通會》**：秋三月（申酉戌）之木，惟欲晴雨得宜；亢旱則物皆枯槁，淫雨則物不收成。初秋（申月）炎威未退，不宜與火同行，陰雨生者為妙；見金雖有剝剋之嫌，然火氣尚炎、金氣未盛，不為害也；處暑以後，逢土培植、利就名成；水盛無土，主飄蕩無居。八、九月（酉戌）之木，正凋零之時，晝火同躔者貧夭（秋陽燥烈，木皆枯落）；或夜生或陰雨或水解之方吉。得土栽培，根基穩厚；見金反吉，蓋金司令則萬物摧落，既無長養以遂其生，又未歸根以復命，所可藉者在一金耳！苟無金制以成其器，則為天地間一朽木耳。所以仗斧斤之力剗削成器，而為棟樑之用，正所謂「斧斤以時入山林，材木不可勝用也」。氣運宜往東方南方。

### 冬木

- **《窮通寶鑑》**：冬月之木，盤屈在地，欲土多而培養，惡水盛而忘形；金縱多不能剋伐；火重見溫暖有功；歸根復命之時，木病安能輔助？須忌死絕之地，只宜生旺之方。
- **《三命通會》**：冬木正肅殺之時，復命歸根，微有小春（十月小陽春）生意，以見造化無終窮之理；易曰「碩果不食」者此也。生於晴明者最佳；值陰雨則凝冰積雪。十月之木，遇火貴而有壽，蓋冰寒土凍，仗火以溫暖其根故也；火土輔運，富貴雙全；見金雖無害其根本，未免骨肉參商；得水則有滋助之意。若子丑月（十一、十二月）之木，喜火融之，與土同躔，位登台鼎；見水凶剋，蓋冬令水冷木寒，無火溫之，則冰凝凍合，而生意摧折矣！見金雖傷不害，蓋木任冬令，歸根者斧斤無所施，凋零者剗削可成器，所以見金而無咎也。氣運宜往南方，多木喜南奔也，東方次之。

### 作者總結（p.176–177）

- 木生於春天，就時令言固當屬旺；如果四柱再無比、劫、印綬，而且八字滿布火土金，則剋洩太甚，雖旺猶衰，這是**木得時而不得勢**。
- 反之，木生秋天，就時令言固當為死；然而八字滿布比、劫、祿、刃、印綬，土金有氣無力，這是**木得勢而不得時**。
- 如果木生春天，天干地支滿布比劫祿刃印綬，木氣強盛可知，這是**木得時又得勢**；反之，木生於秋天，天干地支滿布財、官、傷、食，木氣衰弱不堪，這是**木失時而又失勢**。
- 此外，尚有天干合化、地支合化或氣會一方，也可成為得勢。似此情形，均須就命局五行四時強弱旺衰綜合論斷其喜忌，未可盡如前述所論。初學命理者對此暫先認識其梗概，俟了解「取用神」「明喜忌」以後，再詳加研究，以便論人命的富貴貧賤、窮通壽夭。其他各行四時宜忌，也有此種情形，均須先從個別認識入手，才有辦法綜合論斷。

> 💡 初學者解說：「得時」＝月令幫你（得令）；「得勢」＝八字中幫你的字多（得勢）。這就是課堂判斷日主強弱的「得令、得勢、得地」中的前兩項。

## 第二節　四時火的宜忌（p.177–180）

### 火的總論（《窮通寶鑑》）

- 炎炎真火，位鎮南方，故火無不明之理；輝光不久，全要伏藏。故明無不滅之象。火以木為體，無木則火不長焰；火以水為用，無水則火太酷烈。故火多則不實，火烈則傷物。
- 木能藏火，到寅卯方而生火；不利於西，遇申酉而必死。生居離（南方火地）位，果斷有為；若居坎（北方水鄉）宮，謹畏守禮。
- 金得火和，而能鎔鑄；水得火和，則成既濟。遇土不明，多主蹇滯；逢木旺處，決定為榮。
- 木死火虛，雖得永久，縱有功名，必不久長。春忌見木，惡其焚也；夏忌見土，惡其晦也；秋忌見金，金雖剋制，多忌見水，水旺則滅。故春火欲明，不欲炎，炎則不實；秋火欲藏不欲明，明則太燥；冬火欲生，不欲殺，殺則欲滅。
- **作者解說**：火居南方，它的真性是熱與光。有木為生火的原料，火有所附麗，才能顯其光輝；以水為對象，才能顯其功用。火性炎上，行於東南有欣欣向榮之象，行於西北有逆火之性、漸次滅絕。丙丁的功用雖不相似，性質則相同。生於南方，性質果斷、向上有為；生於北方，小心謹慎、能守禮教法令。強金必須得旺火才能盡鎔鑄之功；如果遇水則火得中和，形成「既濟」。如果遇旺土，則土多火晦，一生蹇滯不前。如果火身處死囚休之地，自身難保，哪裡還有餘力去擔當財官呢？

### 春火

- **《窮通寶鑑》**：火生於春月，母旺子相，勢力並行。喜木生扶，不宜過旺，旺則火炎；欲水既濟，不愁水盛，盛則沾恩。土多則塞蔽埋光，火盛則傷多烈燥；見金可以施功，縱重見用財可望。
- **《三命通會》**：三春之火，其氣溫，然而始著也；晴則藉木而明，雨則濕木而晦。正月微陽之火，隱於木中，雖有可親可愛之意，但冰霜之氣未消，遇木生之，則陽氣發揮；逢金為財，官居鼎鼐；逢金值水，夭折無疑。二月見木，敗處逢生，木秀火明，文章富貴人也；但不宜有水，蓋濕木不生無焰之火也。三月穀雨之後生者，微水無凶，蓋土司令，木主時，化凶為吉也。土與金正月同論，但辰月土差旺耳！

### 夏火

- **《窮通寶鑑》**：夏月之火，秉令乘權。逢水制則免自焚之咎；見木助必遭夭折之憂；遇金必作良工；得土遂成稼穡。金土雖為美利，無水則金燥土焦；再加火助，太過傾危。
- **《三命通會》**：夏令之火，陽氣之極，草木為之焦枯，江河為之涸竭；晴則流金爍石，真陽盡洩；雨則水濟其威，方得中和，反應蔭庇發福。

### 秋火

- **《窮通寶鑑》**：秋月之火，性息體休；得木生則有復明之慶；遇水剋難逃隕滅之災；土重而掩息其光；金多而損傷其勢；火見火以光輝，縱疊見而必利。
- **《三命通會》**大意：初秋之火炎威未退，土傳生氣、水不能剋，反主貴榮；見木助之，顯達非常；見金為財，富貴豪奢。八、九月失時之火，見木生之，生意無窮、富貴無敵；金木同躔，官居宰輔；有金無木，主弱敵強，不免有爭擾之事；與土同躔，洩其真元，孤刑冷退。運喜東南，西北忌之。

### 冬火

- **《窮通寶鑑》**：冬月之火，體絕形亡；喜木生而有救；遇水剋以為殃；欲土制為榮，愛火比為利；見金而難任為財，無金而不遭磨折。天地雖傾，水火難滅。
- **《三命通會》**大意：冬月之火，人多親之；晴霽則明，陰雨則滅，故見水為凶、木生為貴。有水無木，輕者疾、重者夭；雖生富厚之家，不免冷退。逢土洩之，弱中又弱，蹇滯終身。見金為財，又被水剋（金生水剋火），也不吉。

## 第三節　四時土的宜忌（p.180–184）

### 土的總論（《窮通寶鑑》）

- 五行之土，散在四維，故金木水火依而成象，四時皆有用、有忌。火死於酉，水旺於子，土賴火生，則土囚；土喜水財，則土弱。土聚則滯，土散則輕。
- 辰戌丑未為土之正位，但分陰陽：**辰有伏水**（辰為水庫）、**未有匿木**（未為木庫）、**戌有藏火**（戌為火庫）、**丑有隱金**（丑為金庫）。辰為木之餘、未為火之餘、戌為金之餘、丑為水之餘。所以辰、未有水木可滋生萬物；戌、丑有金火，則能肅殺萬物；故有貴與不貴的分別。
- **作者解說**：土寄於四維，四時都有用、有忌；土賴火生，如果沒有財、官、食、傷而純是一片土，則失之於滯，土太多反而不好。辰戌丑未雖都是土，但所藏不同，作用也不同。

### 春土

- **《窮通寶鑑》**：春月之土，其勢虛浮；喜火生扶，惡木太過；忌水泛濫，喜土比助；得金而制木為祥，金多仍盜土氣。
- **《三命通會》**大意：土值春時，土膏脈起，萬物含生；雨則陰凝土濕，晴則凍釋陽和。正月之土尚有霜寒，遇水則冰、值木則病，唯得火溫之則榮華無比，逢金制木亦名利兩成。二月之土正木盛土崩之時，遇木同躔有脾胃、腸風、痔漏之災，見火同躔位登台鼎，見水則凶。三月之土是季月、土行最旺，有火溫煥則陽氣發舒；見木非疾則夭；見金制木，反因成吉。

### 夏土

- **《窮通寶鑑》**：夏月之土，其勢燥烈；得盛水滋潤成功，忌旺火煆煉焦坼；木助火炎，水剋無礙；金生水泛，妻才有益；見比肩蹇滯不通，如太過又宜木剋。
- **《三命通會》**大意：土旺長夏，火盛土生之故。陰雨則濕養萬物，故見水為吉；亢旱則田疇龜坼，故遇火為凶。孟夏（巳）之土炎氣未盛，終喜火以助之，逢木則疾夭，見水為財。五、六月（午未）之土見火則燥、萬物焦枯；或陰雨或夜生，雖災不甚；見水滋養萬物，主富貴文章；見木疏通其性，多聰明特達；遇金無用（火盛金衰，不能制木）。

### 秋土

- **《窮通寶鑑》**：秋月之土，子旺母衰；金多而耗盜其氣，木盛須制伏純良；火重重而不厭，水泛泛而不祥；得比肩則能助力，至霜降不比無妨。
- **《三命通會》**大意：土逢秋令，金氣盛旺，洩土而氣薄，晴雨須要得宜。七月（申）之土火氣未除、土性尚燥，喜水滋之，萬物實矣；逢木為災。八、九月（酉戌）之土，見木則不能剋（萬物凋零之時，金氣生旺，子復母仇）；見金洩氣太甚，有冷退怯弱之患；見火助之，文武名高；見水為財（土以水為財星）。戌月僅可運喜火土之鄉，水金木方有忌。

### 冬土

- **《窮通寶鑑》**：冬月之土，外寒內溫；水旺財豐，金多子秀；火盛有榮，木多無咎；再加比肩扶助為佳，更喜身主康強足壽。
- **《三命通會》**大意：土於冬也，正天地肅殺之時，寒亦至矣，雖一陽下生，土脈未溫；值水雪則冰寒土凍，見火則寒谷回春。十月（亥）之土，惟喜火以溫之，則土脈陽和、萬物歸根；見木則凶，逢金則滯，遇水則主孤寒。子丑（十一、十二月）寒氣之極，火日融和，功名成就；見木最忌，見火解之為吉；見水則陰氣愈甚，水寒地凍，輕者疾、重者夭；見金亦主貧薄。歲運南方最佳，北方大忌。

### 四季土

- 四立（立春、立夏、立秋、立冬）以前十八天內，土神用事。辰戌丑未四土之中，**惟未土為極旺**；辰戌丑雖旺而未極，帶金氣洩之，以金洩其旺氣，不失中和。
- 未月之土旺，不可作稼穡看；臨此月而見金結局者，不貴即富。

## 第四節　四時金的宜忌（p.184–188）

### 金的總論（《窮通寶鑑》）

- 金以至陰為體，中含至陽之精，乃能堅剛，獨異眾物；若獨陰而不堅，冰雪是也，遇火則消。
- 金無火煉，不能成器；金重火輕，執事繁難；金輕火重，鍛鍊消亡。金火兩停，格名「**鑄印**」；遇金庫（丑），則犯刑損模。金多火旺，叫做「殺刃兩停」。
- 金白水清（純金遇水），富而聰明；金重而無火，則頑鈍；金能生水，水旺則金沉。
- 金無水則乾枯，金無土則死絕；土重則埋沒不顯。「金未成器，欲得見火；金已成器，不欲見火。」
- **作者解說**：金體至陰而中含陽精，所以堅剛；它與其他各行配合：火太過或不及都不好，金生三水洩氣太過、土太厚埋金也不行。金未成器要火，已成器則怕火，論命時要看命局及行運的不同情況。

### 春金

- **《窮通寶鑑》**：春月之金，餘寒未盡，貴乎火氣為榮；性柔體弱，欲得厚土輔助；水盛增寒，難施鋒銳之勢；木旺損力，有剉鈍之危；金來比助，扶持最妙；比而無火，失類非良。
- **《三命通會》**大意：春月之金，木旺火相，非金得氣之時；絕於寅、胎養於卯辰，正宜遇土以生之，謂其將絕而有生意。正月（寅）之金，見木為財，木神太旺，僅足衣食；遇火則有困難，見水洩其元氣，主貧寒孤弱。二、三月（卯辰）之金，見土則生生之意無窮，主人富貴而壽；遇鬼（火、剋殺）貧夭無疑，土生火制為吉；見木盛旺，以微弱之金欲制之，貧薄無情；見火則因金、困土，官訟爭擾。

### 夏金

- **《窮通寶鑑》**：夏月之金，尤為柔弱，形質未具，尤嫌死絕；火多而卻不厭；水盛而滋體呈祥；見木而助鬼傷身；遇金而扶持精壯；土薄而最為有用，土厚而埋沒無光。
- **《三命通會》**大意：夏月火盛、金至柔，晴時火燥金流，雨則水滋金潤，故夏令之金宜見土（主人有出將入相之權）。見木為財，荊、梁、豫人多主富貴；遇水孤寒（弱金不能生水）；若與火土同行，則富貴康寧。運喜土金，木火最忌。

### 秋金

- **《窮通寶鑑》**：秋月之金，當權得令；火來煆煉，遂成鐘鼎之材；土多培養，反惹頑濁之氣；見水則精神越秀；逢木則琢削施威；金助愈剛，剛過則決；氣重愈旺，旺極則損。
- **《三命通會》**大意：秋金肅殺，萬物凋零，晴則火鍛金堅，雨則水潤金明。七、八月（申酉）之金，得令其性剛強，仗火以制其威，則有玉帶金魚之貴；頑金無火不能成器；見水洩其旺氣，金白水清，多主詞林清貴；水火俱無則主夭折；見木為財，富而且貴；遇土則隱彩埋光，雖有財而不發。九月（戌）之金氣稍退，遇火夜生為奇、晝生少利；逢木則剋，應骨肉參商；見水濟之。

### 冬金

- **《窮通寶鑑》**：冬月之金，形寒性冷；木多則難施斧鑿之功；水盛而未免沉潛之患；土能制水，金體不寒；火來助土，子母成功；喜比肩聚氣相扶，欲官印溫養而利。
- **《三命通會》**大意：冬月天氣嚴肅，金伏藏之時。金胎於春、生於夏、旺於秋、至冬而死，謂其畏寒無生意。晴明則金清水秀，雨雪則水冷金寒，所以冬月之金得火融之，然後可以奪其寒氣，則富貴非常。初冬（亥）之金見火則為傷殘；日生者貧夭，夜生者孤寒；遇土則祿豐足；見水木俱不利。子丑（十一、十二月）生者，喜火以溫之，無火亦喜遇土，得火為貴；見水則寒，見木為財主富。運喜東南，西北最忌。

## 第五節　四時水的宜忌（p.188–191）

### 水的總論（《窮通寶鑑》）

- 水不絕源，仗金生而流遠；水流泛濫，賴土剋以堤防。水火均則合既濟之美；水土混則有濁源之凶。
- 四時皆忌：火多則水受涸；土重則水不流；金死則水困；木旺則水死。
- **作者解說**：水的源頭靠金，水太多要土作堤防；水火相等是既濟之美，水土混雜則是濁源之凶。

### 春水

- **《窮通寶鑑》**：春月之水，性濫滔淫；再逢水助，必有崩堤之勢；若加土盛，則無泛漲之憂；喜金生扶，不宜金盛；欲火既濟，不要火多；見木而可施功；無土仍愁散漫。
- **《三命通會》**大意：春月之水，孰不謂其病寅、死卯、墓辰為至弱？殊不知水為陰氣，至春陽氣上蒸，陰氣下降，故雨露既濡而水生發，這是水勢之常。正月（寅）生者，水有寒氣，見火則冰融凍釋、富貴雍容；得金相助，最佳；逢木無火，則水冷木寒，未有生意；遇土剋水，亦主貧寒。二、三月（卯辰）之水，浩無邊際，見土則有堤防，晝生則富貴，夜生則流移；生於穀雨後者，或主淫邪痺瘧之疾（土渾水濁）；見木洩之，能施惠及人；見火則水火相刑，災訟不免；遇金生水泛濫無情，得金助之無患。

### 夏水

- **《窮通寶鑑》**：夏月之水，執性歸源，時當涸際，欲得比肩；喜金生而助體，忌火旺而焰乾；木盛則盜其氣，土旺則制其流。
- **《三命通會》**大意：夏水失令，逢火則乾涸，所以忌晴而喜雨。初夏（巳）之時，水猶泛濫，得土止而不流，福氣深厚，但不宜與火同行（火盛則土燥而水涸）；逢水利就名成；金若生之，反主孤剋（夏令金衰母弱，不能生子，反傷於母）。五、六月（午未）之水，正能滋助萬物，喜土同行，生時更值陰雨者，主富貴文章。

### 秋水

- **《窮通寶鑑》**：秋月之水，母旺子相，表裡晶瑩；得金助則清澄，逢土旺而混濁；火多而財盛，太過不宜；木重而子榮，中和為利；重重見水，增其泛濫之憂；疊疊逢土，始得清平之意。
- **《三命通會》**大意：水生秋令，正水清秀之時，晴則清澈無瑕，雨則潦水渾濁。七月（申）之水，正能滋實萬物，不宜與火同行，火多者貧夭無依；金為母、子母相生，文章清貴；土來同處，化禍為祥；木若聯行，亦當貴顯。八、九月（酉戌）之水，遇令星（金）則福壽難量；金火同躔則功名炬赫；見木終被疏洩，不免先成後敗；火若同垣，恐金失力，雖有治民服眾之德，未免痰疾刑傷；見土雖凶不凶，蓋秋令金最能化難為福。運利西北，東南失宜。

### 冬水

- **《窮通寶鑑》**：冬月之水，司令專權；遇火則增暖除寒，見土則形藏歸化；金多反曰無義，木盛是謂有情；土太過勢成涸轍，水泛濫喜土堤防。
- **《三命通會》**大意：冬月司令之水，寒氣嚴凝之時；雨則冰凝，晴則凍釋，故冬三月俱喜火以溫之，則富貴無虞。見金母子相生，但冬令金寒水冷，雖相生而反貧薄；得火土同行為吉，逢土金骨肉參商。

## 第六節　五行四時宜忌綜述（p.191–194）

### 一、為什麼要先認識四時宜忌（p.191）

- 以「子平」方法論命，五行四時宜忌實為一重大關鍵；因為子平術以日柱天干為命主，故日干生於何月何節何氣，十天干週行十二地支的生旺死絕，及五行旺相死囚休等關係，其衰旺強弱實有不同。
- 推斷日干喜忌時，四柱天干地支與日干的生剋制化、刑合沖會，以及是否天透地藏，也有相當的關係；此外還有「正常」與「變化」等不同的法則，論命實在複雜多端。
- 初習命理者讀到這裡，不免因繁生厭，不肯多費工夫；這是一個重大的錯誤。須知對五行陰陽的性質及四時宜忌，如果沒有相當的認識，而貿然為人論命，就難免輕心大意之嫌。有的讀命書多年而心得無多，就是沒有用死硬的工夫研讀這些枯燥無味的材料；人情好逸惡勞、避繁趨簡，強人下最大的工夫有時也不可能。
- 所以作者介紹一個簡則，讓大家對五行宜忌有一個粗糙而簡易的概念；但要徹底研究命理的人，千萬不要以此為滿足，須時常將前述講義的內容加以研討。至於「定格局」「取用神」「明喜忌」，以後會一再說明；「五行生剋衰旺顛倒妙義」，也須留待以後詳細介紹。

### 二、《淵海子平》「五行生剋制化各有所喜所忌」（須背念）

| 類別 | 金 | 木 | 水 | 火 | 土 |
|---|---|---|---|---|---|
| 旺而得剋才成器 | 金旺得火，方成器皿 | 木旺得金，方成棟樑 | 水旺得土，方成池沼 | 火旺得水，方成相濟 | 土旺得木，方能疏通 |
| 靠生但生太多反害 | 金賴土生，土多金埋 | 木賴水生，水多木漂 | 水賴金生，金多水濁 | 火賴木生，木多火熾 | 土賴火生，火多土焦 |
| 生別人但別人太多反害 | 金能生水，水多金沉 | 木能生火，火多木焚 | 水能生木，木多水縮 | 火能生土，土多火晦 | 土能生金，金多土變 |
| 剋別人但別人太多反害 | 金能剋木，木多金缺 | 木能剋土，土多木折 | 水能剋火，火多水熱 | 火能剋金，金多火熄 | 土能剋水，水多土流 |
| 自己弱又被剋 | 金弱遇火，必見銷鎔 | 木弱逢金，必為砍折 | 水弱逢土，必為淤塞 | 火弱逢水，必為熄滅 | 土弱逢木，必為傾陷 |
| 強而要洩 | 強金得水，方挫其鋒 | 強木得火，方化其頑 | 強水得木，方洩其勢 | 強火得土，方止其焰 | 強土得金，方制其壅 |

> 💡 初學者解說：這張表是整個五行生剋的「反面教材」：生、剋本來是好事，但**過量**就變壞。背熟了，看到「水多木漂」「土多金埋」這類說法就知道在講哪種失衡。

### 三、旺、強、多、弱的定義（p.193）

- **旺**：五行得時令，或雖不得時令而八字天干地支黨多。
- **強**：五行得時令，又兼八字天干地支黨多。
- 所謂「**旺者宜剋不宜洩，旺極（強）宜洩不宜剋**」，就是指這兩種不同的情形。
- **多**：五行得時或得勢。
- **弱**：五行失時或失勢。

### 四、五行取用簡則（p.193–194）

作者以日干（命主）的五行分別說明，最後都有一條「得時得勢而旺極，就取洩」：

| 日干 | 情況 | 取用 |
|---|---|---|
| 木 | 木重水多（盛） | 用金剋木；金少逢土亦可 |
| | 木微金剛（衰） | 用火制金；火少逢木亦可 |

| | 土多火晦 | 取木；取水次之 |
| | 得時得勢而旺極 | 取土洩其旺氣 |
| 土 | 土重火多（厚） | 用木疏土；木弱逢水亦可 |
| | 土少木多（薄） | 用金制木；金弱逢土亦可 |
| | 水多土流 | 取土幫身；取火生身次之 |

## 第十五次作業題（p.194–195）

1. **初春之木，為什麼喜火？**
   - 答題提示：餘寒猶存，喜火溫暖才無盤屈之患；正月微陽、見水則寒。
2. **夏月之木，為什麼忌火？**
   - 答題提示：根乾葉燥，火旺則有焚化之憂；喜水滋潤。
3. **冬月之木，最怕什麼？**
   - 答題提示：怕水盛（冰凝凍合、忘形）；須忌死絕之地，只宜生旺之方，喜火土溫暖培根。
4. **試簡述夏月之火的宜忌。**
   - 答題提示：逢水制免自焚；見木助必夭折；遇金作良工；得土成稼穡；無水則金燥土焦。
5. **徐、揚、兗、青、荊、梁、雍、冀、豫，各屬於現在何地？**
   - 答題提示（依書中括註）：徐、揚＝江蘇、浙江一帶；兗、青＝山東一帶；荊＝湖南、湖北；梁＝四川、西康；冀＝華北；雍＝西北；豫＝河南。
6. **晝生夜生、晴生雨生，各有何區別？**
   - 答題提示：《三命通會》以晝晴為陽、火氣盛，夜雨為陰、水氣盛；例如夏木、秋木喜夜生或陰雨，冬木、冬火喜晴明。
7. **辰、戌、丑、未四土，以何者為最旺？試說明之。**
   - 答題提示：未土。未月是火之餘氣、火生土，土最旺；辰戌丑雖旺而未極。
8. **何謂「金白水清」？**
   - 答題提示：金日主一派金水、無火土混雜，主富而聰明。
9. **冬月之水，為何喜火？**
   - 答題提示：冬水司令、寒凍，遇火則增暖除寒（調候）。
10. **春水與夏水有何不同？**
    - 答題提示：春水性濫，怕再逢水而崩堤，喜土堤防；夏水時當涸際，喜比肩與金生，忌火旺焰乾。
11. **默寫「五行生剋制化各有所喜所忌」的要訣。**
    - 答題提示：見第六節表格（原文須背）。
12. **五行的「強」和「旺」是怎樣區別的？**
    - 答題提示：旺＝得時或得勢之一；強＝得時又得勢。旺者宜剋，強（旺極）宜洩。
13. **八字日干（命主）屬火，大體應怎樣取用？**
14. **八字日干屬水，大體應怎樣取用？**
15. **八字日干屬木，大體應怎樣取用？**
16. **八字日干屬土，大體應怎樣取用？**
17. **八字日干屬金，大體應怎樣取用？**
    - 答題提示（13–17）：見第六節「五行取用簡則」表。
18. **為什麼研究命理應不怕麻煩？**
    - 答題提示：五行陰陽四時宜忌是論命得失的最大關鍵；粗枝大葉只能知梗概，細微處無從推論（見作者前言與第六節之一）。

## 名詞小辭典

- **《窮通寶鑑》**：又名《欄江網》，專論各日干逐月調候用神的古書。
- **生木／死木**：《窮通寶鑑》以甲寅、乙卯、甲辰為生木，甲申、乙酉、甲午為死木；陳素庵反對這種分法（見第十四章第七節）。
- **斲輪**：金木相等的格局名稱。
- **身殺兩停**：日主與七殺力量相當。
- **鑄印**：金火兩停的格局名稱。
- **殺刃兩停**：金多火旺。
- **既濟／未濟**：水火相濟（調和）／水火不濟。
- **得時／得勢**：得月令／得八字黨多。
- **旺／強／多／弱**：見第六節之三。
- **四季土**：四立前十八天土神用事的時段。
- **調候**：依季節冷暖燥濕調整，例如冬天要火、夏天要水。

## 和課堂、App 的對照

- **得時、得勢**：就是課堂強弱判斷的「得令」「得勢」；App「日主強弱對照」卡的課堂三步法（得令/得勢/得地）與此相通。
- **取用簡則**：是扶抑法（強則剋洩、弱則生扶）的雛形，加上「旺極宜洩」的例外；課堂說扶抑是基礎，調候、病藥、通關不可與它衝突。
- **調候**：各季宜忌大量是調候（冬喜火、夏喜水）；App 的「婚姻・財運・健康」面板有《窮通寶鑑》調候與寒暖燥濕分數可對照。
- **《淵海子平》喜忌表**：App 的量化五行力用分數表示「多寡」，但「水多木漂、土多金埋」這類質的判斷仍需要自己判讀。
