# 《命理新論》上冊 第18章：命主日干衰旺強弱的辨認法（書頁 p280–293，PDF 146–152）

前言：取用神必須先瞭解命主日干的衰旺強弱。例如正官格日干弱、官殺重 → 取印化殺；日干強印多 → 取財星剋印；傷官格日干弱官殺多 → 取印化殺生身、制傷；日干強 → 取印或財。普通格局取用神與日干衰旺強弱有密切關係。

## §1 日干衰旺強弱的區別
- 五行四時旺相休囚死（見第八章）與十干十二運（見第六章）都是用來確定五行或十天干強弱衰旺的，但只就一行一干而言；要認識命主日干強弱，因有天干地支生剋合化刑沖穿及各行多寡、得時失時、得勢失勢、得地失地等錯綜複雜的關係，所以不很容易確認。
- 先賢各說：有的專論強弱，有的專論衰旺，有的以旺極為強、以衰極為弱，有的強旺衰弱互用；「強、旺、衰、弱」從來沒有統一的界說與標準。
- 作者就淵海子平〈五行生剋制化各有所喜所忌〉（第十五章§6）的「強、旺、多、弱」涵義解釋：
  - **旺** = 五行得時令，或雖不得時令而八字天干地支黨多。
  - **強** = 五行得時令又兼八字天干地支黨多。
  - **多** = 五行得時或得勢而言。
  - **弱** = 五行失時或失勢。
  這只是體會原文的涵義，不是標準規定。
- 「得時俱為旺論，失令便作衰看」「黨眾為強，助寡為弱」這類說法，若按其字面，似乎旺、衰、強、弱很清楚，但對得時而又黨眾者，或失時而又助寡者，如何命名？若對得時黨眾者稱「強旺」、失時助寡者稱「衰弱」，也不甚妥貼；八字的構成、五行強弱衰旺變化萬殊，非幾個專有的形容詞所能概括。作者曾有人以「最強、中強、次強；最弱、中弱、次弱」再細分（既當令又多幫扶 = 最強；當令而少幫扶或不當令而多幫扶 = 中強…），但比較標準不明，仍易迷惘。
- 引任鐵樵：「得時俱為旺論，失令便作衰看，雖是至理，亦死法也。」五行之氣流於四時，雖日干各有專令，而其實專令之中亦有並存者……春木司令，甲乙雖旺，而此時休囚之丙丁、庚辛、壬癸未嘗絕於天地；八字雖以月令為重，而旺、相、休、囚，年日時中亦有損益之權，故生月即不值令，亦能值年值日值時，豈可執一而論。有如春木雖強，金太重而木亦危；干庚辛而支申酉，無火制而不富，逢土生必夭，是得時而不強也；秋木雖弱，木根深而木亦強，干甲乙而支寅卯，遇官透而能受，逢水生而太過，是失時而不弱也。是故日干不論月令休囚，只要四柱有根，便能受財官食神而當傷官七殺。長生、祿旺，根之重者也；墓庫、餘氣，根之輕者也。天干得一比肩，不如地支得一餘氣、墓庫……得二比肩，不如支中得一長生、祿旺。蓋比肩如朋友之相扶，通根如家室之可託；干多不如根重，理固然也。今人不知此理，見是春土、夏金、秋木、冬火，不究有根無根，便謂之弱；見是春木、夏火、秋金、冬水，不究剋重洩輕，便謂之旺；更有壬癸逢辰、丙丁逢戌、甲乙逢未、庚辛逢丑之類，不以為通根身庫，甚至求刑沖以開之，竟不思刑沖乃傷吾本根之氣，此種謬論必宜一切掃除也。（此說並見於沈孝瞻之子平真詮）

## 作者的四級分類（以比劫祿旺印綬長生墓庫餘氣 vs 官殺食傷財的總力量比較）
1. **日干旺**：得時（如甲乙見月支寅卯、丙丁見月支巳午、戊己見月支巳午或辰戌丑未、庚辛見月支申酉、壬癸見月支亥子），或得地（如甲乙見年日時地支寅亥卯未辰…；丙丁見年日時地支寅巳午未戌；庚辛見年日時地支申酉戌丑辰巳；壬癸見年日時地支申亥子丑辰；即長生、祿、旺、墓庫、餘氣，命書通稱日干的「根」），或得勢（如甲乙木雖不得時，然四柱干支多得水木之助；丙丁雖不得時，然四柱干支多得木火之助；戊己雖不得時，然四柱干支多得火土之助；庚辛雖不得時，然四柱干支多得土金之助；壬癸雖不得時，然四柱干支多得金水之助），均可統稱為日干旺。
2. **日干強**：凡八字日干得時而復得勢、或得時而復得地、或得勢而復得地、或得時得地又得勢，均可稱之為日干強。如四柱再不見剋制，這就叫做「旺極」。
3. **日干衰**：反之，凡八字日干失時、或失地、或失勢，均可當做衰看。但八字構成種類繁多，有的僅失時失勢而不失地、有的僅失勢失地而不失時、有的僅失時失地而不失勢。如果分別看來，「日干衰」與「日干旺」，有時會辨認不出來；這則須就日干所處的時、地、勢三者綜合論斷其強弱。
4. **日干弱**：凡八字日干失時而復失勢，或失時而復失地，或失地而復失勢，或失時失地又失勢，均可稱之為日干弱。如四柱再不見印綬、比、劫、祿、旺、長生（陰干長生不計）、墓庫（陰干墓庫不計）、餘氣，這就叫做「衰極」。
- 總之，命主日干強弱的分野，絕對不可單就日干是否得時或得地或得勢來看，必須就三者綜合推斷。得時得勢而不得地、得時得地而不得勢、得勢得地而不得時，均作「強」看；失時失勢而不失地、失時失地而不失勢、失地失勢而不失時，大多均作「弱」看；得時、得勢、復兼得地，四柱絕無剋制之氣者是「旺極」；反之是「衰極」。不過八字構成，日干與傷、食、財、官、殺的比較，並不一定全有強弱之分，有時是身主與財星兩者力量不相上下，有時身主與官殺力量不相上下，這就是「身財兩停」「身殺兩停」；有時身主與傷食官殺財的總力量也不相上下，這是一種不強不弱的現象。凡此均須一一加以比較認識，則取用神、明喜忌、下判斷才有準則可尋。

## §2 實例
- 日干強例（就一般情形，凡八字日干得時兼得勢，或得時兼得地，或得勢兼得地）：
  1. 〔四柱判讀不確定〕：庚金建祿於月支申位叫得時；年支時支又兩見祿神，叫得地；既得時而復得地，所以叫命主日干強；益以戊土天透地藏，西柱丙丁火絕跡，可謂旺極。
  2. 庚辰 己卯 壬辰 庚子：壬生卯月不得時令；然兩見水庫（辰）於年支及日支，又得帝旺（刃）於時支，這叫得地；此外兩庚並露年時天干，不見火剋，足以生身，這叫得勢；既得地而復得勢，所以叫做日干強。

## §3 命主日干強弱的其他看法
- 前述假定「日干強弱區分法」並非鐵則，也不是標準規定。因為八字構成複雜多端，並非可由前述法則包括無遺。譬如天干合化、地支會合沖刑穿等，均可以變更原來的形勢；有時從表面上看來似乎是強，但是變化以後，反而成弱；有時從表面上看來似乎是弱，但變化以後反而成強。此外，從五行旺相死囚休的情勢看來：五行凡居旺相者，其力量通常較大；五行凡居休囚者，其力量通常較小；五行凡居死地者，其力量更小。所以五行干支數量之比較，並非一干比一干、一支比一支，尚須斟酌五行旺相死囚休的情勢，始能確認何者為強、何者為弱。關於這類現象，雖然有人設定一定的分數，依式予以加減，然考之實際情形，則不盡然，因為八字構成既有天透地藏、通根不通根的不同，復有天干合化、地支會合沖刑穿的影響，更有貼身、遙遠、阻隔、通關、拱夾等情形，故不免失於「機械性」了，似乎未可視為鐵則。
- 作者在第十一章第三節「命宮與四柱八字的關係」及命式排列法，除說明將命宮的干支混入四柱干支，是「使五行陰陽衰旺的現象，更明朗更易分析」，它具有化學上促進劑的作用以外，並於命式之外另加一「五行數量」，並各別標明最旺、次旺、最衰、次衰、衰的區別，其目的在使大家於斟酌八字五行衰旺強弱時參考損益之用。
- 總之，命主日干強弱，及不強不弱，或日干以外各行的強弱，或不強不弱，實在沒有一個極嚴格的公式可以演算；必須靠推命者，運其智識、能力、經驗就綜錯複雜的各種關係，加以推究，而後才能確認。有時先天命式因受先天空間環境，如靠水、近火出生等關係的影響，也會發生變化的。這種情形，很像法官對犯罪嫌疑者，有的推定有罪、有的推定無罪、即使有罪也有的推定重刑、有的推定輕刑……法官的審判並非均是一推即定，推命也一樣有程度高低的不同或獨斷與合議的差別。作者說命理學者如能比照法官合議或醫師會診方式來推斷，必然可以找出一個較合理的結論；這也許是他的「幻想」。
