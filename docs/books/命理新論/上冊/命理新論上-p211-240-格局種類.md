# 《命理新論》上冊 第17章（上）：格局的種類及選定法（書頁 p211–約240，PDF 111–132）

格局像人的姓名，可判斷富貴貧賤。分兩大類：**普通格局**（正格、常格、八格或六格）與**特別格局**（偏格、外格、變格）。選定時，應最先適用特別格局；沒有特別格局可適用時，才適用普通格局（如同法學「特別法優於普通法」）。

## §1 普通格局的選定法
- 就月支觀察：
  1. 月支本氣透干，先取為格（寅透甲、卯透乙、辰透戊、巳透丙、午透丁、未透己、申透庚、酉透辛、戌透戊、亥透壬、子透癸、丑透己）。
  2. 本氣未透，就月支所藏的天干透出者，取其與日干生剋關係為格（如寅月未透甲而透丙或戊，取丙或戊）；兩者都透，就其在全局力量較大者取格。
  3. 月支所藏皆未透，則就月支所藏各干比較其強弱盛衰，擇一有力者取為格。
  4. 月支為日干的比、劫、祿、刃，則不取為普通格局（因比劫祿刃幫身，命主不弱，其取用神、明喜忌原則與普通格局略有不同，故不列入普通格局）。
- 作者列出十五個例子（日干×月令×透干 → 格名），如：甲生申月透庚七殺格、透戊偏財格、透壬偏印格；乙生酉月透辛七殺格；丙生寅月透甲偏印格、透戊食神格；丁生午月日祿不取；戊生午月透丁正印格；己生辰月透乙七殺格、透癸偏財格；庚生亥月透壬食神格、透甲偏財格；辛生酉月日祿不取；辛生丑月透己偏印格、透癸食神格；壬生子月日刃不取；壬生亥月日祿不取；癸生巳月透丙正財格、透戊正官格、透庚正印格；癸生子月日祿不取。
- 遇比劫祿刃不取普通格局，如甲日寅月、乙日卯月、丙戊日巳月、丁己日午月、庚日申月、辛日酉月、壬日亥月、癸日子月均是建祿格，只取其本氣，不取其他各干；甲日卯月、庚日酉月、壬日子月為月刃格。乙日寅月、丙戊日午月、丁己日巳月、辛日申月、癸日亥月不取為月刃格，而就普通格局取月令所藏其他天干為格（如乙日寅月捨甲取丙或戊；丙日午月捨丁取己…）。
- 普通格局不外正官、七殺、正印、偏印、傷官、食神、正財、偏財八種；如果財印不分正偏，叫財格、印格，再加正官、七殺、傷官、食神合稱六格。

### 一、從格（從象）
- 神峯通考：甲乙日主無根，遇地支純金，謂之從金；四柱純土，謂之從土；四柱純火，謂之從火。
- 就比劫傷食財官殺印看，日主無根、滿盤官星 → 從官格；滿盤七殺 → 從殺格（官殺均剋身，不必嚴格區分）；滿盤食神 → 從食格；滿盤傷官 → 從傷格（從傷從食，因食傷是日干所生之子，又叫從兒格）；滿盤財星 → 從財格；如果日干得時得勢、滿盤都是印星且比劫也很多 → 從強格；滿盤比劫祿刃、絕無官殺 → 從旺格（又叫專旺、屬象或一行得氣、獨象、類象）。如果日干無根、滿盤盡是財官食傷之中，何者較旺則從旺者之勢；如三者勢力均停，則從財以和之，這是從勢格。
- 凡具前述情形之一者都叫從格，因日干無根時遭遇強者劫持或控制或盜洩，逆來順受、只好從之而去，亦可保全生機；日干強旺、財官傷食全無則從其強旺，也是率性存真的一種方法。
- 例：
  1. 從官殺格：丁卯 壬寅 庚午 丙戌（庚生寅月，寅午戌三合火局，干透丙火；丁壬合化木，通根卯木生火，庚金生氣全無，只得逆來順受從丙丁官殺之火，以丙丁火為用神）。

### 五、暗沖格
- 四柱中沒有官星，才以日支相同且多者暗沖對宮的官星，其力量與本局官星無異；假使只有二支相同，則力量不足沖動對宮官星，必須地支有三支或四支最好。如丙午日午多（三或四支）沖子，子為丙火的暗官；丁巳日巳多沖亥，亥中壬水為丁的暗官，舊說叫「倒沖祿馬格」。辛亥、癸亥日亥多沖巳，巳中丙火為辛的暗官、戊土為癸的暗官；庚子、壬子日子多沖午，午中丁火為庚的暗官、己土為壬的暗官，舊說叫「飛天祿馬格」。又如庚日生於秋天，天干有二庚或三庚，地支申子辰全，四柱沒有丙丁及寅午戌，故地支申子辰暗沖寅午戌，財官印俱備，這也叫暗沖格，舊說叫「井欄叉格」。
- 例：〔四柱判讀不確定，見原書〕（庚子日地支三子暗沖午火正官，舊說「飛天祿馬格」）；〔四柱判讀不確定，見原書〕（壬子日地支三子暗沖午中己土正官，舊說叫飛天祿馬格；本造壬日子月，又叫月刃格，就此情形應捨月刃而取暗沖）；甲辰 戊子 庚申 庚辰（庚生於秋天，天干三庚，地支申子辰三合，四柱沒有丙丁寅午戌，地支申子辰暗沖寅午戌，舊說叫井欄叉格）；庚申 甲申 庚子 庚辰（同上）。

### 八、暗合格
- 八字無官星，而日支相同的很多，則以支神六合暗邀合宮的官星。如：甲辰日辰多暗合酉中辛金為官星；癸卯日卯多暗合戌中戊土為官星；癸酉日酉多暗合辰中戊土為官星；戊戌日戌多暗合卯中乙木為官星。必須原局地支三支或四支相同，且無明見的官星，才能成立；甲辰、癸卯日最喜春令，戊戌、癸酉日則喜秋冬，其餘各日或入他格，或不合法，俱不取用。

- 先賢以辰戌丑未為天地不正之氣，且為牢獄之所，又為天地收藏之庫，好像倉庫，各樣東西均可儲藏，一定要等待開庫取出，才能發揮物力的效能，所以有雜氣財官印綬傷官格的設定。作者先將認識法說明：丁日生於辰月，天干透出戊己多的，叫雜氣傷官格；天干透出乙木多的，叫雜氣印綬格；如天干透出癸水多的，叫雜氣財官格（財旺能生官）。又如戊日生於丑月，身弱天干透出丁火多的，叫雜氣印綬格；如透出辛金，則叫雜氣傷官格。其餘各干與四季月的關係，均以此類推。例：〔四柱判讀不確定，見原書〕（庚生戌月，天干透出戊土，雜氣印綬格）；〔四柱判讀不確定，見原書〕（丁生丑月，天干透出己土辛金，雜氣財食格）。

### 十、子遙巳格
- 八字甲子日遇甲子時，原局無庚辛申酉丑午等字，甲以辛為官，地支子中所藏的癸水能遙合巳中所藏的戊土，然戊土畏日干甲木剋制，不致與日支子中的癸水合，轉而與丙火同居，丙戊為父子，戊動丙也動，丙卻與酉中所藏的辛相合，來剋甲木，甲日得官星，戊土方得合癸，這是巳酉會起官星局，大怕午字沖子，丑絆子，則子不能遙合了。例 己亥 乙亥 甲子 甲子。

### 十二、壬騎龍背格

### 十七、財官雙美格
- 繼善篇說：「六壬生臨午位，號曰祿馬同鄉；癸日坐向巳宮，乃是財官雙美。」祿就是官，馬就是財。壬午日，日支午中所藏的己土為日干壬水的正官，日支午中所藏的丁火為日干壬水的正財；癸巳日，日支巳中所藏的戊土為日干癸水的正官，日支巳中所藏的丙火為日干癸水的正財。所以壬午、癸巳兩日，就叫做祿（官）馬（財）同鄉或財官雙美了。人命因祿馬難得雙全，今自坐下財官所以為貴。例 甲午 乙亥 癸巳 丁巳。

### 十八、金神格
- 凡八字六甲日見癸酉或己巳、乙丑時，叫做金神格。癸酉、己巳、乙丑三時地支巳酉丑三合金局，甲木見之可為官星，然以甲子、甲辰二日見之為最，而且必須月令通金氣成火局，才可取用。又六己日見此三時，亦作金神論。例 〔四柱判讀不確定，見原書〕（甲辰日生於己巳金神時，且通月令巳中所藏庚氣金神勢猛，取巳午合火以制金神）。

### 十九、日貴格
- 日貴者，乃日柱天干自坐天乙貴人，只有丁酉、丁亥、癸巳、癸卯四日（可從第十二章附表中查得），地支若聚兩三位貴人最好，但是極怕刑沖破害、空亡。例 〔四柱判讀不確定，見原書〕（丁亥日自坐天乙貴人，月令也逢天乙貴人，地支未遇刑沖破害，所以叫做日貴格）。

### 二十、日德格
- 日德只有五日，就是甲寅、丙辰、戊辰、庚辰、壬戌。取甲、丙、戊、庚、壬五陽干：甲坐寅得祿；丙坐辰為官庫（辰為水庫，水剋火為官庫）；戊坐辰為財庫（水庫被戊土所剋為財庫）；庚坐辰財印兩全（辰中戊土為庚的印，辰中乙木為庚的財）；壬坐戌三奇俱備（戌中所藏辛、丁、戊為日干壬水的財官印，所以叫三奇俱備），且寅為三陽之首，辰戌魁罡之地，干支配合異於別位，所以叫做日德。但日德必須地支除日支外還要他柱地支有一、二位，方可取格，否則不取。例 〔四柱判讀不確定，見原書〕（甲寅為日德，時支又見寅，所以叫日德格；專祿只見甲寅日，歸祿只見甲日寅時，這是有區別的）。

### 二十六、拱祿格
- 拱是兩者相向而夾的意思。祿在這裡是指日干臨官的地支而言，也就是日干祿。凡八字日干無祿（不是祿馬的官祿，而指日干臨官的日祿），日柱與時柱天干相同，兩者虛夾日干祿，這叫拱祿格。就日時天干地支配合的關係，加以分析，計有五日五時配合的結果，可以成為本格，即：癸亥日癸丑時拱子祿；癸丑日癸亥時拱子祿；丁巳日丁未時拱午祿；己未日己巳時拱午祿；戊辰日戊午時拱巳祿。本格構成須日時天干相同，地支暗拱日干祿，忌填實（即他柱有日干祿）。例 癸卯 甲寅 戊辰 戊午（日柱與時柱天干相同，地支辰巳午，按地支次序暗拱日干巳祿，且其他各柱沒有巳字填實，所以本造叫做拱祿格）。

### 二十七、拱貴格
- 拱者是兩者相向而夾，貴是日干天乙貴人所臨的地支或日干正官，或兼指天乙貴人及正官而言。凡八字日干無天乙貴人而日柱及時柱天干相同，地支按序拱合天乙貴人或正官星者，叫做拱貴格。就日時天干地支配合的關係，加以分析，計有六日六時可為本格，即：甲寅日甲子時拱丑，為日干的天乙貴人；甲申日甲戌時拱酉，為日干的正官星；乙未日乙酉時拱申，為日干的天乙貴人兼正官星；戊申日戊午時拱未，為日干的天乙貴人；壬辰日壬寅時拱卯，為日干的天乙貴人；辛丑日辛卯時拱寅，為日干的天乙貴人。本格構成須日時天干相同，地支暗拱天乙貴人或正官星，忌填實（他柱有暗拱的地支）。例 丁巳 丙午 甲寅 甲子（日柱與時柱天干相同，地支子寅，按地支次序暗拱日干的天乙貴人丑，且其他柱沒有丑來填實，所以叫做拱貴格）。

### 二十八、夾財庫格（拱財格）
- 凡八字：己卯日生於己巳時，地支卯辰巳，按地支次序，兩者的中間虛夾一辰字，辰為水庫，乃日干己土的財庫；癸酉日生於癸亥時，地支酉戌亥，按地支次序，兩者的中間虛夾一戌字，戌為火庫，乃日干癸水的財庫；丙子日生於庚寅時，地支子丑寅，按地支次序，兩者的中間虛夾一丑字，丑為金庫，乃日干丙火的財庫；庚午日生於甲申時，地支午未申，按地支次序，兩者的中間虛夾一未字，未為木庫，乃日干庚金的財庫。這四天四時，都叫夾財庫格。夾格與拱格不同者，乃拱格天干必定相同，夾格則相同或不同均可；地支夾拱的情形則相似。但夾財庫格仍忌財來填實，故於比較研究之後，可以發現：丙子日庚寅時，暗夾丑金財庫，時干透庚金財填實，這是破格；庚午日甲申時，暗夾未木財庫，時干透甲木財來填實，也是破格。純粹可觀者，僅有癸酉日見癸亥時、己卯日見己巳時兩種。這兩日兩時，天干相同，地支暗夾，完全與拱貴、拱祿相似，所以也可以叫做拱財格。例 〔四柱判讀不確定，見原書〕（癸酉日生於癸亥時，天干相同，地支酉戌亥，暗夾日干癸水的財庫戌火，天干地支沒有財來填實，純粹可觀，所以叫做夾財庫格，也叫拱財格）。
