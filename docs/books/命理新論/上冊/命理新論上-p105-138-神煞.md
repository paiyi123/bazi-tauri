# 《命理新論》上冊 第12章：命局的關煞及吉凶星（書頁 p105–138，PDF 59–75）

## 作者立場
- 江湖術士多喜談關煞（尤其小兒關煞、婚姻），作者認為多是「星盤」「斗數」的影響，「子平」本身以四柱五行生剋、格局、用神喜忌論命，並不靠神煞。
- 收錄的關煞吉凶星約 4 類 190 餘種（小兒關煞、男女合婚、吉星、凶星），名目繁多，作者只列名不解釋。
- 引張楠《神峯通考》批判呂才合婚、「骨髓破、鐵掃帚、六害、大敗、狼籍、飛天狼、八敗、孤虛」等合婚謬說；引陳素庵《命理約言》（「舊書稱神煞……十嘗七八，一一細推，毫無義理……妄者悉擯而削之」）；引任鐵樵註《滴天髓》「一切神殺荒唐取用，桃花咸池專論女命邪淫……混看奇格異局，神殺納音……必致以正為謬」。
- 作者原則：子平論命全就四柱及歲運的陰陽五行衰旺順悖、喜忌來論；吉神凶煞「可有可無」。吉神如君子、凶煞如小人：吉神若是命局所忌的干支，照樣有害；凶煞若是命局所喜，也可為福。**一定要就命局全體喜忌與歲運綜合推論，不可見一吉神就驚喜、見一凶煞就驚恐。** 吉神在命局不受沖剋、得生旺，「錦上添花」；凶煞得制化，可化凶為吉。
- 這與課程老師「神煞不可靠」的態度一致。

- 三奇：天上三奇甲戊庚、地下三奇乙丙丁、人中三奇壬癸辛；須按年月日時順序。陳素庵主張刪除不論。
- 魁罡：庚辰、壬辰、庚戌、戊戌四日。性剛、聰明；日主身旺、四柱重疊魁罡者發福；見財官則禍，最忌刑沖。

## 例題（p136）
- 丙午　丁酉　辛巳　癸巳（上將）：食神制殺，桃花與正官貴人同柱，為富貴之命；將星坐祿，權高；空亡遇合，雖空無妨。
- 甲申　辛未　己未　甲子（和尚）：孤寡與華蓋同柱必為僧道；桃花、元辰入空亡，可免橫禍；劫煞與天乙同柱，巧於謀事。
- 丁未　乙巳　甲午　丁卯（放蕩的寡婦）：巳午未會又逢貴人，且傷官氣盛，桃花帶刃，紅艷招蜂，主剋夫淫亂。
