# 第二十一章 第三節　取用神應注意的事項及其喜忌（書頁 p.404–415）

> 一句話導讀：知道了四類用神之後，實際動手時要注意哪些順序和陷阱？用神定了，喜神、忌神又怎麼定？這一節是「操作手冊」：一份取用注意事項清單、用神理想條件、沈孝瞻的「相神」觀念，以及六大格局 39 條喜忌對照表。

---

## 本節在講什麼

作者先說明：病藥、扶抑、調候、通關四種方法雖然分開講，但彼此關係密切，共同目的都是**讓五行中和或氣勢流通，避免偏枯或閉塞**。一個命局如果四種方法都能用上，當然最好；至少也要有一種可用。否則——除了可以適用特別格局、或先天五行中和純粹的命以外——**沒有用神可取的命，大多是下等命，或夭折危亡**（p.404）。

作者也坦白說：論命者在取用神時常常感到恍惚迷離、難以決定，這是最痛苦的一件事。所以他把取用時應注意的事項列出來（p.404）。

本節分兩大項：

1. **取用神應注意的事項**（p.404–408）：先定格局再看強弱；一首江湖取用口訣；用神與忌神、閒神的位置；用神在天干、地支的理想條件；先調候；五行不全時所缺即用神；從人事逆推用神；燥濕的辨認。
2. **用神的喜忌**（p.408–413）：喜忌要看用神怎麼取的；沈孝瞻「相神」說與「相神無破」；另一首「用神不可傷」口訣；最後依第二節的取用通則逐格列出 39 條喜忌。

## 一、取用神應注意的事項（p.404–408）

### ㈠ 先定格局，再看日干強弱（p.404–405）

八字排好以後，**一定要先把格局定出來**：

- 如果是正官格，表示正官得了月令的旺氣；
- 如果是傷官格，表示傷官得了月令的旺氣，它的力量一定不小。

然後再看日干是強是弱（p.404）。作者舉正官格為例：

- **正官格、日干弱、官殺旺** → 最好取印為用。因為印可以洩官生身，不但扶抑得宜，而且還能通關（官→印→身）（p.404–405）。
- **正官格、日干強、比劫多** → 應取正官為用。因為正官可以拘束比肩、制伏劫財，保護財星。如果沒有官星，就取食神洩旺生財為用——這雖然不算通關，但扶抑得宜仍可發福（p.405）。

結論：**取用時最先要注意格局的旺神和日干的強弱，然後才注意生剋制化，選擇一行或一字為用神**（p.405）。

### ㈡ 江湖取用口訣（p.405）

作者錄了一首江湖上師徒相傳的取用口訣（即作業中的「取用要訣」），要學命的人背熟以便參考。歌訣很長，這裡挑關鍵句子解釋：

- 「**身強殺淺宜生殺**」：日干強、七殺弱，要用財去生七殺。
- 「**財多身弱用比劫**」：財太多、日干弱，用比劫去分財、幫身。
- 「**官旺身衰印最吉**」：官殺旺、日干弱，用印化官生身最好。
- 「**殺重身輕印為宜**」「**身殺兩停宜制殺**」：殺重身輕要用印化；身與殺力量相當（兩停）時，要用食神制殺。
- 「**滿盤比劫忌殺官**」：作者括號註「旺極宜洩不宜剋」——比劫多到極點，用官殺硬剋反而激怒它，應用食傷洩。
- 「**食重殺多宜用印**」：作者註，食神重、七殺多，日干又被剋又被洩，沒有印生扶就難以自存。
- 「**財官梟殺無軒輊，只問用神在何方**」：財、官、梟、殺本身沒有好壞高低之分（作者註「沒有輕重高低的分別」），只看它是不是用神。

其他句子也是同樣的邏輯：「財輕比重用食傷」「官衰印旺財取用」「制殺太過梟為歡」等，都是「哪裡太多就去減、哪裡太少就去補」。

### ㈢ 看四柱位置：用神要有根、忌神要無力、閒神看是否阻塞（p.405）

除了較量日主、格局、用神、喜神、忌神五者的輕重得失，**還要注意五行在四柱位置中的生剋制化**，看它是否生化有情、剋制得力。**不可以一見有用神，就斷定這個命一定富貴**。

- **日主和用神**都要通根（如果虛懸天干，就是有枝葉而沒有根）、生旺，得時或得地或得勢。
- **忌神**（剋制用神或妨害喜神的五行或干支）以失時、失地、失勢為宜。
- **閒神**要看它在命局中是否阻塞五行流通：不阻塞就可以不理它；阻塞的話也要設法去掉它（可以合去、沖去、剋去）（p.405）。

### 用神的理想條件（p.406）

作者列出用神「通常以具有下列情勢為佳」：

**甲、用神在天干時**

| | 條件 | 例子 |
|---|---|---|
| 子 | 得時 | 用甲木，剛好生在春月 |
| 丑 | 得地或得勢 | 用甲木，天干有同類相助，或地支見寅卯 |
| 寅 | 不見剋合 | 用甲木，不見庚來剋、不見己來合 |
| 卯 | 見剋合而有解救 | 用甲木見庚剋，但有乙來合庚，或丙來剋庚 |

**乙、用神在地支時**

| | 條件 | 例子 |
|---|---|---|
| 子 | 得時 | 用卯木生於卯月，既是格局又是用神，這叫「**真神得用**」 |
| 丑 | 得勢 | 用巳火，得甲、丙生扶 |
| 寅 | 不見刑沖合 | 用巳火，不見亥沖、寅刑、申合 |
| 卯 | 見沖刑合而有解救 | 用巳火見亥沖，但遇卯來合亥（亥卯合，亥就不去沖巳了） |

**白話**：用神最好「當令、有幫手、沒人欺負它；就算有人欺負，也有人出來救」。

### ㈣ 偏枯時先調候（p.406）

八字排好後，如果發現五行偏枯、特別格局又不能成立，就要注意是否過寒、過暖、過燥、過濕。有這種情形，**應先講究調候，再論生剋制化及通關、病藥**。否則格局雖純粹，也難富貴；即使遇到好運，富貴也只像**曇花一現**（p.406）。

### ㈤ 五行不全時，所缺的常常就是用神（p.406）

如果八字五行不全，只有三行或四行，除非有適當的格局和用神可取，通常**所缺的那一行常常就是用神**；大運走到它旺相的地方，也可以發福。尤其是原局沒有用神可取的，常常很應驗。不過時過境遷（運一過就沒了），終究不如原局本來就有用神的穩當（p.406）。

### ㈥ 從人事逆推用神（p.406–407）

取用神也可以從已知的人生事實，用「逆溯法」倒推回去（p.406–407）：

| 一生最得誰的力 | 用神可能是 |
|---|---|
| 父母庇蔭 | 印星 |
| 兄弟姊妹支持 | 比劫 |
| 妻子贊助（男命） | 財星 |
| 子女維護（男命） | 官殺 |
| 丈夫贊助（女命） | 官殺 |
| 子女維護（女命） | 食傷 |

女命的父母、兄弟姊妹與男命類似。作者特別註明：六親的看法不全如此，講義另有專章討論（p.407）。

**白話**：命主一生最得力的六親，對應的十神往往就是用神。這是驗證用神是否取對的好方法。

### ㈦ 燥濕的辨認（p.407）

作者補充：**命局五行乾燥就喜潤澤，命局五行潮濕就喜溫暖**。

- 八字沒有水或水少、生在夏月、又多木火干支 → 乾燥。這時如果命中喜土，碰上**燥土**只會更乾，不一定吉；碰上**濕土**就能滋潤，吉上加吉。
- 八字沒有火或火少、生在冬月、又多金水干支 → 潮濕。這時如果命中喜土，碰上**濕土**只會更濕，不一定吉；碰上**燥土**就能去濕，錦上添花。

怎麼判斷燥濕？

- **天干**不必單獨論燥濕，要與地支配合才能論。
- **地支**中，子（純水）、卯（純木）、酉（純金）是純氣，也不必單獨論燥濕。
- **論濕的四支：丑、辰、申、亥**——因為所藏都有水：丑藏己辛癸（濕土濕金）、辰藏乙戊癸（濕木濕土）、申藏庚戊壬（濕金濕土）、亥藏甲壬（濕木）。
- **論燥的五支：寅、巳、午、未、戌**——因為所藏都有火：寅藏甲戊丙（燥木燥土）、巳藏戊庚丙（燥土燥金）、午藏己丁（燥土）、未藏己丁乙（燥木燥土）、戌藏戊丁辛（燥土燥金）。

這是地支燥濕的辨認法，在調候上用途很廣（p.407）。

### 多讀命譜、多實際推算（p.407–408）

作者最後勉勵：用神選取雖有若干規則可循，但必須常讀命譜，並在空閒時替人推算，藉以實驗；否則只是紙上談兵（p.407–408）。

## 二、用神的喜忌（p.408–413）

### 喜忌以「用神怎麼取」為先決條件（p.408）

作者引自己第十六章第二節的話：一般以生扶用神者為喜、剋制用神者為忌……但命局中**並非全以生用神者為喜，而且有用神必不可生者**。所以喜忌要先看用神是怎麼選定的（p.408）：

- **前者**（生用神為喜）：正官格日干強、比劫多，取官為用 → 喜見財星生官，忌見傷食合官制官。
- **後者**（用神不可生）：正官格日干弱、官殺重，取印為用 → 喜比劫幫身抵抗官殺，**忌見官殺剋身**。照理官殺能生印（用神），但官殺已經太重，再來只會剋身，所以反成忌神。

兩者有很大的區別，要切實注意（p.408）。

### 沈孝瞻的「相神」說（p.408）

沈孝瞻：

> 「月令既得用神，則別位亦必有相神，若君之有相，輔我用神是也。」

白話：月令定了用神之後，其他位置一定還有一個「相神」，就像國君有宰相輔佐一樣，專門輔助用神。作者括號註明：**相神就是喜神**。

沈孝瞻的例子，作者逐一加註：

- **官逢財生**：官為用，財為相。（正官格日干強，取官為用而官弱，喜財生官，所以財是喜神。）
- **財旺生官**：財為用，官為相。（正財格日干強，取財為用，喜官星制劫衛財，所以官是喜神。）
- **殺逢食制**：殺為用，食為相。（七殺格日干強，借殺為用，以食神為喜神——這是「身殺兩停宜制殺」，和「財滋弱殺」不同。）

沈氏說：這是一定之法，不是通變之妙。總之，**凡全局之格賴此一字而成者，都叫「相」**。

作者的提醒：由此可知八字**絕不是全以生扶用神者為喜**，要特別注意，否則議論喜忌時又會恍惚迷離（p.408）。

### 傷用神甚於傷身，傷相神甚於傷用（p.408–409）

沈孝瞻又說：「**傷用神甚於傷身，傷相神甚於傷用**。」——傷害用神（即忌神）比傷害日主還嚴重；傷害相神（喜神）又比傷害用神更嚴重（作者註：傷害喜神的也是忌神，又名「仇神」）。

接著是五個片段例子（都只有幾個干支，不是完整命盤），作者都加了白話註解，整理如下：

1. **甲用酉官，透丁逢壬**（p.408）：甲日干以酉金正官為用。天干透丁火（傷官，會剋官），但又遇壬水（偏印）把丁合走（丁壬合），官星就不受傷——這個格局能成，全靠壬水這個「相」。
2. **戊用子財，透甲並己**（p.408–409）：戊日干以子水財星為用。天干透甲木七殺來攻身，又透己土劫財（會奪財）；但甲己一合，殺與劫兩者都失去作用——身不被攻、財不被劫，一舉兩得。全靠己土這個「相」。
3. **乙用酉殺，年丁月癸，時上逢戊**（p.409）：乙日干以酉金七殺為用，天干依序透丁（食神）、癸（偏印）、戊（正財）。丁火原本被癸水剋住而無法制殺；幸好戊土合癸（戊癸合），丁火又能制殺。全靠戊土這個「相」。
4. **癸生亥月，透丙為財，財逢月劫，卯未來會**（p.409）：癸日干生亥月，天干透丙火正財；月令亥中壬水是劫財（會奪財）；但其他柱地支有卯、未來與亥三合木局，把亥中壬水化成木，木反去生天干丙火財星——化劫為生財。全靠卯未這個「相」。
5. **庚生申月，透癸洩氣，子辰會局**（p.409）：庚日干生申月，天干透癸水傷官吐秀；但癸水不通月令，金氣不夠靈秀；其他柱再見子、辰，與申三合水局，旺金的秀氣就流通了（金水相涵）。全靠子辰這個「相」。

### 相神無破，貴格已成；相神有損，立敗其格（p.409）

沈孝瞻再舉兩個「相神被破壞」的例子：

1. **甲用酉官，透丁逢癸，又逢戊**：甲日干以酉金正官為用。丁火傷官本來被癸水正印制住（癸是喜神/相神），官星受保護；但又見戊土偏財把癸水合走（戊癸合），癸不再制丁，丁火傷官就能剋官了。作者註：這是以酉為用神，癸為喜神，丁、戊為忌神。
2. **丁用酉財，透癸逢己，又透甲**：丁日干以酉金偏財為用。天干透癸水七殺和己土食神，己土制住癸水七殺，並能生財；但天干又透甲木正印，甲己一合，己土就不再制殺，癸水七殺可以攻身，財源也斷了。作者註：這是以酉金為用神，己土為喜神，甲木、癸水為忌神。

沈孝瞻總結：「凡八字排定，必有一種作用，一種棄取，隨地換形，難以虛擬，學命者其可忽諸。」——每個八字都有它特定的作用與取捨，會隨位置與組合而變形，沒辦法憑空套公式，學命的人不可忽略（p.409–410）。

### 作者的收束：喜忌沒有萬用公式（p.410）

作者說：由前所述可知，用神的選取確實複雜多端，喜忌的推定也不是一成不變：

- 有的以**生用神**為喜；
- 有的以**洩用神**為喜；
- 有的以**剋去或合去忌神**為喜。

反之，凡傷害用神或喜神、剋合用神或喜神的，都是忌神。而且天干地支的生剋沖合，也能**變喜為忌、變忌為喜**。實在不容易歸納一個完整的通則，必須視各個命局的構成情勢、所定格局、所取用神分別論斷（p.410）。

### 「用神不可傷」歌訣（p.410）

江湖上師徒相傳的另一首歌訣，作者照錄。這裡挑重點：

- 「**用之為官不可傷，不用官星盡可傷**」：官星是用神時不可以被傷官傷害；官星不是用神時，被傷也沒關係。財、印、食神同理：「用之財星不可劫」「用之印綬不可壞」「用之食神不可奪」。
- 「**用之七殺不可制，制殺太過反為凶**」：七殺是用神時不能被制；制殺過頭反而凶。
- 「**身殺兩停宜制殺，殺重身輕宜化殺，身強殺淺宜生殺**」：這三句是對付七殺的「制、化、生」三法（作業第 12 題）——
  - 身與殺力量相當 → 用食神制殺；
  - 殺重身輕 → 用印化殺；
  - 身強殺淺 → 用財生殺。
- 「**莫道梟神無用處，殺多食重最為良**」：別以為偏印（梟）沒用，七殺多、食神重時，偏印最好（化殺、制食）。
- 「**勿謂羊刃是凶物，財多殺黨亦為貞**」：別說羊刃一定凶，財多或七殺成黨時，羊刃幫身反而是好東西。

作者說：這首歌與前面的取用要訣歌有若干重複句子，為保存原貌沒有刪節，請學者自行參酌辨認（p.410）。

### 各格喜忌通則表（p.410–413）

作者說：取用神、明喜忌雖有軌跡可尋，但不是一成不變，要善於運用。各種格局有不同的取用方法，喜忌也隨取用不同而異。於是根據第二節的「各種普通格局取用通則」，擬定各別喜忌如下（p.410–411）。我把 39 條整理成表（「強／弱」指日干）：

**傷官格（①–⑦，p.411）**

| # | 情況 | 用 | 喜 | 忌 |
|---|---|---|---|---|
| ① | 強，印多 | 財 | 傷食生財 | 比肩劫財；印星制傷食 |
| ② | 強，比劫多 | 殺 | 財生殺 | 印再生身；比肩劫財 |
| ③ | 強，比印多 | 傷 | 財洩傷制印 | 印再生身；比肩劫財 |

**怎麼讀這張表**：
- 「喜」通常是**能幫用神的字**（生它、或保護它）。
- 「忌」有兩類：一是**直接傷害用神的字**（例如用印最忌財星壞印）；二是**讓原本已經太多的東西更多的字**（例如身強還來印生身、比劫多還來比劫）。
- 「須財劫不相礙」「須財印不相礙」：意思是兩者要分開、不直接相剋。例如⑱用比劫、喜印，但命中財多，印若和財靠在一起，就會被財壞掉，所以要求財與印位置不相礙。
- 少數幾條和直覺不同，照書上記錄，例如⑳正官格身強食傷多用財，喜「官殺拘身」；㉝印格身強財多用官殺，喜「印星通關」。讀時可配合本節「喜忌沒有萬用公式」那段理解。

## 名詞小辭典

- **格局旺神**：得月令之氣、在命局中力量最大的那一神，格局就以它命名。
- **拘比制劫**：正官管束比肩、剋制劫財，使它們不去奪財。
- **身殺兩停**：日主與七殺力量相當。這時宜用食神制殺。
- **財滋弱殺**：七殺太弱時用財去生它。與「身殺兩停宜制殺」相反。
- **閒神**：既不是用神、喜神，也不是忌神的字；只要不阻礙流通，可以不理。
- **虛懸天干**：天干的字在地支沒有根（地支不藏同類），像沒有根的枝葉。
- **得時、得地、得勢**：得時＝生在當令月份；得地＝地支有根；得勢＝天干有同類或生扶。
- **真神得用**：月令格局之神本身就是用神，且得時。
- **曇花一現**：比喻富貴短暫，運一過就沒了。
- **逆溯法**：從已知的人生事實反推用神。
- **燥土、濕土**：未戌（以及寅巳午所藏的土）帶火為燥；丑辰帶水為濕。
- **相神**：沈孝瞻用語，即喜神，輔佐用神、使格局成立的字。
- **仇神**：傷害喜神的字，也算忌神的一種。
- **合傷存官**：把傷官合走，保住正官。
- **合殺存財**：把七殺（以及劫財）合走，保住財星與日主。
- **化劫生財**：劫財透過三合局被轉化成能生財的五行。
- **金水相涵**：金生水，金的旺氣透過水流通出來，秀氣顯現。
- **梟神**：偏印的別稱（尤其在剋食神時）。
- **羊刃**：陽干的帝旺之支（如甲的卯），力量強，常被視為凶物，但身弱、財多、殺重時反而有用。
- **財印不相礙、財劫不相礙**：兩個會互相衝突的字，在四柱位置上隔開、不直接相剋。

## 和課堂、App 的對照

- **先定格局再看強弱**：作者的取用順序是「先定格局（月令旺神）→ 再判日干強弱 → 再看生剋」；課堂則以判斷日主強弱（得令、得地、得勢）、扶抑為主。兩者在大多數情況結論相同，但作者會用「格局」來命名用法（例如「正官用印格」）。
- **偏枯先調候**：作者主張五行偏枯時「先講調候，而後論生剋制化」（p.406）；課堂則強調調候不可與扶抑衝突。如果遇到兩者衝突的命局，讀者要知道兩種看法的差異。
- **用神理想條件「得時、得地或得勢」**：與課堂「得令、得地、得勢」的判斷框架一致。
- 其餘無特別差異。
