# 第二十一章 第一節　先賢的議論（書頁 p.374–383）

> 一句話導讀：「用神」是整張八字的精神所在。這一節作者先把歷代名家（張楠、陳素庵、沈孝瞻、《滴天髓》與任鐵樵、徐樂吾）對用神的看法擺出來，讓我們知道取用神有「病藥、扶抑、格局順逆、調候、通關」幾條思路，下一節才正式分類教方法。

---

## 本章前言（p.374）

### 格局像身體，用神像精神

作者一開章就打了一個很好懂的比方：**格局好比一個人的身體，用神好比這個人的精神**（p.374）。

- 身體健全、精神也旺盛 → 身心愉快、萬事如意。
- 身體健全但精神不振 → 有條件卻使不上力。
- 身體不健全、精神也不振 → 灰心失志、百事無成。

所以看八字，不只要看「格局成不成」（身體），更要看「用神有沒有、有不有力」（精神）。

### 什麼叫「用神」？

作者給的定義很實用：八字的日干有強有弱、格局有成有敗，**八字中如果有某一個字，能幫助格局成立、或補救已經破敗的格局；或能讓五行的強弱趨於中和；或能讓五行之氣流通而不阻塞——這個字就是命局的用神**（p.374）。

白話說：用神就是「這張命盤最需要、最能把它調整到平衡順暢的那個字（或那一行）」。

### 為什麼這一章要重講？

第十章第二節雖然介紹過取用神，但只是簡略帶過，原則交代不清楚，前面舉例時講「為什麼取這個用神」也不夠詳細，所以大家只有模糊概念（p.374）。這一章就是補課。

### 普通格局與特別格局分開推

作者特別強調一個分界（p.374–375）：

- 各種**特別格局**（例如從格、化格、一行得氣等）都有很嚴格的成立條件，條件不夠就不能當特別格局看。
- 凡是特別格局成立不了的八字，**一律當普通格局，用五行生剋的正理來推**。
- 特別格局有自己的推法，跟普通格局的推法差異很大，不能混為一談。

而事實上**普通格局的八字最多**，推法有許多共通原則、用途最廣，所以作者希望大家再三注意，一點都不能疏忽（p.375）。本章先講普通格局用神的種類和選法。

## 本節在講什麼

這一節沒有命例，而是一篇「文獻回顧」。作者依序引了四派前人的說法，每一派都代表一種取用神的思路：

1. **張楠《神峰通考》的「病藥說」**：八字裡有害的字是「病」，能去掉它的字是「藥」。有病有藥才是好命。
2. **陳素庵《命理約言》的「扶抑說」**：取用神不過就是「弱的扶起來、強的壓下去」。他還批評張楠病藥說太死板。
3. **沈孝瞻《子平真詮》的「月令格局順逆說」及「配合氣候」**：用神專看月令；善神順用、惡神逆用；而且還要兼看寒暖（調候）。
4. **《滴天髓》與任鐵樵、徐樂吾的「通關說」**：兩股力量對峙相剋時，需要一個中間人來疏通。

作者在中間穿插自己的評論：病藥說有價值但說得太絕對；先天中和的命是「穩健型」富貴，重病得藥的命是「高風險型」富貴。

讀完這一節，你會發現下一節的四類用神（病藥、扶抑、調候、通關），其實就是從這幾家學說整理出來的。

## 一、張楠《神峰通考》的病藥說（p.375–376）

### 什麼是病、什麼是藥

張楠（號神峰）的定義（p.375）：

> 「何以謂之病？即八字中原有所害之神也。何以謂之藥？即八字原有所害之字，而得一字以去之之謂也。」

白話：八字裡原本就存在、會造成傷害的那個字叫「病」；有另一個字能把這個害處去掉，這個字叫「藥」。

他引了幾段古語佐證：

- 古人說「有病方為貴，無傷不是奇；格中如去病，財祿兩相隨」——有病又能治好才是貴命，格局中能去病，財和祿就會跟著來。
- 朱子說「各因其病而藥之」——對症下藥。
- 孟子「天將降大任於斯人也，必先苦其心志，勞其筋骨……」——人生要先經過磨難才能成大器。張楠用這段話說明：命中「有病有藥」，就像人經歷困境再翻身，才是成大器的格局（p.375）。

張楠還現身說法：他早年不懂病藥，只用財、官來論命，十個準不到一兩個；後來悟出病藥的道理，再參以「財官中和」，十個能準八九個（p.375）。

### 病藥的實際例子（p.375–376）

張楠舉了一組例子，先講「日干被某種五行壓太重」：

- 假設四柱純是土：
  - 日干屬水 → 土剋水，是「殺重身輕」；
  - 日干屬金 → 土太多把金埋了，叫「土多金埋」；
  - 日干屬火 → 土太多把火的光洩掉，叫「晦火無光」；
  - 日干屬木 → 土是木的財，財多身弱；
  - 日干屬土 → 比肩太重。
  
  這些情況都是**土為病，要靠木來剋土當藥**（p.375）。

再講「用神被某種五行傷害」：

| 用神 | 病 | 藥 |
|---|---|---|
| 用財 | 比肩（劫財） | 官殺（剋比劫） |
| 用食神 | 印（梟神奪食） | 財（剋印） |
| 用官殺 | 食神、傷官 | 印（剋食傷） |
| 用比劫 | 官殺 | 食傷（剋官殺） |
| 用印綬 | 財 | 比劫（剋財） |

（以上整理自 p.375–376）

### 病藥的輕重決定富貴大小（p.376）

張楠的結論：

- **病重而藥也重**（或病輕藥輕但大運再補到中和）→ 大富大貴。
- **病輕而得藥** → 小富小貴。
- **無病無藥** → 不富不貴，平常人。

### 張楠教的看命步驟（p.376）

1. 先看日干；
2. 再看月令。例如月令地支屬火，就從月令的火著眼；
3. 再看年上、時上有沒有火，把所有的火合起來估量輕重；
4. 然後才看水、看金、看土、看木。

他特別警告：**不可以五行一個個亂看，否則必然混雜不清、茫無定見**——「戒之！戒之！」。

另外：財官印有病，就醫財官印；日主本身有病，就醫日主。如果八字純然不旺不弱，財官印都沒受損，日干又中和，那就沒什麼起伏可觀——張楠認為這是平常人（p.376）。

## 二、陳素庵《命理約言》的扶抑說（p.376–377）

### 扶與抑

陳素庵說（p.376）：

> 「命以用神為緊要，看用神之法，不過扶抑而已。」

白話：論命最要緊的是用神，而看用神的方法，說穿了就是「扶」和「抑」兩件事：

- **凡弱的要扶**：扶它的那個字就是用神。扶得太過，就以「抑制那個扶它的字」為用神；扶得不夠，就以「再扶那個扶它的字」為用神。
- **凡強的要抑**：抑它的那個字就是用神。抑得太過，就以「抑制那個抑它的字」為用神；抑得不夠，就以「扶那個抑它的字」為用神。

他用五行舉例：

- 木弱用水扶；水扶太過，用土制水；水扶不夠，用金生水。
- 木強用金抑；金抑太過，用火制金；金抑不夠，用土生金。

並補充：同類幫助、生氣資助都算「扶」；被洩氣、被剋制都算「抑」（p.376）。

### 用神的幾個層次

陳素庵把用神分成幾種（p.376）：

- **日主的用神**：用六神（傷、食、財、官、殺、印等）來扶抑日主。
- **六神的用神**：六神之間互相扶抑（例如官殺用財來生、用印來化）。
- **原局的用神**：原本命局中就有的扶抑。
- **行運的用神**：原局不足，靠運中的干支補足扶抑。

他的比喻：命好比身體，用神好比身體的精神——精神厚則身旺，精神薄則身衰，精神長存則身生，精神壞盡則身死（p.376–377）。

### 取用雖專一，也要變通（p.377）

陳素庵又說：取用雖然應該專注一神，但也要靈活。例如正、偏官格，有時「制」與「化」可以互用，甚至「生」與「制」並用。何況大運一走就是幾十年，不可能只走木不走金。

他觀察：**大富大貴的命，往往不只靠一神為用**；專靠一神的，多半是「補偏救弊」的命罷了。

另一個重點：「有體而後有用」——日主和六神是「體」，扶抑它們的才是「用」。如果日主或六神本身「強到不可制、弱到扶不起，或散漫無倫、或交戰不定」，那就是體先不成立，有用神也用不上，「其為下命決矣」——必定是下等命（p.377）。

### 陳素庵批評張楠

陳素庵說張楠病藥說「其法甚善」，但有問題（p.377）：

- 一方面找病（求傷），一方面又找藥（求醫），最後還是回到「中和」，這不是正理而是偏門。
- 張楠說「八字純然不旺不弱、財官無損、日主中和，是平常人」，這說法太偏了。人命若純粹中和，怎麼會不富不貴？只怕表面純粹、暗中駁雜，或中和之中有淺露之處，那才是不純粹不中和。
- 他親見大富大貴的命，**無病無傷、不旺不弱，運也走五行都好的地方，一生五福俱全**——這不就是純粹中和的鐵證？何必拘泥病藥？

### 作者的評論（p.377–378）

作者認為：

1. 張楠提出病藥說，**確實是取用神上的一大發明**。
2. 但張楠太拘執病藥，竟推演出「無病無藥，不富不貴」，確實偏激過甚、與事實不符。陳素庵的批評很公正，可以採信。
3. 不過這並不表示病藥說全無價值。

作者自己的比較（這段是作者的獨到看法）：

- **原局五行中和的命**：富貴比較**平穩**，大運不論順逆都沒有大忌，很少遇到慘烈的禍事。
- **重病得藥的命**：當然也是富貴，但大運只有一條路——走到喜用的運就鴻圖大展；但時過境遷、失敗時往往很慘，走到逆用神的運，可能破祖亡家、一落千丈，常有不忍聽聞的事（p.377–378）。

所以：**先天中和 = 比較穩的富貴；重病得藥、後天中和 = 比較有風險的富貴**。

此外，大運、流年的干支和原局發生天干生剋合化、地支沖合會刑穿之後，常會改變原局形勢——有時格局因此破壞，有時喜忌因此變更。所以富貴吉凶不能一概而論，一定要就行運逐一推詳（p.378）。

## 三、沈孝瞻《子平真詮》：專求月令、順用逆用（p.378–380）

### 用神專求月令

沈孝瞻說（p.378）：

> 「八字用神，專求月令，以日干配月令地支，而生剋不同，格局分焉。」

白話：找用神要先看月令；把日干和月令地支對照，看生剋關係，格局就分出來了。（注意：沈孝瞻說的「用神」很多時候其實就是「格局」，這一點作者後面會釐清。）

### 善神順用、惡神逆用

沈孝瞻把十神分成兩類（p.378）：

- **善神（財、官、印、食）**：宜「順用」，也就是生它、護它。
- **不善之神（殺、傷、劫、刃）**：宜「逆用」，也就是制它、化它。

「當順而順，當逆而逆，配合得宜，皆為貴格。」

作者在括號裡補充：這裡的「順、逆」是指**格局的旺神**（月令旺神，常常兼作用神），而不是命局所喜的神；另外取來制剋格局旺神的才叫用神。例如：

- 正官格日干強，用正官 → 順用（喜財來生官）。
- 七殺格身殺兩停，取食神制殺 → 逆用。

### 各格的順逆配合（p.378）

沈孝瞻列的配合（作者用白話整理）：

**順用（善神）**
- 財：喜食神生財，喜生官來護財。
- 官：喜透財來生官，喜生印來護官。
- 印：喜官殺來生印，喜劫財來護印。
- 食：喜身旺來生食，喜生財來護食。

**逆用（不善之神）**
- 七殺：喜食神制伏，忌財、印資扶（財生殺、印化殺都讓殺不受制）。
- 傷官：喜佩印來制伏，或生財來化傷。
- 陽刃：喜官殺來制伏，忌官殺都沒有。
- 月劫：喜透官來制伏，或用財而透食來化劫。

作者附註：**這些都是以月令旺神的格局為準**。例如財格日干強，以財為用神，就喜食神生財或官星制劫護財；又如月劫格日干強，就以官星制劫為用，或用財而喜食神化劫轉生財（p.378）。

### 沈孝瞻批評時人「不知專主提綱」（p.379）

沈孝瞻說：現在的人不知道要先抓月令（提綱），把四柱干支一個字一個字都拿來對照月令論喜忌，結果格局混淆。他舉了一連串「表面相同、本質不同」的對照，作者在括號裡逐一解說：

1. **「正官佩印」vs.「印綬用官」**：兩者都是官印雙全。
   - 正官佩印是**正官格**：日干弱，用印化官生身，或用印制食傷護官。
   - 印綬用官是**印綬格**：日干強，用官來制劫護財星（護住印的根源）。
   - 前者用印忌財來壞印，後者用官則喜財生官。
2. **「見財透食」vs.「食神生財」**：兩者都是食神生財。
   - 見財透食是**財格**：日干強，取透干的食神來化劫生財。
   - 食神生財是**食神格**：日干強，取財星來流通食神之氣。
   - 前者用食忌印，後者用財忌劫。
3. **「見偏印透食」vs.「食神逢梟」**：
   - 見偏印透食是**偏印格**：日干強，取透干的食神洩身之秀氣。
   - 食神逢梟是**食神格**：日干強，偏印來奪食，要用財制梟。
4. **「見殺逢食制而露印」vs.「印綬逢殺」**：
   - 前者是**七殺格**：日干弱、食神制殺太過，見印露出天干來制食保護七殺。
   - 後者是**印綬格**：日干弱而印輕，逢七殺，以殺生印為用。
5. **「殺格逢刃」vs.「陽刃露殺」**：
   - 殺格逢刃是**七殺格**：日干弱，地支見羊刃，取刃幫身敵殺。
   - 陽刃露殺是**月刃格**：日干強，天干露七殺，取七殺制刃。

這些區別，都是因為不懂月令而亂論造成的。作者藉此提醒：**格局的名稱與用神的選取是兩回事**，雖然有時格局的旺神也兼作用神（例如正官格日干強以正官為用），但大多數八字的格局與用神是分開的（p.379–380）。

### 月令沒有用神時怎麼辦（p.380）

沈孝瞻又說：雖然以月令為用，但月令也有不能用的時候，例如「木生寅卯，日與月同，本身不可為用」——日干與月令同五行，月令本身不能當用神。這是指**建祿格、月刃格**（日刃格日干強，從旺不成的也算）。這時必須看四柱有沒有財、官、殺、食透干或會支，另外取用神——但最終還是以月令為主，然後再找用神。所以建祿、月刃這種格局，並非月令即用神（p.380）。

作者括號裡補充：用神的選取不一定都在月令中求，月令中沒有可用的，就在其他干支中找；但取用的關鍵仍要以日干配月柱地支，而判定日干強或弱或不強不弱，才能確切認定何者可用、何者不可用。

### 配合氣候：調候的先聲（p.380–381）

沈孝瞻還說：「論命以月令用神為主，然亦須配合氣候而互參之。」就像英雄豪傑生得其時，事半功倍；生不逢時，再有才也難成功。作者指出**這就是「調候」**，第十五章四時五行宜忌已詳細介紹，請大家再翻閱一遍（p.380）。

沈孝瞻的例子（都以「某日干生於某月、天干透某字」的片段說明，不是完整命例）：

- **印綬遇官**（例：甲木生子月，天干透辛金）：本來是官印雙全，但金寒水凍，凍水不能生木，所以不容易貴（p.380）。
- **身印兩旺透食則貴**；用多木逢火（例：甲木生子月透丙火），不但能洩身，也能調候，尤其秀氣（p.380）。
- **傷官見官本是大忌**，但金水傷官見官（例：庚金生子月透丁火）反而成秀氣——因為冬天金寒水冷，**調候比較急**，所以權且用官（p.380）。
- 傷官帶殺隨時可用，但用在**冬金**（庚金子月透丙火）秀氣百倍，用在**夏木**（甲木生午月透癸水）也秀；火濟水、水濟火的道理（p.380）。
- 傷官用財本是貴格，但用在**冬金**（庚金生子月透甲木）只是小富、多半不貴，因為凍水不能生木；用在**夏木**（甲木生午月透戊土）貴而不甚秀，因燥土不甚靈秀（p.380–381）。
- **春木逢火**（甲木卯月透丙丁）是木火通明；**夏木逢火**則不在此論。**秋金遇水**（庚金酉月透壬癸）是金水相涵；**冬金遇水**則不在此論。取用各有不同（p.381）。
- 春木逢火「不利見官」，但秋金遇水卻「見官無礙」；而庚生申月支中會成水局、天干透丁為官，只要壬癸不透干頭照樣是貴格——這與「金水傷官喜見官」同理，也是調候之道（p.381）。
- 食神雖逢正印也算奪食，但夏木火盛，輕用印（乙木生午月透壬癸）反而秀而貴——與「木火傷官喜見水」同論，也是調候（p.381）。

作者總結：這類例子很多，學者要舉一反三。**凡八字必以中和為貴；偏旺一方而調候不宜的，即使成格成局，也不甚美**（p.381）。

## 四、《滴天髓》與任鐵樵、徐樂吾的通關說（p.381–382）

### 原文與比喻

《滴天髓》說（p.381）：

> 「關內有織女，關外有牛郎，此關若通也，相邀入洞房。」

白話：兩方像牛郎織女被一道關隔開，這道關一打通，就能相會團圓。比喻兩股相剋對峙的五行，只要中間有人疏通，就能化敵為友。

### 任鐵樵的註解（p.381–382）

任鐵樵說：「通關者，引通剋制之神也。」作者括號舉例：日干甲木遇到庚金剋制，得壬水洩庚生甲，壬水就是通關之神。

任鐵樵的重點：

- 陰陽二用，妙在氣交：殺喜印，殺露印也露，殺藏印也藏，這樣就自然通達，不必另生枝節。
- 如果原局沒有印，必須歲運逢印，或暗會、明合來通。
- 原局有印，但印被財星損壞、或被官星化去、或被比劫解掉、或被合住，那就該沖的沖、該合的合、該剋的剋。
- 「前後上下，不能援引，得歲運相逢尤佳」。例如**年印時殺**、干殺支印、前後遠隔、上下懸隔，或被間神忌物阻隔——這是原局無法通的，必須等歲運暗沖暗合、剋制掉間神忌物，該沖則沖、該剋則剋、該合則合，引通相剋之勢。此關一通，就像牛郎織女入洞房，無不遂其所願（p.381–382）。
- 殺印這樣論，食傷財官的關係也一樣（p.382）。

### 徐樂吾補註：通關有兩種（p.382）

> 「通關有二：一為兩神成象，勢均力敵，必須引通其氣；一旺一弱，亦須有以調和之。」

1. **兩神成象、勢均力敵**：兩個五行力量相當地對峙，必須引通。
2. **一旺一弱**：也需要調和。例如官殺旺而日主弱，用印通關；日主強而財星輕，用食傷通關。

即使原局沒有通關之神，也必須運程遇到，才能遂其志。這一點，**通關之神就是全局精神所在**。

徐樂吾又列出幾種典型（p.382）：

- 用神之間，氣勢對峙，如兩神並立不能並用、又不能去一留一，必須以通關之神調和。
- **官、傷並立** → 必須用財（傷生財、財生官）。
- **財、印交差** → 須用官殺（財生官殺、官殺生印）。
- **財逢劫刃** → 必用食傷（劫生食傷、食傷生財）。
- **梟印奪食** → 劫為恩星（梟印生劫、劫生食）。

徐樂吾說這類八字「最不易看」。

## 作業：第二十六次作業題（p.382–383）

1. **什麼叫做用神？**
   - 答題提示：見「本章前言・什麼叫用神」（p.374）。要點：能助成格局、補救破格、使五行中和或流通的那一字。

2. **依張楠的說法，如果用財而以比劫為病，應以什麼為藥？**
   - 答題提示：見「一、張楠病藥說」的表格（p.375–376）：用財以比劫為病，以官殺為藥。

3. **舉例說明陳素庵「凡弱者宜扶，扶之者即用神；扶之太過，抑其扶者為用神；扶之不及，扶其扶者為用神」這段話。**
   - 答題提示：見「二、陳素庵扶抑說」（p.376）。可用「木弱用水扶，水太過用土制，水不足用金生」來說明。

4. **陳素庵批評張楠病藥說，你有何意見？**
   - 答題提示：見「作者的評論」（p.377–378）：病藥說是一大發明，但「無病無藥不富不貴」說得太絕；先天中和者富貴穩健，重病得藥者富貴但風險高。

5. **沈孝瞻說「八字用神，專求月令……當順而順，當逆而逆，配合得宜，皆為貴格」，涵義為何？**
   - 答題提示：見「三、沈孝瞻」的「善神順用、惡神逆用」（p.378）。注意順逆是針對月令格局旺神而言。

6. **什麼叫「正官佩印」、「印綬用官」、「食神生財」？**
   - 答題提示：見「沈孝瞻批評時人不知專主提綱」第 1、2 點（p.379）。重點是先看月令定格，再看日干強弱，同樣是「官印」「食財」，喜忌不同。

7. **試舉一例說明調候的意義。**
   - 答題提示：見「配合氣候：調候的先聲」（p.380–381），例如庚金生子月透丁火，傷官見官本忌，但冬金寒冷以調候為急，反成秀氣。

8. **試舉一例說明通關的意義。**
   - 答題提示：見「四、通關說」（p.381–382），例如甲日逢庚剋，得壬水洩金生木；或官殺旺身弱用印、身強財輕用食傷。

## 名詞小辭典

- **用神**：八字裡最能幫助格局、補救缺陷、讓五行平衡或流通的那個字（或那一行）。好比人的精神。
- **病、藥**：張楠的術語。「病」是八字中造成傷害、使命局失衡的字；「藥」是能把病去掉的字。
- **扶、抑**：扶是幫它（生它、同類助它），抑是壓它（剋它、洩它）。
- **六神**：此處指傷、食、財、官、殺、印等日干以外的十神關係。
- **體、用**：日主及格局本身是「體」，扶抑它的字是「用」。體不成立，用也無從談起。
- **提綱**：月令（月柱地支）的別稱，好比漁網的總繩，提起它全局才看得清。
- **順用、逆用**：沈孝瞻用語。財官印食是善神，用生、護的方式對待叫順用；殺傷劫刃是惡神，用制、化的方式對待叫逆用。
- **建祿格、月刃格**：日干在月令得祿（如甲生寅月）或羊刃（如甲生卯月）。月令和日干同氣，月令本身不能當用神，要另外找財官殺食。
- **梟神奪食**：偏印（梟）剋食神，把食神的福氣奪走。
- **陽刃露殺**：月令是陽刃（日干強），天干又透七殺來制刃，是好的配合。
- **殺格逢刃**：七殺格日干弱，地支有羊刃幫身抵抗七殺。
- **調候**：調和命局的寒暖燥濕。冬天生的八字太冷要火來暖，夏天生的太燥熱要水來潤。
- **金寒水凍**：冬季金水當令，寒冷凝結，水凍不能生木，使命局缺乏生機。
- **木火通明**：木生於春天又見火，木生火、火光照耀，主聰明秀氣。
- **金水相涵**：金生於秋天又見水，金生水而清，主秀氣。
- **通關**：兩種五行相剋對峙時，找一個能「承上啟下」的五行來疏通，例如金剋木時用水，金生水、水生木。
- **間神、忌物**：卡在兩字之間阻礙它們連通的字，或對命局有害的字。
- **恩星**：救命恩人般的字。例如梟印奪食時，劫財能把梟印的力量轉化去生食神，所以劫是恩星。

## 和課堂、App 的對照

- **課堂以扶抑為主**：許羽賢老師教「扶抑為主，病藥／調候／通關不可與扶抑衝突」。本節作者把病藥、扶抑、調候、通關並列介紹，基本精神（求中和流通）一致；但沈孝瞻「專求月令、順用逆用」是**以格局為主**的思路，跟課堂「先判日主強弱再扶抑」的順序不同，讀時要分清楚古書說的「用神」有時其實是「格局」。
- **得令得勢得地**：本節陳素庵、沈孝瞻都強調日干強弱要對照月令判斷，和課堂的「得令」概念相符。
- 其餘無特別差異。
