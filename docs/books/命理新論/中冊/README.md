# 吳俊民《命理新論》中冊：按章節詳細筆記

中冊是函授「高級」講義，第二十一至二十三章，書頁 p.374–799。這份筆記每「節」一個檔，從初學者的角度重讀書頁整理：先講本節在學什麼，再依書上的小標題詳細解說，艱澀詞句與古文引文都另外白話解釋。

每個檔案的結構：一句話導讀 → 本節在講什麼 → 依書上小標題詳解（附書頁）→ 命例 → 作業（附答題提示）→ 名詞小辭典 → 和課堂、App 的對照。

命例一律用 App 排盤格式（時 日 月 年，十神在天干上方，藏干本氣置中並附藏干十神），每例分「書上怎麼說／一步一步看／學到什麼」。書上命例都沒有出生年月日，大運多半只列四步；筆記若依月柱補排大運會註明。這是讀書筆記，不是原文，引文只取短句。

## 章節架構

- **第二十一章 普通格局的用神及其喜忌**：先賢議論（病藥、扶抑、順逆、調候、通關）→ 用神四類的選法 → 取用神的注意事項與喜忌。
- **第二十二章 普通格局的成敗得失**：正官、七殺、官殺並見、傷官、食神、財、印七種格局，每格都是「先賢議論 → 成敗及行運 → 實例 → 歌訣 → 作業」。
- **第二十三章 特別格局的成敗得失**：陽刃、建祿、從格、一行得氣、兩神成象、化格，最後檢討二十多種雜格（飛天祿馬、井欄叉、壬騎龍背…），作者多半認為雜格不足取。

## 掃描缺頁與待核對

- 掃描檔的 p.417 與 p.794 是重複掃描（分別重複 p.416、p.793）；2026-11-03 已依實體書照片補上，分別在第二十二章第一節「一、先賢的議論」開頭，與第二十三章第七節「二十、福德秀氣」。
- 四柱與五虎遁／五鼠遁不合、照書錄入並在表下標 ⚠ 的：p.390 扶抑例（月柱乙丑，應丁丑）、p.400 調候例三（月柱辛丑，應癸丑）、p.667 沈孝瞻引例（作者改年柱的說法存疑）、p.692 一行得氣例七（時柱己未，應乙未）、p.751 遙巳例二、例三（月柱應為癸丑、辛丑）。
- 疑似排印錯誤，筆記已依文意解釋並註明：p.447「日年寅亥」應為時年；p.464「一寅去一卯」應為一酉；p.519「制木」疑衍文、「甲殺」應為制殺；p.574「日干弱」應為日干強；p.579 文說亥月但月柱為戊辰；p.732「申運」字形似「中」；p.734「戊運沖辰」應為戌運；p.761「金木旺月」疑為金水。
- 舊逐頁筆記有兩處與書不符，本版已更正：p.712 化氣與十神的對應（乙庚化食傷、丁壬化官殺、丙辛化財、戊癸化印），p.715 任鐵樵的「五運遁」是從甲子起數。
- 部分作業題只給出生年月日而沒有四柱，筆記只寫思路，四柱需用 App 排。
