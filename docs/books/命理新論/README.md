- 本書 PDF 每頁是左右對開兩頁，所以筆記檔名用的是**書頁**，不是 PDF 頁。上冊對照：PDF 第 n 頁右半 ≈ 書頁 2n−13，左半 ≈ 2n−12。
- 作者主張年柱以**冬至**換年、時辰用真太陽時、夜子時用明日時干，與通行做法不同，讀例題四柱時要注意。
- 例題四柱是直排小字，少數判讀不確定的已在筆記標註。
