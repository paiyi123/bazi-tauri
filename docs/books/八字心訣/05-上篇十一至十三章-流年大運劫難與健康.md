# 上篇第十一、十二、十三章　流年大運、居安思危、健康無價（第 56–75 訣，書第 146–200 頁）

> **這三章在講什麼**：
> - 第十一章「流年大運」：怎麼批流年。先講總原則（汽車比喻、天干看合地支看沖），再分財運、成名、事業、愛情、六親五個主題，每個主題先列「十神在這個主題代表什麼」，再舉名人實例。
> - 第十二章「居安思危」：六種「劫難速斷」的訊號：反吟伏吟、天羅地網、四正四庫四長生齊全、樞紐受制、凶物深藏、破格。
> - 第十三章「健康無價」：天干地支配臟腑、四柱配身體部位、每個五行太過或不及的病症、五行相剋的病、精神健康。
>
> **這三章的讀法**：前面十章看的是「原局」（一輩子的結構），這三章看的是「時間」：什麼時候發生什麼事。方法其實只有一個：**把大運流年的干支加進原局，看它對用神、功神、宮位做了什麼**（生、剋、合、沖、刑、入墓）。每一個例子都可以用這個問題去練習。健康篇的斷語來自中醫五行，只能當保養提醒，不能取代就醫。

## 第十一章　流年大運

### 第 56 訣　流年總訣（書第 146–149 頁）

**這一訣在講什麼**：

1. 批流年＝看大運、流年的干支，對原局「賓主體用作功」產生什麼影響。
2. 比喻：**命局是汽車、大運是路程、流年是天氣、流月是波浪**。車子好不好（原局）決定基本能力；路平不平（大運）決定十年的大環境；天氣（流年）決定這一年順不順；波浪（流月）是更細的起伏。
3. 先把流年和大運合起來看，再加到原局上。
4. 原局是一個靜態的平衡；**天干看合為主，地支看沖為主**。
5. **天干＝外、動、表象**：財透干合日主，人人看得到，容易被劫。**地支＝內、靜、根基**：地支進財比較隱密。
6. 吉凶最後看「作功」是喜還是忌。
7. 流年影響**性格**比大運更明顯：十神影響最大（食傷年快樂、七殺年憂愁、正印年清心寡欲甚至孤獨自閉、財年慾望多、比劫年熱心交友），其次是干支五行，再其次是神煞。

**為什麼天干看合、地支看沖**：天干是浮在表面、流動的氣，最容易被「拉走」（合）；地支是根基，像地基一樣穩，平常不動，一旦被「撞」（沖）才會動搖。所以流年天干來，先看它合了原局哪一個字；流年地支來，先看它沖了原局哪一個字。

**為什麼流年比大運更直接**：大運是十年的背景，流年是當年的主角；作者在下篇第 98 訣還說「太歲有決定生死之權」。

**和其他書比較**：下篇第 98 訣（歲運論）用同一個汽車比喻。《妙算人生八字》也說「流年重於大運」，兩書一致；課堂和陸致極則以大運為主軸；《滴天髓命例研究》說大運以地支為重、流年地支常可忽略，和本書正好相反。

#### 命例：某國家政要（推測為胡耀邦），辛巳運己巳年逝世（書第 148 頁）

**書怎麼說**：水木火三行成象，用神水木火、忌土金；辛巳運、己巳年（1989）逝世：辛金七殺運、己土財年都是忌神。書未明說是誰，筆記依生日推測為胡耀邦。（命盤見 02 檔：乙卯 丁亥 乙卯 丙子）

**一步一步看**

1. **原局**：亥子水 → 乙卯木 → 丙丁火，三行成象；忌土（破水）、金（剋木）。
2. **大運辛巳**：辛金（七殺）透干剋乙木；巳火沖原局月支亥水（巳亥沖）→ 水（源頭）被沖。
3. **流年己巳**：己土（偏財）透干，剋水；巳火再沖亥 → 歲運兩個巳一起沖亥。
4. **合起來**：金剋木、土剋水、源頭被沖 → 三行象被破 → 逝世。

**學到什麼**：先把「歲 + 運」合起來看（兩巳沖一亥），再看它打到原局哪裡（三行成象的源頭）。

#### 命例：貴命，辛亥運官旺身無制而丟官（書第 149 頁）

**書怎麼說**：官旺身無制；辛亥運丙辛合而壞印、亥卯半三合，官旺剋身無制，此運丟官。（命盤見 03 檔：壬寅 丙午 戊寅 乙卯）

**一步一步看**

1. **原局樞紐**：月干丙火（偏印）化寅卯木（官殺）生戊土。
2. **大運天干辛**：辛和丙相合（天干看合）→ 印被合走。
3. **大運地支亥**：亥和時支卯半合木、又和寅合 → 官殺更旺。
4. **結果**：化殺的印沒了，官殺直接剋身 → 丟官。

**學到什麼**：「天干看合」最典型的例子：大運天干合走原局的用神。

（書上這一訣還舉了韓信、譚嗣同，命盤見 02 檔，分析見第 20、21 訣。）

### 第 57 訣　流年財運訣（書第 150–151 頁）

**這一訣在講什麼**：測財運時，十神的意思是：

| 十神 | 在財運的意思 |
|---|---|
| 官殺 | 耗財 |
| 印 | 耗財在投資的事情上 |
| 財 | 錢財 |
| 食傷 | 財源 |
| 比劫 | 破財 |

**規則**：原局的財干被流年天干剋、財支被流年地支沖，都影響財；**天剋地沖最嚴重**。另外，流年或大運天干是財星，主進財但人人知道，所以容易被劫。

**為什麼比劫＝破財**：比劫是和我同類、和我搶東西的人（兄弟、朋友、合夥人、競爭者）；它剋的正是財。所以比劫年容易借錢給人、合夥出事、被搶生意。

#### 命例：乾造，甲寅運甲戌年破財千萬（書第 150 頁）

**書怎麼說**：甲寅運、甲戌年、戊辰月，比劫為破財，破財千萬元。第 61 訣又用這個命盤說「乙卯年歲運並臨，卯戌合，父緣盡」。

| | 時 | 日 | 月 | 年 |
|---|:-:|:-:|:-:|:-:|
| 十神 | 七殺 | 日主 | 傷官 | 偏財 |
| 天干 | **庚**<sub>金</sub> | **甲**<sub>木</sub> | **丁**<sub>火</sub> | **戊**<sub>土</sub> |
| 地支 | **午**<sub>火</sub> | **辰**<sub>土</sub> | **巳**<sub>火</sub> | **戌**<sub>土</sub> |
| 藏干 | 己 **丁** | 乙 **戊** 癸 | 戊 **丙** 庚 | 辛 **戊** 丁 |
| 藏干十神 | 正財 **傷官** | 劫財 **偏財** 正印 | 偏財 **食神** 七殺 | 正官 **偏財** 傷官 |

**一步一步看**

1. **日主**：甲木生巳月，火旺洩木 → 失令；日支辰（有乙木、癸水）是微根；天干沒有比劫印 → 身弱。
2. **財**：年柱戊戌、日支辰（偏財），財旺。
3. **大運甲寅**：甲木（比肩）、寅（祿）→ 比劫運。
4. **流年甲戌**：甲木又是比肩；戌和原局年支戌伏吟、和日支辰相沖（辰戌沖）→ 財星互沖。
5. **流月戊辰**：戊土（財）透出，被歲運兩甲爭剋；辰再沖戌。
6. **結果**：比劫重重 + 財庫沖動 → 破財千萬。

**學到什麼**：比劫運、比劫年疊在一起，加上財的地支被沖，是典型的大破財組合。

#### 命例：乾造，甲戌運甲戌年破財數十萬（書第 150 頁）

**書怎麼說**：甲戌運、甲戌年，和日柱庚辰天剋地沖，戊辰月破財數十萬；流年或大運天干是財星，主進財但人人知道，所以也容易被劫。

| | 時 | 日 | 月 | 年 |
|---|:-:|:-:|:-:|:-:|
| 十神 | 七殺 | 日主 | 食神 | 正印 |
| 天干 | **丙**<sub>火</sub> | **庚**<sub>金</sub> | **壬**<sub>水</sub> | **己**<sub>土</sub> |
| 地支 | **戌**<sub>土</sub> | **辰**<sub>土</sub> | **申**<sub>金</sub> | **亥**<sub>水</sub> |
| 藏干 | 辛 **戊** 丁 | 乙 **戊** 癸 | 壬 **庚** 戊 | 甲 **壬** |
| 藏干十神 | 劫財 **偏印** 正官 | 正財 **偏印** 傷官 | 食神 **比肩** 偏印 | 偏財 **食神** |

**一步一步看**

1. **日主**：庚金生申月 → 得令；日支辰、年干己（印）→ 身旺。
2. **歲運甲戌**：甲木是庚金的偏財，透在天干 → 「財透干，人人看得到」。
3. **天剋地沖**：嚴格說，天剋地沖是流年的干剋日干、支沖日支；這裡是庚剋甲（日主剋流年），作者的意思是甲（財）和庚（日主）相戰、戌沖辰（日支）。
4. **歲運並臨**：運和年都是甲戌 → 作用加倍。
5. **流月戊辰**：辰再和戌相沖 → 引爆。

**學到什麼**：財透天干，看起來是「進財」，但天干的財容易被爭奪；日支被沖是自己的根基動搖。

#### 命例：坤造，己未運壬申年大耗破財（書第 151 頁）

**書怎麼說**：己未運（比劫）、壬申年（財），大運逢比劫再逢財年，大耗破財，幾乎無以為生。

| | 時 | 日 | 月 | 年 |
|---|:-:|:-:|:-:|:-:|
| 十神 | 七殺 | 日主 | 正印 | 偏財 |
| 天干 | **乙**<sub>木</sub> | **己**<sub>土</sub> | **丙**<sub>火</sub> | **癸**<sub>水</sub> |
| 地支 | **丑**<sub>土</sub> | **丑**<sub>土</sub> | **辰**<sub>土</sub> | **卯**<sub>木</sub> |
| 藏干 | 癸 **己** 辛 | 癸 **己** 辛 | 乙 **戊** 癸 | **乙** |
| 藏干十神 | 偏財 **比肩** 食神 | 偏財 **比肩** 食神 | 七殺 **劫財** 偏財 | **七殺** |

**一步一步看**

1. **日主**：己土生辰月 → 得令；日支丑、時支丑 → 身旺。
2. **財**：年干癸水（偏財），坐卯；辰、丑中藏癸水。
3. **大運己未**：己土（比肩）、未土（比肩）→ 比劫運，未又沖兩丑。
4. **流年壬申**：壬水（正財）透出 → 財一出現，就被大運的比劫搶走（比劫爭財）。
5. **結果**：大耗破財。

**學到什麼**：大運是「誰在場」，流年是「什麼東西出現」：比劫在場時財出現，財就會被搶。

#### 命例：乾造，食品加工發財（書第 151 頁）

**書怎麼說**：水木火為體、土為用；時干丁火生旺時支丑土、巳丑拱合，食傷生財有效作功；30 歲後丙午、丁未運作功效率增高，從事食品加工發財致富。

| | 時 | 日 | 月 | 年 |
|---|:-:|:-:|:-:|:-:|
| 十神 | 食神 | 日主 | 偏印 | 正印 |
| 天干 | **丁**<sub>火</sub> | **乙**<sub>木</sub> | **癸**<sub>水</sub> | **壬**<sub>水</sub> |
| 地支 | **丑**<sub>土</sub> | **巳**<sub>火</sub> | **卯**<sub>木</sub> | **寅**<sub>木</sub> |
| 藏干 | 癸 **己** 辛 | 戊 **丙** 庚 | **乙** | 丙 **甲** 戊 |
| 藏干十神 | 偏印 **偏財** 七殺 | 正財 **傷官** 正官 | **比肩** | 傷官 **劫財** 正財 |

**一步一步看**

1. **日主**：乙木生卯月 → 得令；年柱壬寅、月干癸 → 印比旺，身旺。
2. **食傷**：日支巳（傷官）、時干丁（食神）。
3. **財**：時支丑（偏財）。時柱丁丑，丁火生丑土（同柱）；日支巳和時支丑拱金……作者說「巳丑拱合」，重點是巳火和丑土連在一起，火生土。
4. **作功**：身旺 → 食傷 → 財（生用），有效。
5. **大運**：丙午、丁未是食傷大運 → 加強生財 → 發財。
6. **行業取象**：食神（飲食）生財（土）→ 食品加工。

**學到什麼**：食傷大運最利身旺的人生財；行業可以從功神的十神取象（食神 → 飲食）。

### 第 58 訣　流年成名訣（書第 152–155 頁）

**這一訣在講什麼**：測名運時，十神的意思是：

| 十神 | 在名運的意思 |
|---|---|
| 官殺 | 壓力（也是官位、頭銜） |
| 印 | 憂愁煩悶 |
| 財 | 錢財名譽 |
| 食傷 | 名譽 |
| 比劫 | 幫手、助力 |

**怎麼用**：配合第 12 訣「官殺主貴、食傷主名」：流年是官殺，容易得到職位頭銜；流年是食傷，容易得到名聲獎項。原則是「喜用的十神到位就應驗」。

#### 命例：李嘉誠的榮銜年表（書第 152–153 頁）

**書怎麼說**：官殺主貴（即官位）、食傷主名（即名譽）。作者列出李嘉誠的榮銜年份，對照流年十神。（命盤見 01 檔：戊辰 戊午 甲申 癸酉）

| 年 | 干支 | 對甲木的十神 | 事件 |
|---|---|---|---|
| 1981 | 辛酉 | 正官 | 風雲人物、太平紳士 |
| 1986 | 丙寅 | 傷官（丙是食神，書上依火統稱食傷） | 比利時勳銜 |
| 1989 | 己巳 | 巳為傷官（巳中丙火是食神） | 英女皇 CBE、加拿大榮譽博士 |
| 1990 | 庚午 | 七殺／夏季火旺即食傷旺 | 商業成就獎、汕頭榮譽市民 |
| 1992 | 壬申 | 申為七殺 | 北京大學名譽博士 |
| 2001 | 辛巳 | 巳為食傷 | 大紫荊勳章 |
| 2006 | 乙酉 | 酉為正官 | 港大醫學院以其命名 |

**一步一步看**

1. **原局**：甲木身弱，申酉官殺化成水印 → 官殺對他是「化用」的功神（第 34 訣：權為所用）。
2. **官殺年**：辛酉、庚午、壬申、乙酉 → 官殺到位 → 得頭銜、勳章（貴）。
3. **食傷年**：丙寅、己巳、辛巳 → 食傷到位 → 得名譽、榮譽學位（名）。
4. **為什麼食傷對身弱的他也能得名**：作者說原局食神得令（第 13 訣「果」吉），食傷是他晚年的福；這裡只看「十神主題」，不看喜忌。

**學到什麼**：流年的十神直接對應那一年的「主題」：官殺年得官位、食傷年得名聲。這是最簡單的流年取象法。

#### 命例：郭富城，火運三十年成名（書第 153 頁）

**書怎麼說**：水木火為體、土為用；丙火、巳火生旺戌土財星，食傷生財有效作功；命造因有食傷貼身洩秀且為用神，好交友、好人緣；23 歲後三十年火運，在歌壇成名，事業能持續。（命盤見 03 檔：乙巳 丙戌 甲辰 甲子）

**一步一步看**

1. **原局功神**：月干丙火（食神）貼身洩秀，生月支戌土（財）。
2. **大運**：23 歲起三十年火運 → 食傷大運 → 名（食傷主名）且生財。
3. **持續性**：大運是十年的背景，連續三步都是用神 → 事業長紅。

**學到什麼**：成名看食傷，能不能持續看大運是不是連續有利。

#### 命例：梅艷芳，甲木運大紅（書第 153 頁）

**書怎麼說**：丙火身弱，卯戌逢合不生火，財官無制，作功效率低，失運時一定落魄；20 歲甲木運，印能洩官殺生日主，有效作功，大紅；1982 壬戌年食傷主名，新秀奪冠。（命盤見 01 檔：癸卯 壬戌 丙戌 丁酉）

**一步一步看**

1. **原局**：丙火身弱，壬癸官殺、戌土食神、酉金財 → 異黨多。
2. **用神被合**：年支卯木（印）被戌合住，不能生火 → 原局作功效率低。
3. **大運甲木**：甲木（偏印）透出天干 → 官殺生印、印生身（化用）→ 有效作功 → 大紅。
4. **流年壬戌 1982**：戌是食神（食傷主名）→ 新秀奪冠。

**學到什麼**：原局用神被綁住的人，要等大運把同樣的五行「透出天干」才發。

#### 命例：伏明霞，己未運成名（書第 154 頁）

**書怎麼說**：己未運成名：1991 辛未年比劫為助力，成為最年輕的世界冠軍；1992 壬申年食傷旺極，14 歲奧運冠軍；1996 丙子年官主貴，雙料冠軍；2000 庚辰年，辰是水庫，復出再奪冠。（命盤見 04 檔：戊午 庚申 庚戌 甲申）

**一步一步看**

1. **原局**：庚金生申月，身旺；年支午火（正官）、時干甲木（偏財）。身旺喜洩（水）、喜官（火）。
2. **大運己未**：己土（正印）、未土 → 印運，幫身（運動員要體力）。
3. **1991 辛未**：辛金（劫財）→ 比劫是幫手 → 世界冠軍。
4. **1992 壬申**：壬水（食神）坐申長生 → 食傷旺極 → 奧運冠軍（名）。

### 第 60 訣　流年愛情訣（書第 158–159 頁）

**這一訣在講什麼**：測婚姻時，十神的意思男女不同：

| 十神 | 女命 | 男命 |
|---|---|---|

**規則**：

1. 日支是夫妻宮，大運流年對日支的沖、刑、化、合都影響感情。
2. 男命日主太強，歲運再不利財星 → 感情波折、夫妻不睦；日主太弱，財剋不住 → 懼內，再逢財旺之年 → 留不住妻。女命同理看官。

### 第 61 訣　流年六親訣（書第 160–161 頁）

**這一訣在講什麼**：

2. 合會多凶險：某十神被合會 → 易生劇變。
3. 年、月、日、時支分別配父母、兄弟、配偶、子女；被大運流年合沖刑 → 那位親人不安，輕則病、重則大劫。

**為什麼「入墓」代表有難**：墓是收藏的地方，也是「埋葬」的地方。代表某位親人的十神本來在外面活動，流年把它收進墓裡，就有「被埋」的象。另外第 66 訣說「墓藏者怕露天干」：藏在墓裡的十神，被流年引到天干，也是凶象。

#### 命例：宋慶齡，孫中山逝世（書第 160 頁）

**書怎麼說**：官星（金＝夫）只藏在丑土墓庫；1925 乙丑年、大運庚寅，書說丑丑戌「三刑」官星受損，加上庚金被乙合，孫中山逝世。（命盤見 02 檔：壬辰 癸丑 甲子 乙亥）

**一步一步看**

1. **夫星**：甲木女命，官殺是金；原局只有月支丑中藏辛金 → 夫星在墓（規則 1）。
2. **大運庚寅**：庚金（七殺）透出 → 夫星在天干。
3. **流年乙丑**：乙木和大運庚金相合（乙庚合）→ 夫星被合（規則 2）；丑又是金庫，和原局丑伏吟 → 夫星再入墓。
4. **書上的三刑**：書寫「丑丑戌三刑」，但原局和歲運都沒有戌。

**學到什麼**：照第 32 訣只認寅巳申、丑未戌，這裡的三刑說法不完整，讀時存疑（README 已記錄）；夫星被合 + 入墓，已足以說明。

#### 命例：張學良，父親被炸死（書第 160–161 頁）

**書怎麼說**：巳火（財＝父）被丑合，父星易變；1928 戊辰年、癸巳月、辛卯運，子辰一片旺水無制，巳酉丑暗三合剋死巳火財星，父親張作霖被炸死。另外，書上這裡寫生日 1901-06-04，但壬子日其實是 6 月 3 日（第 25 訣寫 6 月 3 日）。（命盤見 02 檔：辛丑 癸巳 壬子 庚子）

**一步一步看**

1. **父星**：男命以偏財為父；壬水的財是火，月支巳火（偏財）→ 父星。
2. **原局**：巳和年支丑合（巳丑半合金）→ 父星被合，容易變化（規則 2）。
3. **流年戊辰**：辰和日支子、時支子合水（子辰合）→ 水極旺，剋火。
4. **流月癸巳**：癸水（劫財）透出剋火；巳再引出巳丑合金。
5. **結果**：父星（巳火）被合化、被水剋 → 父親遇難。

**學到什麼**：六親星被合化（變成別的五行）又被剋，就是六親出事的應期。

## 第十二章　居安思危（劫難速斷）

> **這一章在講什麼**：作者把「哪一年容易出大事」整理成六個訊號，叫「劫難速斷訣」：反吟伏吟（第 62 訣）、天羅地網（第 63 訣）、四正四庫四長生湊齊（第 64 訣）、樞紐受制（第 65 訣）、凶物深藏（第 66 訣）、破格（第 67 訣）。前三個是「看得見的形狀」，一眼就能在干支上找到；後三個要先把原局的用神、功神、格局弄清楚才能用。初學者可以先背前三個當警報器，但記得作者自己一再強調：**警報響了，還要看它有沒有破壞原局的功用神，才能斷吉凶**。

### 第 62 訣　反吟伏吟訣（書第 164–166 頁）

**這一訣在講什麼**：

1. **伏吟**＝兩柱干支完全相同（例如流年丙子遇到原局丙子）。**反吟**＝兩柱天剋地沖（天干相剋、地支相沖，例如庚午對丙子：丙剋庚、子沖午）。反吟比伏吟災重。
2. 日柱是「主位」，日柱犯反吟災最重；年、月、時柱較輕。受損的多半是錢財、健康、事業、家庭。
3. 柱位對應年齡：小時候歲運和年柱反吟 → 小時候有災；青年對月柱；中年對日柱（剋配偶或自身）；晚年對時柱（剋子女或自身）。這和第 42 訣「一柱一限、每限十六年」是同一套想法。
4. 仍要看它有沒有破壞原局功用神的作功，才斷吉凶；如果被沖的正好是忌神，反吟反而可能是好事。
5. 大運或流年犯反吟 → 動盪不安；犯伏吟（特別是「歲運並臨」，流年和大運干支相同）→ 影響激烈，破壞功用神必有災。
6. 原局本身已經有反吟伏吟 → 這個人的命本來就不穩，再遇歲運的反吟伏吟更要小心。

**為什麼反吟比伏吟重**：伏吟是「同一股氣又來一次」，像同一首歌重播，把原有的力量加倍（好的更好、壞的更壞）；反吟是「正面相撞」，天干地支同時打架，原來的結構直接被拆開，所以變動更大。

**怎麼用**：拿到一個流年，先寫出它的干支，再一柱一柱比對原局四柱和當下大運：有沒有完全相同（伏吟）？有沒有天剋地沖（反吟）？找到之後，再問「被撞的那一柱上面，坐的是用神還是忌神」。

**和其他書比較**：App 已有「反吟」「日柱伏吟」「歲運並臨」標籤（來自陸致極書），定義相同。本書多了「年齡對應柱位」的說法，和第 42 訣宮位運限配套。

#### 命例：蔣緯國，庚午年反吟日柱（書第 165 頁）

**書怎麼說**：1990 庚午年，流年和日柱丙子天剋地沖（反吟），破壞了原局「子水沖剋午火」這個有效作功，所以主凶；那一年有人提議他選副總統，最後沒有參選。（命盤見 03 檔：丙辰 丁酉 丙子 甲午）

**一步一步看**

1. **日主**：丙火生酉月，金旺、火休囚 → 失令；時支午是丙火的羊刃（得地），年干丙、月干丁、時干甲（偏印）幫身 → 身不弱，火氣偏多。
2. **原局的作功**：日支子水（正官）沖時支午火（羊刃），等於「官制刃」，把多餘的火氣管住，這是原局的好結構。
3. **流年庚午**：庚金被丙火剋（天剋），午火沖子水（地沖）→ 和日柱丙子天剋地沖，就是日柱反吟。
4. **為什麼凶**：流年又帶來一個午火，變成兩個午沖一個子，子水反而被火圍攻；「官制刃」的作功被打亂。
5. **結果**：書說有人提議選副總統，最後未參選；也就是「有機會但落空」。

**學到什麼**：判斷反吟的吉凶，不是看「有沒有沖」，而是看沖完之後，原局那個好用的作功是加強還是被破壞。

#### 命例：曹錕，戊午運甲子年被囚（書第 165 頁）

**書怎麼說**：1924 甲子年、大運戊午；原局三個子加上流年子，四子沖一午，而午火是他的官星，於是被囚，政治生命從此斷送。

|---|:-:|:-:|:-:|:-:|
| 十神 | 劫財 | 日主 | 比肩 | 傷官 |
| 天干 | **丁**<sub>火</sub> | **丙**<sub>火</sub> | **丙**<sub>火</sub> | **己**<sub>土</sub> |
| 地支 | **酉**<sub>金</sub> | **寅**<sub>木</sub> | **子**<sub>水</sub> | **卯**<sub>木</sub> |

1. **日主**：丙火生子月，水旺剋火 → 失令；日支寅（藏甲丙）是長生之地、年支卯是印 → 得地；月干丙、時干丁幫身 → 得勢。三選二，身不算弱。

**學到什麼**：月令是全局的「提綱」，月柱被反吟、伏吟同時打到，是很重的訊號。

#### 命例：坤造，原局自行反吟（書第 166 頁）

**書怎麼說**：原局日柱癸亥和時柱丁巳天剋地沖，本身已經不穩；七歲癸亥年，流年和日柱伏吟，又和兩個丁巳反吟，因肺結核夭亡。

| | 時 | 日 | 月 | 年 |
|---|:-:|:-:|:-:|:-:|
| 十神 | 偏財 | 日主 | 比肩 | 偏財 |
| 天干 | **丁**<sub>火</sub> | **癸**<sub>水</sub> | **癸**<sub>水</sub> | **丁**<sub>火</sub> |
| 地支 | **巳**<sub>火</sub> | **亥**<sub>水</sub> | **卯**<sub>木</sub> | **巳**<sub>火</sub> |
| 藏干 | 戊 **丙** 庚 | 甲 **壬** | **乙** | 戊 **丙** 庚 |
| 藏干十神 | 正官 **正財** 正印 | 傷官 **劫財** | **食神** | 正官 **正財** 正印 |

**一步一步看**

1. **日主**：癸水生卯月，木旺洩水 → 失令；日支亥是癸水的根（得地）；月干癸幫身 → 得勢。表面上三選二，但年、時兩個丁巳火很重，水火相對。
2. **原局反吟**：日柱癸亥對時柱丁巳 → 癸剋丁、亥沖巳，天剋地沖。年柱丁巳和日柱也同樣關係。
3. **流年癸亥**：和日柱完全相同（伏吟），又再和兩個丁巳反吟 → 原局的沖被流年放大。
4. **小孩子為什麼會應在日柱**：書的原則是「小時候看年柱」，但這裡原局已在日柱、年柱、時柱之間自相反吟，流年一到就全盤震動。
5. **肺結核**：金代表肺；這張盤的金只藏在兩個巳裡（庚金），巳被亥沖，金的根被打掉。這是筆記的推想，書沒有細說。

**學到什麼**：原局本身就有反吟伏吟，等於地基有裂縫，遇到同一組干支的流年就容易出大事。

#### 命例：乾造，歲運並臨加三刑，車禍重傷（書第 166 頁）

**書怎麼說**：34 歲戊寅年，大運也是戊寅（歲運並臨），和日柱甲申天剋地沖，加上寅巳申三刑，車禍重傷。（命盤見 03 檔：乙巳 辛巳 甲申 己巳）

**一步一步看**

1. **日主**：甲木生巳月，火旺洩木 → 失令；日支申是七殺之地，不是根；年干乙是唯一幫手 → 身弱。
2. **原局**：三個巳火（食神）、申金（七殺）、辛金（正官）、己土（正財），剋洩交加。
3. **歲運並臨**：大運戊寅、流年戊寅 → 同一股氣疊兩次，力量加倍。
4. **反吟日柱**：甲剋戊、寅沖申 → 戊寅和日柱甲申天剋地沖。
5. **三刑**：寅和原局的巳、申組成寅巳申三刑，地支一片混戰。
6. **結果**：日柱（自身）被沖 + 三刑 → 身體受傷；書斷車禍重傷。

**學到什麼**：「歲運並臨 + 反吟日柱 + 三刑」三個訊號疊在同一年，是最需要提防的組合。

### 第 63 訣　天羅地網訣（書第 167–168 頁）

**這一訣在講什麼**：辰和戌叫「天羅地網」。原局辰戌相沖，或辰、戌出現很多個，容易犯官司、牢獄之災；最嚴重的是**三辰沖一戌、三戌沖一辰**（原局加歲運湊齊）。

**為什麼是辰戌**：辰是水庫、戌是火庫，兩個都是「庫」，裡面收藏東西；辰戌相沖等於兩個倉庫被撞開，裡面的水火一起放出來，局面失控。古書把它比作「羅網」，人被困在裡面掙脫不了，所以聯想到牢獄、官非。

**怎麼用**：先數原局辰、戌各有幾個，再加上大運、流年的辰戌；湊到「三對一」時要特別小心。仍要配合用神：被沖出來的若是忌神，災就重。

**和其他書比較**：其他書多把辰戌沖當作一般的「庫沖」，看沖開後是財是官；本書把它特別拉出來當劫難訊號，是作者的經驗法則。

#### 命例：黃興，丙辰年病逝（書第 167 頁）

**書怎麼說**：1916 丙辰年、大運戊寅；原局三個戌沖流年一個辰，加上大運戊寅土木大戰，在上海病逝。

### 第 64 訣　神煞劫難訣（書第 169–170 頁）

**這一訣在講什麼**：作者不信傳統上百種神煞，只承認三組（第 43 訣）：

- **四驛馬（寅申巳亥）齊全** → 事業、官祿受阻，因「瞋」（爭執、發脾氣）遭殃。
- **四桃花（子午卯酉）齊全** → 防色情、身體劫難，因「癡」（縱情）受困。
- **四墓庫（辰戌丑未）齊全** → 防家宅、錢財、凶災，因「貪」不幸。

原局加大運、流年湊齊四個就算。貪、瞋、癡是佛家「三毒」，作者是佛教居士，所以這樣配。

**為什麼湊齊四個才算**：第 43 訣說四正、四庫、四長生各有性格傾向（固執、佔有、多變）；只有一兩個時只是性格色彩，湊齊四個就是「這股性格被推到極端」，於是應在劫難上。

**怎麼用**：查原局有幾個寅申巳亥／子午卯酉／辰戌丑未，再看哪一步大運、哪一年會把它補齊。

**和其他書比較**：傳統說「子午卯酉全為遍野桃花」「辰戌丑未全為四庫全」也有類似說法；本書把它和三毒連起來，是作者自己的整理。

#### 命例：戴安娜，四桃花（書第 169 頁）

**書怎麼說**：1983 癸亥年，時值丁酉大運，四桃花可算齊全，防色情、身體劫難；書順帶提到外界對哈利王子生父的傳言。（命盤見 01 檔：辛丑 甲午 乙未 丙子）

**一步一步看**

1. **日主**：乙木生午月，火旺洩木 → 失令；日支未藏乙木 → 得地（微根）；月干甲幫身 → 得勢。身偏弱。
2. **原局桃花**：月支午、時支子 → 已有兩個四正，而且子午相沖。
3. **大運丁酉**：酉又是一個四正。
4. **流年癸亥**：亥不是四正；所以實際上只有子、午、酉三個，**缺卯**。
5. **書的說法**：作者說「可算齊全」，沒有說明為什麼缺卯也算。筆記把這點標為**存疑**：照他自己的定義，應該要湊齊四個。

**學到什麼**：書上的例子也有「差一點點」就硬套的情形；讀的時候要自己數一次，不要只看結論。

#### 命例：和珅，四桃花齊全被賜死（書第 169–170 頁）

**書怎麼說**：天干乙庚合、羊刃成格，地支子午沖，金水火交戰；命中缺木，木主仁、主印 → 沒有父母長輩觀念，做大人物則賣國求榮、做常人則不認父母、出賣兄弟朋友（古書式的人格論斷）；戊子、己丑二十年最得意；辛卯運子午卯酉湊齊，被賜死。（命盤見 01 檔：庚午 乙酉 庚子 壬午）

**一步一步看**

1. **日主**：庚金生酉月 → 得令（酉是庚的羊刃）；年干庚幫身 → 得勢。身旺。
2. **原局**：子、午、酉三個四正已在；乙庚合（財合身）；子沖午（傷官沖官）→ 書說金水火俱戰。
3. **缺木**：木是庚金的財，在這裡書另外用「木主仁」的類象來論人品；這屬於古書的人格推論，當參考即可。
4. **戊子、己丑運**：戊己是印，生身又制水 → 二十年最盛。
5. **辛卯運**：卯補上 → 子午卯酉四正齊全；卯又沖月令酉（羊刃）→ 刃被沖。
6. **結果**：被嘉慶賜死。

**學到什麼**：四正齊全加上沖月令的羊刃，是劫難的強訊號；但「缺木所以無仁」只是書的類象說法，不能當作對人的定論。

#### 命例：坤造，四驛馬齊全，丈夫自殺（書第 170 頁）

**書怎麼說**：亥運、壬申年，原局的寅、巳加上亥、申，四驛馬齊全，夫妻因爭執申請離婚，丈夫自殺。（命盤見 03 檔：乙巳 乙酉 戊寅 丁巳）

### 第 65 訣　樞紐受制訣（訣中訣）（書第 171–174 頁）

**這一訣在講什麼**：《滴天髓》說「道有體用，不可以一端論」。作者把「體用」解成命局的**機關樞紐**：有時日元是體、財官是用；有時格局是體、用神是用；有時全局氣勢是體、順逆是用。找到這張盤真正「撐住整個結構」的那一個字（樞紐），就知道哪一年它被合、被沖、被剋時會出事。

**為什麼叫「訣中訣」**：前面幾訣都是看外形（反吟、辰戌、四正），這一訣要求先把整張盤讀懂，所以作者說它是訣中之訣。它其實就是第 33–41 訣「賓主體用作功」在流年上的應用。

**怎麼用**：問自己：「這張盤如果拿掉哪一個字，整個結構就垮？」那個字就是樞紐。然後找出能合它、剋它、沖它的干支，那些年份就是危險年。

**和其他書比較**：《滴天髓》原文「體用」有多種解釋；任鐵樵把體用解為日主與用神，本書則強調「樞紐」這個比喻，比較好懂。

#### 命例：韓信，丁火是樞紐（書第 171 頁）

**書怎麼說**：乙木身弱，七殺旺是忌神，丁火能剋金，是命局的樞紐；用神木火；甲午運拜將封王；癸巳運癸水剋丁、巳酉合金，樞紐受制，被斬。（命盤見 02 檔：辛酉 丁酉 乙卯 乙酉）

**一步一步看**

1. **日主**：乙木生酉月，金旺剋木 → 失令；日支卯是乙木的祿 → 得地；時干乙幫身。但三個酉金加年干辛金，七殺極重 → 身弱。
2. **病**：七殺太重，日主扛不住。
3. **樞紐**：月干丁火（食神）貼著年干辛金，能剋金；它一個字擋住了大部分殺氣 → 樞紐。
4. **甲午運**：甲木幫身、午火是丁火的祿 → 樞紐有根、日主有幫手 → 拜將封王。
5. **癸巳運**：癸水剋丁（樞紐被剋）；巳和酉合成金局（殺更旺）→ 兩頭夾擊。
6. **結果**：被斬於長樂宮。

**學到什麼**：樞紐往往是「一個字擋一群忌神」；它一被制，整個局面就倒向忌神那邊。

#### 命例：賈似道，丙火無根、外陽內陰（書第 171–172 頁）

**書怎麼說**：本來像假從格，但大運走火木，不能從，只算身極弱；偏財成格旺盛，一心想錢、貪財忘義；天干丙火無根，地支金水成局一片陰寒，外陽內陰（書的人格推論）；缺木無仁；戊午到甲寅運木火大旺，扶搖直上；癸丑運乙亥年金水旺極，被處死。（命盤見 01 檔：癸酉 庚申 丙子 丙申）

**一步一步看**

1. **日主**：丙火生申月，金旺 → 失令；地支酉、申、子、申，沒有一個火或木 → 失地；時干丙雖是比肩，但也無根 → 身極弱。
2. **為什麼不從**：從格要「一路順」，但這張盤的大運走火木（戊午、丁巳、丙辰、乙卯、甲寅），日主一再得到幫助，所以不能從，只能當身弱看。
3. **樞紐**：日主本身就是樞紐，全靠大運的木火撐住。
4. **戊午到甲寅運**：火木一路幫身 → 扶搖直上，做到宰相。
5. **癸丑運、乙亥年**：癸水剋丙、丑是金庫；亥水再加 → 金水旺極，日主被淹。
6. **結果**：被處死。

**學到什麼**：「假從而不能從」的命，好壞全看大運；一旦運轉回原局最強的那股氣（金水），就垮得很快。

#### 命例：貴命，印為樞紐（書第 172 頁）

**書怎麼說**：戊土身弱，官殺重重貼身剋，全靠丙火印化殺生身 → 當官之命；但印化不了時干貼身的乙木；己酉運酉卯沖開始升官；庚戌運乙庚合、卯戌合，絆住官殺，又升官；辛亥運丙辛合壞了印（樞紐受制），亥卯合官殺旺而剋身，丟官。（命盤見 03 檔：壬寅 丙午 戊寅 乙卯）

**一步一步看**

1. **日主**：戊土生午月，午火是印、午中藏己土 → 得令；但地支寅、寅、卯都是官殺 → 失地；天干沒有比劫 → 失勢。書判身弱。
2. **病**：官殺（寅寅卯乙）太重，貼身剋戊土。
3. **樞紐**：月干丙火（偏印）——木生火、火生土，把官殺的力量轉成生身，就是「殺印相生」。
4. **己酉運**：酉沖卯，去掉時支貼身的官殺 → 升官。
5. **庚戌運**：乙庚合（時干官星被絆）、卯戌合 → 官殺被綁住 → 又升官。
6. **辛亥運**：丙辛合（樞紐被合走）；亥卯合木、寅亥合木 → 官殺更旺，又沒有印化 → 丟官。

**學到什麼**：殺印相生的命，印就是樞紐；歲運來合印、剋印，是最直接的危險訊號。

#### 命例：袁世凱，己土制癸水（書第 172–174 頁）

**書怎麼說**：木火土為體、金水為功用神；以年干己土剋制月干癸水七殺為有效作功 → 七殺可為命局所用，掌極大權力。歲運遇戊己土或火助旺土 → 制殺有效，仕途順遂。（命盤見 01 檔：己未 癸酉 丁巳 丁未）

|---|---|
| 壬申、辛未運 | 科場失意，22 歲投軍 |
| 午運 | 指揮清軍擊退日軍 |
| 己巳運 1895 | 小站練兵（北洋新軍） |
| 戊辰運 1901 | 直隸總督、北洋大臣 |

| 乙卯運 1911 | 卯沖酉（月令金）、制癸水七殺有功，復出任內閣總理、臨時大總統 |
| 1915 乙卯年 | 印星歲運並臨，權力欲頂峰，稱帝 83 天 |

**一步一步看**

2. **樞紐**：月干癸水（七殺）透出，年干己土（食神）貼著它剋 → 食神制殺。己土就是樞紐。
3. **為什麼七殺反而是權力**：七殺被制住，就從「害我的力量」變成「我能使用的力量」，所以主權。

### 第 66 訣　凶物深藏訣（書第 175–176 頁）

**這一訣在講什麼**：《滴天髓》說「吉神太露，起爭奪之風；凶物深藏，成養虎之患」。

- **吉神太露**：喜用神只出現在天干、地支沒有根。歲運不遇忌神還好；一遇忌神來合或沖剋，它就被奪走，最糟。
- **凶物深藏**：忌神藏在地支（尤其藏在庫裡），平常看不見；歲運扶它、或沖開它所在的庫，就像養大的老虎出籠，為患不小。所以忌神要「制化得當」。

**為什麼**：天干是露在外面的，人人都能「搶」；地支是藏在裡面的，平常不動，一旦被引出來，力量比天干還大。好東西要藏、壞東西要露（露出來才好被剋制），這是本訣的核心。

**怎麼用**：找出喜用神是不是只在天干；找出忌神是不是藏在地支而沒有被沖剋。前者怕「合沖」，後者怕「扶起、沖開」。

**和其他書比較**：任鐵樵在《滴天髓闡微》原註中有完整說法；本書的命例大多直接引自任註和《滴天髓徵義》。

#### 命例：乾造，凶物深藏（書第 175 頁）

**書怎麼說**（引《滴天髓徵義》）：木火旺，成假專旺格；日支酉金（財，對專旺格是忌）深藏地支，原局又沒有卯木沖它；戊辰、己巳兩運辰酉合、巳酉合，去不掉酉，有災；庚午、辛未運本應去酉，壬申運金水齊來，大敗。忌神深藏，一生多成多敗。

### 第 67 訣　破格訣（書第 177–179 頁）

**這一訣在講什麼**：

1. **從弱**：日主衰到極點，就順從最旺的那股氣（從財、從殺、從兒等）。
2. **專旺／從旺**：日主旺到極點，不可以抑制、也不可以硬去洩；強行制它必大凶，就算順著它流行也未必合適。
3. 特殊格局遇到**逆運、逆年**（和格局方向相反的運）就「破格」 → 神枯、氣濁，出大事。

**為什麼**：普通格局講「平衡」，弱了補、強了洩；特殊格局的整體氣勢已經偏到一邊，平衡反而做不到，只能「順」。這時逆著它的力量來，就像逆水行舟、或拿一杯水澆大火，激怒旺神。

**怎麼用**：先判斷是不是特殊格局（從格、專旺、化氣）；若是，列出「順的五行」和「逆的五行」，逆的歲運就是劫難期。

**和其他書比較**：《子平真詮》《滴天髓》都有從化格論；本書的例子多取自任鐵樵、徐樂吾的註。

#### 命例：某國家政要（推測為鄧小平），從食財官（書第 177 頁）

**書怎麼說**：同第 23 訣：1966–67 火年遭難；1980–81 金年再起；1989 己巳年不利；1992 金水年再度活躍。書未明說是誰，筆記依生日推測為鄧小平。（命盤見 01 檔：甲辰 壬申 戊子 甲寅）

**一步一步看**

1. **日主**：戊土生申月，金洩土 → 失令；地支申子辰合水局，寅木是七殺 → 失地；天干甲甲壬，沒有比劫印 → 失勢。極弱。
2. **格局**：戊土無力，順從食神（申金）、財（申子辰水）、官殺（甲寅）→ 書稱「從食財官」，也就是從勢格。
3. **順的五行**：金、水、木；**逆的五行**：火（印）、土（比劫）會把日主扶起來，破格。
4. **1966 丙午、1967 丁未**：火年 → 逆，遭難。
5. **1980 庚申、1981 辛酉**：金年 → 順，再起。
6. **1989 己巳**：己土比劫 + 巳火印 → 逆，不利。**1992 壬申**：金水 → 順，再度活躍。

**學到什麼**：從格的人，「幫身」的歲運反而是凶；這和普通身弱命要補身的想法正好相反。

#### 命例：陳方安生，土從旺（書第 177 頁）

**書怎麼說**：時支寅木官星逆生丙火印、再生日干和月支的土，成土從旺格；走金運洩氣，官運終止。（命盤見 01 檔：己卯 丁丑 己未 丙寅）

**一步一步看**

1. **日主**：己土生丑月 → 得令；日支未、年干己 → 得地、得勢；丁丙火印生身。極旺。
2. **格局**：寅卯木（官殺）不剋土，反而生丙丁火、火再生土 → 「官印相生」併入土勢，書稱土從旺。
3. **順的五行**：木火土；**逆的五行**：金（洩土、剋木）、水（剋火）。
4. **金運**：金洩土氣、又剋寅卯官星 → 破格，官運終止。

**學到什麼**：書對陳方安生的格局說法前後不一（第 15、22 訣「土從旺」、第 26 訣「三行成象」、第 59 訣「墓用功神」），但都同意木火土為用、金為忌，結論一致。

#### 命例：乾造，夫從妻化（書第 179 頁）

|---|:-:|:-:|:-:|:-:|
| 十神 | 食神 | 日主 | 正官 | 傷官 |

## 第十三章　健康無價

> **這一章在講什麼**：用五行和十天干、十二地支去對應身體的臟腑和部位，再看八字裡哪一行「太過」或「不及」，推測容易出問題的器官；大運流年則決定什麼時候發病。作者的資料大多來自中醫五行理論和《三命通會》。

> **讀這一章的提醒**：這些是命理上的「傾向」，不是診斷。書上的病例都是事後對照，當作保養的提示就好；身體不舒服一定要看醫生。

### 第 68 訣　健康總訣（書第 182–183 頁）

**這一訣在講什麼**：

1. 每個天干、地支都對應一個臟腑（見下表）。
2. 四柱配身體：年干＝頭面；月柱＝胸背；日支＝腹腰；時支＝腳。
3. 五臟（陰）的病源多在地支；六腑（陽）的病源多在天干。
4. 命局看「病在哪裡」，大運流年（和季節）看「什麼時候發病」。
5. 五行流通有情 → 一生少病；信佛修道、心境平和 → 也一生少病。

| 天干 | 臟腑 | 地支 | 臟腑 |
|---|---|---|---|
| 甲 | 膽 | 寅 | 膽 |
| 乙 | 肝 | 卯 | 肝 |
| 丙 | 小腸（也代表眼睛） | 巳 | 小腸 |
| 丁 | 心 | 午 | 心 |
| 戊 | 胃 | 辰、戌 | 胃 |
| 己 | 脾 | 丑、未 | 脾 |
| 庚 | 大腸 | 申 | 大腸 |
| 辛 | 肺 | 酉 | 肺 |
| 壬 | 膀胱 | 亥 | 膀胱 |
| 癸 | 腎 | 子 | 腎 |

**為什麼這樣配**：中醫把五臟六腑分屬五行（肝膽屬木、心小腸屬火、脾胃屬土、肺大腸屬金、腎膀胱屬水），而且一陰一陽成對（臟為陰、腑為陽）。天干也是一陰一陽成對，所以陽干配腑（甲膽、丙小腸、戊胃、庚大腸、壬膀胱）、陰干配臟（乙肝、丁心、己脾、辛肺、癸腎）。

**怎麼用**：先找原局最受傷的五行（被剋最重、或太旺沒有出路的），對照表上的臟腑；再看哪一步運、哪一年把它打得更重，就是容易發病的時候。第 58 訣劉翔的例子（時支受傷應在腳）就是用「四柱配身體」。

**和其他書比較**：App 的健康標籤（陸致極表 13.3 弱臟強臟）也是天干配臟腑，對應大致相同。本書特色是「四柱配身體部位」。

> 書另舉南懷瑾（戊午 乙卯 甲子，時辰不詳）為信佛修道、一生少病的例子；因缺時柱，這裡不排盤。

#### 命例：孫中山，肝癌（書第 182 頁）

**書怎麼說**：甲乙寅卯都屬肝膽；原局木極旺，中醫叫「肝實症」；1925 年 3 月，甲辰運、乙丑年、己卯月，都是木旺剋土之象，因肝癌逝世，享年 58 歲（虛歲）。（命盤見 01 檔：丙寅 己亥 辛卯 庚寅）

**一步一步看**

1. **日主**：辛金生亥月，水洩金 → 失令；地支寅、亥、卯、寅沒有金的根 → 失地；時干庚、月干己（印）幫身 → 勢不強。身弱。
2. **最旺的五行**：寅、卯、寅加上亥中甲木 → 木（財）極旺。
3. **對應臟腑**：木＝肝膽（乙肝、甲膽、寅膽、卯肝）。木太旺沒有出路，中醫叫「肝實」。
4. **大運甲辰**：甲木透干，木更旺。
5. **流年乙丑、流月己卯**：乙木、卯木再來；乙剋己、卯剋丑（木剋土）→ 木勢到頂。
6. **結果**：肝癌逝世。

**學到什麼**：「太旺」也是病：某一行旺到沒有出路，它對應的臟腑反而容易出事。

#### 命例：某國家政要（推測為周恩來），膀胱癌（書第 183 頁）

**書怎麼說**：壬為膀胱、癸為腎；1972 壬子年證實膀胱癌，那時大運辛酉，辛酉和日柱丁卯反吟、時柱丙午和流年壬子反吟；1976 年 1 月 8 日（仍屬乙卯年）去世，又碰上辛酉、壬戌大運交接，歲運反吟三連環。書未明說是誰，筆記依生日推測為周恩來。（命盤見 01 檔：戊戌 甲寅 丁卯 丙午）

**一步一步看**

1. **日主**：丁火生寅月，木生火 → 得令；日支卯（印）、時支午（祿）→ 得地；時干丙、月干甲 → 得勢。火木極旺。
2. **最弱的五行**：全盤沒有水；水在這張盤是官殺。
3. **流年壬子**：壬水、子水來了，但火土太旺，水反被剋（火多水沸、土多水塞）→ 壬（膀胱）受傷。
4. **反吟**：壬子對丙午（丙壬沖、子午沖）、辛酉運對丁卯日柱（丁剋辛、卯酉沖）→ 兩組天剋地沖。
5. **1976 年 1 月**：乙卯年（立春前）；卯木和大運辛酉再沖，運又將交到壬戌 → 書說三連環。
6. **結果**：膀胱癌去世。

**學到什麼**：火土旺的命，遇到水年不一定是「補水」，弱水入旺火，反而是水被傷；被傷的那一行（壬）就是病位。

#### 命例：五行流通的上佳命造，一生少病（書第 183 頁）

**書怎麼說**：五行流通有情，一生少病。（命盤見 02 檔：辛丑 癸巳 甲子 丙寅）

**一步一步看**

1. **日主**：甲木生巳月，火旺洩木 → 失令；日支子（印）、時支寅（祿）→ 得地；月干癸印生身 → 得勢。中和。
2. **流通**：年干辛金（官）→ 生月干癸水（印）→ 生日主甲木 → 生時干丙火（食神）→ 火生巳、丑之土。一路相生，沒有斷點。
3. **沒有偏枯**：五行都有，也沒有哪一行特別過旺或被打到極弱。
4. **結果**：書說一生少病。

**學到什麼**：健康篇的總原則就是第 1 訣「流通」：氣一路通，身體也通。

### 第 69–73 訣　五行健康訣（書第 184–193 頁）

**這五訣在講什麼**：每一個五行（水、木、火、土、金各一訣）都有五種「失衡」的方式，每一種對應不同的病：

1. **被剋太過**（例如土多水塞、強金伐木）。
2. **被生太過**（母旺子衰，例如金多水濁、水多木漂）。
3. **洩太過**（例如木盛水縮、火多土焦）。
4. **剋不動**（反剋，例如火多水沸、木堅金缺）。
5. **自己太旺沒出路**（例如水旺無洩、木重無洩）。

| 五行 | 五種失衡 | 常見病症（書上的整理） |
|---|---|---|
| 水 | 土多水塞、金多水濁、火多水沸、木盛水縮、水旺無洩 | 腎、膀胱、泌尿、耳疾；金多 → 結石；火多 → 腎虛；木盛 → 生殖器官；水太多 → 腦溢血、心臟病、糖尿病、風濕、四肢寒冷 |
| 木 | 強金伐木、土重木折、水多木漂、火炎木焚、木重無洩 | 肝膽、神經衰弱、四肢筋骨；火炎 → 頭髮棕赤捲曲、皮膚病、神經痛；木重 → 肝實症、胃腸、跌傷 |
| 火 | 水多火熄、土多火晦、金多火衰、木多火塞、火多無洩 | 心血、腦、小腸、眼疾；土多 → 貧血；火太多 → 肺、鼻、大腸、皮膚、牙痛、腎水不足 |
| 土 | 木重土陷、水多土流、金多土虛、火多土焦、土旺無洩 | 脾胃；木重 → 胃潰瘍出血；金多 → 胃下垂；火多 → 皮膚過敏、富貴手；水多 → 胃腸寒、精神分裂；土太多 → 腎、耳、貧血、肺結核 |
| 金 | 強火熔金、木堅金缺、土多金埋、水多金沉、金旺無洩 | 肺、大腸、鼻、皮膚、骨骼；火熔 → 肺炎、肺癆、耳疾；土埋 → 風濕、關節、肺結核；金太多 → 肝膽、筋骨、眼、結石 |

每一訣最後附中醫五臟理論（如「腎開竅於耳」「肝開竅於目、主筋」「心開竅於舌」「脾開竅於口」「肺開竅於鼻」），用來解釋為什麼水弱會耳聾、木受傷會影響眼睛和筋。

**為什麼這樣分**：這五種失衡，其實就是第 16–21 訣「五行生剋制化」（反剋、母旺子衰、洩太過……）搬到身體上。學會了前面的生剋制化，這裡只是把五行換成器官。

**怎麼用**：先判斷原局哪一行最有問題、屬於哪一種失衡，查表得到可能的病；再找哪一步運、哪一年把這種失衡推到極點。

**和其他書比較**：App 目前的健康標籤用陸致極的「弱臟/強臟」；本書的「五種失衡 × 五行」更細，可以補充「為什麼弱」（被剋、被洩、被生太多）。

#### 命例：梅艷芳，子宮頸癌（書第 184–185 頁）

**書怎麼說**：火多水沸、土多水塞；2003 癸未年、大運丁丑，因子宮頸癌病逝。（命盤見 01 檔：癸卯 壬戌 丙戌 丁酉）

**一步一步看**

### 第 74 訣　健康五行相剋訣（書第 194–198 頁）

**這一訣在講什麼**：作者先整理《三命通會》引《燭神經》的五行相剋病症（古文很長），再改寫成白話。意思是：原局或歲運中兩個五行打得很兇（例如木和土互不相讓），就會出現以下的病：

| 相剋 | 容易的病 |
|---|---|
| 木土相剋 | 脾胃、腸炎、肝膽結石、老花或弱視、偏頭痛、筋骨扭傷 |
| 火金相剋 | 肺、咽喉、皮膚、頭暈、失眠；婦女血氣經脈失調、燒燙傷 |
| 土水相剋 | 健忘、尿毒、腎膀胱、動脈硬化中風、腦溢血、失聰、脾胃寒、消化不良 |
| 金木相剋 | 筋骨、關節、肝膽、十指、眼目、四肢、骨骼脆弱、哮喘、顏面神經、牙痛 |
| 水火相剋 | 心血衰弱、中風、小腸炎、眼目、泌尿；婦女血氣經脈不調、燙傷 |

**為什麼**：第 69–73 訣看的是「一個五行失衡」；這一訣看的是「兩個五行交戰」，兩邊都受傷，所以病症同時涉及雙方的臟腑。

**怎麼用**：找出原局最激烈的一組相剋（通常是天干地支都對沖的那一組），查表；再看歲運何時讓這組戰爭升級。

### 第 75 訣　精神健康訣（書第 199–200 頁）

**這一訣在講什麼**：

1. 食傷洩得太重 → 神經系統不良、失眠；日主旺極又沒有食傷洩秀 → 痛苦無處宣洩，容易抑鬱。
2. 日主弱又缺印 → 體質和意志薄弱；印多為病 → 精神恍惚、神經衰弱。
3. 剋洩太重，日主不勝負荷 → 意志消沉、腦力衰退。
4. 刑沖重見 → 容易鑽牛角尖、神經質。
5. 土多為病又沒有強木疏導 → 不懂變通、鑽牛角尖。
6. 火代表生機和意志：丙丁日主身弱、火受剋 → 生機意志薄弱；火受剋足以傷腦；全局火旺無制也會傷腦神經或精神異常。

**為什麼**：十神本來就代表心理（第 9–13 訣）：食傷是表達、印是安全感、官殺是壓力、比劫是自我。精神健康就是這些心理力量失衡的結果：壓力（官殺）太大、表達（食傷）沒出口、安全感（印）沒有或太多。

**怎麼用**：看日主強弱，再看「出口」（食傷）和「靠山」（印）各自是否健全；刑沖多的盤要特別留意情緒。

**和其他書比較**：這是本書少見把心理健康單獨拿出來談的一訣；其他命書多半只說「刑沖多則性急」。

## 這三章學到什麼（給初學者）

1. **批流年的方法只有一個**：把大運、流年的干支加進原局，看它對用神、功神、宮位做了什麼。天干看合、地支看沖；流年十神決定那一年的「主題」（官殺年有官位或壓力、食傷年得名或快樂、財年慾望多、比劫年交友或破財、印年清靜甚至孤獨）。
2. **財運、名聲、事業、愛情、六親**各有一張「十神代表什麼」的表；先查表，再看那個十神在歲運中被生、被剋、被合還是被沖。
3. **劫難的六個訊號**：反吟（天剋地沖）、伏吟（尤其歲運並臨）、辰戌多見被沖（天羅地網）、四正／四庫／四長生湊齊、樞紐被合沖剋、深藏的忌神被引出或太露的喜神被奪、特殊格局遇逆運。前三個看形狀，後三個要先讀懂整張盤。
4. **警報不等於結論**：作者一再強調，反吟、天羅地網等訊號要配合「有沒有破壞原局功用神」才斷吉凶；蔣緯國、和珅的例子都在示範這點。
5. **健康的看法**：天干配臟腑、四柱配身體部位；每個五行的「被剋、被生太多、洩太多、剋不動、太旺」各有病症；兩個五行交戰，雙方的臟腑都受影響。
6. **精神健康**看日主強弱、食傷（出口）、印（靠山）和刑沖；土多無木、火弱無印都是要留意的組合。
7. **讀書時自己驗算**：本章有好幾處年份、歲數或「齊全」與命盤對不上（戴安娜四桃花缺卯、皮膚過敏例的歲數、貧血例的 1992／壬午、駱秉章起運歲數），練習時自己排一次大運流年，比照抄結論更有收穫。
8. 書上的健康斷語來自中醫五行理論，**只能當作提醒保養的方向**，不能取代就醫；「貧賤」「無仁」之類的人格論斷是古書說法，不是對人的定論。
