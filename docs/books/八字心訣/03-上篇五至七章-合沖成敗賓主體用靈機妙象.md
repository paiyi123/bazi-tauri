# 上篇第五、六、七章　合沖成敗、賓主體用、靈機妙象（第 28–44 訣，書第 68–109 頁）

> **這三章在講什麼**：
> - 第五章「合沖成敗」：合、沖、刑**本身不分好壞**，要看合走的、沖走的是喜神還是忌神。
> - 第六章「賓主體用」：本書最有特色的部分，講**賓主、體用、功神廢神、六種作功方式**，用來回答「為什麼這個命富貴、那個命平庸」。作者自己說這套方法和「盲派」相通，但他用十神和五行重新講清楚。
> - 第七章「靈機妙象」：宮位（本書年柱＝父母宮）、四正四庫四長生、神煞。
>
> **這三章的讀法**：第五章是第三、四章的延伸，只要記住一句話：「合沖刑的好壞，看它對喜用神做了什麼」。第六章是新方法，術語多，建議先把第 33–35 訣反覆讀懂（賓主、體用、作功、看作功的順序），再看第 36–41 訣六種作功方式，最後用書上的名人命例練習。第七章有很多作者和一般書不同的地方（宮位、神煞），要特別留意。

## 第五章　合沖成敗

### 第 28 訣　因合而成訣（書第 68–70 頁）

**這一訣在講什麼**：

1. 合就是聚合，力量連結在一起；形象上代表合作（事業合作、男女結合），也代表融洽與和解。
2. 合了可以化，也可以不化，不能一概而論。能化就照化神論；不能化，就當作「羈絆」（兩個字互相綁住，原本的作用減弱）。
3. 合出來是喜是忌，看命局需要；**該合而合才是吉**，不該合而合不能以吉論。
4. 以下四種情況叫「因合而成」，主吉：
   - 忌神被合住而不化（忌神被綁住，作不了怪）；
   - 忌神被合化成喜用神（壞人變好人）；
   - 忌神被合住，不去沖喜用神（合而解沖）；
   - 用神被合住，因此不受沖（也是合而解沖）。

**白話和比喻**：合像「結婚」或「結盟」。一個麻煩人物（忌神）結婚後安分了，是好事；如果結婚後還變成了好幫手（合化成喜用），更好。另一種情況是兩個人要打架（沖），其中一個被朋友拉走（合），架就打不起來（合而解沖）。

**和其他書比較**：課堂講天干五合有五種變化（合而不合、合而不化、合來合去、爭合妒合、合而能化）；《妙算人生八字》說日干合不化（除了化氣格）。本書把合的結果全部歸結到「對喜用神有利還是不利」，比較實用。

#### 命例：《滴天髓闡微》命例，忌神合化成用神（書第 68 頁）

**書怎麼說**：地支寅卯辰三會木局，月干壬水（劫財，忌神）和年干丁火合化成木，化去壬水後八字清純，命局成為從兒格；所以早年科甲，置身翰苑，仕至封疆。《妙算人生八字》也用了這個命例（從兒格）。

| 天干 | **丙**<sub>火</sub> | **癸**<sub>水</sub> | **壬**<sub>水</sub> | **丁**<sub>火</sub> |
| 地支 | **辰**<sub>土</sub> | **卯**<sub>木</sub> | **寅**<sub>木</sub> | **卯**<sub>木</sub> |
| 藏干 | 乙 **戊** 癸 | **乙** | 丙 **甲** 戊 | **乙** |
| 藏干十神 | 食神 **正官** 比肩 | **食神** | 正財 **傷官** 正官 | **食神** |

**一步一步看**

1. **日主**：癸水生寅月，木旺洩水 → 失令；地支寅、卯、卯、辰全是木或木氣，沒有水的根（辰中癸水被三會木局拉走）→ 不得地。
2. **全局**：寅卯辰三會木（食傷），時干丙火、年干丁火（財）。日主極弱，傾向從兒（從食傷）。
3. **壬水的問題**：月干壬水是劫財，會幫癸水、破從兒格 → 忌神。
4. **丁壬合**：年干丁火和月干壬水相鄰，丁壬合，化神是木；生在寅月，木當令，又有三會木局支持 → 合而能化。
5. **結果**：壬水變成木，忌神化為用神；全局只剩木（食傷）和火（財），從兒格成立，食傷生財。

**學到什麼**：「忌神被合化成喜用神」是最好的一種合。判斷能不能化，看化神（木）有沒有得令、得勢。

#### 命例：《滴天髓闡微》命例，忌神被合而解沖（書第 69 頁）

**書怎麼說**：金多水濁，取水生木、順勢洩秀為用；日支寅木本來被月支申金沖，幸得申子合成水局而解沖，水木不傷，所以運行水方而顯貴；亥運洩金又生合寅木，科甲連登，名高翰苑；甲子運水木齊來，仕途暢順；乙丑運乙木合庚金被羈絆，罷職回家。

| 地支 | **丑**<sub>土</sub> | **寅**<sub>木</sub> | **申**<sub>金</sub> | **子**<sub>水</sub> |

**一步一步看**

1. **日主**：壬水生申月，申是壬水的長生，金生水 → 得令。
2. **金**：月柱庚申、時柱辛丑（丑藏辛），印很多 → 「金多水濁」（第 17 訣）。
3. **用神**：日支寅木（食神），水生木、洩秀。
4. **沖的問題**：月支申和日支寅相鄰，申寅沖，用神寅木受威脅。
5. **合而解沖**：年支子水和月支申金相鄰，申子半合水，申被子拉住，不去沖寅 → 「忌神（申）被合而不沖喜用」。
6. **大運**：亥運：亥水洩金、亥寅相合，用神得力 → 科甲；甲子運：水木齊來 → 仕途順；乙丑運：乙木和月干庚金合（被羈絆），丑土又合子水，把解沖的子水拉走 → 罷官。

**學到什麼**：「解沖」的條件：沖的那個字被別的字合走。大運如果把「負責解沖的那個字」也合走，沖就恢復了。

#### 命例：《滴天髓闡微》命例，用神被合而不受沖（書第 69 頁）

**書怎麼說**：天干三個壬水，地支申、辰，水勢洶湧；幸得寅午合，解了寅申之沖，喜用不傷；運至丙午、丁未，寅午化成火局，又有甲木通關，食傷生財為用，考試及第、出任地方官；到申運，兩申沖寅木，不祿（去世）。

**一步一步看**

2. **用神**：月支寅木（食神）、時干甲木（食神）洩水；日支午火（財）。食傷生財。
3. **沖的問題**：年支申和月支寅相鄰，申寅沖，食神受傷。
4. **合而解沖**：月支寅和日支午相鄰，寅午半合火，寅被午拉住，申沖不動它 → 「用神被合而不受沖」。
5. **大運**：丙午、丁未是火運，寅午合成火局，財星得力；甲木通關（水 → 木 → 火）→ 及第出仕。

**學到什麼**：合可以保護用神，但保護有極限；大運再來一個沖的字，保護就破了。

#### 命例：大貴之命，戊癸合化火（書第 70 頁）

**書怎麼說**：命局火旺，癸水和戊土本來是雜氣、忌神，幸得戊癸合化火，命局由渾濁轉為清純，炎上格成，大貴；用神木火，加官進爵，水運被貶。（命盤見 02 檔：丙戌 癸巳 戊午 丁巳）

**一步一步看**

1. 原局火旺（巳、午、丙、丁），癸水是格格不入的雜氣。
2. 月干癸、日干戊相鄰，戊癸合，化神火，生在巳月 → 合而能化。
3. 合化後全局一片火 → 炎上格，清純。

**學到什麼**：「忌神被合化成用神」，同時讓命局變純，是因合而成的最好例子。

#### 命例：孔祥熙，合而解沖（書第 70 頁）

**書怎麼說**：忌神被合而不沖命局的喜用神，就是合而解沖；命局金旺得申癸辰暗三合水局洩之，用神水木；辰酉合解了卯酉之沖，卯木不受沖，加上大運水木，成就大富大貴。（命盤見 02 檔：庚辰 乙酉 癸卯 庚申）

**一步一步看**

1. 用神：日支卯木（食神）。
2. 沖：月支酉和日支卯相鄰，卯酉沖。
3. 解：年支辰和月支酉相鄰，辰酉合，酉被拉住。
4. 結果：卯木保住，水木大運就發。

**學到什麼**：看到「用神被沖」時，先找有沒有字能合住沖的那一方。

#### 命例：《滴天髓闡微》命例，忌神被合化成用神（巳酉丑）（書第 70 頁）

**書怎麼說**：丁火日主生巳月，天干一片木火，身強宜洩；喜丁火有丑土洩秀，更喜巳酉丑三合成金局，巳火化為金，忌神變喜用，所以是富貴極局，仕至藩臬，名利雙全。

**一步一步看**

1. **日主**：丁火生巳月，火旺 → 得令；年干丁、時柱丙午、月干乙木（偏印）→ 身極強。
2. **用神**：身強要洩、要耗：日支丑土（食神）洩火，年支酉金（財）是耗。
3. **巳火的問題**：月支巳火是劫財，幫身，對身強的命是忌神。
4. **三合**：年支酉、月支巳、日支丑，巳酉丑三合金局；生在巳月，金不當令，但三支齊全、丑中藏辛、酉是金的帝旺，作者判為化成。

### 第 29 訣　因合而敗訣（書第 71–72 頁）

**這一訣在講什麼**：

1. 喜用神被合住而不化 → 該喜不喜（好幫手被綁住）。
2. 喜用神被合化成忌神 → 好事變壞事（好幫手變成敵人）。
3. 女命忌多合，古書說易惹狂蜂浪蝶。（這是古書說法，現代可理解為人際關係複雜、感情牽絆多。）

**為什麼**：第 28 訣的反面。合的作用是「綁住」和「改變」，綁住忌神是好事，綁住用神就是壞事。

**怎麼用**：看到命局有合時，先問：被合的是喜神還是忌神？能不能化？化成什麼？流年天干如果被原局合走，也是同樣道理。

#### 命例：《滴天髓闡微》命例，用神被合絆（書第 71 頁）

**書怎麼說**：戊土生辰月，丙火旺盛，地支四土，本來可以用庚金洩秀，可惜庚乙合而不化，用神受羈絆；所以早棄詩書，不事生產，以酒為事。第 90 訣（奮鬱論）又用它說「貪合忘官、陰晦用事」。

**一步一步看**

1. **日主**：戊土生辰月，土當令 → 得令；日支辰、時支辰、年支未 → 得地；時干丙火（偏印）→ 得勢。身極旺。
2. **用神**：身旺要洩，月干庚金（食神）坐辰土（土生金），本來是最好的出口。
3. **合**：年干乙木和月干庚金相鄰，乙庚合。乙木（正官）坐未（木庫，有根），化神金不當令（辰月），合而不化 → 庚金被綁住。
4. **結果**：唯一的出口被綁，土的力量發不出去，人就「不事生產」。

**學到什麼**：身旺的人用神被合住，有本事施展不出來，容易消沉。

#### 命例：《滴天髓闡微》命例，用神被合絆（亥未合）（書第 71 頁）

**書怎麼說**：時支亥水、月干癸水透出，日柱天干秀氣流行，本為佳造；可惜亥未合而不化，癸水用神受羈絆；雖然資質好、中了舉人，但所學無法施展，終其一生貧苦。

#### 命例：貧賤女命，用神被合（書第 72 頁）

**書怎麼說**：己土生卯月失令，金水洩氣嚴重，命中缺火，所以身弱；夫妻宮的未土是用神，本可幫身，可惜被卯木合住，不能為用。到乙未大運，卯未合化木，未土用神變成木來剋日主。丙子流年，丙火用神被辛金合住而不化，那年離婚又再婚；第二年丁丑，丁火用神被壬水合住而不化，丑土又沖夫妻宮，又離婚。「貧賤」是書上原話。

3. **身弱**：只有日支未土、年支丑土是根；缺火（印）。
4. **用神**：火（印）、土（比劫）。日支未土就是用神，也是夫妻宮。
5. **合**：月支卯和日支未相鄰，卯未半合木 → 用神未土被綁。
6. **乙未運**：乙木再加上卯未，木局成形，未土化木 → 用神變忌神。
7. **流年**：丙子年，丙火（用神）透出，但被原局辛金合（丙辛合）→ 用神失效；丁丑年，丁火被原局壬水合（丁壬合），丑又沖日支未（夫妻宮）。

**學到什麼**：流年天干如果被原局合走，也是「因合而敗」；夫妻宮的字被合、被沖，婚姻就動盪。

#### 命例：財多身弱，喜用合化為忌（書第 72 頁）

**書怎麼說**：丁火生申月，財多身弱，以木火為用神；幸好坐巳火幫身，可惜巳申合為水局，巳火化為水；亥運溺死。（命盤見 02 檔：戊辰 庚申 丁巳 庚戌）

**一步一步看**

1. 唯一的根：日支巳火。
2. 合：月支申和日支巳相鄰，巳申合水，生在申月，水有長生 → 作者判為化。
3. 結果：根變成官殺（水），反過來剋丁火。
4. 亥運：亥水沖巳、水更旺 → 凶。

**學到什麼**：「喜用入命合化為忌」最可怕：不只少一個幫手，還多一個敵人。

### 第 30 訣　逢沖反成訣（書第 73–75 頁）

**這一訣在講什麼**：

1. 沖就是力量被沖散；形象上代表爭戰、心不安定，所以容易有事業上的爭戰、男女不和，也代表變動和勞苦。
2. 喜用和忌神相沖，要看強弱定吉凶。
3. 會合有時解沖，有時反而助沖，要看全局氣勢流通。
4. **沖去忌神**，主吉。
5. **兩種忌神互沖、互相消磨**，主吉。

**白話**：沖像打架。兩個麻煩人物打起來，兩敗俱傷，對我反而是好事；強的好人把弱的壞人打走，也是好事。只有好人被打傷才是壞事（第 31 訣）。

**怎麼用**：看到地支相沖，先問兩邊誰強、誰是喜誰是忌；再看有沒有合在旁邊（可能解沖，也可能幫忙沖）。

#### 命例：蔣緯國，沖去忌神（書第 73 頁）

**書怎麼說**：1916 年 10 月 6 日生。命局天干三火得甲木生，加上時支午火，火極旺為忌；幸得日支子水沖剋忌神午火，是逢沖反成，所以夫妻宮子水是用神。第一任妻子石靜宜 1953 年難產去世，那時正好進入丑土大運，丑合子水，破壞了子水對午火的沖剋；1990 年庚午年，正好進入乙巳大運，庚金（用神）被乙合而不化，加上午火沖子水用神，主不吉，那年國民大會選舉時有人提議他參選副總統，最後未參選；1997 丁丑年去世，又是丑土合住子水、解開了對午火的沖剋。

#### 命例：乾隆皇帝，沖去忌神（書第 74 頁）

### 第 31 訣　沖之為忌訣（書第 76–77 頁）

**這一訣在講什麼**：

1. 沖去喜用神，主凶。
2. 兩種喜用神互相沖、互相消磨，更不利。

**為什麼**：喜用神是命局的「支柱」，被沖等於支柱被打斷。特別要注意喜用神的**根**：天干的喜用神如果坐在被沖的地支上，根一斷，天干也枯。

#### 命例：刑妻剋子之命（《滴天髓闡微》）（書第 76 頁）

**書怎麼說**：庚金日主得令，加上地支四土，身旺，以乙木（財）、丁火（官）為喜用；乙木坐未土，未是木的庫根，丑未沖則根傷；丁火以未土為餘氣弱根，沖則枯死。初運甲午，木火俱旺，蔭庇有餘；一交癸巳，剋丁拱丑，刑喪破耗；壬辰運，妻子兩傷，家業蕩然，削髮為僧。「刑妻剋子」是古書說法，筆記只記錄推理。

### 第 32 訣　三刑訣（書第 78–79 頁）

**這一訣在講什麼**：

1. **三刑只有寅巳申、丑未戌兩種**；子卯刑、辰辰午午酉酉亥亥自刑的說法「不應驗」。

## 第六章　賓主體用——本書最大特色

> **這一章的讀法**：前面五章問的是「五行平不平衡、用神是什麼」；這一章換一個問題：「這個人**想要什麼**、**拿不拿得到**、**拿得多有效率**」。作者把命盤裡的字分成「我的」和「別人的」（賓主）、「工具」和「目標」（體用），再看工具有沒有作用到目標（作功）。這是解釋富貴高低的框架。

### 第 33 訣　賓主訣（書第 82–83 頁）

**這一訣在講什麼**：分清楚命盤裡「哪些是我的、哪些是別人的」。

1. 賓主是多層次的：
   - 以日主為「我」→ 其他干支都是「別人」；
   - 以日柱為「我和配偶（我的家）」→ 其他柱是外面的世界（父母的家、兄弟姊妹的家）；
   - 也可以把日、時柱當「我家（我和孩子）」，年、月柱當「大家族」。
2. 大運流年是外來的，所以**八字為主、歲運為賓**。
3. 財星在主位（日柱）就是我的財，在賓位就是別人的財；官、印、食傷、比劫類推。
4. 看主和賓的作用關係：財來合主、財被賓合、財被賓沖……就知道財能不能成為我的。
5. 賓主關係體現一個人在社交中的能力大小、富貴貧賤，所以極重要。

**白話**：同樣看到一大筆錢（財星），要問「這錢在誰的口袋」。在日柱（我家）或合到日主身上，是我的；在年柱、時柱又被別的字合走，就是經手而不是擁有，像會計師、銀行員每天經手大筆錢，但錢不是他的。

**和其他書比較**：課堂講宮位（年祖上、月父母、日夫妻、時子女），沒有「賓主」的概念；這是盲派的說法，本書吸收進來。

**一步一步看**

1. **日主**：辛金生巳月，巳中有庚金（長生）；地支巳、酉、丑三合金局 → 金極旺。
2. **全局**：年干庚、月干辛（比劫），時干己（偏印），全是自黨；只有年支子水（食神）是異黨 → 作者稱假從格（從旺）。
3. **主位**：日柱辛酉是「我」。
4. **財從哪裡來**：原局沒有木（財）。歲運來甲木 → 時干己土和它相合（甲己合）；來乙木 → 年干庚金和它相合（乙庚合）。
5. **財去哪裡**：己在時柱、庚在年柱，都是賓位 → 財被別人拿走。

**學到什麼**：這就是「賓主」的用處：同樣有財，要看財被誰拿走。律師、會計、理財顧問這類「經手別人錢」的工作，常見這種結構。

#### 命例：張國榮，日柱暗合財（書第 83 頁）

**書怎麼說**：壬水為主，日柱壬午，壬與午中丁火暗合（財），壬又合月干丁火（財），財富極豐；財星丁火的祿位在夫妻宮午火，所以伴侶唐先生助他財富成就。（命盤見 02 檔：丙申 丁酉 壬午 己酉）

**一步一步看**

1. **暗合**：日柱壬午，午中藏丁，丁壬合 → 日柱自己就合著財（README「暗五合」之一）。
2. **明合**：月干丁火和日干壬水相鄰 → 再合一次財。
3. **財在主位**：丁火的祿在午，午是日支（夫妻宮，主位）→ 財是自己家的，而且和伴侶有關。

**學到什麼**：日柱暗合 + 日干明合，財都合到主位，是財富豐厚的訊號。

### 第 34 訣　體用訣（書第 84–85 頁）

**這一訣在講什麼**：賓主訣用「宮位」分我和別人；體用訣用「十神」分工具和目標。

| | 是什麼 | 十神 |
|---|---|---|
| **體** | 我自己、我能使用的工具 | 日主、印、比劫 |
| **用** | 我的目的、我想要得到的東西 | 財、官 |
| 兩者皆可 | 思想、智力方面是體；享受、名譽方面是用 | 食傷 |

**為什麼要分體用**：命局財星多，表示這個人對財有追求，但不一定富，還要看財在哪裡、和我有沒有作用關係。財星多但我沒辦法和它們發生關係，就得不到；財星極旺為害，反而代表破財或為財遭殃。

**白話**：「體」像一個人的身體、手腳、工具（學歷、人脈、兄弟）；「用」像他想要的東西（錢、地位）。有手有工具，但沒有伸手去拿（不作用），等於沒有；手太弱而東西太重，拿了會受傷。

#### 命例：香港特別行政區，體是金融、用是知識型經濟（書第 84 頁）

**書怎麼說**：子辰合開了水庫，所以體是甲辰、甲子（水木）；辰土偏財化成水印，可知財經金融實為香港的本體；用是火生丑土財星，也就是知識型經濟，所謂「食腦」。（命盤見 01 檔：丁丑 丙午 甲辰 甲子）

**一步一步看**

1. **體**：日柱甲辰、時柱甲子，子辰半合水（印），水木是體。
2. **辰的轉變**：辰本來是偏財（土），合成水後變成印 → 「財變成我的工具」，作者取象為金融業是香港的本體。
3. **用**：年柱丁丑、月柱丙午：丙丁火（食傷）生丑土（財）→ 食傷生財 = 用頭腦賺錢。

**學到什麼**：體用可以拿來描述一個城市的產業：工具是什麼、目標是什麼。

#### 命例：李嘉誠，水木為體、火土為用（書第 84 頁）

**書怎麼說**：申癸辰暗三合為水印，水木為體；用是火生三土財星，即念念求財並得財；日支申金七殺化為水印，酉金生旺水印，可知權也為他所用，所以在社會上有影響力。（命盤見 01 檔：戊辰 戊午 甲申 癸酉）

**一步一步看**

1. **體**：甲木日主 + 申癸辰水印。
2. **用**：午火（傷官）生戊戊辰土（財）。
3. **官殺的去向**：申金（七殺）、酉金（正官）本來剋身，但都生水印 → 官殺不是壓力，而是變成工具（權為我用）。

**學到什麼**：官殺化成印，就從「壓我的」變成「我能用的」。

#### 命例：乞丐命，金水為體、全然無用（書第 84 頁）

**書怎麼說**：癸酉日柱，金水為體，命局全然無用，所以缺乏進取、遲鈍消極。（命盤見 01 檔：辛丑 辛丑 癸酉 辛酉）

**一步一步看**

1. **體**：癸水、辛金、酉金、丑中癸辛……全是印比。
2. **用**：財（火）沒有；官（土）只有丑中己土，被金洩掉。
3. **結果**：有工具、沒目標 → 不進取。

**學到什麼**：命局全是「體」沒有「用」，人就沒有追求。

#### 命例：貴命也是凶命，七殺寅木為用（書第 85 頁）

**書怎麼說**：戊土和庚申金為體，七殺寅木為用；寅木逢申沖剋，是制殺得宜，主威權、主吉；命局雖有貴氣，可惜地支全被沖動，也極危險；用神火，火運顯達，申運被害。（命盤見本檔第 30 訣：庚申 戊寅 戊寅 庚申）

**一步一步看**

1. **體**：戊土日主、月干戊土，加上庚申金（食神，這裡當體，用來制殺）。
2. **用**：寅木七殺（官 = 地位、權力）。
3. **作用**：申沖寅 → 體去「制」用 → 掌握權力。

**學到什麼**：同一張盤，第 30 訣說「兩忌互沖」，這一訣說「食神制殺為用」，是同一件事的兩種說法：申寅沖讓殺被制住。

### 第 35 訣　賓主功神訣（書第 86–88 頁）

**這一訣在講什麼**：這一訣是全書方法的核心，值得慢慢讀。

1. **體一定要「有事做」**：日干、日支如果是體，就要和別的十神發生關係；只是閒著，必無事生非，是劣命。
2. **用要和體發生關係**：財官要被體剋制、合住或化掉，才有作為。
3. 食傷用來生財、制官殺 → 是「用」；食傷用來洩秀 → 是「體」。
4. 體用賓主之間的作用叫「**作功**」；參與作功的叫「**功神**」，不參與的叫「**廢神**」。
5. 主位的體去追求賓位的用 → **正向作功**；主位的用和賓位的體發生作用 → **反向作功**。
6. 作者把干支看成能量體：合、沖、刑、剋是能量碰撞；能量耗散後產生效率的就是功神，沒效率或不耗散的就是廢神。
7. **成功者：多功神少廢神，或功神少但效率高；平庸者：多廢神少功神，或有功神但效率低。**
8. 主（體）強時，賓（用）出現才有價值；主弱時，賓出現反而不利。
9. **看作功的順序**：
   - 先看**日干**有沒有合（合正官、合正財 → 是本人想追求的東西；能不能得到，看這個合有沒有效率）；
   - 日干沒合，看有沒有**貼身生食傷**，再看食傷在命局的功用；
   - 日干既無合又無生，就專看**日支**：有沒有和其他地支成黨成勢，有沒有合、沖、刑、害；
   - 日柱干支都不作功，才看其他干支的比劫是否作功，但這種八字格調不高，一般沒什麼成就。

**白話**：想像一個工廠。體是機器和工人，用是原料和訂單。機器要開動（作功）去加工原料，才會有產出；機器閒著，或原料堆在倉庫沒人碰，都沒有產出（廢神）。效率高的工廠，少量機器也能做大量產品。看一張命盤，就是看「誰在工作、對誰工作、效率多高」。

**和其他書比較**：這套「賓主、體用、作功、功神廢神」是盲派（段建業一系）的核心術語。作者在序中說自己不屬於任何流派，但這一章明顯吸收了盲派思路，再用正五行的生剋去解釋。已整理的其他書（課堂、量化五行力、陸致極、蘇民峰、《滴天髓命例研究》）都沒有這套方法。

#### 命例：乾造，無功神（書第 87 頁）

**書怎麼說**：天干戊癸合、地支午未合，官星（午）和傷官（癸）被羈絆成為廢神；體是日干辛金和時干庚金，只透過時干庚金剋時支寅木起少許作用，效率低；日干辛金本身不作功，也成廢神。所以凡事欠動力，對周圍的事物缺乏興趣，無上進心，為人怠懶，命局可說沒有功神。

| | 時 | 日 | 月 | 年 |
|---|:-:|:-:|:-:|:-:|
| 十神 | 劫財 | 日主 | 正印 | 食神 |
| 天干 | **庚**<sub>金</sub> | **辛**<sub>金</sub> | **戊**<sub>土</sub> | **癸**<sub>水</sub> |
| 地支 | **寅**<sub>木</sub> | **未**<sub>土</sub> | **午**<sub>火</sub> | **酉**<sub>金</sub> |
| 藏干 | 丙 **甲** 戊 | 丁 **己** 乙 | 己 **丁** | **辛** |
| 藏干十神 | 正官 **正財** 正印 | 七殺 **偏印** 偏財 | 偏印 **七殺** | **比肩** |

**一步一步看**

1. **日干辛**：有沒有合？辛的合是丙，命局沒有丙 → 無合。有沒有貼身生食傷？左邊是戊（印），右邊是庚（劫）→ 沒有 → 日干不作功。
2. **日支未**：和月支午相合（午未合），但午是官星，和未合在一起只是互相綁住，沒產生剋、化、生的效果。
3. **天干**：年干癸水（食神）和月干戊土（印）相合（戊癸合）→ 互相綁住，都成廢神。
4. **剩下的**：時柱庚寅，庚金剋寅木（劫財剋財），但在賓位、自己剋自己，效率低。
5. **結論**：沒有一個有效的功神 → 平庸、怠懶。

**學到什麼**：按第 9 點的順序（日干 → 日支 → 其他）檢查，就能判斷「有沒有作功」。合太多的命，字都被綁住，反而沒動力。

#### 命例：曾蔭權，辛酉金是功神（書第 88 頁）

**書怎麼說**：申癸辰暗三合化水為木的印星，加上年干和日主甲木為體；全局以月支酉金生旺印星癸水、得令的辛金有效率地剋制日干甲木為有功，所以辛酉金是命局的功神，主貴氣，官至香港特首。（命盤見 01 檔：甲申 癸酉 甲辰 辛未）

**一步一步看**

1. **體**：甲木、申癸辰水印。
2. **用**：辛金、酉金（官星）。
3. **作功**：辛金得令，貼身剋日干甲木（時干剋日干）；酉金生癸水，癸水再生甲木（官 → 印 → 身）。
4. **效率**：官得令有力，又有印轉化，不傷身 → 效率高。

**學到什麼**：官星剋身而有印化，就是「官貴」的功神結構（第 37 訣化用會再講）。

#### 命例：乾造，執法人員（書第 88 頁）

**書怎麼說**：這個命以七殺巳火生主位的辰土（印）為功，殺主權力；再看巳和天干辛金暗合，有「七殺制刃」之象，七殺主權力、刃主武，所以是執法人員。

| | 時 | 日 | 月 | 年 |
|---|:-:|:-:|:-:|:-:|
| 十神 | 劫財 | 日主 | 食神 | 食神 |
| 天干 | **辛**<sub>金</sub> | **庚**<sub>金</sub> | **壬**<sub>水</sub> | **壬**<sub>水</sub> |
| 地支 | **巳**<sub>火</sub> | **辰**<sub>土</sub> | **寅**<sub>木</sub> | **子**<sub>水</sub> |
| 藏干 | 戊 **丙** 庚 | 乙 **戊** 癸 | 丙 **甲** 戊 | **癸** |
| 藏干十神 | 偏印 **七殺** 比肩 | 正財 **偏印** 傷官 | 七殺 **偏財** 偏印 | **傷官** |

**一步一步看**

1. **日主**：庚金生寅月，木旺 → 失令；日支辰（偏印）生身；時干辛金（劫財）。
2. **作功一**：時支巳火（七殺）和日支辰土相鄰，火生土 → 七殺生印，印在主位 → 殺的力量轉給我。
3. **作功二**：時柱辛巳，巳中丙火和辛金暗合（丙辛合）→ 七殺合住劫財（刃），「七殺制刃」。
4. **取象**：七殺 = 權力、紀律；刃 = 武力。殺制刃 = 用權力管武力 → 警察、執法人員。

**學到什麼**：功神的組合可以對應到職業：殺生印 → 有權；殺制刃 → 武職。

#### 命例：蔣緯國，反向作功（書第 88 頁）

**書怎麼說**：命局日柱丙子，子是官星，是用而不是體；天干三火得印星甲木生，加上時支午火，木火極旺為體；幸得主位的子水沖剋火體，是水官「反向作功」有效，所以主官貴。這裡書上明寫蔣緯國。（命盤見本檔第 30 訣：丙辰 丁酉 丙子 甲午）

**一步一步看**

1. **主位**：日支子水是官星（用）。
2. **賓位**：年干丙、月干丁、時柱甲午 → 木火（體）。
3. **方向**：主位的「用」去沖賓位的「體」（子沖午）→ 反向作功。
4. **效率**：子水有酉金生、辰土合，有力 → 有效 → 官貴。

**學到什麼**：正向作功是「我去拿」，反向作功是「東西在我家，主動來作用外面」；兩種都可以有效。

### 第 36–41 訣　六種「功神作用」（總說）

| 訣 | 名稱 | 作功方式 | 代表的人生態度 |
|---|---|---|---|
| 36 | 制用 | 剋、合、沖、刑、害制服對方（比劫制財、財制比劫、比劫制官殺、官殺制比劫、食傷制官殺、官殺制食傷、食傷制印、印制食傷、財制印、印制財，共十種） | 直接追求 |
| 37 | 化用 | 印化官殺：官殺 → 印 → 身 | 把凶險的力量轉為己用 |
| 38 | 生用 | 食傷生財 | 把想法變成財富 |
| 39 | 洩用 | 食傷洩秀 | 發展才華 |
| 40 | 墓用 | 某五行入墓（庫） | 得到、控制、管理、擁有、佔據 |
| 41 | 日柱合用 | 日干或日支合賓位的用 | 合到的就是想要的 |

**作功效率**（有沒有力）是判斷富貴高低的依據。效率怎麼看？大致是：作功的一方要比被作功的一方強（剋得動、化得了、生得出），而且位置要近（貼身、同柱、鄰支）。

### 第 36 訣　制用功神訣（書第 89–90 頁）

**這一訣在講什麼**：體和用之間用「制」的方式（剋、合、沖、刑、害）發生作用，直接表現一個人的人生追求。十種組合裡，制的一方強、被制的一方弱，就有效率；反過來就沒有效率。

#### 命例：忽必烈，官殺制比劫有效（書第 89 頁）

**書怎麼說**：乙木天元一氣，加上年支亥水，水木為體、金為用；日柱乙酉，酉金七殺直接剋木作功，是有效率的官殺制比劫，所以成就「一代天驕」的霸業。（命盤見 02 檔：乙亥 乙酉 乙酉 乙酉）

**一步一步看**

1. 體：四乙 + 亥水。
2. 用：三個酉金（七殺）。
3. 作功：日柱乙酉，酉在日支（主位）直接剋乙木 → 同柱、貼身。
4. 效率：金木勢均力敵，七殺得令 → 有效。

**學到什麼**：同柱的剋最直接、效率最高。

#### 命例：韓信，制用效率不高（書第 89 頁）

**書怎麼說**：以木為體、金火為用；日柱乙卯，三個酉金沖日支卯木，是正方向作功，可惜金旺木弱，效率不高；雖有月干丁火剋酉金，成「食傷制官殺」的制用，可惜金旺火弱，效率也不高；要等火運才能改善，所以甲午運得蕭何引薦、登壇拜將封王；癸巳運，癸水剋丁火，巳酉合加強金力剋木，制用完全失效，被呂后斬首。（命盤見 02 檔：辛酉 丁酉 乙卯 乙酉）

**一步一步看**

1. 體：乙木、卯木。
2. 用：酉金（官殺）、丁火（食神，用來制殺）。
3. 作功一：酉沖卯，主位卯木被沖，木弱金旺 → 效率低。
4. 作功二：丁火剋酉金，火弱金旺 → 效率低。
5. 大運：甲午運補火 → 效率提升 → 封王；癸巳運火被剋 → 失效 → 死。

**學到什麼**：用作功效率來解釋大運：運來補強「作功的一方」就發，運來打掉它就敗。

#### 命例：丈夫大富的女命，官殺制比劫有效（書第 89 頁）

**書怎麼說**：以土為體、金木為用；日柱己未、時柱戊辰，得乙木月干及地支卯未類木局，形成官殺制比劫的順方向制用，有效。（命盤見 02 檔：辛卯 乙未 己未 戊辰）

**一步一步看**

1. 體：己土、未土、戊辰（比劫）。
2. 用：乙木、卯木（官殺）。
3. 作功：月干乙木貼身剋日干己土；卯未半合木，木的力量集中。
4. 效率：土雖旺，木有根有勢 → 剋得動 → 有效。

**學到什麼**：女命官殺制比劫有效，丈夫有成就。

#### 命例：盜賊命，官殺制比劫沒有效率（書第 90 頁）

**書怎麼說**：以木為體、金土為用；日柱乙丑，命局辛巳丑暗三合成局，辛金順方向剋乙木日元，是官殺制比劫之局，可惜木弱金強，弱木逢金必為砍折，這個制用沒有效率。（命盤見 01 檔：辛巳 戊戌 乙丑 辛巳）

**一步一步看**

1. 體：只有乙木日主。
2. 用：辛金（七殺）、戊戌丑土（財）。
3. 作功：金剋木，方向是用去制體（我被剋），而且木太弱。
4. 效率：被砍斷，不是「有效的管理」，而是「被摧毀」。

**學到什麼**：「制」要雙方力量相當才有效；一方太弱就是毀滅（第 21 訣）。

#### 命例：常人之命，財制印無效率（書第 90 頁）

**書怎麼說**：以金水為體、火為用；日柱癸酉，金旺成局，丙火合剋金，原可成財星制印之局，可惜丙火剋金乏力，是無效率的作功；加上丙火只向賓位的年干辛金用功，命局格調極低。（命盤見 02 檔：辛酉 丙申 癸酉 辛酉）

**一步一步看**

1. 體：癸水、一堆金。
2. 用：月干丙火（財）。
3. 作功：丙辛合（丙火合年干辛金）、丙火剋金。
4. 效率：一個無根的丙火對六個金 → 沒效率；而且合的是年干（賓位），不是日柱。

**學到什麼**：作功要看「對誰作功」：只在賓位之間互動，和主位無關，格調就低。

### 第 37 訣　化用功神訣（書第 91–92 頁）

**這一訣在講什麼**：體和用之間用「轉化」的方式發生作用，主要是印星化官殺：官殺 → 印 → 身，把官殺凶險的力量轉化為自己所用。表現一個人「把人生中凶的力量轉為己用」的態度。

**為什麼化比制更好**：制是硬碰硬，有輸有贏；化是借力使力，官殺的力量越大，經過印轉來的也越多。所以化用有效的人，壓力越大越能成事，多是當官、掌權的命。

#### 命例：劉鏞，太平宰相（書第 91 頁）

**書怎麼說**：以火土為體、水木為用；日柱己丑，日干己土被時干甲木合剋，幸得丙火貼身化解，形成殺生印、印生身，把官殺凶險的力量轉為己用，所以甲木丙火化用作功有效，能做數十年的太平宰相。（命盤見 01 檔：甲子 丙寅 己丑 甲子）

**一步一步看**

1. 剋我的：時干甲木（正官）合剋日干己土；年干甲木、寅木。
2. 化的：月干丙火（正印），貼著日干。
3. 路線：甲 → 丙（鄰干，木生火）→ 己（鄰干，火生土）。
4. 效率：丙火坐寅（長生），有根 → 化得動。

**學到什麼**：官殺越旺，只要印有根，化過來的力量就越大。

#### 命例：曾蔭權，辛金癸水化用有效（書第 91 頁）

**書怎麼說**：以水木為體、土金為用；日柱甲辰，申癸辰三合水局，日干甲木被得令的時干辛金所剋，幸得癸水貼身化解，形成官殺生印、印生身，所以辛金、癸水化用作功有效。（命盤見 01 檔：甲申 癸酉 甲辰 辛未）

**一步一步看**

1. 剋我的：辛金（正官），得令。
2. 化的：月干癸水（正印），貼著日干，又有申辰合水支援。
3. 路線：酉金 → 癸水（同柱）→ 甲木（鄰干）。

**學到什麼**：同一張盤，第 35 訣說「辛酉是功神」，第 37 訣說「化用有效」，是同一件事。

#### 命例：貴命，乙木化子水（書第 91 頁）

**書怎麼說**：以木火為體、金水為用；日柱丙子，子水貼身剋制丙火，幸得強旺的乙木貼身化解，形成官殺生印、印生身，加上運行東南，所以大貴。（命盤見 02 檔：壬申 壬寅 丙子 乙未）

**一步一步看**

1. 剋我的：日支子水（正官）、兩壬（七殺）。
2. 化的：時干乙木（正印）、月支寅木（偏印）。
3. 路線：月柱壬寅，壬水生寅木（同柱）；時干乙木貼著日干丙火（鄰干），木生火。水的力量經過木才到日主。
4. 運：東南木火，體得地 → 大貴。

**學到什麼**：化用的印越強，貴氣越大。

#### 命例：貴命，七殺剋身、印化殺（書第 92 頁）

**書怎麼說**：以火土為體、水木為用；日柱戊寅，七殺寅木剋日主直接作功，得月柱丙午火印洩官殺、生身，化七殺為我所用，所以是當官之命；可惜時柱乙卯的乙木貼身剋日主而無制，是忌。己酉運，酉沖卯，剋制乙卯忌神，開始升官；庚戌運，庚乙合、卯戌合，官運亨通；辛亥運，丙辛合壞了印，亥卯又半合，官旺剋身無制，丟官。同一個命盤在第 56、65 訣出現，可以對照看「樞紐」：丙火印就是樞紐，被合走就出事。

### 第 38 訣　生用功神訣（書第 93–94 頁）

**這一訣在講什麼**：體和用之間用「食傷生財」的方式發生作用，表達「把自己的想法變成財富」的人生態度。效率看三件事：食傷有沒有力（有根）、財受不受得了生（不會太弱被漂走）、日主撐不撐得住。

#### 命例：香港特別行政區，生用效率極高（書第 93 頁）

**書怎麼說**：以水木火為體、土為用；食傷火旺，生丑土、辰土，食傷生財的生用作功效率極高，所以經濟自能富裕。（命盤見 01 檔：丁丑 丙午 甲辰 甲子）

**一步一步看**

1. 食傷：丙、丁、午，火旺。
2. 財：丑、辰。
3. 路線：年柱丁丑，丁火生丑土（同柱）；月支午火生日支辰土（鄰支）；午火也生年支丑土（鄰支）。
4. 效率：火旺土濕，能接住火 → 高。

**學到什麼**：食傷旺、財能接，就是生用有效。

#### 命例：小貴之命，生用效率較低（書第 93 頁）

**書怎麼說**：以土金水為體、木為用；日柱庚辰，命局三合成水局，甲木過弱不受水生，所以食傷生財的生用效率較低，只能維持小康。（命盤見 02 檔：癸酉 甲子 庚辰 甲申）

**一步一步看**

1. 食傷：申子辰水局、癸水。
2. 財：兩甲木，坐子、申，無根。
3. 效率：水太多、木無根 → 「水多木漂」，生不進去。

**學到什麼**：財太弱時，食傷再旺也生不出財。

#### 命例：貧賤女命，生用無效率（書第 93 頁）

**書怎麼說**：以金水木為體、火為用；日柱壬辰，水多木漂，乙木不受水生，不能生旺丙火，食傷生財的生用作功無效率，主貧賤。（命盤見 02 檔：丙辰 庚子 壬辰 乙巳）

**一步一步看**

1. 食傷：時干乙木，無根。
2. 財：年干丙、時支巳。
3. 斷點：乙木漂浮，水 → 木 → 火 斷在木。

**學到什麼**：生用的鏈條中間一環斷了，整條就失效。

#### 命例：孫中山，財生官殺的生用（書第 94 頁）

**書怎麼說**：日柱辛卯，辛金不作功，以地支卯木為八字的中心；四柱地支形成木局，勢極旺盛，借丙火洩秀，是有效率的財生官殺生用作功，所以能成為中國走向共和的第一任總統。（命盤見 01 檔：丙寅 己亥 辛卯 庚寅）

**一步一步看**

1. 日干辛金：沒有合（丙辛合，但丙在年干，不相鄰）、沒有貼身食傷 → 不作功。
2. 日支卯木：和寅、寅、亥成木勢 → 以它為中心。
3. 作功：木（財）生年干丙火（官）→ 財生官。
4. 效率：木極旺、丙火有寅根 → 高 → 貴。

**學到什麼**：日干不作功時，看日支；這裡「生用」生的是官而不是財，作者也歸在生用。

### 第 39 訣　洩用功神訣（書第 95–96 頁）

**這一訣在講什麼**：體和用之間用「食傷洩秀」發生作用，表達「發展自己才華」的人生態度。這時食傷是體（才華、思想），重點是洩得有沒有力、有沒有再生到財官。

#### 命例：孔子，洩用有效、才華蓋世（書第 95 頁）

**書怎麼說**：日柱庚子，日支子水（傷官）表示有才華，水勢浩瀚，洩秀有力，地支子水直接洩用作功有效，所以才華蓋世、名垂千古、為萬世師表；可惜命中官殺乏力，對日主作功無效，所以做不了大官；食傷又不生財，所以也不是大富之命。（命盤見 01 檔：己酉 癸酉 庚子 丙子）

**一步一步看**

1. 洩：日柱庚子，庚生子（同柱）；癸酉、子水。
2. 效率：金旺水旺 → 洩得有力。
3. 官：時干丙火（七殺）坐子水，被剋 → 無力 → 官小。
4. 財：沒有木 → 不富。

**學到什麼**：功神決定成就的「類型」：洩用有效 → 名；化用、制用有效 → 貴；生用有效 → 富。

#### 命例：大企業董事長，洩用有效（書第 95 頁）

**書怎麼說**：日柱壬子，日支子水生了食傷，子水順方向洩用作功有效；食神寅木裡暗藏財星（丙火），將自己的想法變成財富之象，運走南方火旺之地，大富。

### 第 40 訣　墓用功神訣（書第 97–98 頁）

**這一訣在講什麼**：體和用之間用「入墓（入庫）」的方式發生作用。墓（辰戌丑未）像倉庫，某個五行進了某個庫，就是被收藏、控制、管理、擁有、佔據。例如財星入我的庫 → 我擁有財；官星入我的庫 → 我掌握權力。

**四個庫**：辰是水庫、戌是火庫、丑是金庫、未是木庫。看日支是不是庫、哪個五行入了它。

#### 命例：克林頓，反向墓用（書第 97 頁）

**書怎麼說**：以水木火為體、金土為用；日柱乙丑，丑土是金庫，金是官星，月令申金入丑土，發揮有效的墓用反方向作功，所以能貴為美國總統。（命盤見 01 檔：丙戌 丙申 乙丑 丁亥）

**一步一步看**

1. 日支：丑（金庫），主位。
2. 官星：月支申金（正官），得令。
3. 入墓：申金入丑庫 → 官星被我收藏 → 掌權。
4. 方向：丑是主位的「用」（財，土），收的是賓位的官 → 作者稱反向。

**學到什麼**：日支是某個五行的庫，而那個五行在命局很旺，就有「收藏、掌握」的象。

#### 命例：董建華，順向墓用（書第 97 頁）

**書怎麼說**：以木火土為體、水為用；日柱丙辰，辰是水庫，水是官星，時支亥水入辰土，發揮有效的墓用順方向作功，所以能貴為香港特區第一任特首。（命盤見 01 檔：丁丑 乙巳 丙辰 己亥）

**一步一步看**

1. 日支：辰（水庫）。
2. 官星：時支亥水（七殺）。
3. 入墓：亥水入辰 → 官殺被我收 → 掌權。

**學到什麼**：官殺入日支的庫 = 掌握權力。

#### 命例：李澤楷，壬寅運墓用正向作功（書第 98 頁）

**書怎麼說**：以土金水為體、木火為用；日柱辛未，日干辛金不作功，以地支的作功為核心；地支未土是木墓，亥未拱木，木勢暗藏；直到大運壬寅，寅木入庫，發揮墓用正向作功，因買賣 Orange 公司而成就鉅大財富。（命盤見 01 檔：丙午 己亥 辛未 壬辰）

**一步一步看**

1. 日干辛：丙辛合？丙在年干，不相鄰；左邊己（印）、右邊壬（傷官）→ 辛生壬是洩，但作者判日干不作功，改看日支。
2. 日支未：木庫；亥未半合木 → 木（財）暗藏在主位。
3. 大運壬寅：寅木（正財）來，入未庫 → 財被我收 → 鉅富。

**學到什麼**：原局「拱」而未成的局，大運補上那個字時就應驗。

#### 命例：小貴之命，企業經理（書第 98 頁）

**書怎麼說**：壬寅日柱，以金水木為體、土為用；日支寅木食神表示此人有才華，木入未土（官墓）是官星在命局的作功方式，有才華被官方所用之象；寅為「內食神」，可象徵企業，所以此人是企業經理。

|---|:-:|:-:|:-:|:-:|
| 十神 | 偏印 | 日主 | 劫財 | 正官 |
| 天干 | **庚**<sub>金</sub> | **壬**<sub>水</sub> | **癸**<sub>水</sub> | **己**<sub>土</sub> |
| 地支 | **子**<sub>水</sub> | **寅**<sub>木</sub> | **酉**<sub>金</sub> | **未**<sub>土</sub> |

**一步一步看**

1. **日主**：壬水生酉月，酉金（正印）生水 → 得令；時柱庚子（偏印、劫財）、月干癸（劫財）→ 身旺。
2. **日支**：寅木（食神），在主位，代表才華。
3. **官**：年柱己未（正官），未是木庫，也是官星所在。
4. **墓用**：寅木的力量入未（木入木庫），而未是官 → 才華被官方（機構）收用。
5. **取象**：「內食神」（日支的食神）象徵自己經營或服務的企業 → 企業經理，小貴。

**學到什麼**：墓用不一定是「我收別人」，也可以是「我的才華被機構收用」，看庫屬於誰。

#### 命例：曾國藩，兩亥入辰墓、極其官貴（書第 98 頁）

**書怎麼說**：丙辰日柱，以火土為體、水金為用；日支辰土食神表示有才華，辰為內食神，也可象徵服務大企業；兩亥入墓，即辰土對亥水發揮墓用正向作用，加上兩個己土剋制月支、時支的亥水官星，說明自己是極其官貴之人；可惜年干辛金（財）無制，說明財富不是自己的。

|---|:-:|:-:|:-:|:-:|
| 十神 | 傷官 | 日主 | 傷官 | 正財 |
| 天干 | **己**<sub>土</sub> | **丙**<sub>火</sub> | **己**<sub>土</sub> | **辛**<sub>金</sub> |

**學到什麼**：一張盤可以同時有好幾種作功（墓用 + 制用）。作功對象決定成就類型：對官作功 → 貴；對財沒有作功 → 不富。

### 第 41 訣　日柱合用功神訣（書第 99–100 頁）

**這一訣在講什麼**：

1. 日主或日支是「體」，合著賓位的「用」，就是日柱合用。
2. 日主可以合財或合官；日支逢六合可以合財、合官、合食傷，所合的東西就是日主所求的。
3. 能否順利得到想合的東西，要看八字整體配合；合的東西被破壞，這個八字就被破壞。
4. **合財要看身強身弱**：

| 身 | 財 | 結果 |
|---|---|---|
| 旺 | 旺 | 大富 |
| 弱 | 旺，財又不作功 | 貧 |
| 旺 | 虛 | 不窮，但一生愛花費，一般而已 |
| 弱 | 虛 | 不會得大財，不缺吃喝而已 |

**為什麼**：合是「想要」，身強弱是「拿不拿得動」，財強弱是「東西值不值錢」。三者配合才知道結果。

#### 命例：劉鏞，日主合正官（書第 99 頁）

**書怎麼說**：日主合正官（甲己合）。（命盤見 01 檔：甲子 丙寅 己丑 甲子）

**一步一步看**

1. 日干己土和時干甲木相合 → 合官 → 追求官位。
2. 有丙火化殺生身 → 合得到又不受傷 → 太平宰相。

**學到什麼**：日主合官 = 想當官；有印化，就能「合而得之」。

#### 命例：張國榮，日主合財、身財俱不弱（書第 99 頁）

**書怎麼說**：日主合財，身財俱不弱，主能任財富。（命盤見 02 檔：丙申 丁酉 壬午 己酉）

**一步一步看**

1. 合：壬合丁（明合月干、暗合午中丁）。
2. 身：申酉酉印生身。
3. 財：丙丁午火。
4. 照表：身財俱不弱 → 能任財。

**學到什麼**：表上的第一格（身旺財旺）就是張國榮這類。

#### 命例：宋子文，日主合財從財成格（書第 99 頁）

**書怎麼說**：日主合財，而且能從財成格；命局屬「夫從妻化」，庚乙合而化木，其人必主大富；只是「夫從妻化」有夫憑妻貴之象，必敬畏妻子。（命盤見 02 檔：甲午 乙亥 庚辰 己卯）

**一步一步看**

1. 合：庚合乙。
2. 化：化成木（財）→ 日主自己變成財 → 從財。
3. 結果：大富；取象「夫從妻化」。

**學到什麼**：合財到「化成財」的程度，就是從財格，財富最大。

#### 命例：左宗棠，日主合財、身財俱旺（書第 100 頁）

**書怎麼說**：日主合財，身財俱旺，主富；清代名將左宗棠擁有二等恪靖侯、東閣大學士、太子太保、一等輕騎都尉、賞穿黃馬褂、兩江總督、南洋通商事務大臣等七個頭銜，風光半生。（命盤見 01 檔：壬申 辛亥 丙午 庚寅）

1. 合：日干丙火和月干辛金相鄰，丙辛合 → 合財。
2. 身：丙坐午（帝旺）、寅（長生）→ 身有根。
3. 財：辛、庚、申，金旺。
4. 照表：身財俱旺 → 富。

**學到什麼**：日主合財的四種結果，先判斷身和財各自的強弱，再對照表格。

## 第七章　靈機妙象

### 第 42 訣　宮位象訣（書第 102–103 頁）

**這一訣在講什麼**：

1. 本書的宮位（**和一般書不同**）：

| 柱 | 象 | 宮 | 時期（本限） | 代表 |
|---|---|---|---|---|
| 年 | 根 | **父母宮** | 出生–16 歲 | 幼年家庭、長輩父母、學業、責任感 |
| 月 | 苗 | **兄弟宮** | 16–32 歲 | 青少年、自我、兄弟姊妹、同輩 |
| 日 | 花 | 夫妻宮 | 32–48 歲 | 壯年中年、夫妻感情、財官成就 |
| 時 | 果 | 子女宮 | 48 歲以後 | 晚年、享受、名譽、社交、子女晚輩 |

2. 喜用神在年柱有力 → 初限運佳；在年柱但無力 → 家境雖好也有限；在年干被鄰干沖剋 → 家境由好變壞。

**為什麼年柱是父母**：作者的理由是「根」：一個人最早接觸的是父母家庭，所以年柱（根）是父母宮；月柱（苗）是自己和同輩一起成長的階段。這樣四柱剛好對應人生四段，每段 16 年。

**和其他書比較**：《妙算人生八字》把父母放在**月柱**（年柱是祖上），課堂和多數書也是「月柱看父母兄弟」。本書把年柱定為父母宮，月柱只看兄弟。每柱 16 年也和《妙算》的 17–18 年不同。學習時兩套都要知道，看別人的分析時先確認他用哪一套。

#### 命例：李澤楷，根苗俱吉（書第 102 頁）

**書怎麼說**：父母宮丙午火能生旺兄弟宮的己土印星，火也能調節命局陰陽，有「根」「苗」俱上吉之象，代表幼年、青年、成年時期家庭環境良好；加上官星代表上進心、積極進取，所以少年得志，「雛鳳清於老鳳聲」。（命盤見 01 檔：丙午 己亥 辛未 壬辰）

**一步一步看**

1. 父母宮（年柱）：丙午，官星，喜用（調候）。
2. 兄弟宮（月柱）：己亥，己土印星。
3. 關係：丙火生己土（鄰干）→ 父母宮生兄弟宮，兄弟宮的印再生日主 → 一路生到我。
4. 結論：0–32 歲都順。

**學到什麼**：年柱、月柱都是喜用而且相生 → 早年得力。

#### 命例：梅艷芳，根被破壞（書第 102 頁）

**書怎麼說**：父母宮的地支卯木是用神，可惜被戌合而不化，「根」遭破壞，所以幼年失學，小小年紀就要以賣唱為生。（命盤見 01 檔：癸卯 壬戌 丙戌 丁酉）

**一步一步看**

1. 父母宮：年柱癸卯，卯木（印）是用神。
2. 合：月支戌和年支卯相鄰，卯戌合，用神被綁。
3. 結論：根（童年）受損。

**學到什麼**：用神在年柱卻被鄰支合住，童年有心無力。

#### 命例：李嘉誠，根苗俱不佳、白手興家（書第 103 頁）

**書怎麼說**：父母宮是財星（忌神），又逢兄弟宮月令的生旺，有根苗俱不佳之象，所以幼年青年家庭生活較艱苦，李嘉誠是靠個人努力白手興家。（命盤見 01 檔：戊辰 戊午 甲申 癸酉）

**一步一步看**

1. 父母宮：戊辰，財星，身弱以財為忌。
2. 兄弟宮：戊午，午火生戊土 → 忌神更旺。
3. 結論：0–32 歲辛苦；日、時柱（申、癸酉）有官印化水 → 中晚年發。

**學到什麼**：年月柱是忌神，早年辛苦；喜用在日時柱，晚發。

#### 命例：韓信，父母宮是忌神（書第 103 頁）

**書怎麼說**：父母宮是官殺星（忌神），又逢兄弟宮月令的相旺，有根苗俱不佳之象；韓信年少時家中極窮，常在城下釣魚，受漂母贈飯，又受當地惡少胯下之辱。（命盤見 02 檔：辛酉 丁酉 乙卯 乙酉）

**一步一步看**

1. 父母宮：辛酉，七殺，忌神。
2. 兄弟宮：丁酉，酉金又是殺，月令金旺。
3. 結論：早年受壓（殺 = 欺壓）。

**學到什麼**：年月柱是忌神官殺，早年容易受人欺壓。

### 第 43 訣　四正四庫四長生訣（書第 104–106 頁）

**這一訣在講什麼**：把十二地支分成三組，每組有固定的性格：

| 類別 | 地支 | 為什麼 | 性格 | 傳統神煞 | 佛家三毒 |
|---|---|---|---|---|---|
| 四正 | 子午卯酉 | 東南西北最正中的方位，五行最純，不易改變 | 固執、堅守原則；對感情執著（作者用粵語「死牛一便頸」形容） | 桃花（咸池）、將星 | 癡 |
| 四庫 | 辰戌丑未 | 能儲存、能湧出水火金木的庫 | 能生能藏，能生財、佔有欲強；孤芳自賞、唯我獨尊 | 華蓋 | 貪 |
| 四長生 | 寅申巳亥 | 四季的開始（孟月），剛出生 | 變數多、變幻莫測、不安於現狀（變化、變節、搬遷、暴發、破產） | 驛馬 | 嗔 |

**怎麼用**：數命局裡每一組有幾個字，偏多的那一組就是這個人明顯的性格傾向。作者把它和佛家「貪嗔癡」三毒對應，提醒人修心。

**和其他書比較**：一般書的桃花、驛馬、華蓋是**用年支或日支查**（例如申子辰見酉為桃花），本書則直接看命局有幾個四正、四庫、四長生字，算法完全不同。課堂和量化五行力都不太用神煞。

#### 命例：張國榮，三個四正（書第 104 頁）

**書怎麼說**：三個地支是四正（桃花），為情必執、多情多愁，為人也太癡。（命盤見 02 檔：丙申 丁酉 壬午 己酉）

**一步一步看**

1. 地支：申、酉、午、酉。
2. 四正：酉、午、酉 → 三個。
3. 結論：癡情、執著。

**學到什麼**：四正多 → 感情執著。

#### 命例：董建華、龔如心，兩個四庫（書第 105 頁）

**書怎麼說**：兩人都有兩個四庫，主能生財、佔有欲強；四庫也是華蓋，主孤芳自賞、孤獨自我、唯我獨尊，逆耳忠言聽不入耳。（命盤見 01 檔：董建華 丁丑 乙巳 丙辰 己亥；龔如心 丁丑 己酉 己未 壬申）

**一步一步看**

2. 龔如心：丑、未 → 兩個四庫。
3. 結論：能聚財、主觀強。

**學到什麼**：四庫多的人善於「收」，也容易「固守己見」。

#### 命例：左宗棠，三個四長生（書第 105 頁）

**書怎麼說**：三個地支是四長生，所以一生充滿變數：14 歲湘陰縣試第一，次年長沙府試第二，之後三次赴京會試都未考中；37 歲才遇到年逾花甲的林則徐，40 歲寄身湘軍幕府才初露鋒芒；44 歲因接濟曾國藩軍餉奪回武昌有功，封兵部郎中；47 歲得罪永州鎮總兵樊燮，險被就地正法；63 歲任欽差大臣督辦新疆軍務，68 歲抬棺出征、收復新疆；72 歲再任軍機大臣，中法戰爭時督辦福建軍務，74 歲病逝。（命盤見 01 檔：壬申 辛亥 丙午 庚寅）

**一步一步看**

1. 地支：申、亥、午、寅。
2. 四長生：申、亥、寅 → 三個。
3. 結論：一生大起大落、多次轉折。

**學到什麼**：四長生多 → 人生變動大，起伏多。

#### 命例：某國家政要（推測為鄧小平），五個驛馬（書第 106 頁）

**書怎麼說**：兩個地支是四長生（申、寅），加上天干甲木、壬水也是四長生的透出（干支互象：甲是寅的本氣、壬是申中藏的），所以八字中有五個字是驛馬星，一生充滿變數、變幻莫測，是風雲變幻的一代歷史巨人。書未明說是誰，筆記依生日推測為鄧小平。（命盤見 01 檔：甲辰 壬申 戊子 甲寅）

**一步一步看**

1. 地支：辰、申、子、寅 → 四長生是申、寅。
2. 天干：甲（寅的本氣）×2、壬（申中長生之水）→ 作者也算驛馬。
3. 合計五個。
4. 對照：一生三起三落。

**學到什麼**：作者把天干也拿來對應四長生（干支互象），這是他的延伸用法。

### 第 44 訣　神煞象訣（書第 107–109 頁）

**這一訣在講什麼**：

1. 傳統神煞上百個，只有極少數影響性情；**性格決定命運**，所以只有影響性情的才重要。
2. **十神才是真神煞**：有些十神本身就被加上神煞名稱：地支劫財＝羊刃（好鬥、好逞威風）、地支比肩＝祿神（剛愎自用）、地支食神＝文昌（配合得宜主智慧成就）。印貼身生旺日主有力且為用 → 有教養、得長輩護蔭；食傷貼身洩秀有力且為用 → 好人緣、受愛戴。這些比天德、月德、天乙貴人準。
3. 四正四庫四長生偏多，才是真正的桃花、華蓋、驛馬。
4. 孤辰寡宿主孤獨自閉，可以靠宗教或心靈修養轉化，不然會影響六親和姻緣，值得提醒當事人。

**作者的方法**：舉神煞「應該準卻不準」的反例，說明八字離不開五行生剋制化。

**和其他書比較**：《妙算人生八字》把神煞當輔助，列了 25 個；課堂說神煞不可靠；量化五行力不用神煞。本書立場最接近課堂。

#### 命例：貴命，帶亡神卻是一等貴命（書第 107 頁）

**書怎麼說**：年支亥水以寅木為亡神，神煞派有歌訣「亡神七殺禍非輕，用盡機關一不成，剋子刑妻無祖業……」，但此命是一等貴命，可知亡神歌訣並不準，準確率很低，因為基本道理本身有問題。

|---|:-:|:-:|:-:|:-:|
| 十神 | 七殺 | 日主 | 正財 | 正財 |
| 天干 | **甲**<sub>木</sub> | **戊**<sub>土</sub> | **癸**<sub>水</sub> | **癸**<sub>水</sub> |
| 地支 | **寅**<sub>木</sub> | **午**<sub>火</sub> | **亥**<sub>水</sub> | **亥**<sub>水</sub> |
| 藏干 | 丙 **甲** 戊 | 己 **丁** | 甲 **壬** | 甲 **壬** |
| 藏干十神 | 偏印 **七殺** 比肩 | 劫財 **正印** | 七殺 **偏財** | 七殺 **偏財** |

**一步一步看**

1. **日主**：戊土生亥月，水旺 → 失令；日支午火（正印）→ 得地。
2. **財**：年柱、月柱兩個癸亥（正財、偏財），水旺。
3. **殺**：時柱甲寅（七殺），坐祿，有力。
4. **結構**：財（水）生殺（木），殺生印（寅中丙火、午火），印生身 → 財 → 殺 → 印 → 身，逆流到日主。
5. **神煞**：亥見寅是亡神，又是七殺，歌訣說凶；但從五行看，殺有印化，是官貴。

**學到什麼**：神煞說凶、五行說吉時，以五行為準。

#### 命例：郭富城，天德月德不是成名的原因（書第 108 頁）

**書怎麼說**：月支戌土以丙火為天德月德貴人星；那郭富城是因為天德月德而成名嗎？其實命理不外乎五行生剋制化：郭富城命造食傷貼身洩秀有力且為用神，自然好交友、好人緣、受愛戴，加上 23 歲後三十年火運，所以能成名且持續；況且命帶天月德而不能走紅的藝人多得多。第 58 訣說他「水木火為體、土為用，丙巳火生戌土財星，食傷生財有效作功」。

| | 時 | 日 | 月 | 年 |
|---|:-:|:-:|:-:|:-:|
| 十神 | 比肩 | 日主 | 食神 | 劫財 |
| 天干 | **甲**<sub>木</sub> | **甲**<sub>木</sub> | **丙**<sub>火</sub> | **乙**<sub>木</sub> |
| 地支 | **子**<sub>水</sub> | **辰**<sub>土</sub> | **戌**<sub>土</sub> | **巳**<sub>火</sub> |
| 藏干 | **癸** | 乙 **戊** 癸 | 辛 **戊** 丁 | 戊 **丙** 庚 |
| 藏干十神 | **正印** | 劫財 **偏財** 正印 | 正官 **偏財** 傷官 | 偏財 **食神** 七殺 |

**一步一步看**

1. **日主**：甲木生戌月，土旺 → 失令；時柱甲子（比肩、正印）、年干乙木（劫財）→ 得勢；日支辰中有乙木、癸水 → 微根。
2. **食傷**：月干丙火（食神），貼著日主；年支巳火（食神）。
3. **財**：月支戌、日支辰（偏財）。
4. **作功**：甲 → 丙（鄰干，洩秀）、丙 → 戌（同柱，生財）。
5. **大運**：火運三十年，食神得地 → 成名。

**學到什麼**：一個人紅不紅，看食傷（表現力）和運，不是看貴人星。

#### 命例：張柏芝，天月二德不準（書第 108 頁）

**書怎麼說**：神煞派有歌訣「年臨天月二德，父母心慈而祥，行善積德之人」；巳月以庚金為月德、辛金為天德，年干庚、月干辛都有；但眾所周知她的父親是江湖中人，「心慈而祥、行善積德」好像談不上。

| | 時 | 日 | 月 | 年 |
|---|:-:|:-:|:-:|:-:|
| 十神 | 食神 | 日主 | 偏財 | 正財 |
| 天干 | **己**<sub>土</sub> | **丁**<sub>火</sub> | **辛**<sub>金</sub> | **庚**<sub>金</sub> |
| 地支 | **酉**<sub>金</sub> | **酉**<sub>金</sub> | **巳**<sub>火</sub> | **申**<sub>金</sub> |
| 藏干 | **辛** | **辛** | 戊 **丙** 庚 | 壬 **庚** 戊 |
| 藏干十神 | **偏財** | **偏財** | 傷官 **劫財** 正財 | 正官 **正財** 傷官 |

**一步一步看**

1. **日主**：丁火生巳月，火旺 → 得令；但只有巳一個根，其餘全是金（財）。
2. **財**：庚、申、辛、酉、酉 → 五個金，財極旺。
3. **父母宮（本書年柱）**：庚申，財星，對身弱的丁火是忌神。
4. **神煞**：年干庚（月德）、月干辛（天德），照歌訣應該父母慈祥。
5. **五行看**：父母宮是忌神 → 和父母緣分、家庭環境不一定好。

**學到什麼**：同一個柱，神煞說「吉」，五行說「忌」，作者以五行為準。

#### 命例：貧命，將星坐羊刃卻一生無成（書第 109 頁）

**書怎麼說**：神煞派歌訣說「命帶將星而無破壞，主官界顯達……將星坐七殺或羊刃，主掌握生死大權」；此命子水將星坐日支羊刃，為什麼一生無成、晚運淒涼、僅足衣食？因為此命以木火為用神，卻一直運走北方水地，所以一事無成。八字仍離不開五行生剋制化。

| | 時 | 日 | 月 | 年 |
|---|:-:|:-:|:-:|:-:|
| 十神 | 正官 | 日主 | 正財 | 偏財 |
| 天干 | **己**<sub>土</sub> | **壬**<sub>水</sub> | **丁**<sub>火</sub> | **丙**<sub>火</sub> |
| 地支 | **酉**<sub>金</sub> | **子**<sub>水</sub> | **酉**<sub>金</sub> | **子**<sub>水</sub> |
| 藏干 | **辛** | **癸** | **辛** | **癸** |
| 藏干十神 | **正印** | **劫財** | **正印** | **劫財** |

**一步一步看**

1. **日主**：壬水生酉月，酉金（正印）生水 → 得令；日支子（羊刃）、年支子 → 身旺。
2. **財官**：年干丙、月干丁（財），坐子、酉上，無根；時干己土（正官），坐酉，被洩。
3. **用神**：身旺要用財官，即木火（木洩水生火）。
4. **大運**：北方水運 → 水更旺，財被剋 → 一生無成。
5. **神煞**：子是將星，又是羊刃，歌訣說掌大權；實際不準。

**學到什麼**：命的高低看用神和大運，神煞只是名稱。

## 這三章學到什麼（給初學者）

1. **合、沖本身不分好壞**：合走忌神、沖走忌神是好事；合住用神、沖走用神是壞事。合有時能解沖（把要沖的字拉走），有時大運再補一個字，沖又回來。
2. **三刑只認兩種**（寅巳申、丑未戌），但作者自己在日課和滴天髓篇又放寬，讀時要知道。刑沖要看刑入哪一柱、是不是本限。
3. **賓主**：日柱是我，其他是別人；財在主位、合到主位才是我的財。
4. **體用**：日主、印、比劫是工具（體），財、官是目標（用），食傷兩邊都可以。
5. **作功**：體和用之間有沒有發生剋、合、化、生、洩、入墓的關係，效率高不高 → 決定富貴高低。看的順序是日干 → 日支 → 其他。
6. **功神類型對應成就**：洩用 → 名；化用、制用、墓用官 → 貴；生用、合財、墓用財 → 富。
7. **宮位**：本書年柱是父母宮、每柱 16 年，和一般書不同。
8. **神煞**：作者只認十神和四正四庫四長生，其他神煞都用反例否定。
