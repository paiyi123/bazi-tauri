## 一、這本書是什麼樣的書

一句話：**一本用「100 條口訣」把作者自己的正五行方法和《滴天髓》串起來的書，命例多半是名人（政治人物、明星、古人）**。

和已經整理過的書比起來，它的特色是：

1. **方法自成一派**：作者說自己不屬於任何流派（不受神煞派、調候派、十神派、捉用神派、盲派局限），但實際上是「**正五行 + 流通 + 賓主體用作功**」三者結合。
2. **流通規則很嚴格**：天干地支要在**同一柱**才相生，異柱不能直接相生；天干和天干、地支和地支要**相鄰**才相生（第 14、80 訣）。
3. **賓主體用、功神廢神**（第 33–41 訣）：這是本書最有特色的方法，用「體（我和我的工具）有沒有去作用到用（財官）」、「作功效率高不高」判斷富貴高低。這套術語來自盲派，作者用正五行的生剋重新解釋。
4. **大量名人命例**：李嘉誠、孔子、孫中山、袁世凱、梅艷芳、張國榮、劉翔、香港特區……同一個命盤常在不同訣裡從不同角度解讀，很適合練習「一個命盤用多種工具看」。
5. **應用面廣**：除了論命，還有**借盤論命**（用家人命盤看另一人）、**合婚**、**正五行擇日**（全書獨有）、健康、小兒讀書。
6. **下篇是《滴天髓》的白話導讀**：25 訣每訣都有任鐵樵、徐樂吾的命例，對初學者是讀《滴天髓》前很好的入門。
7. **很多性格描述**：五行性情、十神心性、性情論，比其他書更重視「性格決定命運」。

**和其他已整理的書相同的地方**
- 「得令、得地、得勢」→ 課堂、妙算都用。
- 「寒雖甚而暖有氣、暖雖至而寒有根」→ 《滴天髓》原文，蘇民峰和《窮通寶鑑》系統也重調候。
- 「合婚看夫子二星、反生肖神煞」→ 《命理新論》引張楠、袁樹珊，立場一致。
- 「反吟、伏吟、歲運並臨、日犯歲君」→ 陸致極書和 App 已有這些標籤。
- 「庫宜沖開」→ 陸致極「夫妻星庫沖開為婚期」、App 的「沖祿刃庫」。
- **借盤論命**（把親人的十神當新日主重算）→ 和《子平正源》的「**轉盤**」是同一個方法。差別是：本書規定了新日主的優先位置（父母取年干、夫妻取月干、子女取時干），並說借盤後不論宮位歲限；《子平正源》講得更細（角色轉換、借妻安子、夫妻強弱逐運比拼），有 16 個轉盤例。

**本書獨有、其他書沒看到的**
- **異柱干支不能直接相生**的嚴格流通規則和三種流通路線圖。
- **賓主、體用、功神廢神、正向/反向作功、六種作功方式**（制用、化用、生用、洩用、墓用、日柱合用）。
- **正五行擇日**：扶山相主、催財/催官/聽格日課、六種凶日課、婚課實例。
- **五合的「正化／夫從妻化／妻從夫化」**對照表。
- **五行之十神象**：不管日主，金旺＝官象、土旺＝財象……
- **清濁三法**（寒暖、順逆、神枯）＋「三清得幾」的分級。
- **四正四庫四長生齊全**分別對應癡、貪、嗔三種劫難。

## 四、這本書的特色和要小心的地方

**優點**
- 口訣化、條列化，很好記；每訣都有例子。
- 名人命例多，有些有詳細的年表（李嘉誠、袁世凱、劉翔、伏明霞），可以驗證流年。
- 賓主體用和流通規則提供了「**為什麼這個命富貴、那個命平庸**」的解釋框架，是其他書少有的。
- 下篇是很好的《滴天髓》白話入門。

**要小心**
- **同一個命盤，作者常用不同理論解釋**（陳方安生就有「土從旺格」「三行成象」「墓用功神」三種說法；蔣緯國有「逢沖反成」「反向作功」「反吟」三種）。結論一致，但初學者容易以為方法可以隨意套。
- **前後不一致**：三刑範圍、專旺格能不能用食傷、六害要不要理。
- 名人命例的**時辰多半是公開資料或推算**，有些不可靠（孔子、姜太公、梅艷芳等），作者沒有說明出處；有些時辰不詳。
- 「事後解釋」為主：大多是知道結果再找理由，不是事先預測。
- 健康、性生活、生男生女、「水性楊花」「娼命」等斷語屬傳統取象，**只能參考，不宜直接對人說**。
- 擇日部分和八字推算是兩件事，需要風水坐山資料，App 不容易做。

## 五、名詞解釋（本書特別用到的）

| 名詞 | 白話解釋 |
|---|---|
| 正五行 | 只用五行生剋制化論命，不用神煞、納音、生肖。 |
| 流通 | 五行一路相生沒有被卡住。本書規定只有「同柱干生支/支生干」「相鄰天干」「相鄰地支」三種路線。 |
| 順流／逆流 | 順流＝日主 → 食傷 → 財 → 官（身旺喜）；逆流＝官 → 印 → 日主（身弱喜）。 |
| 通關 | 兩個五行相剋時，找一個中間的五行讓它變成相生（水剋火 → 加木變成水生木生火）。 |
| 成象 | 命局只由一到五種相生的五行組成，份量相當。一行成象＝專旺格。 |
| 類象 | 不完美但大概看得出的形象；作者說每個命局一定有一個明顯的氣勢。 |
| 賓主 | 主＝我（日主或日柱），賓＝別人（其他柱）；八字是主、歲運是賓。 |
| 體用 | 體＝我和我能用的工具（日主、印、比劫）；用＝我想要的東西（財、官）。食傷兩可。 |
| 作功 | 體和用之間發生剋、合、化、生、洩、入墓等關係，產生效果。 |
| 功神／廢神 | 參與作功且有效率的字＝功神；不參與或沒效率的字＝廢神。 |
| 正向／反向作功 | 主位的體去作用賓位的用＝正向；主位的用和賓位的體作用＝反向。 |
| 制用、化用、生用、洩用、墓用 | 五種作功方式：剋制、印化殺、食傷生財、食傷洩秀、入墓庫。 |
| 借盤 | 用某人的命盤，把代表親人的十神當新日主，推那位親人的命。 |
| 扶山相主 | 擇日心法：日課地支生扶房子坐山（扶山），日課日干是當事人的用神（相主）。 |
| 日課 | 擇日時把選中的年月日時排成的四柱。 |
| 本限 | 本書每柱管 16 年：年柱 0–16、月柱 16–32、日柱 32–48、時柱 48 以後。 |
| 四正、四庫、四長生 | 子午卯酉、辰戌丑未、寅申巳亥；作者用它們代替桃花、華蓋、驛馬。 |
| 天羅地網 | 辰戌；三辰沖一戌、三戌沖一辰最凶。 |
| 樞紐 | 命局成敗關鍵的那個字（例如韓信命的丁火）；被制住就出事。 |
| 吉神太露／凶物深藏 | 喜用只在天干，容易被合沖奪走；忌神藏在地支，被引出來就為患。 |
| 天戰／地戰 | 天干相剋／地支相沖；天戰輕、地戰重。 |
| 生方、庫、敗地 | 寅申巳亥（怕沖）、辰戌丑未（宜沖開）、子午卯酉（看喜忌）。 |
| 夫從妻化／妻從夫化 | 天干五合時化成陰干（妻）的五行／陽干（夫）的五行，例：乙庚夫從妻化成木。 |

## 七、App 想法

依對 App 的價值排序（★＝建議優先）：

1. **★流通路徑檢查**：照本書規則（同柱干支、鄰干、鄰支）畫出命盤裡實際能流通的箭頭，標出起源（最旺的五行）和終點（停住的地方）。App 的「五行生剋流程圖」已經有生剋線，可以加一個「流通路線」模式，並標示「異柱不相生」。第 80、81 訣有現成的測試命例（富貴雙全、福祿壽全兩例、貧賤命）。
2. **★清濁評分**：用第 99 訣三法組合：(a) 寒暖燥濕分數（App 已有）；(b) 流通方向是否合身強身弱（順流/逆流）；(c) 用神是否被剋、被合（神枯）。三項各給清/濁，顯示「一清到底／澄濁求清／半清半濁／滿盤濁氣」。第 99 訣四個命例可做測試。
3. **★調候例外**：在寒暖燥濕卡片加一條提示：「寒甚而暖無根（或暖至而寒無根）時，書上主張反以無暖/無寒為美」。第 92 訣四個命例可做測試。
4. **作功檢查清單（賓主體用）**：照第 35 訣的順序列出：日干有沒有合、有沒有貼身生食傷、日支有沒有成黨或合沖刑；標出功神、廢神。這是解釋型卡片，不改分數。
5. **合化結果說明**：在「天干生剋合化」卡片加「正化／夫從妻化／妻從夫化」的對照，當合而能化時顯示可能化成的五行。
6. **陽干難從、陰干易從**：特別格局卡片（蘇民峰從格）判斷從格時，加一條提示：陰干日主通根月令也可能從勢；陽干要本氣死絕才從。
7. **四正／四庫／四長生齊全標籤**：大運流年和原局湊齊子午卯酉、辰戌丑未、寅申巳亥時加灰色提示（本書第 64 訣）。App 已有「三沖一」等標籤，可並列。
8. **天羅地網標籤**：三辰沖一戌、三戌沖一辰時提示（第 63 訣）；App 已有「三沖一」，可加辰戌特例說明。
9. **借盤試算**：在六親區塊提供「以某十神為新日主重算十神」的檢視（只顯示，不做斷語），夫妻取月干優先；可和《子平正源》README 的轉盤表想法合成一個功能。
10. **測試資料**：`命例.tsv` 有 331 筆（含名人和擇日日課），其中名人命例多有年份事件，可挑有明確歲運事件的（李嘉誠榮銜年表、袁世凱、劉翔、伏明霞、曹錕、胡漢民、黃興、楊宇霆）做大運流年標籤的回歸測試。

不建議做：擇日（需要坐山資料）、生男生女、色事、面相對照。
