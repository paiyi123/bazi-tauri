# 第七篇　政治呀政治！（p163–190）

開頭（p164）：本篇先論大中華的政治人物，再論中國和香港的國運。作者的手法是拿別的命書對同一命例的批法，與他自己的「量化五行力」算法對照，再用命主的實際經歷驗證。

- 原書的批法：身強，可用火土金，己運大旺，庚辰運還能繼續替香港服務。原書之所以取子時，是因為命主 1995 年在己運中當上財政司：財是用神，所以要身強，而前三柱申酉連剋、辰也耗木，只好靠子時把身旺起來。
- **作者反駁**
  - 很多人以為「辰土耗木」，作者認為不懂量化化理論才會這樣想，是大謬。
  - 子時的話，申子辰三合化水，加上月干癸印，印星四柱互相得透，天干又見兩個比肩，其實是**從強**格。原書因為甲木生在酉月，就不讓它入從強，這是讓月令橫掃全局，等於「變成月令論命」。
  - 「天干看現象，地支看力量」。很多算命先生都無視地支三合、三會的強大力量。
  - 調候理論能推翻生旺剋耗的較量原理嗎？作者難以苟同。

- 地支辰酉六合化金。**總分 −131，身弱**，用水木，忌火土。天干官印並見，所以金干運只算局部可用，整體偏吉；金的專氣支運也是局部可用，但整體偏忌。
- 原書取未時的理由：時上正官透出、通月令，合乎特首的徵象；2005 年庚運當選，兩年後連任，因為庚有月干癸印守護，能殺印相生。
- **作者反駁**
  - 能做大官，不一定要正官透干。
  - 如果身弱，怎能在 1995 年一入己（土）運就當上財政司？1998 年入市擊退金融大鱷，也證明土運可用。
  - 1975–1995 年連行二十年火土大運（丁丑、戊寅），身弱忌火土的話，仕途怎會步步高升？
- **大運游走原理（p166）**
  - 1990 年的寅運不能只看成生旺日主的祿運。寅運游走到年月柱時，會和年支申相沖而「變土」，成為剋耗甲木的土運。身強的命用土，寅運就不差。
- **流年不能蓋過大運（p166）**
  - 「流年蓋大運」是謬論，論命以大運為主、歲運為輔。
  - 惡運中的吉年可以防守、得點小利，但難有突破；吉運中的惡年會妨礙進程，但不至於逆轉運程。
  - 運程有累積效應：很少人一運登天，多數是連行吉運之後才飛躍。

- **合化會讓大運停止游走（p167）**
  - 2005 年入庚運。月干有癸印，庚運本來會殺印相生而成忌。
  - 但庚與時干乙合化，附在時干的位置，不再游走，癸印之氣也帶不動，殺印相生無法啟動。
  - 時干化成強大的金氣，直接剋耗甲木日元，所以庚運反而為用、大吉，把命主推上特首之位。

- **徵象（p168）**
  1. 月令酉正官格。辛氣雖然沒透干，全局卻沒有一點傷官之氣，所以仕途暢順。
  2. 天干全是自黨，性格非常主觀；幸好月支酉直剋，稍減固執，所以被叫「醒目仔」。
  3. 時柱正財遇劫財：身為特首，但財運一般，名大於利。
  4. 妻宮（日支辰）內合月令：夫妻恩愛。
  5. 以財土為喜：喜歡結交富豪、迎合地產財閥，任內樓價飛升，民怨載道。
- **結論**：作者認為命主最可能生於丑時，因為丑時兼取子時、未時兩說之長。

- **作者反駁：不能只看地支主氣**
  - 寅是土的長生，一定能生旺戊土。只看地支主氣、忽略地支本身的含義，是八字學普遍存在的問題。
  - 寅中丙火雙透，加上天干二丙印，這個命應入身強。
  - 寅藏甲丙戊，是混雜的雜氣支。量化理論認為**只有專氣才能產生一元生一元的效果**，雜氣支難以殺印相生。

**四寅匯聚的計算（p171）**

1988 年入寅運。寅不是專氣，不能殺印相生，要拆開生剋細看。寅運入局遇上原局三寅，形成四寅匯聚。

| 四寅匯聚（比照） | 每支甲木之氣增值到 1.15 個木（還要有甲干引發） |

結論：這是身強日主的大吉運，「四祿匯聚」使命主黃袍加身。1993 年入癸卯運，癸水為喜，卯木入局又引發木旺匯聚，所以權位穩如泰山。

**運程要點（p172）**
1. **1958 年亥運**：亥與寅六合化木。月令申的庚氣被二寅夾剋、死絕無力，無法阻止合化。化神甲干在時柱，所以亥運與時支寅合化，停在時支的位置，遠離二丙印星，化出的木可以直剋戊日元，為喜。
2. **1983 年壬運**：壬入局被二丙夾沖，變成平運。但游走到日時二柱時就脫離夾沖，仍有餘力，是大財運；而且壬衝擊二丙這兩個忌神，也是吉象。
3. **1998 年卯運**：游走到年月柱時，透過二丙殺印相生，為忌；游走到日時柱時直剋戊土，為用。更關鍵的是卯與三寅形成四木祿旺匯聚，增值雖不及四寅匯聚，但卯運肯定可用。
4. **2003 年甲運**：入局後殺印相生，整體為忌；但游走到時柱時有時甲相助，甲殺直剋戊土，所以可用（退下後仍有餘威）。

## 4. 毛澤東（p179–184）

- 大運：1900 癸亥、10 壬戌、20 辛酉、30 庚申、40 己未、50 戊午、60 丁巳、70 丙辰

# 第八篇　八字的前世今生（p191–207）

引言（p192）：四柱論命雖是徐子平發明的，但整個八字系統是歷代先賢的集體成果。算命的概念源自王充《論衡》，體制完成於徐子平，前後約一千年。現在很少算命先生真正懂得干支佈局背後的理念，例如地支為何藏干、藏干結構怎樣解讀、六合的玄機、十神如何設定。

## 2. 建寅：寅為一年之始（p193）

- 黃帝時期已知冬至日照最短，之後陽氣漸生（陰極陽生），所以冬至所在的子月本應是一年之始，十二地支也以子為首。
- 但氣溫比日照滯後：冬至後仍然寒冷，丑月最冷，寅月立春後才回暖。卯月可見正大的木星，屬深春；所以寅月才是春天之始。
- 歷代曆法：夏朝建寅，商朝建丑，周朝建子。春秋時有了仲春、仲夏、仲秋、仲冬四個節氣，秦漢正式定出二十四節氣（春天從立春開始），東漢起恢復建寅至今。四柱算命創於北宋初，以立春為一年之始。

## 3. 干支紀月（p194）

- 確定的干支紀日始於公元前 720 年二月己巳日，至今沒有間斷。
- 有記載的干支紀月始於唐代之後的五代，可能是李虛中創三柱算命後才流行；干支紀時則是北宋子平四柱興起後的事。
- 作者推論：東漢以前已有人以天干定月，依據河圖「一六同宮、二七為朋」，形成「五虎遁」（原本是甲己年以甲作首，乙庚年以丙作首……）。當時建子，所以甲年子月是甲子月、寅月是丙寅月。到唐代李虛中創三柱時改為建寅，口訣就從「甲己甲作首」改成「甲己丙作首」。實際上，六十甲子最後一年（癸亥年）的子月就是甲子月，往後推兩個月，正好是甲子年正月丙寅。

## 4. 從論衡至四柱（p194–195）

- 王充《論衡》：萬物都由氣構成（元氣、精氣、和氣）；萬物的差別源於稟氣不同。人一生下來，命就決定於在母體中稟受的自然之氣：氣厚則體強、命貴，氣薄則體弱、命賤。這是一種宿命論、自然命論。
- 後人據此用**胎元**（受孕那個月的干支）推算強弱。因為資訊太少，改用出生時刻論命，發展出三柱、四柱，但原理仍是「先論命身強弱，再用大運平衡」。
- **作者觀點**：「強則抑之、弱則扶之」才是理所當然的取用神方法。北宋後衍生出的調候法、病藥法、大象直觀法（二象相向、獨象全象、君臣母子論等）都屬多餘。既然明白八字理論的建立歷史，扶抑用神就是必然的選擇。

## 6. 干支佈局（p197）

## 7. 地支藏干（p197–201）

- 天干的五行屬性與生俱來（來自河圖），但地支只代表季節，判斷不了五行屬性。如果寅卯辰只當成甲或乙，推算會缺乏變化，也表達不了複雜的人文關係，所以古人用「藏干」來表示地支的五行力量和徵象。
- 作者在《量化五行力》中已說過：**藏干是當月的星象圖**。例如卯月夜觀星象可見陰態木星，所以卯藏乙；寅月可見正東的陽態木星，加上偏側的陽態火星和陽態土星，所以寅藏甲丙戊。這有實況，也有設計成分。
- 兩個天文事實：
  1. 卯月見正大木星；午月同時見正大火星和土星；酉月見正大金星；子月見正大水星。
  2. 土星位於天空中央，四季幾乎都看得到。
- 兩條設計原則：
  1. 四季分明，例如寅卯辰都必須是春木的旺地。
  2. 干支佈局要體現平衡：金木水火各得其所，土平衡其他五行，陰陽二氣也要平衡。
- 十二支分成四組，每季前兩支代表該季五行的旺盛，第三支用土來平衡。

## 8. 天干五合（p202）

- 依河圖「一六同宮、二七為朋」設定。五合全是**陽干剋陰干**，例如甲己合是陽木剋陰土，乙庚合是陽金剋陰木。作者認為十神的妻財概念很可能是根據天干五合設計的，這比反過來的說法合理。
- 合化的次序：甲己合化土（土是萬物之本，所以從土開始），然後土生金（乙庚化金），金生水（丙辛化水），水生木（丁壬化木），木生火（戊癸化火），完成「土生萬物」的概念。

## 9. 天干徵象與十神（p202–204）

- 四柱以前流行用星曜論命（星暗則人失勢，例如諸葛亮死時有流星殞落）。紫微斗數的前身《果老星宗》出現在唐朝，比四柱早一百多年。徐子平把星象含義帶入八字：天干就是星曜，以日元為「我」，各干與日元的生剋關係再加以徵象化，就是**十神**。十神很可能是徐子平的傑作。

| 十神 | 設定由來 |
|---|---|
| 正印、偏印 | 生我者為母，最容易定位；偏印剋食神，所以又叫梟印、倒食 |
| 正財、偏財 | 由五合「陽剋陰為妻」而來；古人有錢才有妻，所以妻財同義 |
| 正官、七殺 | 剋我者是「官人」（宋代妻子對丈夫的稱呼），引申為大官，財可生官。正官、偏官又對應文官、武官；七殺是南斗第六星（將星），殺破狼皆屬武將，七殺是「武將中的武將」 |
| 劫財 | 剋正財的就是劫財 |
| 比肩 | 取「我自空彈指，君誰可比肩」；與我相同，既並肩也拼比 |
| 傷官 | 剋正官，也就是剋夫、剋事業 |
| 食神 | 七殺剛暴，只有天神能制，以「食」為名，取以柔制剛；代表福氣、智慧、溫良。另引《春秋左氏傳》「小人有母，皆嘗小人之食矣」，食也含有子女孝順母親的意思 |

- 十神的制定遵從「陰陽相生、同性相剋」。後來十神又被賦予更多含義，例如食傷代表才華，印代表名氣和文筆。「天干看現象」，十神的徵象要好好推敲。

## 10. 地支徵象（p204）

天上的五行星各有徵象，地上的人類各有盤算。地支要體驗人間複雜的關係：協作、排斥、刑害。所以徐子平等先賢設計了地支的刑、沖、破、害、合。

## 11. 地支六合（p204–205）

- **天文解釋**：古人把天空分成十二宮，以十二地支命名，但宮支的排列方向與太陽運行方向相反，所以太陽所在的宮位永遠與當月錯開，兩者就構成六合：

| 月份 | 太陽所在宮 | 六合 | 合化 | 象徵（太陽系） |
|---|---|---|---|---|
| 丑月 | 子宮 | 子丑合 | 土 | 土星，離太陽最遠 |
| 寅月 | 亥宮 | 寅亥合 | 木 | 木星，次遠 |
| 卯月 | 戌宮 | 卯戌合 | 火 | 火星，第三遠 |
| 辰月 | 酉宮 | 辰酉合 | 金 | 金星，次近 |
| 巳月 | 申宮 | 巳申合 | 水 | 水星，最近 |
| 午月 | 未宮 | 午未合 | 土（化成太陽、太陰） | 太陽和月亮 |

- 有人用「亥水生寅木、卯木生火庫、辰土生酉金」來解釋合化，但巳申為何化水就解釋不了（巳中丙火沖水、戊土剋水）。作者認為：**六合合化化出的是一幅太陽系星象圖**（p205 有附圖：太陽、水星、金星、火星、木星、土星、太陰、地球）。

## 12. 合會刑沖破害（p206–207）

- 三合是一個五行的生、旺、墓結合；三會是一個五行在本季的臨官帝旺表現。兩者都是五行專氣的凝聚，自然合理。
- **三刑是三合與三會碰撞的結果**：

| 三合 | 碰撞的三會 | 產生的刑 |
|---|---|---|
| 申子辰 | 寅卯辰 | 申刑寅、子刑卯、辰刑辰 |
| 寅午戌 | 巳午未 | 寅刑巳、午刑午、戌刑未 |
| 巳酉丑 | 申酉戌 | 巳刑申、酉刑酉、丑刑戌 |
| 亥卯未 | 亥子丑 | 亥刑亥、卯刑子、未刑丑 |

- 先賢認為人生的刑害無可避免，所以每個地支都有刑害。
- **六破**：同一類地支（專氣、長生、墓庫）五行性質其實不同（例如墓庫雖然主氣都是土，各自所生旺的五行卻不一樣），「同類而不同性」最容易互相傷害，所以設計了六破。

| 類別 | 推導 | 六破 |
|---|---|---|
| 四專氣 | 子沖午、子刑卯，酉不能閒置，所以子酉破；為對稱，卯午也破 | 子酉、卯午 |
| 四長生 | 寅刑巳、寅沖申，亥不能閒置，所以寅亥破；對稱 | 寅亥、巳申 |
| 四墓庫 | 丑刑戌、丑沖未，辰不能閒置，所以丑辰破；對稱 | 丑辰、未戌 |

- **六沖**是地支與對位的碰撞（水火相剋、金木交戰）。
- **六害**用來表達沖與合的矛盾：子丑合，而丑未沖，未沖走了子所喜的丑，所以子未害。照此類推，得出**子未、丑午、寅巳、亥申、卯辰、酉戌**六害。
- 六破六害和合會有矛盾（例如寅亥既合又破、申巳既合又破，卯辰同屬春旺卻相害），所以逐漸被人忽略。作者用人際關係解釋：好朋友也有互相計較的時候，差的人也有可用之處。
- **實用規則（p207）**
  - 論命時可以忽略**六破、六害**，這些微小的破害無傷大雅，做人和論命都要看大局。
  - 千萬**不要忽視三刑**，刑害可以造成很大的影響。
  - 三刑之中，**寅巳申、丑未戌**兩組最嚴重，但只見其中兩個字就不必理會；其次是**子卯相刑**；**自刑**只作參考。

# 第九篇　千古誤讀（p208–223，未完）

引言（p209）：八字算命千多年來缺乏明確法則，各家隨緣立論，產生不少誤讀。作者認為最大的謬誤有五：
1. 十神力量強弱不分
2. 以地支主氣論命
3. 計較日元以外的干支生剋
4. 從化格與日元合化
5. 調候法（這次的範圍還沒讀到）

## 1. 十神力量（p209）

- 很多人以為各路十神的正負力量差不多，作者說這是「謬誤之最」。
- 官殺的剋耗比食傷兇猛，這是眾所周知的；但很少人知道，**印比的生旺力量要比官殺的剋耗略強，也遠大於食財**。很多人看到局中逆黨較多就判身弱，忽視了印比巨大的正能量。
- **反證**：如果食財官的負能量與印比的正能量相當，世上約 60% 的人會是身弱或從弱，只有約 40% 是身強或從強，這違反陰陽平衡的大原則。
- 「旺相休囚死」早已暗示了十神的正負力量，只是缺少數字說明，千年來沒有人參透。

## 2. 地支主氣論命（p210）

- 只憑地支主氣論生剋的人，一是不明白地支以四季劃分，二是不明白長生的含義。
- 規則與反駁：
  - **辰不耗木**：辰如果耗木，怎能成為春木的一員，又與寅卯三會化木？
  - **未可生火**：未雖會洩火，但絕對可以生火。
  - **丑可生水**：丑中金水雙旺，否則丑怎能與亥子三會化水？
  - 四個土支都是當季的旺氣。（參考支日五行力對照表，表在前書《量化五行力》。）
  - 申是水的長生、亥是木的長生，這兩點多數人都接受；但**巳可生金、寅可生土**，很少人明白。坊間仍說巳火剋金、寅木剋土。如果巳是剋金之力，又怎能和酉丑三合化金？寅除了生火，其實也能生土。

## 3. 干支生剋較量（p210–219）

核心主張：**日元是命局的核心，干支的力量都傾向日元。推算強弱或專從時，只需考慮各干支與日元的關係。** 干支之間的生剋互動只屬局內的化學變化，不會直接或間接影響日元的力量。命局在誕生那一刻是靜態的；要等大運、流年入局，帶動干支之氣在局中流動，干支互動才會出現。即使如此，也不至於蓋頭截腳，更不會影響命身強弱的判斷。

## 4. 從化格與日元合化（p220–223，第 224 頁以後未讀）

- 從化格是指日元與鄰干合化，又因局中化神強橫，日元跟著化成另一個五行。
- **作者立場**：根據量化五行力，**日元的份量為零，難以與鄰干合化，所以從化格其實不存在。**
- 示意盤（p220）：時干壬、日干丁、日支卯，其餘以 X 表示，用來說明丁壬合化木。
  - 很多人把壬水當成木，那丁火日元算不算木？於是出現「真化、假化」：真化是丁化為木，假化是丁的性質不變。
  - 真假怎麼判定？有人說看化神強弱：木氣當道、沒有剋木的金干，丁就可化。也有人說要看「宜化、不宜化」：解釋得通就是宜，解釋不通就是不宜，這是用經歷凌駕八字原理。
  - 最荒謬的是：判定丁不化之後，仍把壬當成木。所謂「壬化而丁不化，所以叫假化」，違反基本邏輯。而且五合合化必有餘氣，難道丁火日元會變成八成木、二成火？

1. **日元是命局的核心。** 推算強弱只看各干支與日元的關係；干支之間的生剋（蓋頭、截腳、互動較量）只是局內的化學變化，不會改變日元的力量。命局誕生時是靜態的，要大運、流年入局才會引發干支流動。
2. **日元的份量為零，不能合化。** 從化格不存在；所謂真化、假化、宜化、不宜化，都是用經歷倒推的說法，前後矛盾。
3. **十神力量不均等。** 印比的生旺力略強於官殺的剋耗，更遠大於食財，否則世上 60% 的人都會是身弱，違反陰陽平衡。見到兩三個逆黨，仍然可能是從強（蔣介石）。
4. **地支看力量，不能只看主氣。** 辰可生木，丑可生水，未可生火，寅可生土，巳可生金。三合、三會、專氣凝聚會產生巨大增值（四土、四寅匯聚每支增值到 1.15 個；巳午戌的火氣額外加 0.1 個）。只有專氣能殺印相生，雜氣支不行。
5. **大運游走原理。** 大運會游走四柱，在不同柱位的作用不同（例如寅運游到年月柱時，與申相沖變土）；合化會讓大運停駐在合化的位置。論命以大運為主、流年為輔，運程有累積效應。
6. **反對調候法，以及病藥、大象等取用法。** 從《論衡》到四柱一脈相承的是「強則抑之、弱則扶之」的扶抑用神。調候往往是批法自相矛盾時才拿出來補救的（毛澤東辰時從殺之說）。只有總分接近零時，才借用通關、病藥來佐證。
7. **反對以經歷論命、以命就局。** 原理必須一致並且普遍適用；遇上不準的命例就承認不準，不要編歪理。
8. **干支佈局有天文和設計上的根據。** 河圖是太陽系星象圖；藏干是當月的星象圖，再加上陰陽平衡的設計；地支六合合化出一幅太陽系圖；三刑是三合與三會的碰撞。
9. **刑沖破害的實用分量。** 六破、六害可以忽略；三刑不可忽視，其中寅巳申、丑未戌三字齊見最嚴重（只見兩字不必理會），其次是子卯，自刑只作參考。
10. **政治人物和國運的徵象。** 正官格的人多是文官（曾蔭權、江澤民）；羊刃駕殺、殺印相生多屬武略梟雄（毛澤東）；傷官格難以管治（香港）；官強財弱、缺乏制化，容易貪腐（中國）；伏吟大運常應在大動盪（文革、佔中）。
