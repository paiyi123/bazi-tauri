# 《算命方程式@八字真理》上下冊研究

日期：2026-10-10
作者：沈淵滴（和《量化五行力》同一位作者，本書是續篇）
書頁：兩冊頁碼連續。上冊 PDF 頁 = 書頁（p1-162）；下冊 書頁 = PDF 頁 + 158（p163-288）。
書上命盤都是由左到右印「時 日 月 年」，下面一律改寫成「年 月 日 時」。

## 一、這兩本書是什麼

不是新的計分系統，而是用量化五行力去批大量名人命例，外加幾章修正和補充理論：

- 第二篇 算命方程式（p16-53）：批命四步驟（定格局、評清濁、判運程、看徵象），從強總分超過 +260 可用食傷（p18）。
- 第三篇 量化理論再深入（p54-76）：四土匯聚、游走的大運、大運遇沖遇合、殺印相生、大運對原局的影響（R 值）。
- 第四至七篇：名人命例，幾乎每例都有七格分數和總分。
- 第九篇 千古誤讀、第十篇 爭議命題（p208-244）：干支之間不互相生剋（只看對日元）、日元不合化、朱氏合化論加作者四條補充、半合成立、午未化土、土從火性。
- 第十一篇 算命江湖、第十三篇 不確定性原理：更多命例，含換時辰比較。

書上共 100 個有總分的命例（清單：[八字真理-命例比對.tsv](八字真理-命例比對.tsv)），全部丟進程式：

## 三、這次順便修好的程式錯誤（已寫回 quant_model.rs）

1. **亥子丑、申酉戌三會從來沒被認出來**（原始程式就有的錯）。`resolve_three_meeting` 用排序後的字串比對，但這兩組的排序結果寫錯，所以永遠對不上。修好後下冊 p211（丙子 己亥 乙丑 壬午）從 +92.6 變 +380.1，書 +380。
2. **三會不化應壓過半合**（下冊 p222 鄧太：申酉戌三會不化，午戌不化火）。修好後 −189 變 −129.9，書 −130。
3. **祿支只要有藏干受沖化零，就不再整支 +100**（上冊 p30 沖剋男命、p71 阮玲玉：巳被亥沖，戊日／己日的巳只剩戊 +25）。上次只處理到「祿神本身五行被沖掉」的情況。
4. **兩個未夾巳午成三會時，巳午被提升了兩次**（上次修正自己造成的）。上冊 p52 柯震東說「年未亦然」，只提升一次。

## 四、書上有、程式沒有的規則（2026-10-10 第二批已處理 B–G，見第六節）

依影響大小排序。

**A. 三會化的倍數：2.3 還是 2.1？**
- 本書 p55 和下冊 p282 明寫：三會化時專氣支 2.3 個、墓庫支 1.15 個（四土匯聚也用 ×2.3）。
- 量化五行力下冊 p132 是 2.1 / 2.1 / 1.05，楊啟彥一例也是用 2.1 算的。
- 下冊 p282 謝霆鋒酉時（庚申 甲申 甲戌 癸酉）：書 −451，程式用 2.1 是 −408；換成 2.3 幾乎每一格都對上（申 −207、年申 −97、戌 −54.6）。
- 兩本書互相矛盾，要選一個。
- 2026-10-10 補測（書上所有三會成化的命例，書 / 2.1 / 2.3）：下冊 p211 +380 / +380.1 / +421.3；上冊 p82 李雲迪 +588 / +588.0 / +632.3；量化五行力楊啟彥 +118 / +115.5 / +140.9；下冊 p282 謝霆鋒酉時 −451 / −407.8 / −451.3；上冊 p139 蘇東坡 +712 / +790.3 / +862.5（另有別的差異）。
- 結論：作者自己算命例時大多用 2.1；只有謝霆鋒酉時用 2.3，而那一例有兩個申（年申也化金），四支同氣凝聚，比較像作者說的「專氣凝聚增值」。所以維持 2.1，2.3 只當四支凝聚的特例。

**B. 四土匯聚（上冊 p55-56）**
- 辰戌丑未四支齊全、天干見土：合化巨土，各支 1.15 個土，無餘氣。
- 天干不見土：合而不化，各支土氣由 0.5 提升到 0.7。
- 辰戌辰丑這類也算匯聚，力量較小，書上例子假設各支提升到 1 個土（命例 −130 → −255，判從弱）。
- 本書稱四寅匯聚等也比照（下冊 p171）。

**C. 半合化可以解沖**
- 上冊 p68 梁瑞珠（辛卯 丁酉 丁巳 乙巳）：巳酉半合化金，卯酉不沖、卯完整保留。書 −36，程式 +222.6（程式讓卯酉沖先成立，半合就不化）。
- 同類：上冊 p149「酉丑半合成化，丑未並沒相沖」、下冊 p185「酉丑合化，卯酉並未相沖」、上冊 p136「未丑沖勝子丑合，但合可緩沖……以無沖無合推算」。

**D. 合化條件，作者自己的補充（下冊 p235）**
- 月令主氣受損（被鄰支沖或合而不化）就擋不住合化。下冊 p238（辛卯 戊戌 壬子 甲辰）：卯戌六合不化傷了月令戌，子辰可半合化水。書 +32，程式 −43（剛好就是書上說「不化」時的分數）。
- 鄰近的強天干剋化神也可以擋住合化。下冊 p222 阿宏（丙辰 丁酉 乙丑 庚辰）：丙丁剋金，辰酉、酉丑都不化。書 −201，程式 −261。

**E. 一支被兩邊夾合**
- 上冊 p52 柯震東：午被兩未夾住，只和靠近化神的一邊化土，年未不變。程式兩邊都化（+312，書 +266）。
- 下冊 p257 例二（癸卯 甲寅 己亥 丙寅）：二寅夾合亥，互相牽制，全部合而不化。程式全化成木（−357，書 −109）。
- 這和量化五行力第七篇假從女命的「未午未夾合 0.04」是同一類問題，都還沒做。

**F. 大運**
- 大運入局的影響要加上它造成的原局變化（上冊 p70）：己運合甲化土，運本身 −45，原局甲從 +55 變 −22（−77），整體衝擊 −122，R 值從 0.41 變 0.77。程式目前只用運本身的分數算 R 值。
- 游走的大運（上冊 p58-59）：大運從年柱游到時柱，與局中某支相沖時，按游到的位置分別是化零、×0.75、×8/9。程式目前照量化五行力 p202 一律當緊貼。程式原本的「隔二位 ×0.89」很可能就是出自這裡（8/9 ≈ 0.89，這是我的推測），只是原本被套到原局上。
- 大運與局中天干合而不化，會被合住在那個位置，不再游走（上冊 p60）；半合不化仍會游走。
- 殺印相生（上冊 p60-65）：身弱時官殺運可不可用，看印星在哪一柱、是不是專氣，分「完全可用、局部可用」。程式沒有。

**G. 巳亥沖的細節**
- 上冊 p30、p71 和下冊 p250 都有巳亥沖，亥不是整個化零，而是留一小部分；下冊 p250 說「相鄰相沖為 2 個專氣沖力，隔一位為 0.5 個」，二巳沖一亥時按 80/20 分攤。
- 和量化五行力第七篇 0.64 / 0.308 的寅亥緩沖是同一個尚未完成的部分。

**H. 小地方**
- 天干隔一位相沖：本書大部分命例（S先生、徐樂吾）用簡化法忽略，但阮玲玉一例用了 ×0.875。
- 祿支遇三會不化的提升：本書柯震東用「整支 ×1.45」，量化五行力特殊男命用「+100 再加 0.95 個火」，兩本算法不同。程式目前跟量化五行力。
- 總分剛好 0 時，陽干日主偏強（下冊 p218，「陽干從氣不從勢」）。
- 日元不合化，從化格不存在（下冊 p220-226）。程式本來就沒讓日元合化。

## 五、和課堂、App 其他部分有關的觀點

- 干支之間不互相生剋，強弱只看各干支對日元（下冊 p213-219），否定蓋頭截腳。和程式目前做法一致。
- 調候準確度不到五成，不能判從強從弱，只能參考（下冊 p226-228）。
- 三刑只看寅巳申、丑未戌三支齊全；六破、六害可不理（下冊 p207）。App 目前會畫出破、害。
- 大運為主、流年為輔；大運前五年看干、後五年看支（下冊 p239-242），和 App 一致。
