## 一、這本書在講什麼

這本書其實是**兩套東西放在一起**：

1. **作者自己的東西**（書第 1–16 頁）：
   - **寒熱命論**：作者說不必再算身強身弱、不必找用神，甚至不必分從格化格，只要看出生季節：寒命（立秋後到驚蟄前）喜火，熱命（立夏後到立秋前）喜水，平命（卯辰月）水火都可以。
   - **八字秘法**：以前只傳給入室弟子的經驗口訣，例如「沖刃 → 刀傷、官非」「丁坐亥 → 眼疾」。作者說不是百分百準，但應驗時很驚人。
2. **傳統子平八字講義**（第 1–17 章）：
   - 第 1–7 章是基礎。
   - 第 8–11 章大體依照《子平真詮》（格局、用神、成敗救應、論行運）。
   - 第 12 章依照《滴天髓》和《子平真詮》講格局高低，附很多名人八字（李鴻章、蔣介石、蘇東坡、康熙、乾隆、袁世凱……）。
   - 第 14 章特別格局有作者自己的判斷：認可從格、化氣格、兩神成象、魁罡、金神，**否定**飛天祿馬、井欄叉、遙巳、刑合這類古格。
   - 第 15–17 章是神煞、六親、疾病的查表。

兩套東西的關係：作者在寒熱命論的示範例裡說，傳統方法「亦有其準繩」，有時和寒熱法結論一樣，有時不一樣（例二大運的判斷就不同）。後面第 1–17 章完全用傳統方法，沒有再提寒熱命論。

## 二、作者的核心觀念（附例子）

### 1. 格局是體，用神是用

格局一律從月令來，但格局的名字不是用神。例：第 8 章「傷官格」戊戌 辛酉 戊戌 戊午，用神剛好也是傷官，原因是日主太旺要洩，不是因為格局叫傷官。

### 2. 取用神五法，扶抑是基本

扶抑日元、扶抑用神、通關、病藥、調候。需要調候的時候「只以調候為重，其餘概置緩論」。例：乙木生丑月「寒木向陽」，殺印都先不管，專取巳中丙火。

這一點和許老師課堂說的「扶抑是基本，病藥、調候、通關不能和它衝突」方向一致，但本書把調候放得更優先。

### 3. 反生剋：生剋要看季節

夏天燥土不能生金、秋冬寒金不能生水、冬天凍水不能生木、春夏木渴會自焚。所以「夏令不可無水，冬令不可無火」。這也是作者後來發展寒熱命論的源頭。

### 4. 成中有敗、敗中有成，全看救應

格局「帶忌」就是病，「救應」就是藥。救應的方式有：印制傷、合去忌神、會合解沖、財制梟、比劫制財……第 9 章有 15 個半張八字的示範。

### 5. 看運和看命是同一套方法

運的每一個字都要拿回原局配合看。要注意「似喜實忌」（印運卻合掉官星）、「似忌實喜」（傷官運但原局有印回剋）、「行干不行支」、「一沖得兩沖」。例：康有為午運，原局兩子一午本不沖，運再來一午就引起兩沖。

### 6. 地支要「動」才作禍福

天干是動的，地支是靜的；地支因沖、因會才動。原局藏著的喜忌，要等大運透出（透清）或會局才應驗。例：趙鐵橋丑運三合金局大貴，庚運合乙傷甲被刺。

### 7. 格局高低：用神真假最重要

清濁、有力有情、合神聯珠拱夾都是加分，但「用神不真，其餘團結皆無所用」。作者對「虛神」保留：只承認地支拱夾。

### 8. 特別格局要嚴格，古怪格名多半沒用

- 從格分真假，**陰干比陽干容易從**；月令是印就不能從。
- 化氣格有六個條件（日主極弱、緊貼五合、月令是化神、化神旺、原神透、不爭妒）。
- 作者明說飛天祿馬、倒沖、井欄叉、遙巳、刑合、專食合祿、六辛朝陽、六甲趨乾、十靈日、陰差陽錯日等是古人為了「找財官」而造出的錯誤格局，用一般格局看就好。

### 9. 神煞只當輔助

作者實際常用的神煞只有九個：紅鸞、天喜、沐浴、咸池、紅艷、驛馬、天乙貴人、天德、月德。其他都「只供參考」。他還算給讀者看：十靈日佔六十甲子的六分之一，總不可能六個人就有一個靈童。

### 10. 六親不分正偏

男命正偏財都可以是妻和父；女命官殺都以夫論。重點是那個十神、那個宮位對命主是喜還是忌。

## 三、名詞解釋

| 名詞 | 意思 |
|---|---|
| 體、用 | 體＝格局（從月令來）；用＝用神（格局裡真正被用的那個字） |
| 相神（喜神） | 幫用神成格的字。例：官逢財生，官是用、財是相 |
| 扶抑 | 弱的幫它（扶），強的壓它（抑） |
| 通關 | 兩神相戰時，用被一方生、又去生另一方的字把它們連起來 |
| 病、藥 | 傷用神的字是病；能去掉病的字是藥 |
| 調候 | 調整冷熱：冬天要火、夏天要水 |
| 反生剋 | 季節不對時，相生變成不生（例如燥土不生金） |
| 透清 | 地支藏的字在天干出現（原局或大運），力量才顯出來 |
| 犯旺 | 去剋、去壓一個很旺的字，反而激怒它招禍 |
| 真神、假神 | 真神：月令最需要、又剛好當令的用神；假神：不是最需要但得勢的 |
| 虛神 | 四柱沒有，但被暗沖、暗合、拱夾出來的字 |
| 聯珠、夾、拱 | 地支連續相鄰（聯珠）；兩支中間缺一字（夾）；三合缺中間那一字（拱） |
| 體用同宮 | 月令藏干同時透出天干，剛好是日主和喜用 |
| 真從、假從 | 從格條件全符合是真從；有一點根或雜氣是假從 |
| 真化、假化 | 化氣條件全符合是真化；缺條件要等運補的是假化 |
| 化神還原 | 化氣格被剋，合化的字又變回原來的五行，是凶兆 |
| 兩神成象 | 八字只有兩種五行，各佔兩干兩支 |
| 魁罡 | 日柱是戊戌、壬辰、庚戌、庚辰 |
| 金神 | 日柱（或時柱）是乙丑、己巳、癸酉，月支有火 |
| 填實 | 大運流年正好來了那個被拱出、沖出的字 |

## 七、和其他資料的比較

- **許老師課堂**：三步法（取格 → 強弱 → 喜忌）和本書第 8 章「先定格局再取用神」方向一致；許老師說神煞不可靠，本書作者也只留九個常用的。課堂的「天干五合五種變化」（合而不合、不化、合來合去、爭合妒合、合而能化）可以和本書第 14 章化氣格六條件、第 3 篇「甲己隔位不合」對照。
- **陸致極教程**：陸致極的「弱臟／強臟」和本書第 17 章的五行病大致相同；陸致極的寒暖燥濕和本書的寒熱命論都重視季節。
- **量化五行力**：本書沒有計分，是純質化的子平法。
